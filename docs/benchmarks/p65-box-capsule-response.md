# 自由长方体与有限胶囊连杆的受力

普通 Panda 入口的 `structural_response=True`（命令行 `--resolve-structure`）让长方体与非指垫的有限胶囊、球形连杆交换结构力。历史箱输入默认使用净距监测。指垫和桌面沿用原有材料律。非圆形机器人结构与箱、机器人与桌面仍记录首次未求力的净距边界。[公共入口](../../src/phymeo/experiments/panda_cube.py) · [箱–胶囊几何](../../src/phymeo/solvers/box_link_contact.py)

在箱体局部坐标中，轴段参数 u 限于 [0,1]。算法在轴段穿越各坐标边界处划分区间，逐段最小化到实心轴对齐盒的平方距离。对传入局部 FP64 坐标的候选最小值和材料参数作精确有理数比较。唯一最近点占全部权重。若最近点覆盖真实材料区间，区间两端各占 1/2，各自按实际点速求法向阻尼和切向力。调换两个参与者会交换表面见证、反转法向。输出保存真实轴参数、世界轴点和双侧世界表面点。当轴段已进入箱体实心区域，当前外侧距离模型会拒绝该构型。[独立面、棱、端帽、旋转与调换例](../../tests/test_box_link_contact.py)

力在两侧表面见证的中点施加，权重同时作用于力和力矩。两端从各自质心计算力臂。一个面上倾转的留出中，接触区端点实际法向力为 2 N 和 0 N，总法向力 2 N，同时产生 −0.5 N·m 的恢复力矩；仅在中点施力会少掉这整个力矩。[差异点速和端帽收据](../../artifacts/p65-night-box-capsule-loads-20261105-01/11-detail-proof/final.json) · [共用球反力的相邻回归](../../artifacts/p65-night-box-capsule-loads-20261105-01/08-sphere-neighbor/final.json)

## 偏心活动箱的实际受力

1 kg 均匀长方体全尺寸为 (0.25, 0.125, 0.5) m。2 kg 均匀胶囊的轴段长 1 m、半径 1/32 m，装在 1 kg 滑动载架的自由转铰上。箱、胶囊全域质心惯量根据均匀实体计算。首步穿入 1/1024 m，箱初速为 (0.02, 0.125, 0) m/s。两个引擎各用自己的实际状态，从静止载架、静止转铰和自由箱独立推进 96 个 1/1024 s 物理步。Newton 1.7 使用原生 BOX、CAPSULE 和 Featherstone CPU。两端接触使用同一组材料点与力学规则，原生流形没有再次叠加。[两套独立步进及解析核对](../../tests/reference_newton/robot/box_rail_window.py)

## 普通 Panda 原箱正控

120 g、46×58×40 mm 的原强夹输入，除启用结构响应材料外各字段与存档完全相同。Phymeo 和 Newton 各走完 3,600 步，均能搬运与放置。原路线避开了非指垫连杆，每步结构记录都为空。逐时刻对各自的原始存档比对，九轴位置速度、箱质心与四元数、线角速度、左右指力及桌面力全部相同。真正有结构受力的运动由上面的偏心机构验证。[两组逐时刻比较](../../artifacts/p65-night-box-capsule-loads-20261105-01/trace-comparison.json) · [Panda HOST 收据](../../artifacts/p65-night-box-capsule-loads-20261105-01/04-box-phy/final.json) · [Panda Newton 收据](../../artifacts/p65-night-box-capsule-loads-20261105-01/07-panda-newton/final.json)
