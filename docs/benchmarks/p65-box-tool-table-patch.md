# 箱形机器人足部与有限桌面的接触面

`FixedTableContacts` 现在接受实际移动的长方体、球和有限胶囊。箱对箱沿用已有凸体 SAT、支撑特征和材料多边形裁剪。唯一分离方向的面接触保留两侧原始顶点的材料权重，在线接触时取两个端点，点接触时只取一个点。多个并列分离方向对应不同物理法向时显式拒绝。普通 Panda 的移动箱形连杆和指垫可与桌面接触。指垫–自由载荷仍是另一对参与者。[固定台面入口](../../src/phymeo/solvers/fixed_table_contact.py) · [箱面求积](../../src/phymeo/solvers/table_box_patch.py) · [原有限胶囊能力](p65-robot-finite-table.md)

凸多边形分成若干以内部点为共同顶点的三角形，每片用三个对称的二阶面积采样点。每行记录 `patch_area_m2`、实际 `area_weight_m2` 和归一化 `weight`。原材料仍按每对刚度 N/m 和阻尼 N·s/m 解释，归一化权重之和为 1。这样既保留了均匀压力对应的实际面积质心，也保留线性点速场产生的力矩。使用 N/m³ 面压刚度属于另一个材料模型。

独立菱形试片被一条台边切去三角形，裁剪后面积为 7r²/4，质心 X 为 −2r/21，而五个顶点的简单平均值为零。中心矩形另一控制中，绕竖轴以 0.125 rad/s 自转只改变切向力矩，切向合力为零，实际纯偶矩 −0.02604167 N·m。倾转阻尼、棱边、顶点、分离及球与箱同时支撑均有独立断言。曾在整体施加一般刚体旋转后看到原平面退化为点。现以桌面局部帧作比较，仅在点积的逐分量舍入界内恢复本应抵消的分量。该同面变换通过，实际 2⁻²⁵ rad 的小倾斜仍给出两点边接触。[独立证书](../../tests/test_table_box_patch.py) · [原始协变失配](../../artifacts/p65-night-table-patch-20261105-01/14-oblique-covariance/final.json) · [修正后六项](../../artifacts/p65-night-table-patch-20261105-01/16-cov-proof/final.json)
