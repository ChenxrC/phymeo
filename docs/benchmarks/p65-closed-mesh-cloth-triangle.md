# 闭刚体网格与整张柔性三角面

一张斜三角形的三个节点都在立方体外，三条布边也绕过了立方体，布面仍有 **1/8** 位于实体内部。公共 `ph.detect` 返回 `RD / overlap`，在八张实际网格三角面上给出八段截线，各端点均有刚、柔双方的材料权重。相反，三个节点分别在凹 U 的实心臂内时，连接它们的布面也只有 **1/3** 在实体内，其余 **2/3** 横跨空槽。[冻结几何](../../tests/reference_newton/rd/mesh_triangle_cases.json) · [普通入口验收](../../tests/collision/test_mesh_triangle.py)

`row.mesh_triangle.end` 给出 `relation`、非负 `boundary_gap_m` 和三个互不重叠的面积分数 `inside_fraction`、`boundary_fraction` 与 `outside_fraction`。`boundary` 按原刚体网格面 ID 保存实际交点、线段或共面多边形。有边界净距时，`closest` 保存所有并列面及各自最近点集。严格包含有正的边界净距，对应普通见证的 gap 取其负值。穿过实体时，边界见证的 gap 为零，正的内部面积指出穿越。零厚三角面从两侧均可接触网格。非零表面偏移、非零角速度的转弧与路径退化有显式状态。[静态截面与连续接口](../../src/phymeo/geometry/_mesh_triangle.py)

| 物理构型 | 内部 / 在表面 / 外部面积分数 | 边界与材料 |
| --- | --- | --- |
| 大平面或斜面横截立方体 | 1/8 · 0 · 7/8 | 所有八段及其面、节点 ID 均与独立线面求交一致 |
| 完全包含的小布面 | 1 · 0 · 0 | 净距 0.25 m。两张顶面三角形给面内最近区域，y 正壁另有一个距离同为 0.25 m 的点 |
| 凹 U 空槽 / 同时穿两臂 | 0 · 0 · 1 / 1/3 · 0 · 2/3 | 前者净距 0.5 m，后者在相互分离的两臂中都有材料 |
| 1/32 m 厚的壁 / 从上方掠过 | 1/96 · 0 · 95/96 / 0 · 0 · 1 | 后者最小边界净距 1/128 m |
| 布面只与箱顶部分共面 | 0 · 179/324 · 145/324 | 两个实际面片及其相邻边上的线段 |
| 一个布角外部接触 / 一个布角内部接触 | 0 · 0 · 1 / 1 · 0 · 0 | 同是零边界净距，前者 `touching`，后者 `contained_touching` |

产品把各真实三角面的点、线和共面多边形放入布材料坐标图，沿边端点及交叉处划分条带。每个开区域的内外关系恒定，单个条带的面积由其中点处的线性宽度精确积分。该计算有最多 4,096 个区域的显式上限。独立验收则用输入给定的长方体或凹 U 的三个实心长方体，直接将完整布三角形与各个盒子的六个半空间裁剪。[独立面积判据](../../tests/collision/mesh_triangle_oracles.py)

### 相对平移与三节点独立变形

刚体可作线性平移，三个布节点可各自沿一条不同的线段运动。粗包围只缩减候选，首触由有限顶点–面、棱–棱条件隔根。大布面平移穿箱的时刻是 1/4。独立变形的试片最先在箱顶角 (−1,−1,1) m 接触，布的材料权重为 (1/2,1/4,1/4)，归一化区间 [0.421052631578277, 0.421052631579187] 包含 8/19。凹槽样本的首触包含 3/5，孤立擦角为 3/8，初始包含为 0。末态见证和首触见证各自在自己的公开时刻核对。反向注册、改换坐标系与两体共同漂移均有留出。[扫掠判据及双方材料](../../tests/collision/test_mesh_triangle_sweep.py)

### Newton 1.7 原生网格 SDF 对照

在相同零粒子半径、零 soft gap 和零形状 margin 下，CPU 与真实 RTX 4060 CUDA 的七种无 SDF 构型都能执行粒子查询，并在构造整面管线时明确要求 signed-distance field。为完整面在 CUDA 重新烘焙原生网格，用临时空缓存、最高分辨率 64、padding 0.125 m。纹理返回的箱、U、薄壁子网格数分别为 448、162、128，均从实际 CUDA 数据读回。下面的数量是 Newton 返回的离散记录。[粒子、整面与真实纹理读回](../../tests/reference_newton/rd/mesh_triangle_sdf.py)
