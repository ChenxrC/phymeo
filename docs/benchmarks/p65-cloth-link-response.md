# 布面与结构连杆的受力接缝

## 实际差异

M2 的 RD02 已能定位胶囊轴身、端帽与有限布面的最近点，并在适用运动上返回首触。双臂程序向机器人内部和桌面检测注册了六个结构胶囊；布料受力清单此前只有有限指垫和桌面。一个几何命中没有进入联合受力步骤。[RD02 几何范围](p65-collision-m2-capsule-face.md) · [转动轴与运动布面](p65-collision-m3-curved-faces.md)

对材料跟踪的两条真实轨迹，逐显示帧检查一个模型中的 276 个布面自配对和 144 个布面–连杆配对。竖直 142 帧中有 70 帧、153 次面–杆重叠，最深是 B 前臂 6 mm。倾斜 205 帧中有 39 帧、51 次重叠，最深 4 mm。两种初态的 A 腕都已经与布中面重叠。两条轨迹在这些帧均只有合法材料邻接，没有额外中面自交或未判定的配对。这里检查的是保存的帧，厚壳及帧间路径仍需各自的验证。原始逐对观测在 `artifacts/p65-collision-m4-loads-local-20261102-01/with-material-feedback-v1/middle-links-{vertical,tilted}.json`。

Newton 的碰撞模型将宽相/窄相检测、材料地址和软接触缓冲交给动力学消费者。其源码另有可选的边／面接触生成，以覆盖只检查粒子时遗漏的接触。本项目的现成 RD02 完整轴段见证可作为独立几何依据。[Newton 碰撞文档](https://newton-physics.github.io/newton/latest/concepts/collisions.html) · [Newton 碰撞管线源码](https://github.com/newton-physics/newton/blob/main/newton/_src/sim/collide.py)

## 实施顺序与成功条件

1. **胶囊–布面通用受力。** 用完整轴段最近点区间的真实材料权重分配一个配对的弹性及摩擦载荷。独立检验轴身线支撑、端帽点支撑、异体对调、净力、力矩、功率和分离；在 HOST、tyx interpret 与 CUDA 验证。不从端点自行推断未知的旋转轨迹。
2. **真实铰接连杆。** 把同一点的反作用映射到关节广义力和实际布节点，进入同一受力步、历史及失败回滚。以独立机器人模型验证改变连杆姿态、材料网格和载荷方向，保留身部扫过面内但轴端都在外的控制。
3. **夹爪几何。** 用实际腕、夹爪开口与指垫的安装尺寸检查初始占据。保留原装配的反例。新装配须对所有结构胶囊和所有布面跑初态检查，并在独立运动中主动触发布–连杆反力；不得仅以清空结构形状或屏蔽布–腕配对取得净空。
4. **再到系统案例。** 保留 A 首次独立抬升、真实双侧承载、原转运高度、B 的 3.5 cm 搬运、最后 0.10 s 稳定放台以及原位姿和穿透门槛。与递布单独记录 RR、RD、DD，只有这些模块与双初态都过关才进入完整系统验收。

## 胶囊与材料三角面的公共受力

`CollisionLoadSystem` 现在使用 RD02 已经求出的完整最近轴段。线支撑用两个极端的轴端参数和面材料地址分享一个配对的弹力，端帽的唯一极端只取一次。非零摩擦的反作用在同一布材料世界点施加。一个总法向 2 N、切向 1 N 的轴身算例给出净内力和净内力矩零、摩擦功率 −0.5 W。端帽单点的刚体力矩为 0.25 N·m，分离后载荷归零。中心线直接落在布面上的无方向输入保持拒绝。

独立 HOST 回归 5 项通过。相同轴身正控在 tyx interpret 和实际 CUDA 上各运行了一次几何宽相、接触力内核、材料求解器和刚体求解器。一个 1/64 s 子步后，刚体法向速度为 +0.0625 m/s，三个布点的法向速度均为 −1/96 m/s。该受力步验证的是平移胶囊；曲线碰撞查询和铰接连杆受力分别验收。[公共 HOST 回归](../../tests/collision/test_capsule_cloth_loads.py) · [设备回归](../../tests/collision/test_tyx_capsule_cloth_loads.py)
