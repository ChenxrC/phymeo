# RD05 · 变形布面进入凸刚体

`phymeo.detect` 支持锐边、满维、静止或平移的凸刚体与非退化零厚布三角形配对。凸体可直接使用无序顶点云；布的三个顶点可以有各自的速度。`pair.hull_surface` 保存初态、末态、首次事件的取样和可独立证明的精确首触时间。非零凸体转角或正厚布面有明确的未支持分类。[实现](../../src/phymeo/geometry/_hull_surface.py) · [结果接口](../../src/phymeo/geometry/collision_witness.py)

每个姿态用凸体面裁剪布面，返回分离、边界相触、切入或完全处在实体内部。点、线段及有面积的截面都带有凸体和布两侧的材料权重。报告分别列出相交的凸体边界面、以及在该时刻实际能分开两物体的 SAT 支撑方向。布覆盖整个箱顶时，顶部和四个侧面都与布相交，唯一支撑法向是 +z。截面深入实体的部分通过凸体内部的材料坐标表示。

连续检测沿原始仿射布顶点轨迹检查真实边界的点–面、边–边事件。若一个初始严格分离的支撑面能够证明此前整段无交，首次端点可额外给出精确有理时间。一般变形产生的代数根保留在首次区间中，`entry` 对应明确的取样时刻。布一开始已被包含的运动返回零时刻占据。中途退化的布面返回 `unresolved`。

| 构型 | 实测 |
| --- | --- |
| 原下弯布尖和同一运动刚体变换 | 首触区间包住 1/2。接触材料点始终是原顶点 |
| 布尖在箱顶上方停止或从侧面经过 | 全程分离 |
| 更换布尖位置和顶点存储顺序 | 首触区间包住 2/3，材料点仍对应原布尖 |
| 整面覆盖、整边先触及 | 整面在 1/2 首触，区域 1 m²；横穿箱体的边在 1/4 首触，截面是线段 |
| 变形面先碰凸体顶点 | 区间 [0.561552812808259, 0.561552812809168] 包含独立根 (√17−3)/2 |

HOST 集成回归 258 项通过，tyx interpret 与实际 CUDA 各 32 项通过。同一批七个场景的公布结果在三端一致。每个 tyx 后端完成 5 次三角窄相启动，含 152 个点–面特征和 100 个边–边特征。早期整面测试把相交面数预期为一；此后区分五个相交面与一个支撑法向，两种量各有断言。原始记录在 `artifacts/p65-collision-m2-rd05-local-20261102-01` 的 `08-host-pytest-202018796`、`09-interpret-pytest-202048314` 和 `10-cuda-pytest-202126800`。设备同次输出为各自 basetemp 的 `rd05.json`。[HOST 回归](../../tests/collision/test_hull_surface_contact.py) · [设备回归](../../tests/collision/test_tyx_hull_surface_contact.py)
