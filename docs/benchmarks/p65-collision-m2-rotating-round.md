# RR04 · 旋转胶囊与球的连续检测

`phymeo.detect` 接受绕固定世界轴转动的刚体胶囊和球。胶囊的枢轴可平移，球心可沿独立直线运动。与平移查询一样，`pair.witness` 给出末态，`pair.sweep` 给出首次接触区间、见证时刻、双方表面点及原始材料权重。角度使用有符号弧度，时间归一到一步的 [0,1]。[运动输入](../../src/phymeo/constraints/collision_shapes.py) · [查询实现](../../src/phymeo/geometry/_rotating_round_sweep.py)

球心相对枢轴静止时，一圈用两个闭半转区间表达。把旋转放到球心的逆向轨迹后，胶囊轴段固定。四元数的标量部分取 `1-s`，向量部分取 `-s * axis`，平方范数始终为正。两个端帽的平方距离和轴身的投影约束给出至多四次的多项式。tyx 核对这些不等式提出候选。HOST 对原始数据隔离全区间的根，再把区间转换到真实的角运动时间，包含孤立的偶重根。多圈运动只需要查询首圈。四元数与轴角的关系可见 [MIT 机器人操作课程](https://manipulation.csail.mit.edu/Fall2020/pset5/pset5_rotation.html)。

球心相对枢轴有位移时，先由覆盖其运动的球给出可跳过的时间前缀。随后按照时间顺序，用原球心到有限轴段的有界距离和速度上界排除时间段。返回首触需要在原轨迹上找到占据样本，并将所有可能更早的时间压入同一窄区间。最多检查 4096 个时间单元。无法区分的孤立相切、角度化简或时间分辨率不足均返回 `unresolved`。其他同时旋转的形状对按其各自支持范围分派。[角度界](../../src/phymeo/geometry/_rotation_angle.py)

本轮 HOST 77 项通过，tyx interpret 11 项通过，实际 CUDA 11 项通过。两个 tyx 后端对同一批七对形状的全部结果与 HOST 相同。每个后端为这七对完成一次窄相核启动，计算 27 组角运动特征，其中 5 组给出采样候选。另有转动反向、斜轴、多圈、两段运动重组、交换双方、端点材料重排、初始重合、零长轴、故障与发布历史回归。最初六项原案例在两个物体顺序上都返回 `unsupported`。随后独立球位移测试还复现了仅处理相同平移的限制。[HOST 回归](../../tests/collision/test_rotating_round_sweep.py) · [设备回归](../../tests/collision/test_tyx_rotating_round_sweep.py)
