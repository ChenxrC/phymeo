# M3 · 真实转弧与变形布面的连续检测

`phymeo.detect` 已支持固定世界转轴、移动枢轴的旋转胶囊与三个顶点各自仿射运动的非退化零厚三角面。结果的 `sweep.first_t` 是本步首触区间，`sweep.witness_time` 对应一个在原轨迹上证实已接触的可表示时刻。末态见证独立保留。双方顺序、材料重心坐标、胶囊上的轴参数和完整最近线段沿用公共结构。[实现](../../src/phymeo/geometry/_rotating_capsule_face.py) · [回归输入](../../tests/collision/rotating_face_cases.py)

每个角区间最多一弧度。用两个球覆盖胶囊轴的两半，半径计入轴段长度、区间内的角位移和旋转计算的误差。tyx 检查包围球对运动三角面的各特征，HOST 用原始坐标验证哪些时间可以排除。对剩余时间，在真实枢轴运动和旋转上求有限轴段与布面的距离，用两者的速度上界封住整个时间单元。只有找到原轨迹上的占据样本才返回命中。此处借鉴了保守运动界的思路，实现复用了项目已有的曲线区间搜索与有限轴段几何。[运动界参照](https://graphics.ewha.ac.kr/c2a/C2A.pdf) · [区间搜索](../../src/phymeo/geometry/_bounded_contact.py)

| 检验 | 实测 |
| --- | --- |
| 胶囊从布面侧面转入，布面同时改变倾角 | 两端均分离，首触区间为 [0.499999999985448, 0.50000000372529]，包住独立参考 1/2。端点直线会从布外经过 |
| 直线替代路径会穿面，真实转弧绕行 | 真实路径返回全程分离；另一条真正沿直线运动的输入返回命中 |
| 两边内部先相遇 | 区间包含 acos(1/8)/π，见证在胶囊轴内部及布边内部 |
| 一直处于接触，布面倾角换向 | 最近轴参数区间按 [0,0]、[0,1]、[1,1] 依次变化，两个相邻子步都保留共同端点的完整轴身 |
| 首触、持续、离开、重新分离 | 同一工作区连续执行五段原路径，在首触前注入容量拒绝，旧结果保留，重试仍得到相同的绝对首次时间 |

该路径最多 64 个角区间、4096 个距离单元。区分不了的孤立相切或预算耗尽返回 `unresolved`；正厚布面仍需相应的接触层或壳几何。此次验收覆盖几何检测和材料见证，力和运动在 M4 独立验证。

最终相关回归通过 HOST 72 项、tyx interpret 和实际 CUDA 各 8 项。两种 tyx 后端的四对原始场景分别得到命中、分离、初态命中、全轴身持续接触，完整结果与 HOST 一致。各自实际计算 140 组包围特征，26 组给出了采样候选。重新检查的 74 构型完整配对输出保持同一摘要 `27c8d007052b9dfac23f6ac54ec6142b41311f1e88464cd815df09c6458630a0`。
