# M3 · 碰撞候选筛选、包围盒树与实际成本

`CollisionWorkspace(model, backend, broad_phase="sap", mesh_midphase="bvh")` 可选择两个独立阶段。宽相默认 `all_pairs`，也可选 `sap` 或 `bvh`。闭合网格与凸体之间的面级筛选默认 `all_facets`，可单独切到 `bvh`。所有组合仍通过 `phymeo.detect` 返回原顺序的完整配对表、过滤原因、首次时间及材料见证。容量不足时返回需要的数量并保留上次发布。[实现](../../src/phymeo/geometry/collision_pipeline.py)

SAP 在每个世界按闭区间重叠数选择投影轴，先处理无界平面。HOST 排序，所选的 tyx 后端沿排序后的区间扫描、检查其余轴，并按位打包候选。已有外向舍入包围盒及对称掩码保持原样，同坐标端点也进入检查。返回完整配对表仍需要与形状对数量成比例的空间和发布工作。[SAP](../../src/phymeo/geometry/_collision_spatial.py) · [tyx 内核](../../src/phymeo/backends/_tyx_spatial_kernels.py)

BVH 按稳定 ID 与中位数分割叶子。通过预排序的子树区间跳过不相交节点，逐帧用当次整段运动的包围盒重新计算树节点。tyx 原生执行节点归约及遍历；拓扑构建及少量排序留在 HOST。不可变模型绑定形状与版本，新模型创建新工作区。被容量拒绝的首次试算不发布新布局。闭网格只减少无需进入面级裁剪/SAT 的三角面，实体内外与最近边界距离继续使用完整几何。[包围盒树](../../src/phymeo/geometry/_collision_bvh.py) · [设备缓冲](../../src/phymeo/backends/_tyx_collision_bvh.py) · [GPU 树遍历参照](https://developer.nvidia.com/blog/thinking-parallel-part-ii-tree-traversal-gpu)

### 正确性

在全部 74 个登记构型的同一模型上，每个后端分别将 SAP、形状 BVH 配合网格 BVH 与自己的穷举结果逐字段比较。三种后端都返回 13,366 条配对、101 对候选，以及相同的包围盒和软体汇总。去除后端名称差异后，完整输出 SHA-256 均为 `27c8d007052b9dfac23f6ac54ec6142b41311f1e88464cd815df09c6458630a0`。本批闭网格有 140 个原始面–凸体组合，保留 30 个。变形布第三帧翻转条带的空间顺序，包含物体而没有边界相交的网格返回正确的实体关系和正边界距离。另验过共享端点、平面、稀疏与密集掩码、30 位打包字边界、版本变更、试算拒绝及设备故障后的历史。[74 构型回归](../../tests/collision/test_spatial_catalog.py) · [树和网格回归](../../tests/collision/test_collision_bvh.py)

### 成本

测量的产品提交为 `1abf7a9`，使用项目固定的 tyx。在一个工作区先预热，做三次相同帧序列，列出完整序列耗时的中位数。表中单位是毫秒；球场景每序列一帧，布与网格场景每序列三帧。每个计时结果都与相同输入的穷举结果比较。下表的加速列用于比较指定算法，不能用不同工作负载之间的时间推断设备排名。[可复现基准](../../tests/collision/benchmark_spatial_indexes.py)

| --- | --- | ---: | ---: | ---: |
| 65 个稀疏球 | SAP | 17.26 / 7.37 | 215.27 / 14.83 | 8.15 / 7.85 |
| 34 个密集球 | SAP | 76.97 / 74.21 | 133.63 / 308.95 | 92.24 / 81.13 |
| 18 面变形布与球 | 形状 BVH | 19.55 / 24.24 | 415.30 / 593.90 | 46.73 / 65.54 |
| 72 面变形布与球 | 形状 BVH | 71.27 / 85.32 | 1,298.71 / 2,157.81 | 146.66 / 161.22 |
| 28 面凹闭网格与凸体 | 面级 BVH | 3,459.45 / 3,310.57 | 3,748.03 / 3,166.96 | 3,568.15 / 3,528.81 |
| 112 面的同一凹网格 | 面级 BVH | 14,550.95 / 13,322.43 | 17,657.43 / 14,982.73 | 15,707.89 / 15,659.02 |

稀疏球的 2,080 个配对都保留分类，SAP 的投影窗口有 0 对需要三维复查；密集球保留全部 561 对。28 面网格三帧共把 84 个面级 SAT 减至 2 个，112 面从 336 个减至 4 个。对应的实际 CUDA 投影轴数量分别从 772 减至 18、从 3,088 减至 36。112 面网格的三帧主机到设备传输从 1,556,784 B 降至 31,224 B，回传从 688,284 B 降至 8,516 B。

在该 112 面 CUDA 工作负载中，树每帧增加一次节点归约和一次遍历，中筛平均约 1.39 ms/帧。原窄相平均约 5,232 ms/帧，开启面级 BVH 后约 5,172 ms/帧；其中仍有完整网格有效性、占据和最近边界查询。各阶段时间是同步公共调用的主机墙钟观测，字节数是实际复制的缓冲长度。表中的微小端到端差异不能确认为稳定提速。保留原穷举默认值，由工作负载选择加速方式。

原始记录位于 `artifacts/p65-collision-m3-spatial-local-20261102-01`。完整正确性组为 `14-full-host-pytest-214621222`（44 项）、`15-full-interpret-pytest-214807579`（10 项）及 `16-full-cuda-pytest-214937127`（10 项）。成本组为 `18-cost-host-pytest-215252973`、`19-cost-interpret-pytest-215500960` 和 `20-cost-cuda-pytest-215748559`。各组 basetemp 下的 `spatial-cost.json` 保存每帧记录，`spatial-measurements.json` 汇总六个场景和所有选项。首次 tyx 内核编译的两项失败分别定位到增强赋值和带标量循环状态的提前退出，均保留原始日志。
