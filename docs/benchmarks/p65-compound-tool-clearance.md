# 复合关节凸工具的连续净空

将凸工具绑到实际 link 后，多条转轴、转轴下游伸缩和任意中间固定姿态现可沿同一条仿射关节坐标路径作整段净空检查。原有单转轴和纯平移路径继续使用原几何。新路径最多 64 个祖先关节、64 个工具顶点，每转轴在该段至多一周。接触力由物理程序读取同刻真实工具和布几何，净空检查独立覆盖两个力采样之间的区间。

计算从工具顶点逐级返回根部，按 URDF 的转轴/伸缩、固定关节原点姿态与平移顺序组合。固定四元数使用已存输入的有理正交矩阵。转轴使用已有的有理旋转包围，伸缩使用单位轴长度区间；每级压回有界二进制网格时保留位置误差。某祖先转轴对一个顶点的速度上界为角增量乘到该轴的最大触及半径，半径包含全部下游关节偏移与伸缩位置。各关节的上界之和乘时间半宽，加上中点位置误差，给出整个子区间的定向支撑上界。每片布的有限三角形按真实仿射材料路径与半厚度参与比较。预算用尽或无法证明正净空会拒绝该步。[实现](../../src/phymeo/geometry/_joint_chain_support.py) · [物理程序接入](../../src/phymeo/geometry/articulated_hull_clearance.py)

- 两根非平行转轴的半转、以及旋转下游持续伸长的径向滑轨，均有端点和端点弦都绕开小三角面、真实中点穿过小面的反例。两例均拒绝硬核相交，平移到独立远处的有限面均放行。
- 在真正承载的双轴腕部，两个广义坐标和自由布节点在四个实际子步中一起运动。原远离材料的两活动轴案例也在相同入步上通过；原先的“不支持多个活动转轴”失败收据保留。含相邻原案例的 9 个 HOST 用例通过。[复合运动留出](../../tests/collision/test_compound_tool_motion.py)
- 从真实 3,600 步箱体抓放取闭指与搬运两个姿态，另作这两点间的九坐标仿射查询。左指垫有七个转动祖先和一个实际伸缩关节。两套资产分别由 Phymeo 与真实 Newton CUDA 加载；九个时刻的 72 个指垫角点最大距离差为 0.196 µm。沿整条仿射查询对实际有限桌面两个三角片外加 0.5 mm 涂层检查正净空。此插值查询与原控制轨迹分别记录。Newton 核对的是 FK 点位，整段净空由 Phymeo 计算。[原生对照](../../tests/reference_newton/robot/compound_panda_pad.py) · [逐点结果](../../artifacts/p65-newton-night-20261105-01/native-panda-compound.json)

本项适用于普通标量转动/伸缩关节链上的有限凸工具与当前材料面。它未测完整软布递交，未将全部机器人形状组合或实时 GPU 连续窄相纳入同一结论。
