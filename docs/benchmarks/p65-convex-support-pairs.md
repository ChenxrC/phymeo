# 曲面刚体之间以及曲面与布的公开几何查询

使用同一 `phymeo.detect` 登记有限形状和材料 ID。圆柱、圆锥和椭球在已有解析分支以外可与其他有限凸体查询。球、胶囊、未扩张凸包、布的零厚三角面及材料点使用各自的支持映射。三角面与刚体的计算覆盖整张有限面，包括边和顶点。软粒子的显式球皮记录独立的材料偏移。[公共分派](../../src/phymeo/geometry/collision_pipeline.py) · [支持映射与见证](../../src/phymeo/geometry/_convex_support.py)

## 两侧各能读到什么

`CollisionPair.witness` 给出从第一体指向第二体的法向、有符号米制间隙、双方世界点、原始材料权重及可选表面偏移。`support_map` 提供距离上下估计、所用阶段和迭代计数。GJK 求单纯形到原点的距离，发生体积相交后以内部凸多面体及真实形状的支持面夹住退让深度。有限的 FP64 空间、迭代预算和给定误差下，只在能重建双方材料位置时发布点见证。深包含可能只给负间隙区间。圆柱与半空间另有解析见证，可分别给出整端盖的代表点、侧面支撑线段及斜向的单个圆缘点。[GJK 原论文](https://www.dtecta.com/papers/jgt98convex.pdf) · [解析支撑](../../src/phymeo/geometry/_curved_solids.py)

## 同一坐标下的 Newton 1.7.0 原生记录

刚体五对分别在 CPU 和 RTX 4060 CUDA 运行，每对各取两个离散姿态。正隙处五对没有原生接触；−31.25 mm 处则都有接触。最深间隙的最大差为 0.10002 mm，法向 L2 差在 0.000002 内，均满足预先登记的 2 mm / 0.02 判据。原生锚点按原样保存，另外比较有符号间隙和世界法向。[原生 RR 入口](../../tests/reference_newton/rr/support_pair_poses.py)

刚柔每端另做十个姿态，每个都运行 Newton 的粒子缺省模式及完整表面模式。两端各有九个姿态的两种模式均符合预先登记的结果。第十个姿态中，朝下的锥尖穿过布面 31.25 mm。Newton 完整表面缓冲给出三节点面接触，两端测到的局部有符号间隙约 −9.464 mm，法线沿锥侧。Phymeo 使整个圆锥和三角面刚好分离的位移为 31.25 mm，法向垂直于布面。两者都检出同一次相交，距离差 21.786 mm、法向 L2 差 1.169，完整保留原比较失败。消费这类输出时应为点的 SDF 力和整对退让距离分别指定合同。[Newton 的完整表面观测](../../tests/reference_newton/rd/curved_faces.py) · [Newton 碰撞文档](https://newton-physics.github.io/newton/1.7.0/concepts/collisions.html)

## 跨一步的有限几何

对于固定方向的有界凸刚体平移及独立仿射运动的零厚布面，公共查询在每一时间格尝试一个固定分离方向。沿给定方向，每个材料顶点的投影在时间上是仿射函数，凸体的支持是这些函数的最大值加定向形状半径。若两端的向外支持界在整个格上有严格净隙，可排除格内穿越。其余格按时间顺序细分；第一次得到有余量的穿入样本时，记录此前最后连续证明净空的边界与该样本之间的首触区间。若无法排除更早的擦触、预算用尽或见证分辨率不足，返回未决。检查布面整条路径的退化，首触见证使用其公开采样时间的实际材料坐标。[时间格实现](../../src/phymeo/geometry/_convex_support_path.py) · [连续控制](../../tests/collision/test_convex_material_paths.py)

HOST 初次完整运行的 11 个路径及相邻控制通过。穿过椭球的球在两端都分离，归一化首触区间覆盖 1/6；三个节点各走独立路径的布面首触区间覆盖 1/4。起始重叠给出时刻零，共同平移及材料换序也参与核对。本节的离散距离和穿入见证采用有界 FP64 估计；Newton 参考表只测各指定姿态。

原始命令、退出码和观测见 `artifacts/p65-20261104-0800/validation` 的 `support-*`、`curved-*`、`convex-motion-*`。阈值、首个不支持、斜盒相切的数值修复及未过的参考项均可追溯。

## 实际受力、入层及卸载

`CollisionLoadSystem` 可为光滑椭球与另一椭球、球、零厚三角面或材料点登记原有顺应接触层。入步姿态由刚体状态左乘到资产局部 XYZW，各材料点取真实线速度和力臂。滑动牵引在同一空间点对两侧施加反向力。物理步使用所选参与者的实际线速度、角速度和姿态；若曲体发生转动，以其相对于移动支点的最大半径与角位移夹住整段。无法证明硬芯净空时拒绝提交。这里的角度上界只用于排除相撞，不能据此给出一般旋转碰撞时刻。平端盖、共面多点压力与任意曲形–曲形摩擦仍有各自的物理接缝。[受力入口](../../src/phymeo/solvers/collision_loads.py) · [静态、偏心转动及拒步控制](../../tests/collision/test_curved_material_loads.py)

| 同一连续轨迹 | 实际结果 |
| --- | --- |
| 两椭球，0.5 kg 与 1 kg，层外初始相对入射速度 0.5 m/s | 80 个 1/256 s 物理步。三端均在第 10 步首次有力、第 38 步峰值、第 67 步最后有力。峰值 HOST 2.3102463 N、CUDA 2.3102453 N；末态已分离。最小硬芯净距约 26.4024 mm。以两体相对坐标的离散振子解逐步校验。CUDA 整窗动量最大误差 5.96×10⁻⁸ N·s，机械能最大偏离 1.159 mJ。 |
| 倾斜椭球与初速 0.25 m/s 的布，接触摩擦系数 0.25 | 48 个相同步长的物理步。三端均在第 1–32 步受载，随后卸载。首步 2 N 法向、0.5 N 切向、接触功率 −0.125 W，偏心接触使椭球产生真实角速度。另对刚体施加 8 步横向外载。HOST / CUDA 整窗动量最大误差分别为 4.58×10⁻¹³ / 1.69×10⁻⁴ N·s，CUDA 末角速度约为 (0.06408, −0.10554, 0.01448) rad/s。 |

两条轨迹分别在 HOST、TYX interpret 与实际 CUDA 上运行。真实 CUDA 负责宽相、接触层力、刚体和粒子材料积分；支持面复核与材料寻址仍在 HOST。独立读回程序无需导入 Phymeo，直接从六条原始轨迹逐步核对材料点、法向力、摩擦锥和双方动量。完整材料见证、实际力和原外载保存在本批 `temp-smooth-windows-*`，汇总在 `smooth-window-readback/summary.json`。[离线核验入口](../../tests/collision/read_curved_load_windows.py)

## 两个自由刚体的滑动与有限平面的连续首触

两个自由椭球在相同空间点承受大小相等、方向相反的力。首个入步点给出 2 N 法向力、0.5 N 滑动摩擦力；关于各自质心的 z 力矩为 −0.1328125 和 −0.0703125 N·m。接触功率 −0.125 W，两体开始自转。沿同一条运动积分 20 步并交换形状登记顺序，HOST、TYX interpret 和实际 CUDA 均核对了双方状态及总动量。这里使用有厚度、可标定的接触层。[受力控制](../../tests/collision/test_smooth_rigid_friction.py)

固定方向的圆柱、圆锥和椭球可以随刚体或平面移动，查询给出整步最早相切时间。独立控制包括相对平移、同速运动、平面翻转和材料换序。机器人组合用例从两个工具点的 IK 目标出发，用真实 −4 N 推动 2 kg 滑轨；IMU 对应 −2 m/s²，第三个物理子步在归一化时间 1/3 首次触地。转动椭球走单独的有界路径，仍区分能证明的首触、整段净空和未决。[地面和机器人控制](../../tests/collision/test_translating_curved_ground.py) · [转动椭球控制](../../tests/collision/test_rotating_ellipsoid_plane.py)
