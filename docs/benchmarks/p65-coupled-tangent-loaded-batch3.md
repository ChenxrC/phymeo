# 第三批：耦合切向状态与受载窄相诊断

本批从第二批的通用持续摩擦与受载性能问题推进，三个原作者在隔离 worktree 编码，父独占执行槽。新核和状态工具可供刚体、粒子、机器人适配器复用；默认 ContactScene/RobotScene 摩擦行为不变，未重跑或改写原100 g mimic持稳失败。

## 新公共机制

- solve_coupled_tangent 同时处理全部站点及完整交叉响应 W。等静/动摩擦系数、正切向刚度、固定步内切向坐标下，返回力、位移预测、弹性能、塑性/隐式耗散与释放能量。冗余站点可有秩亏W，弹簧柔度使联解目标正定。它是 HOST 求解，没有宣称新的 TYX 切向核。
- TangentHistory 以显式材料站点身份及双侧地址维护状态；完整材料坐标系运输、换面/拓扑/所有者重置、退出重入和能量释放都有记录。prepare/commit均为纯候选，物理状态与历史由调用方共同发布。
- result.verify_motion 比较真实材料增量。位移通过只是其中一项要求，调用方还须审核实际功与物理能量。偏心刚体的真实旋转留出会拒绝错误的线性位移假设。

[切向核](p65-coupled-tangent.md)和[材料历史](p65-tangent-history.md)列出精确API、来源与限制。低层二维disk优化来自原摩擦模块；没有复制已有标量返回律或把数值目标冒充物理动能。

## 诊断边界

同进程保留完整分派为A、当前过滤分派为B，两独立scene逐帧交替。loaded/birth各W1/W32、每档16帧，并分别记录无插桩与有插桩窗口。全部公开帧完整比较，只有列明的统计时钟可不同；不重新读取旧归档，不以不同时间段的快照推断因果。真正GPU设备耗时没有测量，TYX调用墙钟不能代替它。

## 后续功能节点

下一步将这些机制接入共享场景适配层：使用实际法向载荷和入步速度，组装全切向W与真实自由增量，一次施加全部反作用，再以实际运动/功/储能核验共同发布。下一切片分别验普通刚体双面支撑、URDF滑轨双站点与共享祖先、偏心转动的实际位移拒步与重试；随后再接真实可变形路径。原mimic是补充回归，不是唯一判据。法向采样与切向施力必须拆开，不能直接把旧friction设零，因为它还影响求积与作用点选择。有限转动、材料换面与默认scene自动接入仍需各自案例。本批不扩大为全Newton功能或整体性能对齐完成。
