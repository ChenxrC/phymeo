# 运动柔性三角面的正余量首次进入

`sweep_deformable_features` 接受注册三角材料面的仿射节点轨迹与两项米制阈值。每条返回路径处理一个实际顶点–面或规范无向边–边，分别给出 `search` 与 `contact`。归一化时间 0 和 1 对应输入两端姿态。正常完成时，省略的特征全程没有达到搜索阈值。[公共运动查询](../../src/phymeo/geometry/deformable_feature_sweep.py)

```python
with ph.CollisionWorkspace(model, "cuda") as work:
    sweep = ph.sweep_deformable_features(
        model, affine_node_paths, work,
        search_distance_m=3/32, contact_distance_m=1/16,
    )
    if sweep.status == "ok":
        earliest_compression = sweep.first_force_entry_interval
```

每个阈值的 `first_touch` 是首次满足 d ≤ R 的时刻，`first_entry` 给出 d < R 的下确界并附带一个已经严格在内的采样。初始就在层内时两者均从 0 开始。若起点只等于阈值，开离可没有严格进入，闭向则下确界为 0、内点采样晚于 0。纯切触只有闭事件。每个事件的 `sample_time`、`sample_relation` 与两侧世界点、材料权重对应同一实际采样。若代数根不能由时间浮点数精确表示，`distance_error_bound_m` 用双方最大节点速率和时间括区限制采样距离与事件距离的差。

### 判据与资源边界

对原始二进制节点坐标，用有理数构成各子特征的距离与有效性多项式。顶点–面包括三个端点、三条有限边及合法的面内投影。边–边包括四种端点组合、四种端点–有限边与两条边内的非平行最近对。平行时由端点–边覆盖整个最小距离。在实际见证处保留完整最近点区间。Sturm 链隔离可能改变符号的根，公共根用最大公因式核对。在各无根开区间内，候选投影和距离不等式的真值恒定。独立的实际内点采样用于定位材料见证。[精确符号判据](../../src/phymeo/geometry/_deformable_feature_roots.py)

同一材质拓扑、同世界/排除和无向边归并沿用离散特征接口。设备包围盒覆盖每个仿射材料顶点的完整端点范围。HOST 在有限原语上验证时间与材料点。默认归一化时间目标宽度为 2⁻³⁶，根工作预算为 131,072。时间分离精度、根工作预算、候选预算或完整输出容量不足均有显式状态，失败批不发布部分事件。任一面在中途或端点退化时，整批返回未决。[静态特征定义](p65-dd-material-features.md)

先切后入的留出可独立因式分解。取 u 从 1 线性变到 −1/4，d²−R² 的符号等于 u(u−3/4)²(u+15/8) 的符号。首切括区为 [0.19999999999708962, 0.20000000001164153]。实际读出双方材料点的时刻 0.20000000000436557 位于层外，真实场景的有限特征间隙约 +2.08×10⁻²⁵ m，所给距离误差界为 4.89×10⁻¹² m。严格入层的括区为 [0.7999999999883585, 0.8000000000029104]，实测内点间隙约 −2.13×10⁻¹⁴ m。另一条边轨迹有两个互不相连的严格窗口，第一个入口位于 [0.21982493034738582, 0.21982493036193773]。还验证了 64 个等距采样全部漏掉、真实入口恰为 0.2660980224609375 的短窗。[仿射轨迹与独立解析真值](../../tests/collision/test_deformable_feature_sweep.py)

在折回带全模型上，48 个运动面组合产生 49 个需精确核对的 VT/EE 原语，记录 955 次根工作，返回 32 条触及搜索域的特征路径。t=13/32 时所有节点逐一重现此前 Newton 1.7 的离散参考姿态，表中进入时刻则由实际运动路径和独立几何给出。[原生离散参考](p65-dd-vbd.md)

真实 RTX 4060 和 TYX interpret 都为独立运动 VT 与 EE 给出了相同的首入括区和实测材料地址。每个两面模型的 CUDA 工作区累计 2 次实际宽筛核启动、216 B 上传、52 B 读回和 1 次同步。VT 与 EE 两例的 HOST 精确根工作次数分别为 402 和 3,249。[设备与 HOST 分工](../../tests/collision/test_tyx_deformable_feature_sweep.py)
