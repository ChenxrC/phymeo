# 柔性材料点在有限表面上的滑动与滑离

两张三角面以 2 N 正压力接触，上侧 1 kg 节点从 1 m/s 开始滑动。32 个 1/64 s 子步后，Phymeo 的受力节点速度为 0.75 m/s，累计滑移 0.435546875 m，摩擦在接受位移上做功 −0.2177734375 J。Newton 1.7 VBD 在同一初态和外力下给出近似结果。旁侧另设有限表面边缘，滚动查询真实几何，观察到 VT 与两个 EE 的受载和结束。

| --- | ---: | ---: | ---: | ---: |
| 独立半隐式递推 | 0.750000000 | 0.435546875 | −0.250000000 | −0.217773438 |
| Phymeo TYX interpret、CUDA | 0.750000000 | 0.435546875 | −0.250000000 | −0.217773438 |

| Newton VBD CUDA | 0.749998093 | 0.435546428 | −0.250001907 | −0.217773518 |

下侧三个节点固定，上侧三个节点各 1 kg，结构刚度和重力为零。上侧顶点与下侧面相距 1/32 m，载荷层宽 1/16 m，搜索半径 3/32 m，法向刚度 64 N/m。对该顶点施加 −2 N 法向外力，初态法向力为 +2 N。两侧相对滑速高于 1/32 m/s 的正则化阈值，动摩擦系数 0.25，因此 Phymeo 返回 0.5 N 剪力。它在上侧反向减速、在下侧按不断变化的三角形重心权重分配反力。在均匀载荷区，h 为物理步长，有 vᵢ=1−0.5ih，滑移路程 sᵢ=ih−0.25h²i(i+1)，切向功为 −0.5sᵢ。另一个 1/32 s 步长、同样半秒的 HOST 轨迹得到 0.43359375 m，与该步长的离散解一致。输入还覆盖轴循环旋转、粒子重排和反序注册。

## 材料地址、力与历史

一步开始时取真实 VT 或唯一最近点的 EE 及其原节点权重。法向由已有 `DeformableFeatureLoadSystem` 求出，切向相对速度为两侧按权重插值的节点速度之差在接触切平面上的投影。对第二侧施加 `−μ F_n v_t / max(|v_t|,v_reg)`，另一侧取反。再用同一组材料权重转置回各节点。原粒子求解器将接触和外载一起推进。

历史键包含特征类别及两侧的世界、物体、节点 ID。只要同一键在连续入步采样中承受正法向力，允许三角形或边上的重心坐标随运动改变。已经接受的每一步，以该步**开始时两侧各自的材料权重**插值真实节点位移并作切向投影。由此累计滑移路程、法向冲量、作用于第二侧的切向冲量和切向功。最近几何点的迁移不加入材料滑移。键消失时单次报告本段历史，再接触从新的入步 tick 计数。

检查点持有独立粒子状态和当前活跃历史，重复以同一检查点推进可分支重放。法向/几何错误、粒子候选未通过或准备施加的摩擦会在本步实际位移上明显做正功时，不产生新历史。当前只处理离散入步能唯一识别的材料站点和速度正则化动摩擦。多点最近线段、采样间的潜在换面、历史弹簧静持仍需独立物理约束。两侧切向力作用于各自的材料点，有限开距可产生力偶。双自由体测试直接核对相应的角动量变化。

## 有限边界与双侧受力

有限下表面的右边界在 x=0。以 1/128 s 连续推进 80 步，统计的是每次入步真实几何。第 1–27 步只出现一项受力 VT，第 28 步同时出现两项唯一 EE，第 44 步三段历史均结束。原 VT 受力 43 步，实际滑移 0.286899 m，切向功 −0.135973 J。两项 EE 各受力 16 步、累计滑移 0.075671 m、切向功 −0.023885 J。到第 80 步，上侧顶点在 (0.273364, 0, 0.013852) m，虽然距离无限延伸平面的高度仍小于层宽，有限面已没有受力特征。

另一个程序化外载令同一 VT 正常离层并返回，重新入层的历史从新的步号开始。两侧都自由的留出按原三角面节点权重 19/48、13/48、1/3 独立核对六个节点的速度增量。零摩擦时，新入口在所测 8 步产生的粒子位置和速度与原无摩擦入口逐字节一致。无效粒子候选和强反向外载造成的正摩擦功拒绝均保留原检查点，随后可以按原输入重放。[物理接口](../../src/phymeo/solvers/deformable_sliding.py) · [解析、滑离与事务留出](../../tests/collision/test_deformable_sliding.py)

## 设备与 Newton 的读数

Phymeo 在 HOST 计算切向速度投影、材料节点分配和历史功。CUDA 组使用真实 TYX 宽相、32 次原生法向层计算和真实 TYX 粒子推进。Newton 以 3 次 VBD 迭代推进每个物理步，输入来自对应的 Phymeo 原始节点状态、非连续材料行序和外载。固定下侧的节点真实保持不动。Newton 原生接口不导出软体自接触力，故先保存全部实际状态，再在相邻两份接受位置上用原生力/Hessian 核计算每个步末的力。表中 Newton 的功由这些步末力与真实切向位移求积，另由实际节点速度变化单列净冲量。Newton CPU、CUDA 的力采样积分分别为 −0.250001103、−0.250000262 N·s。第 16 个真实 CUDA 子步的活动包含三次自接触力/Hessian 核、三次弹性更新和一次速度更新。[Newton 独立对照](../../tests/reference_newton/dd/sliding_window.py)

用项目解释器运行 `python -m pytest -q tests/collision/test_deformable_sliding.py`，真实设备窗口加 `-m tyx --require-tyx --tyx-mode cuda`。Newton 解释器单独运行 `python tests/reference_newton/dd/sliding_window.py --device cuda:0 --phymeo-receipt <对应窗口JSON> --cache-root <Warp缓存> --out <新JSON>`。两端版本为 Newton 1.7.0、Warp 1.17.0。所有串行收据、逐步物理状态与材料地址存于 `artifacts/p65-day-dd-material-sliding-20261104-01/`，包括 HOST 的 `material-sliding-edge-release.json`、两份 `material-sliding-window.json` 及 `slide-newton-{cpu,cuda}/report.json`。
