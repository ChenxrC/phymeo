# 两个自由变形材料面在持压下换面

`DeformingMaterialSeamStepper` 推进一个自由材料顶点及两张三角面的独立正质量节点。相同材料 ID 只绑定一个粒子行。每个节点接收自己的力、推进自己的位置和速度，共享边可以平移、伸缩，两侧面可以产生不同面内应变。已有距离弹性可直接作用于支撑节点。[步进器](../../src/phymeo/solvers/deforming_material_seam.py) · [材料几何](../../src/phymeo/geometry/deforming_material_seam.py)

## 越边步如何求解

对一个速度先行的物理步，令 `s∈[0,1]`，`xᵢ(s)=xᵢ(0)+s Δxᵢ`。在固定法向的切平面内，当前三角面的两倍有向面积 `D(s)` 与三个子面积 `Aᵢ(s)` 均为二次多项式。先检查整步不退化、端点分别只有一个严格面内站点，并确认共享边材料 ID 与绕向。越边时在运动共享边的有向面积变号处求根，实际节点位置决定事件。验证两段中的其他边未被越过，同时拒绝擦顶、并列或同面离开再返回。

每段权重为 `Iᵢ = ∫ Aᵢ(s)/D(s) ds`，范围仅覆盖该面实际承载的部分。积分自适应细分，利用 `D w = A` 逐阶估计四阶导数，给出单个 Simpson 面板的截断误差，并另计根区间与浮点余量。累计两段权重 `w̄ᵢ` 同时出现在相对速度、有效逆质量 `1/m_v + Σ w̄ᵢ²/mᵢ` 以及实际节点力 `−w̄ᵢ F` 中。法向载荷由入步真间隙和原法向层给出。同一份静持与库仑返回映射给出切向牵引。每个物理步冻结此站点牵引。[原返回映射](../../src/phymeo/solvers/_material_stick_law.py)

局部迭代用当前权重预测所有自由终点，重新计算运动面、事件与两段权重，直至相邻迭代闭合。实际粒子求解器使用该组节点力推进一次。随后从实际接受终点独立重算材料站点。权重不一致量加积分误差超限、节点惯性不符、布面倾倒或极旋转、越边并同时卸载等都拒绝。报告分别保存实际施加的节点冲量、由实际几何分段重建的冲量和两者的权重差。输入和原检查点在失败后可以重放。

## 有限域

两张面及点可以在三维空间任意恒定法向上平移和作面内正展伸。允许两面有不同应变。法向发生变化、面内发生材料极旋转、非共面折角或需要追踪多个换面事件的轨迹不在本合同内。平面投影仅用于局部迭代和材料几何，实际粒子状态不经投影或约束回写。弹簧储能只在相同材料切向框架中传递。上一批平移片的结果仍由原入口提供。[平移片基线](p65-material-seam-transfer.md)

## 布节点零外载的开环物理步

四个支撑节点按左端、公共边下端、公共边上端、右端的顺序具有 **1、3、3、1 kg** 质量，点为 1 kg。五个物理行均可自由移动。法向层宽 1/16 m，入步间隙 1/32 m，法向刚度 64 N/m，初始载荷 2 N。切向刚度 16 N/m，静、动摩擦系数 0.5、0.25，步长 1/8 s。四个支撑节点外载均为零。点上的固定外力为 (9/16, 0, −9/4) N，由名义动摩擦、正压力和点与片总质量比选择。运行中不从目标坐标或求解器输出修改这个力。

共享边长 2 m，原长 1.75 m，刚度 4 N/m，因此真实内部拉力为 1 N。其两节点初速度的 y 分量分别为 −0.25、+0.25 m/s。点与布的初始相对 x 速度为 8 m/s。两面的实际受载步在材料节点 17、31 之间的中点换面，事件分数为 0.5。下表的权重是整步归一化时间上的区间积分，每段之和为 0.5。

## 带预剪切历史的异应变留出

另一组使用制造解。先在左面形成 1/256 m 弹性剪切，随后公共边平移 1/16 m 并伸长，左、右两面末态面积分别为 **81/64 和 135/128 m²**。几何参照用 60 位十进制对数原函数计算两边随时间变化的有理重心权重，再据此构造外载。实际越边分数为 **1/3**，作用点 x 为 1/48 m。把公共边留在初始位置会得到 1/11。两段分布冲量、各支持点功和末态自由行与独立参照一致。
