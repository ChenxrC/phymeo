# 已承重的捐出臂对目标材料边的控制权

本实验固定接收臂 B 的可执行指令，检验改变 A 的真实执行器控制后，受载布边能否改变接近路径。样本来自已有的 [0° 早窗](../../artifacts/p65-night-kinodynamic-approach-20261104-01/05-early-vertical.json.gz) 与 [2° 同源延长窗](../../artifacts/p65-night-kinodynamic-approach-20261104-01/12-first-loaded-tilted.json.gz)。起点分别为 0.81 s 和 0.75 s。B 仍受关节、材料、指垫和结构载荷作用，其四个执行器的逐帧输入在同一倾角三支中逐元素相同。

## 激励和观察

从起点第一次观察取得接收侧材料边 13–20 上的位置比例，两个倾角分别为 0.5241788943 与 0.5277928219。整个窗口跟踪这一固定材料地址。A 原承重停留参考沿当下 B 工具指向材料地址的 XZ 单位方向加上正、负或零位移。在 60 ms 内使用前半匀加速、后半等量减速的运动参考，然后保持末位置。原加速度上限 3.40817 m/s² 给出 3.06735 mm 的峰位移。A 经过原关节限位、FK、IK 和受限 PD 计算实际扭矩，双侧手指沿用该时刻原目标。每个 10 ms 窗运行 128 个原物理子步，保留材料节点、双方机器人真实状态、首笔结构力和逐垫载荷。[激励与放行计算](../../src/phymeo/experiments/donor_material_authority.py) · [真实回放驱动](../../scripts/benchmark_donor_authority.py)

中性支采用已有完整物理回放的所有力样本，并在首、末两个原输入窗口分别独立重做全部 128 子步，核比 A/B 关节坐标与速度、布节点位置与速度。每个非零支从同一完整状态连续积分到该倾角原窗口末端。0° 比较 9 帧，2° 比较 12 帧。A、B 关节状态与材料点均由积分器产生。

- 危险法向取已有中性路径第一次真实受载时的 B 连杆–材料面法向。它用于离线评价，并保留该面的重心权重与杆轴位置。分别记录材料地址的法向变化和原危险面相对杆的投影变化。真实净空仍由所有 B 结构与所有材料面查询。
- 指垫入口方向取当下材料指向 B 指窗中心、投影到指面内的单位方向。材料减去 B 实际指窗中心后的位移在该方向上比较。两片有限多边形的最小侧边余量和两指轴向余量另外记录，正值表示进入预留后的范围。

## 预先冻结的放行条件

1. 同时刻正、负 A 输入在同一投影上分处中性两侧，至少一支在危险法向或入口有利方向连续两帧各改变至少 0.75 mm。该同一对照窗口中，两支 A 的较弱指垫在每个物理力样本都超过 0.20 N，且逐帧平均竖直力超过 0.25 倍布重。两支实际速度也须在原预算内。
2. 同一支还须在中性原首个受载帧将真实最小结构净空提高至少 0.75 mm，或将真实首次结构载荷至少推后 10 ms，或取得连续两帧原双臂共同承重。窗末仍未受载只作为延时下界。0° 是前一批仍受阻的输入，须在这里通过两项条件才开发双方运动分配。2° 作为独立留出。

独立小例覆盖激励速度与加速度、镜像方向、有限指窗的侧边和轴向余量，以及 2 kg 执行体通过真实弹簧发力后才移动 1 kg 材料的离散两步解。负控分别撤去传力、破坏负支的响应符号，降低 A 支撑或只微调几何净空。[独立测试](../../tests/test_donor_material_authority.py)

### 0° 的实测结构层

同一份 B 扭矩下，中性支的首笔结构力在 0.893281250 s。A 正向激励令首次力推后至 0.893515625 s，负向激励令其提前至 0.892968750 s。旧受载帧中，三支最小结构层间隙依次为 −1.2103、−1.1505 和 −1.2401 mm。正向改善 0.0598 mm 与 0.234375 ms，负向变化为 −0.0298 mm 与 −0.312500 ms。原受阻输入这两项的改善都低于预先设定的下游门槛；A 保持了真实双侧夹持。[中性逐帧](../../artifacts/p65-night-donor-authority-20261104-01/03-neutral-vertical.report.json) · [正向力与运动](../../artifacts/p65-night-donor-authority-20261104-01/05-positive-vertical.report.json.gz) · [负向力与运动](../../artifacts/p65-night-donor-authority-20261104-01/06-negative-vertical.report.json.gz)

## 复现

```powershell
python -m pytest -q tests/test_donor_material_authority.py
python scripts/benchmark_donor_authority.py --source <accepted-trace.json.gz> --sign 1 --out <plus.report.json>
python scripts/benchmark_donor_authority.py --compare <neutral.report.json> <plus.report.json> <minus.report.json> --out <qualification.json>
```

用同一源分别运行 `--sign 0`、`1`、`-1`。每个非零支还生成含原始受力和运动帧的 `.json.gz`；判定核对 B 扭矩序列的 SHA-256 和共同材料/方向定义。
