# 浮动机器人在真实首触时的反冲

公共函数 `solve_witness_impulses` 接受碰撞查询提供的时刻、法向和两侧材料点，按形状键把它们绑定到参与者的点速度端口。浮动树端口使用完整质量矩阵和点雅可比，保留根平动、根转动与关节之间的耦合。端口位置必须对应同一采样配置；两侧分离、时间不一致或地址不符会拒绝求解。参与者接收已有多域库仑求解器产生的同一组冲量。[见证绑定](../../src/phymeo/coupling/witness_impulses.py) · [浮动树端口](../../src/phymeo/coupling/floating_port.py)

## 偏心碰撞

2 kg 的根连着平移关节，1 kg 子连杆位于局部 x=1 m。两段主惯量各为 0.5 kg·m²。另一独立的 1 kg 球以 −1 m/s 沿 y 接近子连杆上的球面。真实扫掠在该步归一化时刻 1 首触。树质心位于 x=1/3 m，绕其质心的 z 向惯量为 5/3 kg·m²。结合另一自由体，接触点法向逆有效质量为 8/5 kg⁻¹。

| 同一位置的速度跳变 | 独立预期与 HOST 读回 |
| --- | --- |
| 对两个材料点的等大反向法向冲量 | 0.625 N·s |
| 浮动根 vᵧ、ω𝓏 | −0.125 m/s、−0.25 rad/s |
| 子连杆及外部球的末 vᵧ | 均为 −0.375 m/s |
| 两侧系统动量 Pᵧ、角动量 L𝓏 | −1 kg·m/s、−1 kg·m²/s |
| 动能变化及法向速度残差 | −0.3125 J、0 m/s |

交换登记顺序、整体旋转和平移均保留这些物理量的大小。切斜入射另检验了摩擦系数 1/8 时的切向冲量 5/64 N·s。实际碰撞后的双方状态还能各自推进下一物理步。重复材料地址、同树两点交叉响应和错误域绑定另有控制。本次 HOST 运行的 6 项新接触控制与 11 项相关浮动树控制均通过。这里验收离散、零恢复系数的已解析接触冲量。多步承载、可能碰撞点的全自动装配和设备侧浮动树接触仍待验证。[物理控制与原始数据字段](../../tests/test_floating_witness_impact.py) · [浮动树动力学](p65-floating-tree-dynamics.md)
