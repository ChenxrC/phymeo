# 浮动树的持续承载与抬离

`step_floating_contacts(systems, attachments, rows, mu_static, mu_dynamic, dt, *, fixed_bodies=None, local_vertices=None, ...)` 用 HOST 的完整浮动质量矩阵推进一个已确定接触时刻的物理子步。每个动态域在 `systems` 中提供模型、入步状态和外载/关节驱动。每个固定支撑在 `fixed_bodies` 中提供零逆质量刚体模型与零线角速度状态。`attachments` 按域给出刚体或连杆 ID 和材料局部点；见证绑定、逐行摩擦系数和按形状键的局部顶点沿用原公共冲量接口。[物理事务](../../src/phymeo/solvers/floating_contact.py) · [原碰撞见证复核](../../src/phymeo/coupling/witness_impulses.py)

每个动态域首先在共同入步 q 上计算 M、偏置、重力、外部 COM 力矩及内部关节力，得到 vᶠ=v+h·a。接触图在同一 q 和这些真实预测速度上求零恢复冲量并验证两侧材料几何。全部域成功后，仅用纠正后的 v 漂移一次。根 COM 的世界平移为 h·vCOM，体原点还需扣除旋转导致的本地 COM 偏置变化；关节坐标按纠正后的关节速度推进。[共享漂移](../../src/phymeo/solvers/floating_tree.py)

接受结果含 `states`（各浮动域末状态）、`predicted`（入步 q 的受力预测态）、`impulses`（原图的纠速态、方向、冲量与动能审计）及 `report`。数值拒步时只返还各域原状态与原因。调用者在当前几何上选择真实 touching 行；已经分开时可给空图。若可能在漂移中首次撞击，应先定位到达时刻。这里没有将连续碰撞判定并入时间推进。

## 已知重量的 32 步支撑与 8 步卸载

2 kg 根的局部 COM 偏心为 1/8 m，1 kg 子体通过真实滑轨连接。重力为 4 m/s²，每步 h=1/64 s。子连杆有限球面与独立固定球面在入步相切，每一步都从真实 FK 重建球心、调用普通 detect 并用新见证复核同一材料接点与法向。第一组滑轨与重力正交；第二组整体旋转、反转形状键次序，滑轨沿竖直轴。轴向组用 −8 N 的内部关节驱动在受载期间平衡根的重量，两组均使用原树质量和接触响应。

| 实测量 | 正交滑轨 | 轴向滑轨 |
| --- | ---: | ---: |
| 连续支撑子步 | 32 | 32 |
| 每步法向冲量 | 0.1875 N·s | 0.1875 N·s |
| 相应已知物理步平均反力 | 12 N | 12 N |
| 32 步累计支撑冲量 | 6.0 N·s | 6.0 N·s |
| 随后抬离的实际步数 | 8 | 8 |
| 末根 COM 速度 | 0.25 m/s | 0.25 m/s |
| 末根原点向上位移 | 0.017578125 m | 0.017578125 m |

抬离阶段向根施加 18 N。轴向模型同时把内部驱动力改成 +6 N，使两体获得共同的 2 m/s² 向上加速度。首步入步仍相切而冲量为零，随后七步实测分离。两体总动量增量为 0.75 N·s，与外力减重力的时间积分相同。另一步把轴向驱动改为 −10 N，可见固定球支撑 14 N，根实际向上移动 h²，关节实际反向移动 h²，受力的子体留在支点。[原数据](../../artifacts/p65-night-floating-contact-window-20261104-01/02-floating-window-host/stdout.log) · [冻结用例](../../tests/test_floating_contact_window.py)

## 力矩、入步速度和回滚

两处有限球面支点分别位于偏心根的 COM 左右 0.5 m，在 8 N 重量外再施加 +1 N·m 的世界 COM 力矩。一次公共图求解得到左 3 N、右 5 N 的实际平均反力；总反力为 8 N，反力力矩为 −1 N·m。预测角速度为 2h rad/s，纠速后根的线、角速度均归零。另一个开图保留非零入步自旋和各向异性惯量，其偏心根姿态与原单刚体自由积分一致，COM 的位移恰为 h 乘新 COM 速度。已知子步的冲量除以 h 用于报告该子步平均反力。

另有两棵各自可动的浮动树，2 kg 参与者以 1 m/s 接触静止的 1 kg 参与者。公共冲量为 2/3 N·s，接触投影的动能变化为 −1/3 J，双方都以 2/3 m/s 漂移一次。在持载情形，冲量审计中的能量变化比较受力预测态和纠速态；总动量窗口则使用已接受的各步末态和完整外冲量。若后一个域的漂移超过 FP64 范围，全部动态域原状态都原样返回，没有半步冲量或漂移对外发布。相同输入缩短 dt 后可以重试。动态质量或非零运动的外部刚体不能作为固定支撑登记。[反力与事务负控](../../artifacts/p65-night-floating-contact-window-20261104-01/03-rotation-atomicity-support/stdout.log)


此节点使用 HOST 真实球面见证完成 8 项新测试，另复核 4 项相邻浮动力学与旧见证回归。可绑定的形状和材料行沿用原见证桥的能力。
