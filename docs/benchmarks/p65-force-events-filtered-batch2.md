## 四条独立轨迹

四例从打开指爪和有限台支撑的同类初态出发；按此前冻结的驱动力、2N/侧目标、力带、步长与滑移门运行一次。第二个自由物体与所有已登记接触通道同场推进。

| 轨迹 | 实际步数 / 时间 | 真正持稳 | 释放与回台支撑 | 原验收结果 |
| --- | --- | --- | --- | --- |
| Panda，半径20mm / 40.96g球 | 3008 / 1.880s | 是 | 是 | 8/8，RAW0 |
| mimic，40mm / 100g箱 | 1807 / 1.807s | 否 | 是 | 7/8，RAW1 |
| 同mimic，零指面摩擦 | 1681 / 1.681s | 否，符合负控 | 是 | 8/8，RAW0 |
| 同mimic，1kg箱超载 | 1789 / 1.789s | 否，符合负控 | 是 | 8/8，RAW0 |

mimic正控在1.048s的相对滑移为3.005689mm，超过原3mm门，物体底部净空仅3.499783mm；因此即便台面反力已为零，也没有冒称满足10mm净空和100ms持稳条件。原RAW1及完整轨迹保留，未改变质量、摩擦、驱动力或阈值重跑。

四例均无执行异常，实际驱动力不越上限，两个自由物体逐步冲量核对误差至多1.388e-17 Ns。负控的“不持稳”只满足其中一项要求，不能掩盖获取/释放/支撑或执行异常。回台支撑表示实际重新产生支撑力，不承诺最终零速度静置。

当前滑移正则化在非零载荷下需要相对滑动产生切向力；这解释了为什么双侧法向力不能独自证明持稳。尚未隔离mimic总滑移中各个耦合与离散误差的贡献，不用一次数据作完整因果结论。

## 收据和时间语义

RobotJointObservation.requested_command保存用户实际请求，包括未指定的feedforward；既有command保留由真实入步动力学解析后的驱动。改变前馈力但保持其他三字段不变的真实反例先失败，修复后在计时推进前拒绝。重复观察、拒步重试不重复累计目标或持续时间。

统一事件以sample_time_s标记入步力，以commit_time_s标记接受末态。全部原PairLoad分量、施力点、局部材料点、摩擦力矩和law类型保留；查询不会再积分。机器人在所有事件材料检查与分配成功后才共同发布状态，错误注入与相同输入重试已有实际验证。

## 性能：有局部收益，没有整体加速结论

C2保持576个完整公开帧与全部非墙钟计数逐步一致。自由运动W128暖态公开step+geometry中位耗时由405.530ms降为260.092ms，约1.56倍；但受载W128由1045.979ms升为1671.171ms，接触出生W128由1123.463ms升为1913.593ms。其余档位也记录在详细报告中。

这些是两个时间段的实际墙钟快照；无跨世界过滤行的W1也变慢，不能仅据这些数据把差异都归因于本次改动。原受载几何仍占主要成本。未增加额外重跑来挑选更好分数，也未声称比Newton整体更快。

后续按通用框架推进：

1. **优先功能：持续切向接触。** 先以箱/球/有限面/机器人指面及刚柔材料点建立静持、起滑、换面、退出重入的独立案例；确认材料身份与法向旋转后，再选择可校准的静/动摩擦状态，避免只加大当前案例夹力。
2. **事件与求解共享状态。** 当前pair episode可复用，但site没有跨步身份；新摩擦状态必须绑定真实材料地址，并保留拒步回滚和同输入重试，不能把事件观察器本身当求解器。
3. **性能：同场定位受载窄相。** 将真实受载几何重建、近点计算和HOST复核分开计量，保完整公开输出和新旧同输入对照；本批只证明过滤复用机制，不提前承诺新加速。

一般机器人GPU动力学、连续/自接触、柔性与机器人统一持续响应、软布递交，以及Newton其他功能族仍按总体路线分别验收。
