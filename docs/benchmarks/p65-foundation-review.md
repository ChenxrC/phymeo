## Important 1：完整三维距离掩盖唯一最近点

- 位置：`geometry/surface_features.py` 的两种 closest 查询，在候选选择时比较包含巨大共同法向分量的距离。
- 反例：单位直角三角形与点 `(.5,2,1e10)` 错选 `(.5,0,0)`，正确点为 `(0,1,0)`；x向单位段与 `(.5,2,1e8)→(.5,3,1e8)` 错选第一段端点，正确参数为 `.5`。有限、非退化、唯一极小值，不属于已声明不支持范围。
- 裁定：必须修复，不能登记成允许错误成功的精度遗留。
- 修复：比较去掉共同垂直分量的面内/线内距离；返回前独立认证原始 FP64 输入与实际世界候选点的凸 KKT 不等式。认证使用精确有理数乘加，误差预算为最长特征边平方的 `1e-12`，不随法向间距扩大。认证不生成或替换几何答案；不可认证则 `SolverFailure`。
- 证据：两项解析反例先失败，修复后通过；额外旋转大间距测试要求已知正确点或明确最优性拒绝，正常解析、随机凸最优性、变换、尺度与退化回归保持。
- 代价：每次几何查询增加主机认证开销；极端尺度或世界坐标舍入可能明确拒绝，后续完整碰撞器必须处理这种失败，不能跳过碰撞对。

## Important 2：响应预测通过，但实际候选状态错误

- 位置：`constraints/contact_impulse.py` 原本在最终 response 审计后直接返回 `graph.apply_impulses`；候选验证仅检查状态族/构型，没有检查真正的候选速度或动能。
- 反例：实际 tyx 节点速度 `(10000,-.03,0)`、逆质量1、平面法向y、μ=.3。预测切向速度约9999.991，实际 FP32 更新后为9999.9912109375，误差约`2.1094e-4m/s`超预设`2e-5m/s`；预测/实际动能变化也不符。初速度1e8时小切向更新完全消失仍曾被接受。
- 裁定：这是 phymeo 验收遗漏，FP32正常舍入不是 tyx 算术实现错误。必须拒绝不满足物理合同的候选；不得放宽阈值、CPU替换状态或只修改报告值。
- 修复：新增公开 `PointCandidateAudit`，粒子/软体、刚体和机器人端口从实际候选计算 FP64 验证用作用点速度及全域动能差。重心端口映射速度，整个状态域能量只计一次。tyx数学响应/候选仍真实执行，FP64验证只接受或拒绝。
- 多域图在每一域独立核对初速、候选速度与实际响应，并检查候选动能差与该域冲量做功；随后再次检查全图速度、能量与接触定律。不能仅看相对速度：两个域相同的错误变化可能抵消。候选全留在局部，最后一域失败也不公开部分结果。
- 能量差采用差值乘均值，避免相减两个巨大平方值。验证包含未挂接节点/自由度的能量，不只统计接触点。
- 证据：实际 tyx 的1e4与1e8反例先失败，修复后拒绝且工作区/端口快照不变；新增1e2速度下能量敏感例、两域同向错误抵消反例（先失败）、隐藏节点能量、重复重心/软体节点能量只计一次、旋转刚体惯量、缺失审计扩展拒绝。
- 接入规则：既有 PointPort 瞬时查询/交换 API 不强制新扩展；调用认证的联合接触求解器时必须提供 `candidate_audit(state)` 返回 `PointCandidateAudit`。无该能力时明确拒绝，不能自称物理认证成功。
- 代价：增加逐域查询、候选复制及独立 FP64 运动学/质量审计；高速度或条件数场景可能超出现有 FP32范围。相关边界见 [NUM-004](../legacy-issues/NUM-004-candidate-representability.md)，已有依赖能力需求见 [TYX-001](../../tyx_flaw/TYX-001-fp64-compute.md)。
