# G4 闭网格认证复用

2026-11-04，工作区开始复用已经成功认证的闭网格。112 面的稳定网格在真实 CUDA W1 上执行原三帧，暖态中位数由 6.237 s 降至 0.751 s。每帧改变绝对材料坐标的另一组从 6.112 s 变为 6.288 s。两组都逐帧核对相同的完整公开输出，记录中的物理子步数均为零。[原始 G4 成本与热点](p65-g4-world-geometry.md) · [缓存实现](../../src/phymeo/geometry/_validated_mesh_cache.py)

## 复用边界

每个碰撞工作区为每个世界内的形状保留至多一份认证记录。依据实际绑定的形状实例、原始 FP64 顶点的形状与字节、全部终点字节，以及刚体运动的起止枢轴、轴向和角度匹配。不同数组对象可以命中。运动或形状改变时先移除旧条目，再执行原连接、正体积和面间自交认证。成功项保存只读数值、材料点与面图表，失败项每次都会重验。位置、距离、真实接触与两侧材料见证仍按当前搭配形状和运动计算。关闭工作区或在设备故障后重建时释放旧认证记录。[公开入口接缝](../../src/phymeo/geometry/collision_pipeline.py) · [失效、非法网格和故障测试](../../tests/collision/test_validated_mesh_cache.py)

原公开入口用两个对象不同但顶点字节相同的运动连续查询，确实认证了两次。加入缓存后，重复材料只认证一次，搭配凸体改变仍会得到新的接触结论。专项通过 5 个 HOST 和 3 个实际 CUDA 用例。运动端点、枢轴、轴/角、材料坐标、形状修订与连接变化均有失效断言。非法折叠和注入的数值失败可重试。容量拒绝保留上一帧，邻居可继续命中自己的认证。已有网格–凸体、网格–网格和网格–球/胶囊消费者通过 59 个 HOST 用例及一组真实 CUDA 矩阵。

## 原三帧的前后对照

对照使用基线 ac3aa7f 与优化代码 1c6c216。每种配置新建工作区，测一个冷帧，然后连续测三轮原三帧序列。表中单位为 ms，取三个完整暖序列的中位数。对八组配置分别复核世界键、形状/顶点数、配对槽、全部帧的完整输出 SHA-256 与材料观测，W2 的容量拒绝和邻居恢复结果相同。物理注册、几何精度、帧序列和输出字段一致。[原尺度入口](../../scripts/benchmark_g4_world_geometry.py)

首次调用仍须认证。112 面 CUDA W1 的首个冷帧为 2,393.415 / 2,382.515 ms。随后的九个暖查询中，每世界命中九次。W4 的总计为 4 次认证、36 次命中。W1 中位三帧的结果阶段由 6,228.970 降至 744.618 ms。该序列的 342 次底层 CUDA 核、1,556,784 B H2D 和 688,284 B D2H 在前后记录中都相同。W4 相应也均为 1,350 次核、6,227,136 B H2D、2,753,136 B D2H。此项收益来自重复 HOST 几何准备的减少，工作区保存的 HOST 几何对象未单独量测进程内存峰值。

## 每个输入都要重新认证

将 112 面网格和凸体一起沿 z 轴平移。冷帧平移 3/32 m，暖序列三帧依次平移 0、+1/32 和 −1/32 m。网格的原始材料坐标持续变化，双方的相对几何和真实接触合同保持一致。改动前的三个完整序列为 6.112、6.088、6.338 s，改动后为 6.396、6.277、6.288 s。这一轮 W1 CUDA 中位数回退 2.9%。含冷帧共 10 次认证、0 次命中。逐帧完整输出各自与改动前同一平移输入匹配。[最坏构型脚本](../../scripts/benchmark_changed_mesh.py)

本机原始证据位于 `artifacts/p65-night-g4-mesh-cache-20261104-01/`。固定材料的两种网格和两种后端在 `cache-mesh{28,112}-{host,cuda}/`，前后字段核对和原始报告哈希在 `stable-comparison.json`。逐帧真异位的旧版和优化后记录在 `cache-changed-before/`、`cache-changed-after/`。

```powershell
python scripts/benchmark_changed_mesh.py --backend cuda --cache-root artifacts/g4-cache --out artifacts/changed-after.json --expected artifacts/changed-before.json
```
