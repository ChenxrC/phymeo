# G4 单世界几何规模和重复世界的成本

2026-11-04，在 RTX 4060 Laptop GPU（驱动 566.07）上，以 3ad7b673 的 WorldCollisionWorkspace 完成 12 个 HOST、16 个实际 CUDA 配置。测量工具提交为 027b35a0。复用 M3 六组原始几何，以及归档中的 HOST、CUDA 逐帧候选数。原构造器与 M3 提交 1abf7a9 相同，另核过 RR05 几何及基准变体。球场景各有一个静止帧，布面和闭网格各有三个不同运动帧。下列时间是几何查询时间，物理子步数为零。[原 M3 记录](p65-collision-m3-spatial.md) · [构型与校核](../../tests/scale/g4_geometry_cases.py) · [测量脚本](../../scripts/benchmark_g4_world_geometry.py)

## 隔离与命中

每个世界复用原局部形状、面和顶点 ID，以 37、5、92、16 为注册顺序。核对每个返回键后，只归一化世界标签和 backend 名称，对完整公开配对、包围盒、时间区间、材料见证及可选诊断取 SHA-256。所有实测配置均与当前 W1 完全一致，共同执行的 HOST/CUDA 帧也逐项匹配。归档 M3 成本文件记录每帧候选数，新的 W1 分区结果提供完整输出对照。

| 每世界几何 | 完整配对槽 | 各帧候选数 | 各帧真实命中数 |
| --- | ---: | --- | --- |
| 65 个稀疏球 | 2,080 | 0 | 0 |
| 34 个密集球 | 561 | 561 | 561 |
| 18 面布与球 | 171 | 2、2、2 | 2、2、2 |
| 72 面布与球 | 2,628 | 4、4、4 | 3、3、3 |
| 28 或 112 面的 U 形闭网格与凸体 | 1 | 1、1、1 | 1、1、0 |

球对以半径和球心距离校核。球从整张布的上方扫到下方，因此球心横向投影到各有限三角形的距离，决定本帧能否碰到该面。两种 U 形网格的第一帧首次接触区间都覆盖 8/11。第二帧起点已包含凸体，边界仍相距 0.25 m。第三帧保持分离。有效材料地址从原形状 ID、顶点和仿射路径重建，网格还检查起点、终点和首次接触时的双侧交点。

W2 的正候选场景中，把一个世界的容量设为所需值减一，目标世界保留旧结果。邻居采用另一条可用原始帧，仍返回与自己独立 W1 相同的见证。恢复容量后两者均重现各自结果。零候选的稀疏场景在容量 0 时可接受。W4 的 65 球与 72 面布加球分别需要 260 与 292 个形状，超过现有 256 形状上限，两种后端均在建表前跳过这两个配置。

## 端到端成本

各配置新建模型和工作区。冷查询为该工作区第一次查询原帧 0，可能包含延迟初始化与编译缓存读取。暖成本是三次完整原帧序列时长的中位数。世界复制、构造、输出稽核及计数采集在计时外，公开 detect 调用必需的包络、设备同步、读回及逐行发布都计入。网格以 HOST W1 作精度对照，W2/W4 在 CUDA 上实测。

| 场景 | W1 HOST / CUDA（ms） | W2 HOST / CUDA（ms） | W4 HOST / CUDA（ms） |
| --- | ---: | ---: | ---: |
| 稀疏 65 球 | 20.664 / 8.636 | 42.012 / 17.516 | 超形状上限 |
| 密集 34 球 | 78.602 / 75.815 | 175.457 / 151.495 | 400.610 / 304.838 |
| 18 面布 | 25.127 / 21.788 | 53.259 / 42.344 | 98.989 / 86.492 |
| 72 面布 | 79.472 / 73.974 | 155.364 / 158.324 | 超形状上限 |
| 28 面网格 | 1,422.597 / 1,685.103 | — / 3,012.896 | — / 5,813.012 |
| 112 面网格 | 6,105.452 / 6,236.825 | — / 12,493.541 | — / 25,292.448 |

W1 稀疏球首次 CUDA 查询为 692.531 ms。同配置暖中位样本为 8.636 ms，包络 1.762 ms，宽相 0.403 ms，生成和发布配对结果 6.420 ms。即使候选数为零，仍须返回 2,080 行诊断。W4 密集球暖态 304.838 ms，同一中位样本的结果阶段占 300.447 ms。narrow_ns 包含候选窄相及完整逐行发布。

112 面 W1 首个 CUDA 查询为 2,393.415 ms，其中设备引擎设置占 262.454 ms。三帧暖中位 6,236.825 ms，包络 4.814 ms、宽相 2.981 ms、结果阶段 6,228.970 ms。该序列底层记录 342 次实际 CUDA 核、1,556,784 B H2D 和 688,284 B D2H，其中宽相工作区计 6 次核。W4 同样三帧有 1,350 次核，H2D 为 6,227,136 B，D2H 为 2,753,136 B。旧 M3 112 面 CUDA W1 穷举三帧为 15,707.894 ms。两次测量分属不同产品版本。

## 已定位的热点

另在 W1 的 112 面第 0 帧对一次暖查询开启 cProfile。输出哈希与正式帧一致，前缀为 35da227be77171ab。剖析时长 6.753 s，与无剖析中位周期中同一帧的 2.102 s 分开保存。prepared_mesh 重建 ClosedMesh 的累积时间为 5.916 s，其中 558 次静态三角面对自交验证的 sample 累积 5.519 s。随后网格–凸体的 _pair 为 0.519 s。这些函数的累积时间存在嵌套。[单帧剖析](../../scripts/profile_g4_mesh.py)

三个原帧的网格材料坐标与运动完全相同，变化在搭配的凸体。下一项只验证工作区内复用已成功准备的闭网格。缓存必须绑定所属形状与完整运动。更换坐标、材料拓扑、版本或运动时重新认证，再以相同完整输出和失效负控衡量收益。

本机原始数据位于 `artifacts/p65-night-g4-scale-20261104-01/`。球与布为 `g4-small-host/`、`g4-small-cuda-version/`，网格为 `g4-mesh{28,112}-{host,cuda}/`，单帧剖析为 `g4-profile-mesh112/`。逐样本保存冷暖墙钟、阶段时间、工作区与底层 TYX 计数、候选/命中、材料示例和容量重试。CUDA 首个启动尝试在读取发行包名时退出，更正为安装环境的 tyx-compute 后完成全部配置。设备快照是整卡可用显存，本进程峰值未采样。
