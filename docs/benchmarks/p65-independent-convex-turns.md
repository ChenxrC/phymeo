# 两侧独立转动的有限物体，以及转动物体与变形布面

公共碰撞查询接受各刚体自己的一条固定世界轴、带符号转角和线性移动的枢轴。每侧至多转一周。这批把已有的凸体支持面方法用于两个独立转动的有限物体，以及不同节点各走仿射路径的整张布面。优先使用原有的专用解析处理。对于完整凸包接触斑的显式请求，仍保留相应的支持范围。[公开分派](../../src/phymeo/geometry/collision_pipeline.py) · [跨步几何](../../src/phymeo/geometry/_convex_support_path.py)

## 独立轨迹

| 控制 | 独立预期 | 实际判定 |
| --- | --- | --- |
| 两根垂直且共同平移的枢轴，两球面沿不同轨道各转半周 | 相对中心距为 √2 × abs(cos πt)，半径和为 5/16 m。首触 t=0.42907742667662085。两端均留有 1.10171356237 m 净距。 | 给出的归一化时刻区间为 [0.4290733337402344, 0.4290809631347656]，宽约 7.63×10⁻⁶。查询访问 38 个时间格、25 个静态姿态。登记换序和整体转框均给出同一区间。 |
| 两条独立的胶囊轨道 | 在首次接近段，两轴线段距离为 √2 × (cos πt − 1/4)；真实最先相遇的材料点分别在两条胶囊的正端帽。 | 两方向登记都覆盖解析时刻，端帽材料地址正确。实际 CUDA 宽相也保留同一对、同一时刻和两侧材料点。 |
| 转动椭球与三节点独立移动的有限布面 | 半轴为 (1/2,1/8,1/8) m，中心高 3/8 m。布面保持在同一平面，椭球下支撑首次到达时 sin²(πt)=8/15。 | 两个登记顺序均命中，布面的三个非零权重可从物理采样时刻的原始节点重建世界点。 |
| 倾倒的箱体与绕竖轴转动的有限箱形支座，或变形布面 | 相对竖直净距为 3/8 − sin(πt)/2 − cos(πt)/8，在第一象限取首根。 | 三个箱–箱或箱–布控制均覆盖解析首根。归一化时刻区间宽度小于 1/1024，双方端点均分离。 |

在圆轨道的近失留出中，平移位移垂直于整个相对中心运动，最小表面净空为 √(1/8)−5/16 m。两侧扫掠包围盒相交，时间格仍能证明全段分离。另有一次孤立切触控制；预算内不能严格判定的格保留未决，调用者可以区分它和已证实的净空。[独立轴和布面控制](../../tests/collision/test_independent_curved_turns.py) · [箱体和胶囊控制](../../tests/collision/test_turning_polyhedra_capsules.py)

每个时间格在中点夹住真实旋后顶点和材料坐标架。枢轴平移用相同时间端点比较，格内转动以枢轴到材料点的半径乘角位移夹住。完整固定分离方向能够排除整格接触；发现有余量的穿入样本时，要连同此前尚未排除的最早时间一起给出括区。首触材料见证有自己的采样时刻；静态 GJK/支持多面体读数和姿态误差各自计量。过大转角、精度不足、无可用见证或工作量上限都有明确边界。原有凹网格、闭体内部、持久多点压力分别由各自模块处理。

父侧两组新 HOST 控制分别为 7 项和 5 项，两个真实 CUDA 宽相专项分别为 1 项。候选筛选在指定后端执行，支持方向、时间格及材料见证在 HOST 复核。原始缺失、成功样本和逐项退出码见 `artifacts/p65-20261104-0800/validation` 下的 `independent-rotations-*` 与 `turning-polyhedra-*`。
