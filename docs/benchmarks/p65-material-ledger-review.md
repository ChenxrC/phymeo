## Important：完整设备输出的精度合同

原实现只检查逐边 frame 是否恰为 FP32 提升到 FP64。独立实际 interpret 探针将 alpha、预测速度、动态预测位置、候选速度各移动一个 FP64 ULP，错误证据仍在物理容差内，因而被接受。这违背设备记录合同，即使物理残差仍很小也不能接受。

新增10个实际后端回归，覆盖普通材料与 None/空边路径；先得到10个 DID NOT RAISE。最小修复对 alpha、最终乘子、预测/候选速度、动态预测/最终位置执行严格 FP32 提升检查。固定点位置仍允许原参与者声明的 FP64 host 恢复，不误拒非 FP32 固定坐标。原逐边门禁、物理容差、积分器和 native 候选均不变。
