# 持压的材料点越过共享三角边

1 kg 材料点在可平移的 2 kg 三角片上滑动，法向载荷保持 2 N。在 1/8 s 的一个实际粒子步内，点于步长的 **64/125（51.2%）** 处穿过材料边，两侧材料站点在世界坐标 (0.04925, 0.023625, 0) m 交接。旧面承担 −0.125 J 切向功，新面承担 −0.119140625 J。该步结束后保有原来的弹簧储能与累计塑性历史。[水平面原始收据](../../artifacts/p65-continuous-material-seam-20261104-01/pytest-host/test_loaded_sliding_crossing_s0/material-seam-loaded.json) · [旋转坐标与倒序注册](../../artifacts/p65-continuous-material-seam-20261104-01/pytest-host/test_loaded_sliding_crossing_s1/material-seam-loaded.json)

## 运动和作用点

`TranslatingMaterialPatch` 用一个材料体、有限三角面的材料节点 ID 和相对于片质心的坐标建模。所有面必须共面、绕向相同并使用同一材料律。片只有一个三维平移坐标。传入有限质量时，点与片由同一真实粒子步分别响应外载和接触力。传入 `patch_mass_kg=None` 可固定片。图上的节点保存作用位置和分布冲量，始终随片平移。自由变形节点使用原可动面入口，其持续带载跨面仍未验证。[材料图与拓扑](../../src/phymeo/geometry/material_seam.py) · [点和片的物理步](../../src/phymeo/solvers/material_seam.py) · [原可变形面](p65-moving-material-stiction.md)

点与片在接触法向和切向的相对逆质量均为 `1/m_point + 1/m_patch`。法向层按入步间隙和速度取力，弹性静持/滑动使用既有的隐式切向弹簧和库仑返回映射。对均质平移片，作用于这两个平移自由度的合力与三角面编号无关。速度更新后，以实际接受的两侧端点确定此积分器的仿射漂移路径。步内恒定的牵引在经过的每一面都有独立的作用区间，交界处沿用同一材料体的切向坐标系。[共用切向返回映射](../../src/phymeo/solvers/_material_stick_law.py)

将相对运动投影到材料片平面后，三个重心权重对步分数都是仿射函数。程序以输入浮点坐标的有理数表示裁出各三角面的作用区间。一次转面要求两段恰好相接，且交点两侧的非零权重对应同两个材料节点并且数值相等。节点在区间 `[a,b]` 上的冲量为 `−h (b−a) (wᵢ(a)+wᵢ(b)) F/2`。总力 `F` 作用于点，片节点的功来自同一段内的片平移。程序分别记录两个应用点、节点冲量、两侧功和切向相对功。片缺少转动自由度，因此另列抵消片上分布接触力矩所需的角冲量，参考点为片质心。[分段、动量和功的独立试验](../../tests/collision/test_material_seam.py)

## 水平滑动的分段收据

法向层宽度为 1/16 m，间隙 1/32 m，法向刚度 64 N/m，得到 2 N 正压力。切向弹簧为 16 N/m，静、动摩擦系数为 0.5、0.25。正式越边前已有一次真实滑动，累计塑性滑移 0.46875 m，弹性位移 0.03125 m。

交界只在节点 17、31 上各占 1/2。整个跨边步的切向力为 −0.5 N。点的横向速度减少 0.0625 m/s，片增加 0.03125 m/s，两者的切向动量变化相消。累计不可逆滑移增至 0.95703125 m，弹簧储能保持 0.0078125 J。此步绕片质心的姿态约束角冲量为 (0, +0.00146484375, 0) N·m·s。点与片之间还隔有 1/32 m，切力的有限间隙力偶与片的姿态约束分别解释。

## 其他验收与范围

- 同一片上的静持跨边在半步处换面，弹簧储能由 1/512 J 增到 1/128 J，永久滑移仍为零，两面各承担 −1/256 J 切向功。另从已接受的滑动状态施加反向外载，在同一材料历史中反向跨回左面，事件位于该步的 61/128 处。
- 两面空间相邻但共享边使用不同节点 ID 时，带压穿越会拒绝。先抬离法向层、清空旧材料历史，然后在离层状态横越，即可在另一面建立新历史。完全叠面的两个独立三角形、恰落在边或顶点的受载端点、沿边、途经公共顶点、一步跨越多边以及翻面均有明确拒绝。失败的粒子候选保留原检查点，使用原输入可重放相同的分段与历史。
- 本入口处理一个命名材料点相对同质平移片的离散接触，只接受一次漂移中的一个严格内点转面。点穿过片平面、同时转面并卸离、片内变形、片转动及两面法向或材料不同的跨缝运输均不在该合同内。每个实际物理步只产生一份恒定牵引，程序按真实作用区间积分。区间边界没有额外求解或隐含子步。
- HOST 专项及受影响的固定/可动面回归共 21 项通过，TYX interpret 和 CUDA 各 3 项通过。新入口的 CUDA 例程执行两个实际粒子步与两次法向层核，法向层上传 13,312 B，下载 5,120 B。材料拓扑、事件、权重、切向本构和功审计在 HOST。本窗口未做 Newton 同本构的动力学对照。[真实 CUDA 轨迹](../../artifacts/p65-continuous-material-seam-20261104-01/pytest-cuda/test_real_particle_steps_and_n0/material-seam-device.json)
