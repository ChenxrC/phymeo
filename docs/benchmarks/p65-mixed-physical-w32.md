## 物理输出与时钟

每个四世界单元包含一个真实受力的有限布面–棱柱连杆、一个自由球、一对分离的布面–连杆和一条延迟一个子步的滑轨。W32 复制八个单元，沿用非连续键和逐单元有差别的控制及外力。每窗从相同的物理状态、驱动历史和初始控制开始，以 h=1/256 s 连续推进 4 个物理步。首步八个受力世界各为 2 N，分离的八个均为 0 N。四步的实际受力站点总量依次为 16、11、9、9，末步八个法向合力为 1.966251–1.972708 N。

三个非重叠进程各有一个首窗、两个预热窗、七个计时窗。每窗两套实现交替先后。时钟包括控制和外载提交、物理求解、同步、接受状态、完整材料审计与检查点读取。每窗复位、状态比较、SHA 及设备计数读取在时钟外。七个正式窗含 28 个物理步，即每种布局每轮 896 个已接受的世界子步。三轮所有 30 个窗的两份完整轨迹均与已通过的 W32 CUDA 资格收据相等，轨迹 SHA256 为 `f1b988bc674fe443d4dad0963c21be9e8b93244e7ffc50cf0fac30cc8ba091ba`。该资格另逐步对照原 HOST 求解器，最大位置差 3.09×10⁻¹¹ m、速度差 3.90×10⁻⁹ m/s、力差 2.04×10⁻⁷ N。[物理输入及独立参照](../../tests/scale/mixed_physical_cases.py) · [W32 资格](../../artifacts/p65-20261104-panda-batch/temp-loaded32-qual/test_group_matches_all_origina0/mixed-scale-qualification.json)

合组每个物理步执行 1 个运动核、6 个材料核，每轮合计 196 次真实 CUDA 提交。逐世界路径每轮为 3,136 次。两套布局的每轮 D2H 都是 155,904 B。H2D 合组为 163,072 B，逐世界为 162,848 B，差额来自持有控制的上传。两边稳态均未新增设备工作区分配。HOST 仍要计算材料几何、双侧地址、路径验收并发布完整审计。本次时间只支持上述应用级比较，没有把各 HOST 算子与设备内核分别计时。
