# 可动有限材料面的静持、转滑与共享边

`MovingMaterialStickSlipStepper` 可同时推进上侧自由顶点和下侧三角面的三个节点。两侧接受同一粒子步，几何由各自实际位置决定。面可整体平移，在保持面不退化的子步中发生面内旋转、伸缩或剪切。本入口允许各面节点具有不同质量。原固定面入口仍使用原来的固定支撑合同。[可动材料步](../../src/phymeo/solvers/deformable_moving_stiction.py) · [原固定面静持](p65-material-static-hold.md)

## 两侧的质量、功和能量

设 `wᵢ` 是入步最近特征给出的三个面材料权重，`b = (1, −w₀, −w₁, −w₂)`。以同一地址插值材料速度，切向有效逆质量为 `A = 1/m_v + Σwᵢ²/mᵢ`。在法向层、外力与重力作用后的自由预测中取切向相对位移 `d_free`，用 `d = d_free + h² A f` 和原切向弹簧返回映射求解。顶点受力 `f`，三个面节点分别承受 `−wᵢ f`。每个节点的候选速度和位移通过校验后才提交材料历史。

相对功为 `f · (Δx_v − ΣwᵢΔxᵢ)`，报告同时保存顶点和三个面节点各自的功。增量由弹性、塑性及隐式积分的离散耗散分别核对。内力的线冲量总和为零。有限开距下，切力施加在两侧不同的材料点，产生 `(x_v − Σwᵢxᵢ) × f` 力偶。其角冲量按真实初末轨道角动量与外载角冲量独立检验。

## 面转动与有限边界

在同一材料面上，先按入步坐标下的真实相对位移更新弹簧，再用面内仿射变形梯度的极分解旋转把弹簧运输到末态。换材料顶点编号不改变同一仿射映射。刚转保持弹簧长度。在任意形变下，极分解定义了此离散模型采用的面内材料旋转。

每个受载子步按节点线性插值。用二次面积函数在全时段内的最小值检查面不退化及顶点投影始终严格位于三角形内部，正间隙还须保持在初始一侧。面法向发生倾倒、共享自由度的多个受载站点、EE、到达有限边界或持续受压时转面均拒绝并保留原检查点。卸离法向作用层并在清空历史后，可以越过共同边并从另一面开始独立的静持历史。对带载的邻面切换仍缺少经验证的材料锚点运输与功分配。

## 实测窗口

法向初始开距 1/32 m，作用宽度 1/16 m，刚度 64 N/m，得到 2 N 法向力。窗口用外部法向载荷维持此压力。两侧节点都为正质量，切向位移按各自受到的合力积分。切向刚度 256 N/m，静、动摩擦系数分别为 0.5、0.25，步长 1/16 s。
