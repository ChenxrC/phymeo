## 使用和适用域

同一个 `ContactSceneBuilder` 可重复 `add_urdf`，注册两台或更多普通固定根或现有 mimic 机械图。`build(backend="host")` 编译为一个事务。调用仍为 `scene.step(dt_s, actions={id: RobotCommand(...)}, external=scene.inputs())`。每台必须有一条当前命令，未知、缺失、越限目标或超过额定驱动力的请求拒绝；不自动沿用上一台或上一步命令。

本首片沿用原 `RobotContactMaterial` 和原几何求值，支持已注册的球/有限胶囊/箱机器人碰撞体、自由球/箱和有限固定支撑。根与连杆、所有实际形状名/材料点和各台独立关节顺序保留。机器人之间必须显式 `pair(a,b,None)`；缺声明和尝试启用直接机器人接触均拒绝。没有隐藏排除，也没有把多台装成一台虚拟树。仍不包含机器人自碰撞、CCD、浮根、柔体、多 world、机器人 CUDA/interpret 或多机器人耦合切向历史。相关模式须另立物理与事务验收。

`scene.inputs()` 的 COM 外力/力矩给自由体和固定支撑；关节 feedforward 在各自 `RobotCommand` 内，和 PD 一起限幅。mimic 在独立坐标中用 `PᵀMP`、`Pᵀbias` 和 `Pᵀcontact` 更新，同一步仍读全部物理轴及每行原关系的真实反力，不重新开发或近似 mimic 模型。

`observe_scene()` 在同锁内取 `RobotSceneObservation` 与完整 `CollisionModel/CollisionMotion`。`robots[(world,id)]` 读各台 q/v、入步状态、驱动力、接触广义力、link COM 扳手、根反力、原始 request 与 resolved command；mimic 另有原每行反力。`shape_key(robot_id,link_name,collision_name)` 重解析当前场景的具名碰撞材料，两个资产相同的模型局部数字 ID 不冲突。

## 一个真实物理步

所有机器人和刚体从同一个入步状态采样。每个机器人 sampler 只贡献该机器人–刚体的实体/指面载荷。刚体–刚体采样全场只运行一次；不能将整个单机器人场景循环运行 N 次，否则共享桌面、自由物体会重复受力或提前移动。

各机器人以自己的完整质量/偏置和已限幅驱动求一个候选；所有自由体用合计接触与外载求一次真实自由刚体候选。只有全部限位、数值、末态几何、拥有的输出副本与 events 均完成后，才共同发布两类状态、时间、载荷和几何。准备、积分、末态几何或事件阶段失败均保留原发布值，合法重试从同一原态开始。例程不直接写 q、速度、球位置或接触力。

默认接触是入步采样的顺应力；这不是多机器人隐式接触求解，也不声称段内防穿透或任意静态抓持稳定。

## 执行前冻结的 A01–A06

- A01：两个 2 kg 同轴滑轨、1 kg 自由球，半径均为 1/16 m，双方 1 mm 压入，k=2000 N/m、无阻尼/摩擦/重力/驱动。真实法向各 2 N，1 ms 后两轴速度 −/+0.001 m/s、位移 −/+1 µm，球速度为零。检查两条真实载荷、物理 owner、同刻几何与动量。
- A02：左右质量 2/4 kg，压入 1.5/0.5 mm，真实力 +3/−1 N。球加速度 +2 m/s²，两轴 −1.5/+0.25 m/s²。交换注册次序，以及转到 (0.6,0,0.8) 轴并平移到 (3,−2,0.75) m，保留全部独立数值门。
- A03：两机器人远离，1 kg 球压入有限箱台 1 mm。全场仍只有一次 2 N 和相反台面反力；横向移出台边的控制无假支撑。
- A04：普通 2 kg 滑轨与三个 1 kg 物理轴的多行 mimic，共同夹住上述球。P=(1,1,−1)，偏移为 (0,3,−2) mm；真实右工具属于从动轴。初始各 2 N，以额定内 +2/−2 N 驱动平衡 32 个 1/8192 s 步，随后 −128/+128 N 撤退 8 个 1/256 s 步。核每原轴冲量、mimic 反力/零约束功、自由球冲量及末四步真实分离。独立动能门用每物理轴 1 kg 的离散更新公式，不把半隐式步当连续能量守恒。
- A05：第二机器人候选跨限、缺/未知动作、非法目标/力帽，以及两候选完成后的事件 stage 异常；两台、刚体、载荷、事件、时间和几何全部保留。合法重试等同独立重建。
- A06：两个资产相同局部 shape ID、三台机器人、拥有快照/输入副本、双 build 隔离，以及设备/直接机器人接触/新历史摩擦明确拒绝。

以上输入、力帽与容差在实现和首次对应执行前写入专项。A04 是预载保持与驱动撤退，不是从桌面获取或完整抓放；两个独立树通过同一个真实自由体交换载荷。
