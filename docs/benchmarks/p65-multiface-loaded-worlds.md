# 变化布姿态下的多面受载世界剖析

在 RTX 4060 Laptop GPU 上，四个独立世界各有八张持续承载的面时，四个真实物理步普通窗的中位墙钟为 **175.73 ms**。同一档带计时窗中，HOST 单姿态最近特征占 **48.25%**，每窗平均 85.91 ms；D2H API 占 **1.13%**，平均 2.00 ms。每世界两张受载面时，这两项分别占 28.23% 与 1.92%。这些比例来自五个计时窗累加后的排他主机墙钟。

## 模型与比较合同

每世界是一张 1 m × 0.25 m 的连通布条，分别剖成 2 个三角面（4 个共享节点）或 8 个三角面（10 个共享节点）。同一世界的两档参考面积均为 0.25 m²，材料面密度及总质量相同。所有边有距离弹性，一根半径 1/16 m 的有限胶囊由有质量的移动关节承载。冻结的初始非匀速节点场使布条倾转和形变，每步对布节点、关节施加同一套随步号变化的输入。每窗从同一检查点推进四步，步长 1/256 s。[独立场景、材料地址、力和形变核验](../../tests/scale/multiface_load_cases.py)

现有 `TrianglePrismSurface` 每次仅登记三个节点。连通布条可在 `CompliantClothContactProgram` 中登记多张面。将同一真实多面程序送进 `TyxWorldContactBatch` 时，两档均被构造器拒绝，原始原因是其每世界只支持单个三节点面与单胶囊。这里使用通用程序，世界内各面材料站点通过同一 `TyxNormalLayer` 批量求力，世界间由 HOST 按子步轮转。各真实世界独立完整推进四步构成对照。[现有跨世界适配器的边界](../../src/phymeo/backends/_world_contact_sites.py) · [通用装配](../../src/phymeo/solvers/cloth_link_contact.py)

每档在独立进程中使用同一 CUDA runtime 和工作缓冲。先完成逐世界参考窗及一次普通轮转预热，再做五对「普通 / 插桩」窗，每对交替顺序。W1×2 和 W4×2 从普通窗开始，另两档从插桩窗开始。窗口包含全部实际状态推进、原有设备同步和公开报告的返回；校验哈希、数据序列化和独立力/运动学验算均在窗外。每世界每步的状态、历史、诊断、子步快照、数组类型与字节及设备计数逐项相等。哈希仅把 `SceneSubstepReport.timings` 每个已存在键的计时值置零；每窗所有原始计时值另存。资格首轮保留了 33 处时钟差异，独立测试确认新增时钟键或改变诊断会改变签名。[驱动](../../scripts/profile_multiface_worlds.py) · [检查合同](../../tests/scale/test_multiface_load_profile.py)

设备相关四行是 API 调用的主机耗时，实际传输和等待可能包含在其中。纯 GPU 核运行时间本批未测。所有排他阶段及其和、实际调用数均在收据中。W4×8 每窗实际有 384 次单姿态最近特征和 16 次整体路径检查。

W4×8 的 128 个受载面–中点样本各自读出 **0.12699–0.14134 N** 法向力。各面从第一个中点到后续中点的最大观测变化，质心移动 **0.261–0.609 mm**，几何单位法向 L2 变化 **0.000601–0.001820**，面积变化 **3.50×10⁻⁷–2.69×10⁻⁶ m²**。每个站点均按原节点与重心权重复原位置，并独立核对参考面积、间隙和相对速度对应的法向力，以及布–连杆反力与关节广义力。可据收据检查单个实际受载面、节点和材料站点。
