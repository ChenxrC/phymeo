# 世界坐标射线与实际碰撞形状

`ph.raycast_scene(model, poses, origins_m, directions, world=..., near_m=..., far_m=...)` 既可从一个原点发射，也可为每束射线提供独立原点。返回每束最近的实际物理表面距离、形状索引和世界法线。距离为米。未命中为 +∞、−1、零向量。稳定索引映射到完整的 `CollisionKey`，其他世界的形状不遮挡该世界。相机和这个公共入口共用一套几何查询。

支持有限球和胶囊、两侧平面/三角片、无圆角凸包、闭合三角网格、四面体，以及按实际对角线三角化的有限地形。解析圆柱、圆锥和椭球使用自身尺寸和完整朝向（局部形状姿态加当前刚体姿态）。裁去入射根后仍可读到出射根；圆柱侧面的母线上可返回剪裁后的首个表面点。圆锥尖点没有唯一法线，返回零向量。[公共实现](../../src/phymeo/geometry/raycast.py) · [束起点、朝向、母线与有限地形验证](../../tests/collision/test_scene_raycast.py)

## 独立光束与 Newton 原生几何

四千一百七十一束射线的起点和方向均随行列变化，背景与三种定向曲面同时出现。Phymeo HOST 的公共射线接口和 Newton 1.7.0 CUDA `SensorCamera` 分别对同一组光束查询。所有形状编号和背景逐束相同，椭球、圆柱与圆锥分别命中 179、491、398 束。最大视线距离差为 43.24 µm，最大世界法线分量差小于 0.000693。两端都计算曲面求交，未用渲染截图派生深度。运行时相机、刚体会话及解析留出共 18 项 HOST 回归通过。[独立驱动](../../tests/reference_newton/robot/curved_ray_observation.py) · [CUDA 原始全帧](../../artifacts/p65-newton-night-20261105-01/curved-rays-gpu.json)

当前公有函数走 HOST FP64。两侧几何和归一化在不同精度下对轮廓擦边可能得出不同标签；这组光束没有发生标签差异。颜色、透明度和材质阴影不在此次测量内。
