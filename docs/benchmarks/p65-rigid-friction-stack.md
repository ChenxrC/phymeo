# 多刚体接触面的滑移和扭转

有摩擦的两个有限凸刚体可以使用现有 `CollisionLoadSystem` 施力，由双方真实速度确定切向滑移，力在接触层中面等量反向作用。面接触共用箱形工具–有限桌面的二阶面积求积，取样点各自保留两边的材料地址。每个刚体随后以自己的质量、惯量和实际合力矩推进。单个材料点的滑动摩擦可共同产生扭矩。现有接触层的系数是切向滑移系数，未引入 Newton 材料中的独立滚动或扭转摩擦系数。

## 叠放留出

固定底块、两个自由方块、两个有限接触面。两个边长 0.25 m 的单位质量活动块在重力下分别由 2 N / 1 N 的接触力支撑。顶块正向或负向自转、顶块平移及交换形状注册顺序分别执行。每次从同一校准压力下推进四个真实子步，步长 1/512 s。一个正常静置面的材料站为 12 个，转动和偏移后重新取当步的真实支撑域。

- 以 ±0.25 rad/s 自转，四角均在切向速度 0.0625 m/s 的线性区。正方形对中心的平均半径平方为 `2a²/3`，`a=0.125 m`。上表面的积分扭矩应为 ∓1/48 N·m，切向合力为零。两自由体实际感受到符号相反的扭矩。
- 以 0.5 m/s 平移，摩擦系数 0.5，1 N 正压力使顶块承受 −0.5 N，中间块承受 +0.5 N。两个自由体的动量改变分别从末速度读取。每步检查全部材料站的内部净力、力矩和滑移耗散。
- 首版 CUDA 在首步拒绝积分。单位正方形对称求积本应消去横轴力矩，逐项浮点累加却产生约 1.7×10⁻¹⁸ 至 3.5×10⁻¹⁸ N·m 的横轴尾差，这些数送入严格 FP32 四元数归一化时触发下溢判据。改为精确累加已表示的各项乘积和接触力矩后，完整原输入在真实 CUDA、interpret 上均通过，无需阈值裁切或更改积分器。原始分叉记录的 JSON 在序列化最后的 NumPy 步长时截断，已保留其中完整的入步位姿、力和力矩；独立的 CUDA 首次失败和复验均有完整运行收据。
