# 固定中心旋转的椭球与固定平面

公开 `detect` 在 HOST 上返回整段旋转的首次和末次相触。对半轴 (0.5, 0.25, 0.25) m、中心高 0.375 m 的椭球，绕 Y 轴正向或反向转 `float(π)` 都在归一化时刻约 0.2233498105 进入、0.7766501895 离开，两端净空均为 0.125 m。反向转动时切向支撑点镜像，交换形状注册顺序时两侧材料点互换、法向反转。[公共分派](../../src/phymeo/geometry/_curved_solids.py) · [专项测试](../../tests/collision/test_rotating_ellipsoid_plane.py)

测试用 84 位 Decimal 重新计算解析时刻，并用独立的 Rodrigues 旋转求每侧表面点。所有解析事件的独立时刻都落在公开区间内，区间宽度上限为 10⁻⁶，点和间隙误差上限为 1 µm，法向分量误差上限为 10⁻⁵。`pair.witness` 对应末态，`pair.curved.first_contact` 和 `last_contact` 各带闭区间、`witness_time` 和该时刻两侧节点的权重、偏移与世界坐标。另有两端穿入而中间净空的构型，使用首末时间推断持续载荷会得到错误结果。[独立解析与表面点](../../tests/collision/rotating_ellipsoid_oracles.py)

将平面法向变换到椭球初始材料系后，平方支撑半径与中心到面的有符号高度给出四次以下的有理系数多项式。HOST 在有理半角坐标上隔离全部实根，再用角度包围裁到实际输入的有符号转弧。孤立重根具备独立时间区间。公开域是固定有向平面半空间与绕自身静止中心、固定世界轴旋转的椭球，允许任意有效初始姿态，0<|A|≤float(π)。偏心/移动枢轴、移动平面、纯平移和长弧返回 `unsupported`。根排序、资源或材料点分辨率不足会返回 `unresolved`。本次验证覆盖 HOST 椭球窄相；转动凹网格仍需单独区分表面交叉和包含关系。[根隔离与材料重建](../../src/phymeo/geometry/_rotating_ellipsoid_plane.py)

Newton 1.7.0 / Warp 1.17.0 的 CPU 公共碰撞接口在 t=0、1/4、1/2、3/4、1 的接触数分别为 0、1、1、1、0。三次发布的间隙依次为 −0.0202847123、−0.1249999702、−0.0202847123 m；两侧世界点与法向也通过独立指定姿态检查。连续首末时间使用上表的整段解析解。3 rad 的相切高度也作了 FP64 诊断。低一格得到两条相隔约 1.15×10⁻⁸ 步长的根，恰在 0.5 m 得到一个根，高一格全段分离。

`ellipsoid-arc-red` 绑定父基线 `8a5355f`，首次得到 `unsupported`（raw 1）。`ellipsoid-arc-host` 在 `c30adca` 首次通过 16 项。随后对三个专属 Python 文件做格式与导入整理，并加一项转轴为 (2,2,1)/3、初始椭球绕 Z 独立倾转的留出，分别用两个异号区间二分求时刻和世界点。最终源码在 `ellipsoid-final-focused` 通过 17 项专项与 12 项相邻回归，覆盖静态圆柱–球、圆锥–平面、椭球–平面及域外圆柱运动。首次 `ellipsoid-lint` 报导入顺序和变量名，修正后的 `ellipsoid-lint-final`、`ellipsoid-format-check` 均返回 raw 0。

复现专项可运行 `python -m pytest -q tests/collision/test_rotating_ellipsoid_plane.py -p no:cacheprovider --basetemp <新目录>`。同批收据位于 `artifacts/p65-wave5-rotating-20261104-01`。每个命名作业保留源文件哈希及原始退出码，`ellipsoid-final-focused/basetemp` 中的九份 JSON 包含解析预期及完整首末事件，`ellipsoid-newton-poses/result.json` 保存五次实际 Newton 发布，`ellipsoid-ulp-diagnostic/result.json` 保存三个浮点高度的根区间。
