# 转动闭网格与有限胶囊的下一批验收目标

此案例库冻结连续几何目标，并保留功能落地前 Phymeo 公共入口和 Newton 1.7 离散姿态的实测结果。后续实现及最新结果见[转动闭网格与有限胶囊](p65-rotating-mesh-finite-capsule.md)。长度单位为米。转角以输入存储的弧度计，时间归一化到 [0, 1]。[构型与公式](../../tests/reference_newton/rr/rotating_mesh_capsule_cases.json) · [解析验证与原生读回](../../tests/reference_newton/rr/rotating_mesh_capsule.py)

| 同一冻结输入 | 连续解析目标 | 实现前 Phymeo HOST |
| --- | --- | --- |
| 绕 Z 半圈的长条与竖直胶囊，胶囊轴两端 z=±1、半径 1/8 | 首触 t=acos(1/6)/π=0.4466996209618863，整段轴参数 [3/8,5/8] 同时接触 | `unsupported`，无时间见证 |
| 长条反转、胶囊移至镜像位置、互换所属顺序，再施以整体刚体变换 | 相同的首触与轴参数，两侧材料点及法向随刚体变换 | `unsupported` |
| 胶囊轴移至 y=9/4 | 全程最小皮肤净距 (17−√257)/8=0.1210975573 | `unsupported` |
| 原闭 U 绕足一圈，胶囊轴在 (0,1/4) | 全程最小皮肤净距 5/8 | `unsupported` |
| 第一组的形状置于不同世界 | 空间几何目标相同，公共查询应过滤 | `filtered/different_world` |

在长条材料坐标中，胶囊轴投影为 (1.5 sin θ, 1.5 cos θ)。首触前其 y 坐标严格大于长条侧面 1/8 加胶囊半径 1/8。到达时局部 x=√35/4 在面内；z∈[−1/4,1/4] 整段与胶囊轴平行。两颗端球在完整转弧中均至少净空 5/8。例库保存轴参数 3/8、1/2、5/8 处的双侧材料权重、世界点和法向。轴中点实测前独立算得共同世界点 (0.1232516621,1.4791666667,0)，胶囊材料 ID 41、93 各占 1/2。凹 U 的任一侧壁或底壁的 xy 半径至少为 1，球轴所在圆半径为 1/4，在四分之一圈处可取到 5/8 的皮肤净距。

四组同世界构型分别在 t=0、7/16、15/32、1 查询静态实体和轴面间隙，16 个观测均符合独立矩形距离。长条正控在中间两个时刻的解析间隙分别为 +0.0426354830 和 −0.1029742895。跨世界用例单列过滤。实现前的四个 `open_ccd` 状态保留为原始读数，供核验后来交付的时间括区、采样时刻与轴段。

Newton 1.7 在同一长条的上述两次中间姿态注册原生 `MESH` 和 `CAPSULE`，关闭接触归约，CPU 与真实 CUDA 均先读出 0 条、随后 4 条接触。后一个姿态的带偏移世界点给出 −0.10307424 至 −0.10307420 m，约比解析值多 0.100 mm 的压入。GPU 与 CPU 接触条目顺序不同，已保存所有行。这里的网格资产为凸长条，Newton 对凹 U 的行为及连续首触均未在本次测量。

在仓库根目录使用 `python tests/reference_newton/rr/rotating_mesh_capsule.py --engine phymeo --device cpu --out <新文件>`。在独立 Newton 环境将引擎改为 `newton` 并选择 `cpu` 或 `cuda:0`。三份原始收据在父工作树 `artifacts/p65-night-rotating-mesh-capsule-reference-20261104-01/`，三个进程均正常退出。
