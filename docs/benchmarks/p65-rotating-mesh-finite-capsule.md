# 转动闭网格与有限胶囊的连续查询

普通 `ph.detect` 已支持无圆角闭合三角网格绕一个固定世界轴转动，同时枢轴与有限胶囊可分别线性平移。胶囊保留固定朝向、两个原材料 ID 和物理半径。两材料端点重合也可查询。时间归一化到 [0,1]；空间量以米计。[实现](../../src/phymeo/geometry/_rotating_mesh_sphere.py) · [冻结的独立解析目标与 Newton 离散观测](p65-rotating-mesh-capsule-targets.md)

### 首触与材料证据

在网格初始材料坐标内逆转整个轴段。每个时刻用真实有限轴段对候选三角作最近距离计算，覆盖端帽、杆身和穿面。线段中任一点的位移都可由两个端点的位移上界控制。用两端点在时间单元上的最大速度和 Rodrigues 误差界排除完整区间；必要时细分，保留最早未排除时刻到实际占用样本的括区。起始实体内含会在 t=0 单独识别。

`pair.mesh_round.first_contact` 提供 `interval`、`witness_time` 和该样本的 `pose`，末态见证仍在 `pair.witness`。每个支持面保留原始三角 ID 与权重，以及胶囊轴材料点和世界径向偏移。若同一面有一段并列最近轴点，`support.witness.capsule_axis_span` 给出其端点及对应三角材料坐标。并列集合按存储采样位置计算，逆转轴在实际输出姿态上的误差上界见 `observed_axis_error_upper_m`。每个时刻的轴段距离检查数按不同时间计入 `axis_samples`。

| 实际输入 | 公开读数 |
| --- | --- |
| 长条中段碰杆身，两端球全程至少净空 5/8 m | 正反序与刚体变换的首触均在 [0.4466996192932129, 0.4466996267437935]，包含解析值 0.4466996209618863。用 45 个时间样本确认，上端轴段已占用 |
| 两面交缝处分段的轴材料 | 正向两主要三角的轴参数分别为 [0.375,0.505245012421] 与 [0.505245012421,0.625]，两侧端面各贡献一个闭端点。各处均可从原始材料坐标重建 |
| 轴位于 y=9/4；原凹 U 绕一圈 | 分别用 21 和 5 个时间样本证明全程净空，对应的解析最小净距为 0.1210975573 和 0.625 m |
| 斜轴端帽与独立上移的枢轴；杆身末态穿过真实面 | 端帽首次占用包含解析 t=4/5，实际最近轴参数为 0。穿透留出在末态给出 `boundary_overlap/on_boundary` |
| 杆身与导入的 URDF/OBJ 顶点相交 | 初始首触为 0，轴面间隙 −1/64 m。首次运行因末态共面棱边缺乏证明而未决；最终区分了在守恒轴向平面内真实相交与轻微离面两种情况 |

共面证明使用转轴方向投影的精确不变量，并检查实际材料点到各三角边的严格余量。沿真实棱边接触时，在守恒平面内验证两条有限线段互跨的方向符号。共面或擦触符号仍不确定、超过资源界时返回未决。胶囊另有自身转动时返回不支持。支持转角上限为 32 rad，中心线不同时间查询上限为 512 个。此次交付连续几何与材料见证，整段接触的摩擦冲量另有物理求解合同。

### 本机验收

2026-11-04 最终 44 项于 17.10 秒通过，涵盖胶囊新用例、球的原转弧、有限平移、真实 RTX 4060 CUDA 宽相和原导入资产。CUDA 胶囊用例读回 3 次内核启动、2 次下载，随后 HOST 认证时间根和完整有限杆身。原冻结独立阅读程序把两项时间目标和两项全程净空目标分别读为 `resolved_time` 和 `resolved_clear`，跨世界仍为 `filtered_by_world`。Newton 1.7 的相邻两离散姿态读取仍见原基线。

原始收据保存在父工作树 `artifacts/p65-20261104-rotating-mesh-finite-capsule/`。其中 `rotating-shaft-first` 与 `rotating-shaft-obj-diagnosis` 保留最早的失败及几何输入，`rotating-shaft-sphere-device` 和 `rotating-shaft-frozen-reader` 保存最终双侧材料、设备计数及每个冻结姿态。最终样式与 lint 均正常退出。[专项测试](../../tests/collision/test_rotating_mesh_capsule_solid.py)
