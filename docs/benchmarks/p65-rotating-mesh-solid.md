# 普通闭网格查询的转弧实体首触

`ph.detect` 在一对闭网格采用同一相对转轴时，分别返回实体的首次占用和边界的首次相交。严格包含或重合使 `pair.sweep.first_t` 为 [0,0]。内嵌实体离开容器时，稍晚的 `pair.mesh_mesh.first_boundary` 仍能读到实际墙面及两个材料点。起始互离时，只有整步边界查询证实无相交，才能据此发布 `separated`。[普通分派](../../src/phymeo/geometry/collision_pipeline.py) · [实体判定与末态证书](../../src/phymeo/geometry/_rotating_mesh_solid.py)

| 独立构型 | 首个实体事件 | 边界及末态 |
| --- | --- | --- |
| 小闭箱在大闭箱内旋转 | 0 | 全弧无边界相交，末态仍严格包含，边界净距 0.91193375784 m |
| 完全内嵌的小闭箱绕偏心轴退出 | 0 | 首次碰壁区间 [0.113539615153059, 0.113539615154878]，末态净距 0.6875 m |
| 旋转内 U 扫外 U 右壁 | 约 0.19016036849 | 两端净空 0.125 m。所有顶点的端点直弦都留在槽内，真实转弧中间进入右壁 |
| 上例仅转到 π/4 | 约 0.38032073698 | 末态有严格边–面横穿，边界净距 0 |
| 长方体转过厚墙的最高支撑 | 约 0.30909840600 | 孤立擦边后分离。提高壁面 1/1024 m，整弧分离 |
| 两张贴合面共同转动平移 | 0 | 两侧世界点随体运动，末态贴合，法向随实际角度旋转 |

包含例以固定箱的右壁与动箱顶点的实际角位移直接求根。U 形对照使用原闭合凹网格与独立的侧壁方程，交叉核对换序和两体共动后各自的材料权重。首个正时刻的弧事件给闭时间区间及其中的 `witness_time`，双方点都在该采样时刻求值。`first_ratio` 仍用于能精确发布的旧平移结果，以及已占用的 t=0。[公开端到端测试](../../tests/collision/test_rotating_mesh_solid.py)

末态逐顶点位置由带误差界的 Rodrigues 旋转求得。若边界净距超过两体误差总和，连续形变不能使边界相交，静态内外判定随之保持。已有非零端点间隙时保留有向可还原见证。有端点穿越时只发布由严格定向符号证明的实际边–面穿越材料点。共同刚体运动保持相对形态及初始距离。输出 `end_certificate` 说明所用证明，`end_error_m` 给出米制位置误差上界，超过 1 µm 时显式未解。未证明的近零贴合、无法决定首根与步终的顺序、超出有界资源均可返回 `unresolved`。不同转轴或枢轴相对平移仍为 `unsupported`。端点穿越未推断全局最小平移深度。退出以首个边界事件和起末实体关系记录，本次公共结果的时间量为首触。[原边界隔根](../../src/phymeo/geometry/mesh_arc_surface.py)

另一组在整数正交矩阵下整体放大三倍，保持原始顶点与 (2,2,1)/3 转轴的精确相对几何。换序后仍得到同一 U 壁首触及实际材料点。用二进制近似的 3/5、4/5 直接旋转整组输入时，原同时首次接触的面被分到不同实根，当前根格无法区分先后，普通入口和独立边界入口均返回 `mesh_arc_competing_first_roots`。原始失败及诊断分别保存在 `solid-arc-oblique` 和 `solid-arc-oblique-diagnosis`。

Newton 1.7.0 CPU 在七个双 U 指定姿态上的原生接触数为 0、0、3、4、3、0、0。三次出现接触时的最深间隙为 −0.028281212、−0.082106709、−0.028281450 m，侧壁解析值分别为 −0.028281482、−0.082106781、−0.028281482 m。退出小箱的八个姿态按时间顺序为 0、0、4、4、6、0、0、0 条原生接触，前两个姿态仍处于严格包含。各姿态保留实际体位姿、法向、世界锚点、偏移和两侧世界表面点。连续时间由整段运动验收。[Newton 离散对照入口](../../tests/reference_newton/rr/rotating_mesh_solid_poses.py)

本批收据在 `artifacts/p65-night-rotating-mesh-solid-20261104-01`。`solid-arc-original-red` 绑定旧父源码，严格包含时得到 `unsupported`（raw 1）。最终 `solid-arc-delivery` 的 21 个新增及受影响用例全部通过，包含旧平移精确 1/5 时刻和原有非法几何预期。`solid-arc-newton-cpu` 完成全部 15 个指定姿态。最终源通过 Ruff 检查，三份新文件、受影响旧测试和共享分派改动区通过格式核对。共享文件整体格式检查另报告了父基线已有的凸体支持分派行，同一行在本次共享差异之外。
