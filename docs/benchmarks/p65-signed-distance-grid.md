# 规则格上的离散有符号距离

闭刚体网格可以在资产局部坐标中烘焙一次，供刚体点或柔性材料点批量查询。距离单位为米，内部负、外部正。每次查询给出三线性插值和它在选定格内的梯度。真实三角面、最近表面点和重心权重由独立几何查询给出。[规则格接口](../../src/phymeo/geometry/sdf_grid.py) · [闭网格与柔性面几何](p65-closed-mesh-cloth-triangle.md)

```python
import phymeo as ph

grid = ph.bake_mesh_sdf(
    mesh_shape, vertices_in_asset_m,
    shape_xyz=(33, 33, 17), origin_m=(-2.5, -2.5, -1.0),
    spacing_m=(0.15625, 0.15625, 0.125),
)
row, = grid.sample_world(
    [[2.0, 0.0, 0.0]], translation_m=(2.0, 0.0, 0.0),
    orientation_xyzw=(0.0, 0.0, 0.0, 1.0),
)
with ph.TyxSdfSampler(grid, mode="cuda", capacity=1024) as sampler:
    samples = sampler.sample_local(material_points_m)
```

也可用 `SignedDistanceGrid(values_zyx_m, origin_m=..., spacing_m=...)` 导入外部场。数组按 Z、Y、X 索引，原点为第一个节点在资产系的位置。位置、间距、`cell_xyz` 使用 X、Y、Z 顺序。节点落在内部格面时取正侧单元，最外节点取最后一个单元。有效行给 `status="valid"`、`distance_m` 及查询坐标系中的无量纲 `gradient`。梯度可为零，在折角处属于所选单元的一侧。域外返回 `outside_grid`。设置 `band_m` 时保存限幅值，只有八个节点的绝对值都严格小于带宽的单元才可用。其余返回 `outside_band` 并保留单元编号。

烘焙先对单连通分量、外向且无自交的闭合网格做一次拓扑验证，把输入浮点网格、资产原点和间距统一到同一整数尺度。面、边、点到每个节点的最小平方距离以整数比值比较。有符号一侧由每条 YZ 扫描线与实际面的交叉奇偶确定，射线作符号扰动处理共享边，边界节点直接为零。平方根的有理包围给出实际节点存储舍入界。当前 `CollisionShape` 接受 4 至 128 张三角面。规则格最多 4,194,304 个节点，烘焙另限 8,000,000 个潜在面–节点组合，批查询最多 262,144 点。[精确有限三角距离和符号](../../src/phymeo/geometry/_sdf_mesh_bake.py)

对已烘焙网格，真实有符号距离满足 1-Lipschitz。三线性权重的角点方差为 Σ hᵢ²uᵢ(1−uᵢ)，因此插值对真实距离的局部绝对误差至多半个体素对角线，加上节点、坐标定位及 HOST 数值求值误差。`geometry_error_bound_m` 适用于有效局部标量查询。输入的世界姿态按实际存储数值计算。外部导入的任意场没有该几何保证。TYX 的 `stats()` 另列 FP32 存储和标量计算余量，梯度仍是三线性场的导数。

正箱、斜箱、凹 U、薄壁分别检查 729、729、1,183、729 个节点，与独立几何距离的最大绝对差依次为 0、2.22×10⁻¹⁶、0、0 m。另一个 33×33×17 的凹 U 用 28 面、561 条扫描线烘焙 18,513 个节点。518,364 对面与节点中，包围盒排除后实际计算 92,420 次有限三角面距离。单次 HOST 用时 0.802 s，返回标量误差界 0.1269381 m。[多资产与容量验收](../../tests/collision/test_sdf_grid.py)

厚度 1/32 m 的箱壁中心位于 x=1/8 m。各轴间距 1/4 m 时，两侧最近节点都在实体外，在 (1/8, 1/16, 1/16) m 插值得到 +0.109375 m 和零梯度。仅将 X 间距缩至 1/64 m，查询恢复解析值 −0.015625 m。中心对两侧壁等距，选中单元的单侧梯度为 (+1,0,0)。两种格的保守标量误差界依次为 0.2165064 m 和 0.1769493 m。

### TYX 批量采样

HOST 将世界点变为局部点，按原始 FP64 位置确定所在单元，以避免靠近外界的点在 FP32 中进错格。一个 TYX 并行核对每个有效行读取八个节点和值的有效标记，实际计算三线性值及三个解析偏导，再读回逐行代次和结果。世界梯度在 HOST 转回。丢失完成标记或设备失败会关闭工作区。每个工作区的物理格只上传一次，空批不启动核。[设备内核](../../src/phymeo/backends/_tyx_sdf_kernels.py) · [资源与实际字节统计](../../src/phymeo/backends/tyx_sdf.py)

外部 5×4×3 格在 RTX 4060 上上传一次，共 480 B。两批共 7 点，查询输入 112 B，结果与逐行状态读回共 140 B，两次核启动、两次同步。除标量及梯度外，三种执行路径也逐点比较格地址、带外和域外状态。[设备验收](../../tests/collision/test_tyx_sdf_grid.py)

### Newton 1.7.0 的同点纹理读回

Newton 接口输入资产局部米。纹理内部先按 `inv_sdf_dx` 转到细格坐标，粗格分数另乘 `fine_to_coarse`，本批三个资产均为 1/8。原生实现返回的格内梯度把角点差乘以细格的逆间距。对原生输出标量求局部米制导数，粗格内还要乘上述 1/8，细格内用原值。在凹槽 (0.825, 0.225, 0.25) m，六个邻点都留在同一粗格，原始梯度 (−8,0,0)，按链式换算得 (−1,0,0)，归一化方向也为 (−1,0,0)。原生标量用步长 1/4096 m 作中心差分得到 (−1.00024414,0,0)。薄壁 x=0.109375 m 的测试点及邻点都在同一细格，原始 X 梯度 −1.00007248，与差分 −1.00008458 对应。所有观测保留原始、换算和归一化向量、活跃层与差分逐轴是否跨格。纹理外提供原始延拓值和方向，跨格差分及多最近面点单独解读。

原基线首次因缺少规则格入口失败。最终 HOST 11 项、TYX interpret 5 项、真实 TYX CUDA 5 项通过，独立 Newton 最终纹理查询和 7 个专用 Python 文件的 Ruff 检查及格式核对均退出 0。原始日志与文件散列保存在本地 `artifacts/p65-night-sdf-grid-20261104-01`。其中 `sdf-grid-final-{host,interpret,cuda}` 记录产品和测试，`sdf-native-formatted-cuda/result.json` 记录 112 次实际原生读数的诊断。
