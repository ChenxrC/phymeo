# 单姿态有限胶囊与三角面的最近特征

布–连杆的同姿态受力现在用 `static_capsule_face_sample` 获取有限胶囊与完整三角面的材料见证。原来的 `capsule_face_query(...).sample(0)` 保留为扫掠入口和独立对照。两者调用同一套 `segment_witness` 重建有符号间隙、法向、双方世界点和材料权重。每次查询都读取当次的五个顶点，原路径检查继续覆盖整个物理子步。[单姿态查询](../../src/phymeo/geometry/_static_capsule_face.py) · [受力入口](../../src/phymeo/solvers/cloth_link_contact.py)

FP64 坐标是二进制有理数，可放到同一精确整数格。先尝试达到胶囊中心线至三角形所在平面的距离下界。中心线平行时，用三条重心坐标约束裁剪整个投影线段；倾斜时核对使平面距离最小的材料点。若下界在有限面内不可达，则比较完整三条有限边与中心线两侧端点和轴内特征，保留全部并列最近点的两个极端材料地址。三角面退化采用原错误分类。输入带真实运动时沿用原整段验证和原时间零观察。

独立平行留出使用半径 1/8 m 的胶囊，轴从 (−1,1/2,1/4) 到 (3,1/2,1/4)。三角面截得轴参数 [1/4,5/8]，皮肤间隙 1/8 m，精确平方距离减半径平方为 3/64 m²。对照还包括 1 ULP 倾角、面内刺穿、共线边、偏斜边、仅角最近、零长轴、换序，以及 54 个固定种子的不同几何和材料排列。原、新观察的有理符号量完全相等，全部浮点字段、材料 ID 和并列端点逐项序列化一致。[专项测试](../../tests/test_static_capsule_face.py)
