# 静态无限半空间与凸包的材料支撑

普通 `ph.detect` 支持有向无限平面和无倒圆、满维的静态凸包，含从机器人资产导入的方盒。给定平面锚点 a、朝未占用一侧的法向 n，以所有凸包顶点中最小的 n·(p−a)/‖n‖ 为有符号间隙。正值分离，零为接触，负值进入实体半空间。穿入时报告最深凸包支撑及其向平面的投影。新配对的运动和凸包倒圆返回 `unsupported`，未发布时间区间。[公共分派](../../src/phymeo/geometry/collision_pipeline.py) · [几何与数值界](../../src/phymeo/geometry/_plane_hull.py)

`pair.convex.end.patches[0].dimension` 的 2、1、0 分别表示面、棱和单角。形状调换时有符号间隙不变，法向与多边形绕序随第一侧到第二侧的方向改变。凸包一侧使用原始极值顶点 ID，平面一侧使用原注册锚点 ID 加该点各自的世界切向偏移；在 `patch.points`、触面交点及选中的代表见证上都能读回。若 FP64 无法在 10⁻⁷ m 内表示该材料投影或锚点偏移，返回 `unresolved`。

`solve_witness_impulses` 与 `step_floating_contacts` 接受已有的 `(pair, bindings, i)` 行格式。面需传完整的全部角，棱需传两端，单角也可省略索引。供给注册顺序的凸包局部顶点、平面实际局部锚及定向法向；求解前会在当前刚体条件下重新验证完整支撑、每个角的材料地址和每个平面偏移。该入口求解同一时刻的闭合接触。[材料复核](../../src/phymeo/coupling/witness_impulses.py) · [独立测试](../../tests/collision/test_static_plane_hull.py)
