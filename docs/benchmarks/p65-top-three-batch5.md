# 第五批：前三优先方向的可运行切片

本批按 [用户优先计划](../superpowers/plans/2026-11-06-priority-top-three-parallel.md) 实施。独立作者在三个 worktree 并行编码；父独占旧共享接缝，并串行执行所有项目命令。没有远程 CI、依赖升级、默认分支合并或发布。

当前 A、B 已本地集成，C 的测量和读回优化正在验收。最终源码外 wheel 尚未完成。本页后续以实际收据更新，不把这个首片当成三个大模块追平 Newton。

## A：多机器人共享场景

同一 HOST world 可登记多台已有普通或 mimic 固定根机器人，通过 actions 的真实 robot ID 分别驱动。各树保留真实 owner 和全质量响应，多个机器人共同作用的自由刚体只推进一次；刚体–刚体的全场力只采样一次。全部候选、状态、载荷和事件共同接受或回滚。

专项覆盖对称/不对称推载、登记换序/刚体变换、台面力不重复、普通树与多行 mimic 的 32 步共同承载及 8 步撤退、第二参与者失败和晚期事件失败的原子回滚。19 项专项通过；受共享接缝影响的原单机器人 26 项兼容通过。公开例程共 40 步、9 项检查全部通过，最大原轴冲量误差 8.327e-17 N·s、动能误差 5.135e-16 J。

首次 CLI 在物理计算结束后的 JSON 输出因 NumPy bool 失败，原 RAW1 保留。只修输出边界，新增 true/false 两项协议验证通过后，公开 CLI 复验成功。没有修改物理参数、原断言或容差。

边界：机器人直接互碰需要显式排除；本首片不支持浮根、柔体、CUDA 或新的多机器人切向历史。详见 [多机器人报告](p65-multi-robot-scene.md) 和 [公开例程](../../examples/multi_robot_push.py)。

## B：转动有限胶囊与闭网格

公开碰撞管线新增胶囊单轴转动、枢轴仿射运动，对静止或仿射平移的有限闭网格。保留有限杆身/端帽、凹闭体分类、最早时间包围和双方材料见证。胶囊朝向真实变化、移动枢轴、两端分离但杆身撞击、凹槽绕行、初始包含/开离、近失/预算未决、换序/镜像/世界隔离分别检验。

HOST 19 项、TYX interpret 1 项和实际 CUDA 1 项通过；设备专项验证真实宽相提交、无 HOST 宽相回退、完整公开结果一致及故障恢复。有效首 RED 在原静态正控通过后，实际转弧返回 unsupported；该原始记录保留。后续只有 import/格式调整，非 import AST 和作用域 import 绑定相同。

边界：TYX 执行宽相，连续有限特征窄相仍在 HOST；双方独立转轴、一般擦触必定求解和接触响应未在本片覆盖。详见 [胶囊–网格报告](p65-rotating-capsule-mesh.md)。

## C：先测成本，再增加显式读回计划

已完成 14 个真实 CUDA 基线任务：W=1/32/128，K=1/8/全量去重，snapshot 与 kinematics 各自独立。每任务 1 冷步、5 预热窗口、20 个 32 步正式窗口，共 801 个连续物理步；没有为了计时复位或删减公开输出。C0 工具资格为 interpret 20 项、CUDA 3 项通过。

W32/K8 snapshot 的旧逐世界提交和同步占完整“推进+同种观测”任务 60.16%，W128/K8 为 59.20%；两个任务的 p50/32步分别为 53.429/56.574 ms。8 个可比较子集都达到原 15% 门槛。上述数字只用于决定是否开发，不能当成加速结果。全量与 W1 的测量保留为控制。

因此实施显式的 prepare_readback/readback/plan.read 接口：固定索引一次上传，预分配输出，读当次接受缓冲。旧 snapshot/kinematics 默认入口不改变。计划需具备请求顺序、拥有的 HOST 输出、空选择、恢复/轮换、故障重试和资源关闭语义。完成后按三轮 AB/BA/AB 比较完整相同输出；收益不足的档位如实报告，不自动切换默认。

C1 当前仅完成有效首 RED 与父共享薄 hook，功能和性能结果待实际执行。详见 [选择观测报告](p65-selected-world-readback.md)。

## 收据与后续边界

本轮 canonical 证据根为父集成树 artifacts/p65-top-three-batch5-20261106-01，每个执行作业保留入口 guard、命令、源快照、stdout/stderr、原退出码和 before/after 源绑定。三作者不占项目执行槽；旧同源已通过组没有重复运行。父对 A/B/C0 的首次样式检查失败、修正与最终检查分别保留。
