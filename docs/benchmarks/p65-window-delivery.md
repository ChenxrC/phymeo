1. **厚度和作用点合同**：先实现正确的块Jacobian、虚功、力矩与实际候选审计；面、边和顶点厚度约定要统一。

3. **布弯曲、自碰撞与单爪承重**：先跑静态支撑、真实夹持以及低摩擦滑落反例；通过后接控制history与完整双臂阶段。
4. **真实A→B→平台及Three.js**：完整重复、步长/网格/扰动、失败对照和事务测试通过后，用同源记录实现暂停、逐帧、接触力回放。
