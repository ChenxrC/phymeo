# 刚柔交互验收对照

本表按[设计合同](../superpowers/specs/2026-10-27-rigid-cloth-coupling-design.md)逐项检查，范围是固定布片与一个动态球的离散顶点接触。[独立审阅](rigid-cloth-review.md)发现的一个速度重建问题已通过回归修复；修复后的完整实验与验证仍进行中，当前不是完成声明。

| 验收要求 | 实际证据 | 当前状态 |
| --- | --- | --- |
| 质量加权解析响应、孤立动量与耗散 | `test_coupled_contact.py` 的单对解析、塑性碰撞、切向保持、无球心力矩；设备单对与多个共享刚体对照 | 通过 |
| 几何、活动集与数值边界 | `test_particle_sphere.py`、`test_coupled_contact.py`：内外/切触、中心重合、极端质量、乘子释放与新接触；实际 CUDA NaN/下溢拒绝回归 | 通过 |
| 状态所有权与整帧回滚 | `test_coupled_solver.py`、`test_tyx_coupled.py`：第二子步失败、预测/设备异常、输入不变、全部字段恢复、快照隔离、再次调用可用 | 通过 |
| CPU 240 帧与每子步验收 | 原版 6 组实验共 6,720 子步全部通过；修复版重新运行相同六组 | 原版通过，最终版本复验中 |

完整参数、配置、报告和数值指纹见[实验报告](rigid-cloth.md)与[CPU 原始摘要](rigid-cloth-reference.json)。原 CPU 六组摘要源码为 `b79cd9f`；旧 `ba09760` 设备套件在 CPU 着色参考结束后主动停止。最终三组设备实验从干净 `027e7cd` 启动且全部结束，六组 CPU 同源复验还在运行。后续文档修改不会被混写成该实验的运行版本。

范围限制：无三角面碰撞、CCD、摩擦、弯曲、自碰撞或机器人关节；钉住的布片系统会向外界交换动量。设备路径有子步分配与主机同步，当前没有加速比或跨硬件逐位一致性声明。CPU 着色对照采用 FP32 状态存储和 FP64 几何/乘子，设备采用 FP32 算术，二者在记录中明确区分。
