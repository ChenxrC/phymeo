# 刚柔双向交互参考实验

本实验按[场景设计](../superpowers/specs/2026-10-27-rigid-cloth-coupling-design.md)推进。M1–M4 的 CPU 参考及六组完整实验已通过。完整配置、环境、指标与数据指纹见[原始 JSON 报告](rigid-cloth-reference.json)。tyx 同场景耦合和可视回放在后续里程碑验收，CPU 结果不能代替 GPU 或整项验收。

## 参数与物理含义

使用 SI 单位、Y 向上。布片为 7×7 网格，间距 0.1 m，面密度 0.4 kg/m²，原点 (-0.3, 0.6, -0.3)，四角顶点 0、6、42、48 固定。结构与剪切顺应度均为 1e-4 m/N，无弯曲和自碰撞。球质量 0.05 kg、半径 0.18 m，惯量 2mr²/5，初始位置 (0.02, 0.30, 0) m，初速度 (0, 2, 0) m/s。重力为 (0, -9.81, 0) m/s²。

接触是离散顶点/球、无摩擦、完全非弹性法向速度投影。法向作用线穿过球心，因此接触关于球心的力矩为零；本场景不能验证摩擦扭转或三角面连续碰撞。固定点会交换外部动量，不声称整个钉住的布片系统动量守恒。独立单对接触测试验证闭合接触对的动量守恒。

参考设置：NumPy FP64，240 帧，每帧 1/120 s，每帧 4 子步，位置和速度各最多 200 次迭代，归一化残差容差 1e-7，参考长度与速度均为 1。记录实际经过 dtype 量化的子步长度和完整时域，所有子步都要验收。

单向对照保留球的离散自由落体轨迹和球面速度，让布片响应这个移动边界，同时由外部驱动抵消布对球的反馈。这是有外部驱动的非物理对照，输出标记为 `one_way_prescribed_sphere`，不是公开物理求解器的反作用开关。

## 复现

先按[环境与 CI 计划](../development/environment-and-ci.md)安装核心环境。下面两个入口等价，分别适用于 uv 和已激活的 pip 环境：

```bash
uv run --no-sync python examples/rigid_cloth.py --suite --output artifacts/rigid-cloth-reference
python examples/rigid_cloth.py --suite --output artifacts/rigid-cloth-reference-pip
```

`--suite` 顺序运行双向基准、完全重复、单向对照、480 帧且帧长减半的同时间跨度实验，以及球质量 0.025 / 0.1 kg 的两组实验。它逐数组比较重复结果，比较单向/双向轨迹，并执行有解析解的自由落体步长收敛检查。接触轨迹的减半步长差异只是敏感性测量，不能单凭差异较小宣称接触解具有某个收敛阶。

单次运行可省略 `--suite`。`--one-way` 单独运行单向对照；`--frames 1` 供 CI 命令行 smoke。输出目录必须尚不存在，失败以非零退出码和 `failure.json` 报告，不生成成功标记。完整实验可能需要数分钟，控制台每 30 帧报告进展。

## 输出与独立检查

每次运行保存：

- `trajectory.npz`：初始状态及每帧六组状态数组、时间、布片拓扑、每子步检查结果；纯数值，可用 `np.load(..., allow_pickle=False)` 读取。
- `run.json`：参数、精度、时长、各项最大误差、耗时、数值数组 SHA256，以及实际导入包的源码 SHA256、Git 版本/脏状态、Python/NumPy/平台信息。
- 套件目录的 `suite.json`：只有全部实验和对照验证通过才写入；汇总重复一致性、轨迹差、步长与质量敏感性。

每个子步在求解器外重新计算顶点穿透、固定点位移、四元数模长、法向相对速度、接触冲量平衡，以及球体动量变化相对于重力和接触冲量的误差。球没有初始自转或外部力矩，检查也要求其姿态不变。构成关系残差明确使用求解器报告值，独立顶点穿透要求 ≤2e-6 m。FP64 球体动量检查阈值为 1e-10 kg·m/s；实现同时记录 FP32 位置重建引起的量化误差界，但 FP32 路径仍须经过 M6 的专门验收。

CPU 核心测试包含 12 帧真实接触对照、单向自由落体解析检查、重复数据相等、逐子步审计损坏数据的拒绝、失败退出与不可覆盖的输出记录。CI 的完整 240 帧性能与 GPU 验收不由短 smoke 替代。

## 2026-10-27 完整 FP64 结果

运行版本为干净提交 `b79cd9f8f0fdaeba8c5966fe9a68aee7cc708588`，Python 3.12.14 / NumPy 2.5.4 / Windows 11。原始轨迹位于本地 `artifacts/rigid-cloth-reference-m4`，可用上面的命令再生成。六份 NPZ 均重新以禁止 pickle 的方式读取，逐数组检查有限性，并核对记录的 SHA256。未调整场景参数、迭代预算或容差。

| 实验 | 接受帧 / 审计子步 | 接触子步 | 最大位置迭代 | 最大独立穿透（m） |
| --- | ---: | ---: | ---: | ---: |
| 双向基准 | 240 / 960 | 17 | 171 | 8.33e-17 |
| 完全重复 | 240 / 960 | 17 | 171 | 8.33e-17 |
| 单向运动球面 | 240 / 960 | 132 | 190 | 8.33e-17 |
| 半步长、相同时域 | 480 / 1920 | 29 | 48 | 2.78e-17 |
| 0.025 kg 球 | 240 / 960 | 13 | 169 | 8.33e-17 |
| 0.1 kg 球 | 240 / 960 | 27 | 175 | 8.33e-17 |

全部 6,720 个子步通过；六组固定点位移和四元数模长误差均为零，最大报告残差小于 1e-7，球体动量平衡误差最大 2.10e-14 kg·m/s。完全重复的 22 个数值数组逐元素相同，基准指纹为 `a44e0e07847a2dcb2491b7fc80c0b5852f533c9af5505b6e5170f766bdcf7241`。

双向/单向的球轨迹最大差 2.09608 m，布片顶点最大差 0.107603 m；单向球的离散自由落体位置解析误差为 4.62e-14 m。相对基准，半质量/倍质量球的最大轨迹差分别为 0.631047 / 0.568467 m。

半步长在相同两秒时域的球/布片最大轨迹差为 **0.145060 / 0.0167852 m**。这表明当前离散接触场景仍有明显时间步敏感性，不能声称结果已经与时间步无关。独立自由落体的位置解析误差从 0.0204375 m 减为 0.01021875 m，误差比 2.00000000001043，符合半隐式 Euler 的一阶位置误差；这项结论不外推到有接触的轨迹。

耗时包括主机审计，并受到同时运行的开发测试影响，记录于 JSON，仅用于复现诊断，不构成性能基准或加速比。
