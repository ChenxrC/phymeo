# 两节滑块的接触载荷传递

2026-11-18，MuJoCo-TYX CUDA 实验分支。两节竖直滑块各重 1 kg。平板只接触近端滑块，远端滑块沿近端导轨自由移动。问题是，能否从同一次接触更新中得到两个关节的运动，以及导轨传给另一节滑块的力。[单滑块基准](area-friction-guide-report-20261118.md)

## 运行前固定的基准

沿竖直向上取正。第一坐标是近端滑块的世界位移，第二坐标是远端相对近端的位移。因此，远端在世界中的加速度等于两个关节加速度之和。两节质量决定了质量矩阵的两行为 `[2, 1]` 和 `[1, 1]` kg。面积推力只沿第一坐标作用。步长 10 ms，初始静止、压入平板 1 mm，面积等效刚度为 1000 N/m。三个工况沿用相同的平板、接触材料和几何姿态，均无重力或黏性阻尼。

令 `a₀, a₁` 为两个关节加速度，`F` 为平板推力，`λ` 为导轨广义反力。在这组首步工况下，`F = 1 − 0.1 a₀` N。导轨位于第二个关节时，质量方程给出 `a₀ = F − λ`、`a₁ = −F + 2λ`。原生干摩擦行的正则化系数为 2，此时 `λ = clip(−a₁/2, −L, L)`。将同一干摩擦行移到第一关节时，其系数为 1，力改沿第一坐标作用。三组首步解析解如下。

| 干摩擦位置及上限 | 平板推力 F（N） | 导轨反力 λ（N） | 第一关节加速度（m/s²） | 第二关节相对加速度（m/s²） | 远端世界加速度（m/s²） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第二关节，2 N | 40/43 | +10/43 | 30/43 | −20/43 | +10/43 |
| 第二关节，0.125 N | 81/88 | +1/8 | 70/88 | −59/88 | +1/8 |
| 第一关节，2 N | 20/21 | −10/21 | 10/21 | −10/21 | 0 |

第三个工况检验力的归属。第二个关节完全自由时，平板可以抬升近端滑块，远端滑块在惯性作用下应保持静止，即使它相对近端仍在滑动。

## CUDA 实测

三个世界在同一场景批次内运行。每一步都从当前几何裁剪接触面，将接触力与模型声明的干摩擦行共同求解。下表的加速度取自同一次已接受步。最后一列单独取两次设备刚体世界速度之差，再除以步长。

| 干摩擦位置及上限 | 平板推力（N） | 导轨反力（N） | 第一关节加速度（m/s²） | 第二关节相对加速度（m/s²） | 设备观察的远端世界加速度（m/s²） |
| --- | ---: | ---: | ---: | ---: | ---: |
| 第二关节，2 N | 0.93023291 | +0.23255827 | +0.69767469 | −0.46511644 | +0.23255819 |
| 第二关节，0.125 N | 0.92045492 | +0.12500000 | +0.79545486 | −0.67045486 | +0.12499993 |
| 第一关节，2 N | 0.95238134 | −0.47619069 | +0.47619066 | −0.47619066 | −4.66 × 10⁻⁸ |

运行时从编译模型取得干摩擦所在的自由度。在每个候选速度上计算面积推力、受上下限约束的导轨反力，并用完整质量矩阵分解计算物理加速度。步末发布原生约束行、面积力和状态。独立验算使用 MuJoCo CPU 前向运算取得质量矩阵、接触点雅可比与原生行系数，在三个力界分支上求候选解，并用运动方程和力界判定唯一可行解。实际场景步在 CUDA 执行。[CUDA 求解](../../src/phymeo/backends/_tyx_area_friction_kernels.py) · [独立参照和场景测试](../../tests/test_mujoco_area_friction_coupled_guide.py)

首步后保存快照，继续第二步，再从快照恢复并重演。两次第二步的力、运动及设备观察复现。单独篡改干摩擦所属自由度或雅可比后重新计算快照校验和，恢复接口均在修改状态前拒绝。两个关节同时具有干摩擦、三个滑动关节、含铰链或含黏性阻尼的混合声明均在设备分配前拒绝。[恢复核验](../../src/phymeo/backends/mujoco_area_guide.py) · [准入测试](../../tests/test_mujoco_area_friction_admission.py)

本批共 23 项测试通过，含 6 项新增测试和 17 项相关回归；10 个改动的 Python 文件通过 Ruff 与格式检查。同时对三组工况的首步、第二步和重演步读取输入与输出，共 18 个设备观察时点，两节滑块的世界位置和速度均与关节运动学一致。原始轨迹与命令保存在工作树的 `artifacts/area-friction-coupled-guide-20261118-01`。其中 08 为真实轨迹，09 为首步力和加速度摘取，11 为世界刚体核验。10 的证据读取脚本误把序列化的 XML 字节当作字符串，修正解码后直接复用同一轨迹。

已验证的混合域为一至两个无黏性阻尼的滑动关节，具有一条原生干摩擦行。下一批在该双轴基准上加入单侧行程限位，分别覆盖限位未激活、承载、卸载，检查关节限位反力、面积力和状态能否共同更新。
