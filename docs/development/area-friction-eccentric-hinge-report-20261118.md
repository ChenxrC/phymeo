# 偏心平板怎样转动串联铰链

2026-11-18，在 MuJoCo-TYX CUDA 的面积接触路径上，把一块接触垫通过铰链安装在可竖直滑动的托架上。有限平板从下方顶住接触垫。移动转轴后，如果平板仍施加相同的向上推力，连杆应随力臂变化而改变转向。本批以同一步的接触力、关节反力和设备连杆状态检验这条传力路径。[上一批的双滑块行程限位](area-friction-slide-limit-report-20261118.md)

## 同一推力作用在转轴两侧

托架和接触垫各重 1 kg。平板宽 20 mm，初始压入量为 1 mm。滑动关节的干摩擦上限为 0.01 N。铰链绕世界 +Y 轴旋转，表中的偏移是转轴相对初始接触中心的 X 坐标。三个世界同批从静止连续运行三步，每步 10 ms。

| 转轴偏移 | 首步平板推力（N） | 首步绕铰链的接触力矩（N·m） | 首步末角速度（rad/s） | 第三步末角速度（rad/s） |
| --- | ---: | ---: | ---: | ---: |
| +30 mm | 0.944520 | +0.028316 | +0.058361 | +0.152850 |
| 0 mm | 0.952858 | 绝对值 < 10⁻¹⁶ | 绝对值 < 10⁻⁹ | 绝对值 < 10⁻⁹ |
| −30 mm | 0.944520 | −0.028316 | −0.058361 | −0.152850 |

首步参考解直接对方形接触面积积分。沿滑动、转动两个坐标，局部横坐标为 x 的竖直力对应方向为 `[1, b−x]`，其中 b 为转轴偏移。均匀方形上 x 的平均值为零，x² 的平均值为 `(0.01 m)²/3`。用这两个矩算出的接触刚度矩阵、两刚体的耦合质量矩阵与饱和导轨摩擦给出独立的首步加速度和接触力矩。此比较也覆盖接触垫与托架的惯性耦合。

## 角度限位、关节干摩擦与表面摩擦同时作用

另一批两个世界沿相反方向运动，起始角速度分别为 ±0.05 rad/s，初始角度越过对应软限位 0.002 rad。接触面的摩擦系数为 0.4，铰链自身的干摩擦上限为 0.001 N·m。两个世界各连续运行三步，使用同一组材料参数。正偏移世界的首步平板推力为 0.891472 N，绕转轴的接触力矩为 +0.027350 N·m，上限反力矩大小为 0.030989 N·m。上限把连杆推回行程方向，步末角速度从 +0.05 变成 −0.023515 rad/s。镜像工况得到相反的转向。另从受载检查点恢复，验证下一步状态、接触力和原生约束行均可重演。

每一步从实际入口几何取接触点。关于铰链的力矩为 `axis ⋅ Σ[(point − anchor) × force]`，包含切向力的贡献。转轴所在机构相对世界原点平移了 0.25 m，借此检验力矩换算。例如正偏移首步的世界原点 Y 力矩为 −0.236150 N·m，同一组力关于铰链为 +0.028316 N·m。独立核对使用 CPU MuJoCo 前向计算的关节轴、质量矩阵和原生行系数；推进状态由 CUDA 场景完成。步末还读取设备连杆的世界角速度和位置，与关节状态重建的运动逐步比较。
