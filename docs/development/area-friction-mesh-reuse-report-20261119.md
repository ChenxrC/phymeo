# 面积接触在同一步内复用已验证网格

2026-11-19，`codex/exp`。可动双爪夹持、承载、再松开自由物体时，两只夹爪会用到同一份物体压力网格。这次把该网格的构建与检查共用一次，每只夹爪仍按自己的位置独立求接触面与接触力。两个世界里同一侧的输入完全一致时也适用。先前的整步测量给出了优化起点。[上批测量](area-friction-step-cost-report-20261119.md)

## 实测收益

表中是一次完整批次推进的墙钟毫秒数，包含 `Scene.step`、刷新设备观察、回读和取得状态快照。两组时间均来自本轮同机普通运行，按每次运行的非首步取平均。右侧计数来自单独的两次分段运行，也去掉首步。“每侧请求”是压力网格与刚性网格各自的请求数。

| CUDA 动力学工况 | 原整步 ms | 本批整步 ms | 原耗时 / 新耗时 | 每侧请求 | 省去的压力 / 刚性网格构建 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 个世界，1 对接触 | 102.59 | 100.56 | 1.02× | 4 | 0 / 0 |
| 4 个世界，相同运动 | 394.57 | 197.69 | 2.00× | 16 | 12 / 12 |
| 32 个世界，相同运动 | 3198.17 | 1000.68 | 3.20× | 128 | 124 / 124 |
| 2 个世界，双爪夹持和释放 | 445.89 | 290.46 | 1.54× | 272 | 142 / 136 |
| 4 个世界，两侧各自运动 | 491.50 | 473.41 | 1.04× | 16 | 0 / 0 |

双爪每个世界每步有两个接触对，指向同一物体。两个世界各自复用一次，贡献了 136 次压力网格命中，其余 6 次来自世界间输入仍然相同的时刻。32 世界相同运动的两次新路径普通运行分别为 1022.00 和 979.35 ms。坐标和速度均分开的四世界对照没有命中，短测的 1.04× 差值不能作为独立运动时的加速保证。32 个世界相同运动时，当前分段求交已经占每批约 701 ms；四个世界独立运动时，网格构建与检查仍占约 287 ms。

## 正确性与复现实验

- 每次批量几何准备单独拥有两张查找表。对每一侧，检查身体与材料身份、节点与单元身份、连接关系、当前世界顶点，以及压力侧的节点压力与定义域。规范化数组的类型、形状、完整字节都参与比较。单请求直接走原构造路径。
- 每个请求重新验证所属世界、配置与步号，逐对求交并随当前步发布。解析输入和构建均成功后才登记该侧网格。覆盖了错误形状、身份、时间戳、非法边界压力、失败后重试和场景重置。[几何实现](../../src/phymeo/geometry/area_pressure_intersection.py) · [字段与失败路径用例](../../tests/test_area_pressure_step_mesh_reuse.py)
- 同一工况运行顺序为原路径、优化路径、两次分段、优化路径、原路径。原路径使用上一提交的逐请求构造方式。五个工况逐步对齐当前接触面、接触力、状态、设备观察数组及完整步回执，新实例单独核验配置绑定。双爪每次连续 35 步，其余工况每次 3 步。几何在主机生成，动力学在 CUDA 上执行。单独的几何测试还覆盖 TYX 混合求交入口。[完整步对照](../../tests/test_mujoco_area_friction_step_cost.py) · [汇总入口](../../experiments/area_pressure/summarize_step_cost.py)
- 本批串行执行了几何、场景准备与 TYX 求交的 49 项测试，五个 CUDA 完整轨迹对照，以及成功命中后的三种非法输入拒绝测试，全部通过。八个 Python 文件通过 Ruff 检查和格式检查。原始逐步记录及命令收据位于 `artifacts/area-friction-mesh-reuse-20261119-01`，其中 `08-summary.stdout.log` 保存生成上表的汇总值。上述时间只覆盖这台机器和这些轨迹。
