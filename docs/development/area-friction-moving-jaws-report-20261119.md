# 双侧可动夹爪对自由物体的面积夹持

2026-11-19，`codex/exp`。两侧电机从间隙开始闭合，对同一自由物体建立反向压力。在 32 ms 的外载窗口，两侧摩擦共同承担向下载荷，反向驱动夹爪后物体恢复自由加速。下面两列来自同一批次的连续轨迹，两个世界只改变接触材料的摩擦系数。

| 实测量 | 有摩擦 μ = 0.6 | 光滑对照 μ = 0 |
| --- | ---: | ---: |
| 夹紧阶段末每侧法向力 | 0.45789 N | 0.45789 N |
| 加载阶段末每侧法向力 | 0.44957 N | 0.44957 N |
| 加载阶段末物体所受向上摩擦力 | 0.219975 N | 0 N |
| 加载阶段末两爪各自所受向下摩擦力 | 0.10999 N | 0 N |
| 加载 32 ms 内物体下滑 | 0.013915 mm | 0.422400 mm |
| 加载阶段末物体向下速度 | 0.44656 mm/s | 23.46667 mm/s |
| 双侧初次承载 / 双侧卸载 / 接触面消失 | 第 4 / 26 / 27 步 | 第 4 / 26 / 27 步 |
| 释放后末步向下加速度 | 0.733333 m/s² | 0.733334 m/s² |

**如何复现。** 在仓库根目录、已安装项目的 MuJoCo 与 TYX CUDA 环境运行下列命令。输出含 70 个世界步的实际输入与输出状态、驱动力、接触广义力、三体在同一参考点的力与力矩，以及各爪采样数和法向载荷。脚本同时打印两组承载期间的下滑量。

```shell
python -m experiments.area_pressure.moving_jaw_grasp --output grasp.json
```

**模型和载荷。** 0.30 kg 自由长方体有 6 个速度自由度。两个 0.05 kg 爪各有一条水平滑轨，电机均以向内为正，滑轨黏性阻尼为 8 N·s/m。单侧初始间隙 0.25 mm，有限接触面为 12 × 6 mm。物体使用中心压力 200 kPa、边界压力为零的 12 个四面体，主机按当前位姿裁剪两处接触面，CUDA 联合求出状态和双侧接触力。滑轨承担竖直反力。重力设为零，便于在夹紧结束后独立施加已知的竖直载荷。[可运行的声明与实验](../../experiments/area_pressure/moving_jaw_grasp.py)

每步 4 ms。前 15 步每爪向内驱动 0.45 N。接着 8 步保持驱动力，对自由物体质心施加 0.22 N 向下载荷。最后 12 步每爪改为向外驱动 0.9 N，物体外载持续存在。面和力按本步入口几何及共同求得的速度发布。在第 26 步，两侧采样仍存在、承载力已经为零，第 27 步入口的采样数才变为零。两组最大单爪内移量减去初始间隙均为 0.64953 mm，这是本柔顺压力场工况下的名义压入量。

**独立验证。** 每步以物体入口质心为共同参考点，从公开观察读取三体的力与力矩，再按自由体姿态和两滑轨方向重建 8 维广义力。同一时间段独立检查动量方程、角动量方程、滑轨阻尼、电机输入及位置、姿态积分。两组的三体接触力之和最大分量为 1.12 × 10⁻¹⁶ N 以内，接触力矩之和在 8.7 × 10⁻¹⁹ N·m 以内。光滑对照符合已知外载下半隐式 Euler 的解析下落量。测试同时阻止 CPU MuJoCo 推进状态。[逐步验证与物理对照](../../tests/test_mujoco_area_friction_moving_jaws.py)

首轮案例的逐分量 0.00005 N 平动力误差断言失败。有摩擦组全窗用竖直动量变化反推的力与发布值最大相差 0.000183 N。现有求解器在冲量的逆响应矩阵范数和速度修正量上设限；本批最终检查按这两项原标准，使用案例独立重建的质量、阻尼和输入。另核承载窗口的外载冲量 −0.007040 N·s、向上接触冲量 0.00690523 N·s 与实际动量变化，三者的平衡误差为 8.05 × 10⁻⁷ N·s。物理参数、求解精度和原始失败记录均保留。

**验证记录。** 本批 CUDA 轨迹与共用压力网格的原声明回归共 2 项通过，17.40 s。改动涉及的 Python 文件通过 Ruff 检查与排版。原始命令、日志及逐步 JSON 保存在本地 `artifacts/area-friction-moving-jaws-20261119-01` 下，最终轨迹在 `07-final-pytest/test_moving_jaws_clamp_load_an0/grasp.json`。

验证范围为水平导向双爪在 0.14 s 内的闭合、指定外载下承载和释放。平滑摩擦允许少量滑移。本例未验证自重 2.94 N 下的提举、长期悬停或机械臂搬运。下一批沿现有计划分解整步成本，覆盖接触面生成、装配、求解和发布。
