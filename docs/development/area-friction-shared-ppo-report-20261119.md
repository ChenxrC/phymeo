# 两个 CUDA 夹爪世界共用一次 PPO 更新

本次实验验证面积摩擦分支的接触力能从仿真步进入训练损失，并实际改变共享网络的权重。两个世界使用同一套八自由度夹爪与 0.30 kg 方块，向上外载分别为 0.22 N 和 0.11 N。两者的任务都是夹起方块。种子为 720，每世界采样 24 步，步长 4 ms。

## 从接触到参数更新

每次决策使用当前关节与物体状态，以及上一个已提交物理步在物体侧产生的接触特征。四个角色各有八个字段。状态、补齐掩码和接触特征共同输入策略网络与价值网络。世界 41 的两个夹爪和一个水平扰动力可控，世界 7 只有两个夹爪可控。两个世界的竖直外载按各自偏置施加。固定载荷和补齐位置均排除在动作概率、熵与 KL 的计算之外。

策略存储原始高斯动作，环境只做一次 tanh 与物理量缩放。48 条样本进入 RSL-RL 5.5.2 的 rollout storage 和一次打乱顺序的完整 minibatch。测试从原始动作逐条匹配取样记录，核对状态、有效动作和接触力，并在带梯度的前向调用中读取两张网络实际收到的接触张量。两张网络第一层连接第一指法向力和 z 向摩擦力的权重均获得非零梯度。[训练适配器](../../src/phymeo/training/rsl_manipulation.py) · [逐样本测试](../../tests/test_manipulation_area_ppo.py)

| 观测 | 世界 41 | 世界 7 |
| --- | ---: | ---: |
| 第 18 步输入，第一指法向力 | 0.41311 N | 0.33912 N |
| 第 18 步输入，第一指 z 向摩擦力 | −0.10973 N | −0.05485 N |
| 第 19 步末是否超时重置 | 是 | 否 |
| 第 20 步输入，第一指法向力 | 0 N | 0.34847 N |

世界 41 第 19 步的原始奖励为零。超时前的终端状态估值为 0.15691626，步初估值为 0.15699047，重置后估值为 0.06218057。轨迹存储的该步奖励为 0.15534709，等于 0.99 乘以终端估值。超时只补一次，优势估计在重置处截断。另一世界继续使用原轨迹。

一次 Adam 更新覆盖 6,953 个参数。策略主干和输出层的最大绝对权重变化分别为 0.000300001 和 0.000300005，价值网络对应为 0.000299998 和 0.000300005。48 条样本的原始任务奖励均为零，本次验证范围是采样、物理响应和参数更新的闭环。抓取成功率与训练吞吐尚待单独测量。

## 复现与故障处理

在仓库根目录，使用已配置 TYX CUDA、MuJoCo 和项目 training 依赖的 Python 运行以下命令。

```powershell
python -m experiments.area_pressure.train_gripper
```

独立运行该命令得到 24 步、有限梯度和 Adam 步数 1。运行日志保存在同一证据目录的 `10-example.stdout.log`。[可运行的夹爪实验](../../experiments/area_pressure/train_gripper.py)

最终两份测试文件合计 10 项通过，耗时 38.70 s，五个相关 Python 文件通过 Ruff 和格式检查。故障用例覆盖轨迹写入中断、环境或底层批次被外部重置、关闭环境，以及 Adam 写入非有限矩。物理步提交后遇到写入失败，须丢弃这次训练会话。优化器已经写入的异常状态也须丢弃。证据保存在本地 `artifacts/area-friction-ppo-20261119-01`，其中 `09-final-contract-pytest/test_shared_manipulation_ppo_u0/shared-ppo.json` 保存逐步力、超时估值及权重变化。[上一批策略输入实验](area-friction-policy-input-report-20261119.md)

下一批在现有面积求解容量内混用两套不同运动学构型。继续用一套网络更新，并验证各自的状态宽度、动作映射、接触身份和独立重置。这样可以检验本批在同构夹爪上打通的训练链能否跨模型复用。
