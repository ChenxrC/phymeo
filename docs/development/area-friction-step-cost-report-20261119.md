## 对照和复现

每个工况依次运行普通、分段、分段、普通四遍，每遍重建批次。首遍提供每个物理步的对照。其他三遍对照完整物理收据、接触面、积分状态、逐接触目录、设备观察数值数组；数组校验形状、类型和全部字节。每个新运行实例的配置身份按当前世界、步及入步状态核对。每步另核每桶、每对、每世界的阶段调用数及时间分区闭合。四项 CUDA 测试通过，113.54 s。所有计时钩子均限于单线程实验调用。[计时实现](../../experiments/area_pressure/scene_step_timing.py) · [工况与对照](../../tests/test_mujoco_area_friction_step_cost.py)

在项目环境从仓库根目录执行，用一个空的新目录作为 basetemp。各工况输出自己的 JSON，含全部步骤及每段耗时。汇总命令读取这些文件，无需重新跑物理。

```powershell
python -m pytest tests/test_mujoco_area_friction_step_cost.py -q --basetemp=./cost-run
$profiles = (Get-ChildItem ./cost-run -Recurse -Filter scene-step-profile.json).FullName
python -m experiments.area_pressure.summarize_step_cost $profiles
```

本机原始记录在 `artifacts/area-friction-step-cost-20261119-01`。普通路径与分段路径都保留已有的 JIT 缓存。分段运行增加同步栅栏；普通路径的吞吐用于端到端比较。同模型每遍只有两个后续步；例如 4 世界两遍普通后续步均值分别为 380.81 和 426.22 ms。这些测量适合决定本机优化顺序，缺少长期吞吐及跨引擎速度比较所需的样本。

## 下一批的改动与验收

先在单次 Scene.step 内，按完整输入复用本步已复核的四面体压力体或刚性面。位置相同但材料、连接关系、标识、坐标字节或压力值不同的输入需独立处理。双爪的两个接触对共享同一物体压力体，即使两个世界经历不同运动，这一侧也可能命中。复制场景产生的跨世界命中要与单世界多接触对的命中分别报告。[每对网格的构建入口](../../src/phymeo/geometry/area_pressure_intersection.py)

每对仍需绑定本世界、本步、双方身份和实际位姿，独立生成接触面并求解。验收使用同输入完整输出对照，并加入同拓扑不同姿态或压力、非法输入、多个世界独立运动的对照。保留未命中的成本和事务失败行为，按普通完整步时评价收益。本批交付测量基线，尚未实施网格复用。
