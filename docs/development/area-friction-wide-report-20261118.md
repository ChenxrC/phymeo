# CUDA 面积摩擦的自由度扩展及刚体压入量

## 可动平板

在同一个 Scene 中，自由方块有六个速度自由度。质量为 0.75 kg 的有限平板在第一组中沿 Z 轴移动，在第二组中还能沿 X 轴移动。法向承载会推动平板沿 Z 轴运动，切向摩擦会推动它沿 X 轴运动。这个选型可直接检验新增的雅可比列和广义力分量。

设备按模型选择六列或八列存储。质量矩阵、双方积分点雅可比、求解向量和迭代记录使用同一列宽。空间雅可比的六行仍表示三维平移和三维转动。既有六列检查点沿用原记录布局。模型声明继续检查原生约束与面积摩擦的组合能力。

[场景与独立测试](../../tests/test_mujoco_area_friction_wide.py)使用编译后的原生 MuJoCo 在相同入步状态计算质量矩阵、积分点雅可比和偏置力。测试以发布的广义速度单独积分位置，并核对平板关节反力、运动、设备观察、保存恢复和重演。

## 接触深度

面积压力接触通过几何重叠生成承载面。每个积分点保存压力、法向压力梯度与真实面积。求解器的等效间隙用于计算接触力；几何压入深度需要从两个物体的位置和外表面单独量取。

原中心跌落轨迹使用 0.30 kg 自由刚体、1 ms 步长与 1 mm 初始间隙。逐个读取 150 个已接受的步末姿态，用刚体变换把压力体的外表面三角形裁剪至有限平板两块三角形的投影，量取最低点距板顶的竖向深度。这个案例的板面水平。量测沿用已保存的状态，未重新求解动力学。

| 事件 | 步末时刻 | 几何压入量 |
| --- | ---: | ---: |
| 首个出现重叠的步末 | 14 ms | 0.03005 mm |
| 150 个步末中的最大值 | 32 ms | 1.96249 mm |
| 观测结束 | 150 ms | 1.24715 mm |

这些值包含模型的接触柔顺性和离散步进影响。这条轨迹没有将两者分别量化。当前面积接触使用入步几何；高速穿越薄壁需要独立的扫掠检测与响应验证。[原案例与互动查看器](area-friction-live-report-20261118.md)

## 验证结果

CUDA 新增三个案例通过（10.57 s）。七、八自由度分别通过质量矩阵、雅可比、关节反力、运动及检查点重演核对。第三例将六、七、八自由度的三个模型按不同于声明的顺序放进同一批，核对各自的状态、载荷有效性、观察补零及迭代记录宽度。四个受影响的兼容测试文件共 15 项通过（10.63 s），涵盖能力检查、既有场景、设备输入装配及独立面积摩擦求解。原六自由度的保存恢复、逐世界重置和失败处理另有 4 项通过（14.11 s），本批合计 22 项。10 个相关 Python 文件通过 Ruff 和格式检查，包括先前待查的查看器源文件。

原命令、逐步输出与 150 个步末的深度保存在 `artifacts/area-friction-wide-20261118-01`。新增范围为实验分支上的 CUDA 刚体面积摩擦，单模型至多八个速度自由度。面积接触与原生约束在同一世界共同作用的能力仍待实现。

## 同一世界的混合约束

下一项是在同一个速度解上处理面积压力和原生关节约束。以下是已装配单行方程的预定对照，可用于检验实现。取一千克滑块、步长 0.01 s、初速度和外力均为零。面积力采用单积分点刚度 1000 N/m、等效压入 1 mm、切向摩擦系数为零。原生导轨干摩擦行取雅可比 1、正则系数 1 kg⁻¹、参考加速度零。

令加速度为 a，步末速度为 0.01a，面积力为 F，导轨反力为 λ。代入得到 F=max(0,1−0.1a)，a=F+λ，λ=clip(−a,−L,L)。下表为解析基准，L 是导轨摩擦上限。

| L / N | a / (m/s²) | F / N | λ / N |
| ---: | ---: | ---: | ---: |
| 2 | 10/21 | 20/21 | −10/21 |
| 1/4 | 15/22 | 41/44 | −1/4 |

将来把实际编译的行参数、速度、两类力和运动分别代回联合方程。这组对照覆盖自由行与触及摩擦上限两种情况。关节阻尼非零时，还需要区分物理加速度和隐式阻尼积分加速度。[原生约束求解](../../src/phymeo/backends/mujoco_tyx/_constraint_solver.py)
