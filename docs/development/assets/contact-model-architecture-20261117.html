检测确定接触域；材料与接触律确定载荷；共同求解决定双方运动。已有事务基础、HOST 面积端口与未来接线，在图中分别标明。

一个 pair 的同一物理机制，只走一条生产路径。失败不能偷偷换物理模型；共同发布的已有基础，也不等于跨模型共同求解已经完成。

哪些基础已经存在？

MuJoCo-TYX 已有原生行、求解、双 bank 入步接触记录和异构共同提交。resident 已有 accepted-state 借用、宽相与有限 HOST 接触事务。

边界：resident 当前姿态宽相不是 CCD；多个机械树共享 publication，也不代表它们已有隐式接触力共同求解。I0/I1 仍是 HOST 几何与代数端口。

面积、材料、求解器不同层

归一 weights：总和为 1，分配全 patch 载荷。真实 dA：单位 m²，压力乘面积产生力；还须保留压力分布的力矩。

Kamino（本地 Newton 1.7.0）是刚体动力学求解器；FFT 是非局部半空间材料参考；Fourier 只表达几何。三者不能凭同一“接触”名称互换。

新计划采用双 C2 紧支撑椭圆峰，非全域凸。12 个固定 FFT 参考已通过；独立峰相加高估总力 8.06%。force-only 插值误差 9.16%，未获 5% 资格，不承诺压力场、CoP、矩或能量。

按什么顺序落地？

① I2 单路径：先在 MuJoCo-TYX 验证面积压力到实际双方速度的离散关系，核 M 与 M+h·Cjoint 的区别。

② 设备与生命周期：容量、失败、entry/endpoint、reset/restore/checkpoint。③ resident：共同机械算子完成后再接入。

总力表不能直接进入 I2：还缺完整 wrench 和已验证的增量响应。fallback 不偷换模型；切换前先处理历史、warm start 与能量。
