## 3. 标定与模型筛选

三个预声明候选F=C_p δ^p，p=1、1.5、2；各自C_p=F0/δ0^p，单位N/m^p。k=dF/dδ，U从0积分到δ且U(0)=0。3/2指数是Hertz先验，不是单点自动学出的物理。第四候选是直接使用R/E*的Hertz解析解，不从FFT拟合，默认始终参与。

| 候选 | 五点最坏载荷误差 | 最坏切线误差 | 最坏储能误差 | 能力 |
| --- | --- | --- | --- | --- |
| 线性标定 | 42.143% | 52.619% | 77.679% | 力/切线/储能，未过5% |
| 3/2次标定 | 0.51044% | 0.51044% | 0.51044% | 三项过1%，未过0.1% |
| 二次标定 | 42.143% | 89.524% | 40.774% | 力/切线/储能，未过5% |
| Hertz解析 | 浮点舍入量级 | 浮点舍入量级 | 浮点舍入量级 | 另有面积/峰值 |

资格依据独立Hertz物理参考，另表保留与FFT离散解的差异。不能因FFT存在离散误差而处罚精确解析式。参数在读取验证点之前保存，验证结果不回写系数。单点拟合准确不等于多个压入量都准确，线性/二次候选正是这个反例。

## 4. 自动选择实际做了什么

完整请求矩阵240项，加4项明确拒绝请求，共244次实际调用导出的冻结registry：
- 65次选择并产生公式实际结果，179次拒绝且无伪输出。这是接口覆盖数，不是操作成功率。
- 默认5%或1%的总力需求，本次选3/2次标定律；0.1%选解析式。
- 力/切线/储能与全部五scalar输出组，本次允许全部时选解析式；只许简化律时按能力与精度决定是否拒绝。
- 域、离散点、所需输出、公式版本/来源绑定、完整验证表、非有限值及计时记录都检查。checksum是完整性绑定，不是抵御恶意重签记录的密码学证明。
- 查询只用预先冻结的最坏误差，不读取当前点参考值重新择优。新响应调用一次选定公式；不是查表冒充评价。

## 5. 速度结论：没有证实整体加速

每个候选/输出组32次warmup，7批×1000次相同输出的真实公式调用，候选顺序轮换；包含输入检查及返回dict，记录batch均值的中位和范围。

| 输出组 | 3/2标定中位μs（范围） | Hertz解析中位μs（范围） |
| --- | --- | --- |
| 总力 | 1.0253（0.9626–2.2784） | 1.0389（0.9435–2.7920） |
| 力/切线/储能 | 1.5673（1.2986–1.9117） | 1.4964（1.3553–1.7781） |
| 五scalar | 不支持 | 2.1246（2.0532–2.1485） |

**范围重叠，不能判定稳定速度胜者。** 本批严格保留冻结的最低中位数规则，默认选中标定律不表示它实质优于解析解。完整“资格筛选＋返回说明＋预测”约数十μs，抽查75μm请求约34–74μs，明显高于公式本身。预算字段只约束候选公式评价中位数，是软预算，不能当完整接口实时保证。

0.398s是本批不含FFT的离线标定/资格/测速runner部分，不是全部参考获取成本。新FFT求解分别4.134/7.313s，含NPZ/元数据保存的case总时间分别5.818/9.272s；旧标定数据获取成本另计。不能用缓存读取时间冒FFT在线成本，也不能据此声称物理引擎倍数加速。

## 6. 可复用接口及边界

新增模块experiments/contact_selection/autoselect.py；构造Selector时读已验证registry，之后查询不需要ContactMechanics或Newton。示例：

```python
import json
from pathlib import Path
from experiments.contact_selection.autoselect import Selector

registry = json.loads(Path(
    "artifacts/contact-autoselection-20261116-01/calibration/registry.json"
).read_text(encoding="utf-8"))
selector = Selector(registry)
decision = selector.select(
    75e-6, profile="force", tolerances={"force": 0.001},
)
# SELECTED: hertz_analytic；字段中保留候选拒因与实际预测。
```

原型只在实验模块，不是Phymeo产品自动后端。没有压力场输出、摩擦、动力学、粗糙面、薄层、大变形、连续点间资格，也没有在线FFT/跨solver状态转移。Hertz解析本身有更广理论适用域，但本原型未据此扩展资格。

## 7. 下一步的有界方向

1. **工程选型放到初始化**：复用已选择模型，参数/域变更时失效；计时无法区分时优先更准确、更简单的已合格模型。先验证缓存和失效，避免每接触每步花数十μs重复选型。这是后续策略，本批没有事后改规则重测。
2. **换一个真正需要数值参考的几何**：预先固定非轴对称或有限粗糙形貌、标定/未见验证输入，继续在半空间模型内。Hertz不适用时明确退出，才能检验FFT离线标定的额外价值；不直接外推本球案例。
3. 只有模型收益和摊销成本明确后，再将单一接触律接入整体动力学，验证同一步力/力矩/运动，避免硬接触与材料压力重复施力。
