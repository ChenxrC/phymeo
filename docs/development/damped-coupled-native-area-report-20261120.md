# 两个有阻尼关节共同承受地面接触与面积摩擦

材料摩擦只施加在近端滑块上，远端滑块带球接触地面。两组使用同一初态、几何、步长和地面摩擦系数，只把侧面摩擦系数从 0 改为 0.5。每个 2 ms 步由当前姿态生成面积接触面，TYX CUDA 同时求两处接触与两个关节的步末速度。[单自由度基线](damped-scalar-mixed-area-friction-report-20261120.md)

## 近端摩擦如何改变远端承载

两个滑块各 1 kg。近端滑轴方向为 (0.6, 0, −0.8)，远端相对滑轴沿 +x。由两物体动能直接得到质量矩阵 `M=[[2,0.6],[0.6,1]] kg`。近端压力积分点相对于远端关节的速度雅可比为零，所以侧面施加给远端的直接广义力严格为零。两块之间仍通过非对角惯量和地面反力交换载荷。

| 步末 | 侧面摩擦系数 | 近端速度 (m/s) | 远端相对速度 (m/s) | 地面法向支撑 (N) |
| --- | ---: | ---: | ---: | ---: |
| 2 ms | 0 | 0.081978 | 0.071482 | 51.877 |
| 2 ms | 0.5 | 0.081597 | 0.071707 | 43.715 |
| 6 ms | 0 | 0.026239 | 0.060273 | 37.928 |
| 6 ms | 0.5 | 0.025363 | 0.060792 | 30.025 |

有侧面摩擦时，第一步的切向力投到近端滑轴上为 −6.847 N，侧面法向与切向合计的两关节广义力为 (3.425, 0) N。关掉侧面摩擦后变为 (10.269, 0) N。两个世界均逐步核对了法向力、摩擦上限、局部功率、双方力矩和两关节的速度。[双滑块与独立二维参考](../../tests/test_damped_coupled_mixed_area_friction.py)

## 转动时重新计算动力学

第二个模型用滑台带动偏心铰链，球和压力体都安装在转动子体上。解析耦合项为 `M01=0.04 cos(θ)−0.03 sin(θ)` kg·m。三个连续入步的设备值为 0.0400000、0.0399846、0.0399739 kg·m，首步偏置力为 −0.003675 N。第一步地面对滑轴和转轴分别施加 −21.457 N、−1.767 N·m，侧面分别施加 +3.459 N、+1.210 N·m。设备直接计算的两列雅可比、偏置、物理加速度与速度积分分别对照了解析几何及 MuJoCo 的当步前向计算。[滑台与偏心铰链测试](../../tests/test_damped_coupled_articulated_contact.py)

## 方程、验证与范围

每个候选速度先决定面积法向力和切向力，得到关节广义力 `Q(v)`。对该次接触的四条原生单边行，在至多 16 个活跃组合中用二维矩阵 `H=M+Σ JᵀJ/R` 求物理加速度和原生反力，再用 `A=M+hD` 检验动量与速度。计算面积力导数时按 `M H⁻¹` 左乘，保留非对角耦合。每个通过的输出还要满足原始行方程。独立测试从自由运动速度出发，在 FP64 直接求解未经消元的二维方程，以 CPU MuJoCo 提供当前姿态的系数。CPU 没有代替 TYX 推进被测状态。[设备求解](../../src/phymeo/backends/_tyx_area_friction_kernels.py)

本机串行最终验证 **43 项通过，22.99 秒**，其中新增 8 项 CUDA 工况和 4 项编译准入检查，另有 31 项回归。双滑块从首步保存点重演后两步，已逐值核对状态、几何及设备观察。分别篡改原生接触雅可比的两列，恢复均在设备写入前拒绝。还验证了空面积、地面分离、两处均无接触、容量溢出后原状态上重试。14 个涉及的 Python 文件通过 Ruff 与格式复检。命令、逐步数据及运行收据在本地目录 `artifacts/damped-coupled-area-friction-20261120-01`。在配置 TYX CUDA 的环境可复现新增用例：

```powershell
python -m pytest -q tests/test_damped_coupled_mixed_area_friction.py tests/test_damped_coupled_articulated_contact.py
```

当前混合路径支持两个标量转动或滑动自由度、一对原生 condim-3 球–平面接触，以及显式面积摩擦。一般多自由度、多原生支持对、关节限位和干摩擦的组合仍待开发。下一批优先在两个有阻尼关节上接入行程限位，覆盖进入、持续承载及退出限位后地面和侧面继续工作。原始 RR Push‑T 包含八个速度自由度、两处限位和九对保留的原生候选，仍需整场景验证。[RR 模型与原生轨迹对照](rr-pusht-area-reference-report-20261119.md)
