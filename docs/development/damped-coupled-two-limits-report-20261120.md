# 双关节独立限位、地面支撑与面积摩擦

在 TYX CUDA 上，两个有阻尼的串联关节可以各自声明软限位。两个滑块在同一条 38 ms 轨迹上先后到限、同时承载、分别退出。整个过程中，远端球与地面的原生接触、近端与侧板的分布面积接触都在同一步产生运动和反力。第二个构型用偏心铰链替换远端滑块，另核对了力与力矩的单位和方向。[连续轨迹和故障测试](../../tests/test_damped_coupled_two_limits.py) · [滑台与铰链测试](../../tests/test_damped_coupled_contact_limit.py)

## 两个滑块的实际运动

近端下限为 −0.35 mm，远端上限为 +0.50 mm。两者使用不同的 MuJoCo 限位时间常数和阻抗。每步 2 ms，控制器根据真实入步状态施加有限广义力，先驱向两个限位，随后依次反向。从实际姿态生成侧面几何。表中时间为步末时间，限位激活按入步姿态判定。载荷列给出反力大小，近端下限的方向为正，远端上限的方向为负。

| 步末 | 近端下限 N | 远端上限 N | 地面法向 N | 侧板法向 N |
| --- | ---: | ---: | ---: | ---: |
| 2 ms | 无行 | 无行 | 221.07 | 18.30 |
| 8 ms | 无行 | 14.68 | 187.55 | 19.22 |
| 18 ms | 10.04 | 17.27 | 153.16 | 20.74 |
| 20 ms | 9.06 | 0 | 1300.17 | 21.04 |
| 28 ms | 12.14 | 无行 | 234.63 | 22.24 |
| 32 ms | 0 | 无行 | 3928.88 | 20.37 |
| 38 ms | 无行 | 无行 | 1284.46 | 13.88 |

20 ms 时远端已经卸载，28 ms 时它的约束行才从入步状态消失。18 ms 时两滑块步末位置为 −0.5072 mm、+1.7525 mm，可见软限位允许越程。32 ms 的反向驱动产生约 3.93 kN 的地面瞬时支撑，这个量随施加的急转向外力变化。该工况验收载荷的传递和释放，尚无硬止挡精度或真实执行器标定结论。

## 求解和发布验证

- 从同一入步的 MuJoCo CPU FP64 前向计算读取质量矩阵、原生约束雅可比、正则化与参考加速度。再独立求解含侧板法向力与切向力的两变量方程，逐步核对 TYX 发布的速度、各行反力、面积力、总广义力和下一姿态。物理加速度使用 `M`，带隐式阻尼的速度更新使用 `M+hD`。19 个原始步的 CUDA 最大归一化残差为 `6.88e-8`，原门槛为 `2e-5`。
- 按关节身份、自由度、上下限和各自的材料参数检查每条限位行。滑台加偏心铰链的首步同时测得滑台限位反力 28.33 N、铰链限位力矩 +2.746 N·m。绕同一铰轴的地面和侧面力矩分别为 −4.508 和 +1.209 N·m。
- 在第 9 步共同承载时保存检查点，恢复后重演第 10–19 步。状态、力、接触几何和设备观察逐值一致，重建的几何标记允许新的配置身份。把第二个限位的来源改成第一个，会在设备写入前拒绝恢复。
- 将容量设为 8，先连续接受 7 步，每步含 1 条限位、4 条地面摩擦棱和 3 个面积采样。第二个限位进入后需要 9 行，该步被拒绝，状态、检查点、已发布结果和设备观察保持相同。从同一入步改用空面积面重试，6 条原生行成功发布，两限位实际反力分别为 10.79 和 19.38 N。
