# 两处地面支撑与侧面面积摩擦的共同求解

一个斜向滑台和一个偏心铰链驱动同一刚体，刚体左右两端各有一个球形接触面，两球与地面使用不同的摩擦和法向参数。侧板从当前姿态生成三个面积积分点。每个 2 ms 的 TYX CUDA 步同时求出地面反力、侧板压力与摩擦、滑台速度和铰链角速度。[连续轨迹与独立参考](../../tests/test_damped_coupled_two_supports.py)

## 载荷怎样从左边转到右边

表内时间为步末时间，接触几何取自该步入口。力矩取两端各自的完整世界接触力绕铰轴的分量。

| 步末 | 左侧法向 N | 右侧法向 N | 左 / 右铰轴力矩 N·m | 侧板法向 N |
| --- | ---: | ---: | ---: | ---: |
| 2 ms | 1320.85 | 分离 | +179.55 / 0 | 22.38 |
| 10 ms | 1299.12 | 310.69 | +171.51 / −29.96 | 18.55 |
| 12 ms | 1416.81 | 1147.02 | +185.83 / −129.74 | 17.69 |
| 14 ms | 已检测，0 | 6172.80 | 0 / −890.55 | 16.46 |
| 30 ms | 分离 | 4073.80 | 0 / −521.49 | 6.59 |
| 32 ms | 分离 | 4187.52 | 0 / −534.82 | 5.35 |

换向时控制器根据实际入步状态施加广义力，右侧瞬时承载达 6.17 kN。这组强驱动用于检验高载荷相消和接触切换，未做执行器标定。左侧先卸载，随后退出检测。30 ms 时右侧在紧凑接触列表中的编号从 1 变为 0，固定几何槽仍是 1。其四条摩擦行、刚体反力和偏心力矩均可追溯到右侧。在 12 ms 保存检查点，再执行并重演末尾十步，状态、各处载荷、几何和设备观察逐值复现。

另一个对照从两球各压入地面 0.2 mm、侧板压入 0.1 mm 开始，外部广义驱动力为零。首步左、右和侧板法向力分别为 3.381、1.539、0.888 N，左、右接触绕铰轴力矩为 +0.169、−0.254 N·m。滑台速度从 0.002 降到 0.000268 m/s。测试先用同一入步的 MuJoCo CPU 结果核对设备质量矩阵、行雅可比、正则化和参考加速度，再以已发布系数和独立运动学雅可比，在 FP64 中求解包含侧面压力与滑动摩擦的两变量方程。

## 力如何进入运动更新

原双支撑试算中约 2361 N 的外载与方向相反的约束力相消。各自先舍入再相加，得到的物理加速度未通过原逐行力检验。双支撑 CUDA 路径现对每个面积点、每条原生行和外载进行带补偿的 FP32 累加，分别发布约束广义力和积分器实际使用的含外载净力。被动力与偏置在原生积分阶段计入一次。至多四轮相邻浮点数检查仅接受能降低最大逐行缺陷的变动。每一步仍独立检查单侧反力、完整动量方程、物理加速度及发布速度。双方力矩用同一已发布接触点与各自质心计算，另与 CPU 入步位姿核对。[设备求解](../../src/phymeo/backends/_tyx_area_friction_kernels.py) · [接触来源与力矩校验](../../src/phymeo/backends/mujoco_area_native_contact.py)

验证覆盖两处均分离时的空面积和非空面积、共同承载后的容量拒绝与原状态重试，以及篡改几何槽、紧凑接触编号或积分器净力的恢复请求。容量为 11 时八条地面摩擦行加三个面积点可接受，八条加六个则在发布前拒绝。[状态与容量测试](../../tests/test_damped_coupled_two_supports_lifecycle.py)

## 成本、复现及下一项

同一条原始 CUDA 轨迹上，除首步外，单个几何接触的端到端步时中位数为 **18.34 ms**（5 步），两个接触为 **20.67 ms**（10 步），两组每步都有三个面积点。记录覆盖从调用场景步到成功返回，包括几何与发布。两个接触组也包含几何仍检测到左侧但其力已为零的步。该样本来自单世界，尚不足以外推批训练吞吐或单独归因 GPU 求解耗时。

本机相关功能和回归共 **57 项通过，38.73 s**。本地执行选择及完整返回码在 `artifacts/damped-coupled-two-supports-20261120-01/27-cuda-regression.guard-command.json` 及同目录收据，数值摘录在 `accepted-trace-summary.json`。在仓库根目录、已安装项目与 TYX CUDA 依赖的环境可复现核心用例。

```powershell
python -m pytest -q tests/test_damped_coupled_two_supports.py tests/test_damped_coupled_two_supports_lifecycle.py
```

本批范围是两个有阻尼的标量关节、两对球–平面、每对四条原生棱及侧面面积摩擦，双支撑路径尚未包含关节限位。当前完整枚举最多有 256 个原生活跃组合。原始 RR Push‑T 有八个速度自由度、两个受限铰链和九对保留原生几何。下一步以原模型实际活跃行及其身份为输入，验证可扩展的共同求解方法，再在同一条推动与撤离轨迹上核对关节响应、桌面承载和推杆面积力。[原始模型和五姿态基准](rr-pusht-area-reference-report-20261119.md)
