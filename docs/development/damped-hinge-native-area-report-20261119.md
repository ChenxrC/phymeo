# 有阻尼铰链上的原生摩擦支撑与面积压力

一个转轴同时受到两个接触的力矩。地面的原生球–平面接触提供法向支撑和滑动摩擦，另一处有限表面提供分布法向压力。两处使用同一次 TYX 约束求解、速度更新和状态发布。接触力通过各自的实际力臂回到关节。[前一批 RR 参考实验](rr-pusht-area-reference-report-20261119.md)

## 同一初态的 CUDA 对照

杆质量 0.6 kg，质心距关节轴 0.05 m，绕轴总转动惯量 0.0315 kg·m²，黏性阻尼 5 N·m·s/rad。入步角速度 0.35 rad/s，步长 2 ms，重力为零。支撑球与地面的初始法向重叠量为 2 mm，摩擦系数 0.7。另一处给定三角面的面积为 0.005 m²，弹性压力梯度为 2×10⁶ Pa/m，初始等效压入量为 1 mm。

| 同一步的实际发布量 | 仅原生支撑 | 原生支撑与面积压力 |
| --- | ---: | ---: |
| 地面法向支撑（N） | 58.1198 | 73.7588 |
| 地面切向力 x 分量（N） | −40.6839 | −51.6311 |
| 面积法向合力（N） | 0 | 9.78393 |
| 地面对铰链的力矩（N·m） | −2.86531 | −3.63631 |
| 面积压力对铰链的力矩（N·m） | 0 | +0.813887 |
| 步末角速度（rad/s） | 0.127576 | 0.129642 |

面积载荷的力矩部分被地面的额外反力矩抵消。空面积输入与同一 XML 的原生 TYX 路径逐值核对了位置、速度、物理加速度、广义约束力和四个摩擦锥边力。在混合工况中，物理角加速度为 −145.156 rad/s²，计算步末速度所用的积分角加速度为 −110.179 rad/s²。[独立参考与设备对照](../../tests/test_mujoco_tyx_damped_hinge_support.py)

## 两类接触怎样共用一个求解器

设标量惯量为 M，步长为 h，黏性阻尼为 D，A=M+hD。对于含接触反力的总广义力 Q，原生接触行使用物理加速度 a=Q/M，弹性面积行使用积分加速度 aᵢ=Q/A；v₁=v₀+h·aᵢ。单自由度时 A/M 为正标量。设备使用 M 求解，对弹性行的正则化系数 R 和参考加速度乘以 A/M，即可在同一次求解中同时满足两类行的原方程。原生行、面积雅可比和双方实际受力保留原单位。发布前恢复面积行的原始系数，分别用 a 和 aᵢ 重算约束残差与互补条件。

独立参考只从 CPU MuJoCo 的初态前向计算取四个原生行的雅可比、正则化及参考加速度。三个面积积分点的面积、力臂与弹性力由测试几何独立计算，以总力矩平衡的一元单调方程求根；参考计算没有调用 CPU 时间步或复用 TYX 的约束求解。[设备行装配](../../src/phymeo/backends/mujoco_tyx/_area_pressure_kernels.py) · [发布核对](../../src/phymeo/backends/mujoco_tyx/_constraint_publication.py)

## 自动接触面、恢复和失败处理

另一个场景把四个四面体组成的压力体装在同一转轴上，刚性承压面固定在对侧。主机每步从实际姿态生成接触面，在设备求解前同时保留地面原生接触。每一步都核对接触双方的作用反作用、两处对转轴的力矩和真实角速度。

| CUDA 步末 | 转轴角速度（rad/s） | 原生法向支撑（N） | 面积法向合力（N） |
| --- | ---: | ---: | ---: |
| 2 ms | +0.130297 | 78.7080 | 17.8593 |
| 4 ms | −0.054106 | 86.2475 | 17.9177 |
| 6 ms | −0.205587 | 91.3495 | 18.1397 |

从第一个运动步末恢复后，后两步的位置、速度、两种载荷及其力矩逐值重现。容量仅容四行而请求七行的另一测试保留了入步状态和修订号；同一实例随后用四个原生行成功推进。另用斜向滑动关节检验了同一标量机制。

## 验证与边界

新功能在解释后端和 CUDA 共通过 10 项测试。15 项既有对照覆盖双滑块阻尼、无阻尼混合、原有拒绝条件、跨世界发布失败和原 RR 模型的准入边界。七个 Python 文件通过 Ruff 和格式检查。可在启用 MuJoCo 和 TYX CUDA 的项目环境运行：

```powershell
python -m pytest -q tests/test_mujoco_tyx_damped_hinge_support.py
```

本地命令、退出码与逐世界结果在 `artifacts/damped-hinge-native-area-20261119-01`。首个测试夹具把质心设在铰链轴上，独立求根后的力矩平衡检查失败。表中采用偏心 5 cm 的夹具，并在参考惯量中计入平行轴项；轴上质心工况仍未获该对照验证。

本批接受单个有阻尼铰链或滑动关节、原生支撑摩擦、面积侧弹性法向响应。下一步在同一个移动铰链加入面积侧切向滑动与卸载，独立核对摩擦承载上限和功；再处理多自由度的矩阵响应、RR 两个关节限位及复合 T 形物体。三步自动接触面的结果覆盖 6 ms，长时稳定性、材料标定与真实 RR 推动仍须单独验证。
