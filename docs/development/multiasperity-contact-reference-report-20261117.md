## 1. 这次为什么需要数值参考

换成两个高低不同、横向形状不同的光滑峰，压入同一弹性半空间。它们不是两个独立地基：一个峰下的载荷，会使另一个峰附近的平面也产生位移。这使接触启闭、两峰载荷分配及压力中心耦合。

固定C2紧支撑高度场详见方案；左右峰中心为(-3,-0.375)/(3,0.375)mm，顶点相对高度为0/-40μm。E*=1MPa，24mm非周期计算窗口，五个压入20/40/60/80/100μm。24mm不是有限厚实体；模型仍为小变形、线弹性、静态、无摩擦、非黏附半空间，采用法向位移/竖向牵引近似。这里没有模拟物体下落或时间连续的冲击。

旧单抛物面Hertz解析候选在该形貌不适用。不能通过挑一个等效半径，继续把它当成新问题的独立真值；也不声称一切数学方法均不存在解析表达。[ContactMechanics模型定义](https://contactengineering.github.io/ContactMechanics/usage.html)、[官方方法与假设](https://github.com/ContactEngineering/ContactMechanics)

## 4. 独立计算两个峰会漏掉什么

![共同与独立压力的差异](../../artifacts/multiasperity-contact-20261117-01/figures/coupling-difference.png)

在同一100μm压入、同一512网格，分别只保留左峰或右峰各求一次，再叠加它们的完整力与矩：

| 输出 | 共同求解 | 独立求解后相加 | 差异 |
| --- | ---: | ---: | ---: |
| 总力 N | 0.14866413 | 0.16064592 | 高估8.0596% |
| CoP x mm | -0.831885 | -0.707304 | 二维距离0.125497mm |
| Mx N·m | -1.53927e-5 | -1.42032e-5 | 相对7.7279% |
| My N·m | 1.23671e-4 | 1.13625e-4 | 相对8.1232% |

矩以同一world原点计算，竖向合力为+z，Mx=Σyf、My=-Σxf。零Mz不制造相对误差。以上是**忽略峰间弹性耦合的模型差异**，并非FFT程序不收敛，也不是所有半空间几何的统一误差常数。

这份对照说明：非局部材料不能一般地拆成互不相干的点弹簧；只匹配总力也不足以保证力矩和运动正确。

验证是预声明的资格验证，不能再当选型后的独立泛化测试。父在只读进度汇总中看到了验证点载荷后，才启动已经冻结的拟合runner；没有因看到结果改变结点、算法或门槛，因此不称人工盲测。资格与系数绑定还经过6类变异负控：篡改系数/knots/schema/capability/预测/真值都不能继承旧误差通过。

## 6. 对新架构的直接约束

[完整说明与源码定位](contact-model-architecture-20261117.md)把目标分为：初始化计划、共享状态、宽相/窄相/CCD、分型几何、接触本构、共同动力学、一致发布。

- 检测与材料响应分别建接口：检测给接触几何及身份，材料层处理压力/耦合/摩擦。曲面Fourier表达不自动提供弹性响应。
- Kamino位于刚体共同动力学层；FFT位于材料数值参考/潜在非局部算子层，不是同层“二选一”。本地参考固定Newton1.7.0。[官方职责](https://newton-physics.github.io/newton/1.7.0/solvers/kamino.html)
- 自动选型先判适用域与输出能力，再精度，再整步成本；初始化选定后复用，有版本/域变化则失效。物理模型改变必须明确选择，不能借fallback静默把非局部半空间变成硬接触。
- 对非局部路径，保留接触域内部乃至同一材料不同接触区间的耦合；`pair`是身份/去重单位，不应强制成为彼此独立的材料求解块。
- 同一机制仅一条生产路径，避免原生法向与新压力重复施力；完整双方Jacobian和实际速度响应共同参与关节/接触/驱动求解。
- 当前面积I0/I1仍是HOST几何/代数；MuJoCo-TYX接触求解用M，实际含关节阻尼积分用M+h*Cjoint。I2必须验证实际运动的接触律，而非只检查预期力或报告加速度。

压力场到速度级共同求解已有公开离散路线，但仍须对应本项目真实积分算子。[速度级压力场方法](https://arxiv.org/abs/2110.04157)

## 7. 后续顺序与本批停止

本批按12次上限停止，不再扩大参考或拟合阶数。当前结论足以明确“数值参考有必要、局部独立相加有偏差、该小力表不能获5%资格”。

产品下一项仍是**MuJoCo-TYX单路径I2共同步**，先完成排他的pair模型、实际响应算子与双方力/矩/速度的一致发布，覆盖自由体/关节与非零阻尼。其后才设备化、生命周期和resident扩展。FFT高保真参考保持独立，不能将这份失败的force-only表当I2材料律。

若后续专门继续自动选型研究，需要另行预声明能感知接触区启闭、输出完整wrench与增量响应的候选及新验证输入；不把旧40/80μm重新称未见测试，也不反复增加同一曲线结点追绿。新架构图是目标设计，不是本批实现了完整碰撞动力学。
