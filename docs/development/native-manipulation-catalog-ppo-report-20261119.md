# 八种原始操作机器人共用一个 CUDA 训练器

2026-11-19，本机 MuJoCo-TYX CUDA。原目录中的两种抓取、三种放置和三种 PushT 模型都进入同一个 PPO。每次更新从每个世界采 32 步，共 256 条。第一次更新落盘并退出后，第二个进程恢复物理状态、策略、价值网络和优化器，又完成一次更新。两次共接受 512 条样本，Adam 从第 1 步走到第 2 步，共 109075 个可训练参数，梯度均有限。验收范围是训练链路可用。这段 64 毫秒的运动中机器人对物体的接触载荷和原始任务奖励均为零。[八种模型及任务定义](../../src/phymeo/training/manipulation_tasks.py)

## 数据如何进入网络

八份原 MJCF 由 CPU MuJoCo 编译。MuJoCo-TYX 按八个模型分组执行 CUDA 动力学，共享一套策略、价值网络和 Adam。各机器人只接收对应电机通道的动作，外加广义力及物体外力通道为零。状态和动作按各自有效宽度填入批次。两张网络收到状态、实际接触、动作掩码、冻结 MiniLM 编码的指令、全部三个可见目标区的文字与位姿，以及目标有效掩码。[训练入口](../../experiments/area_pressure/train_manipulation_catalog.py) · [共享训练器](../../src/phymeo/training/rsl_manipulation.py)

原生接触按左指、右指、桌面及其他几何分别聚合。每行记录角色是否存在、本步是否有有效输入、检测与激活的接触数、法向载荷之和，以及作用到物体的世界坐标合力。每个接触按物体位于哪一侧确定方向。同一物体的多个几何之间、完全无关的物体对、无效填充均排除。回合重置清除上一回合的接触。原面积摩擦输入继续使用自己的字段及检查点绑定。[接触特征实现](../../src/phymeo/training/native_contact_policy.py)

本轮八个模型使用原生接触。面积摩擦 v2 当前最多处理 8 个速度自由度，八个模型中的七个超过上限。余下的平面双关节推杆连同自由物体恰为 8 个自由度，但有多个受限关节、阻尼以及需保留的原生碰撞，超出目前的混合约束路径。直接给这些模型更换接触类型需要额外的求解器和配对支持。[面积摩擦宽度](../../src/phymeo/backends/mujoco_tyx/_area_friction_layout.py) · [原生约束及配对限制](../../src/phymeo/backends/mujoco_area_pressure.py)

## 验证和复现

- 短回合回归显式使用 24–31 步。八个世界各超时一次，逐步核对重置前的物体侧接触力和重置后的空输入。打乱后的 256 条样本按动作逐一找回原行，所有网络输入逐元素相同，策略和价值网络均有权重变化；有效电机指令与原始动作映射相符。合成接触用例覆盖物体位于几何对两侧、复合物体、已检测但未激活的接触和带无效数据的填充。[回归用例](../../tests/test_manipulation_catalog_ppo.py)
- 同一串行队列另运行已有面积接触的混合工具 PPO 和语言检查点回归，三项通过。正常八世界跨进程运行验证了恢复及再次更新。八世界连续与恢复运行的逐位等价尚待独立对照。
- 本机原始逐次命令、日志、退出码和检查点保存在 `artifacts/native-manipulation-catalog-ppo-20261119-01`。表中数据来自 `10-long-save` 和 `11-long-resume`。短回合证据见 `09-short-controls`，面积回归见 `04-area-regression`。

在仓库根目录运行，给两个检查点使用新的文件名。持续训练用 `--updates` 指定追加的更新次数。

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
$model = (Resolve-Path artifacts/models/paraphrase-multilingual-MiniLM-L12-v2/e8f8c211226b894fcb81acc59f3b34ba3efd5f42).Path
$python = ".\.venv-training-cuda313\Scripts\python.exe"
& $python -m experiments.area_pressure.train_manipulation_catalog $model --save-to .\catalog-first.ppo
& $python -m experiments.area_pressure.train_manipulation_catalog $model --resume-from .\catalog-first.ppo --save-to .\catalog-second.ppo
```

下一批从平面 RR 推杆开始。在原模型上用可复现的电机动作取得推杆触物、物体受力移动、分离三个阶段的原生基线。基线成立后，为工具与物体这一个几何对接入面积摩擦，桌面继续使用原生接触，逐步核对两类接触的归属、合力及物体运动。这能把接触实现的验收与随机策略是否碰巧学会推物分开。
