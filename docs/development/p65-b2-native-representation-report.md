  `reference-displacement-f32-v2` with the frozen 4096-bit exact codec bound.
  Program/participant `representation=None` retains v1 defaults/signature and
  behavior. The represented native workspace and participant wrapper are
  selected only by the explicit typed option.
- The integer/rational codec rounds exact expressions nearest/ties-even, rejects
  native nonzero subnormal/zero encodings and overflow, preserves immutable
  original reference bytes, and canonically computes positive zero. Binary64
  world subnormals are not incorrectly prohibited by the binary32 input policy.
  A separate reader proves rounding cells, bracketing and tie parity; it does not
  call the producer rounding algorithm as its ideal oracle.
- Each fresh trial owns immutable FP64 R and initially zero FP32 d. Exact
  directed reference vectors are encoded once with witnesses and actual bytes
  are retained in every batch. There is no rebase, hidden carry, fixture origin,
  world-FP32 projection round trip or two-word implementation.

  native atan2/analytic gradient/lambda/d updates, and one reconstruction from
  d_final-d_pred. Raw18/raw45 coordinate columns mean displacement only; actual
  native update products, before/after directed vectors, statuses and launch
  receipts are separate owned fields. The old raw18/raw45 meaning is untouched.
- World publication is explicitly RN64(q(R)+q(d)), not promoted single-FP32 world
  position and not native FP64 dynamics. Velocity remains promoted actual FP32.
  Host codecs and independent audits cannot replace native solve outputs.
- The v2 reader uses original world-coordinate ideal bounds, original mass/rest/
  compliance/h, both residual families, and all original branch/domain/physical
  gates. It checks the exact identity and charges, once per row coordinate,
  `|a|+|p|+|rho_after|+|rho_before|`. It retains the direct world residual as an
  exact rational-pair diagnostic, proves it is bounded, and does not add it a
  second time. Gradient/equation/lambda terms and whole-path noncancelling sums
  retain original scales. Reference-vector conversion and prediction/publication
  decoder residuals are retained as exact rational pairs.

  derived world view. This is not a v1 native receipt or a path relabeled NumPy.
  Physical energy/angular accounting remains the old independent implementation;
  NUM005 is not subtracted and R1 external receipts are not used for internal work.
- Complete private sweeps commit d, world state, both multipliers and typed frames
  together. Rejected audit caches are restored. Reconstruction fields commit only
  after a complete finite native result. The represented participant wrapper
  restores terminal candidate/requests/accepted receipts after late validation
  failure, retaining executed failed-attempt receipts separately.
- Native status failures preserve returned raw arrays in the engine's failed
  journal. Calls rejected by the existing engine before outputs are returned
  retain counts/inputs and honestly have no returned bytes. No missing output is
