# 同一运动路径上的材料与接触联合求解框架

2026-11-01，P6.5 N2 本机研究。原四节点布片与有限质量平台已通过完整的 125 ms 支撑窗口，共八个连续的 1/64 s 受载步。材料内力、六个下表面材料点的接触力和平台反力在同一条带速度的轨迹上更新。七个步间衔接均从上一进程实际发布的检查点恢复。结果适用于本例的 HOST 研究程序、恒定平动质量、无摩擦支撑及已覆盖的整段几何。[试验协议](../benchmarks/p65-common-motion-protocol.json) · [首两步验证](../benchmarks/p65-common-motion-results.json) · [125 ms 全窗验收](../benchmarks/p65-common-motion-window-results.json)

## 1. 每一步只发布一条运动

对本次支持的平动系统，令 M 为固定正对角质量阵。材料模型提供广义内力。接触地址 a 提供两侧世界作用点、相对点雅可比 Dₐ、有向间隙 gₐ 及相对速度 ġₐ。Pₐ 为一次成对的世界载荷，F₀ 包含原重力和其余真实外载。每次求值同时读取 q(t)、v(t) 和原模型参数。

```text
F(t) = F₀(t) + F材料(q(t), v(t)) + Σ Dₐ(q(t))ᵀ Pₐ(t)
v(t) = v₀ + ∫₀ᵗ M⁻¹ F(u) du
q(t) = q₀ + t v₀ + ∫₀ᵗ (t−u) M⁻¹ F(u) du
```

给定入步 q₀、v₀，位置和速度由同一组力积分得到。对每个接触地址保留 Jₐ=∫Pₐ dt 和 Bₐ=∫(h−t)Pₐ dt。对每个自由度还要保留材料内力、外力以及映射后接触力各自的两个时间矩。几何变化时，Dₐ(t) 必须放在积分内。此前的实验中，合力正确仍留下 0.472205 µm 的局部末间隙差，其中最大材料投影项为 0.472206 µm。这正是需要逐节点记录的量。[上一轮逐节点分解](../benchmarks/p65-gravity-six-owner-moment-balance.json)

本次选用二阶配点法，将加速度积分为速度和位置，强制二者满足微分关系。配点节点只用于求候选，独立检查从最终力系数恢复整段运动。这个分工也容许将来更换求解方法，只要保留同样的路径、物理字段和判据。[二阶配点的运动学一致性研究](https://arxiv.org/abs/2302.09056) · [可复用的积分核心](../../scripts/p65_common_motion.py)

## 2. 模块与交付契约

| 职责 | 输入与输出 | 必须检查 |
| --- | --- | --- |
| 状态和模型绑定 | 原始状态、输入、材料参数、几何参考、稳定地址、时长和检查点构成一次试验身份。 | 从精确检查点恢复 q₀、v₀，逐坐标核对公开状态的 FP64 表示。 |
| 力提供者 | 每次读取同一时刻的 q、v，返回材料广义力、每个地址映射到两侧的广义力行和对应世界力。原始外载单独登记。 | 地址不重不漏，形状和单位正确。在同一身体上按物理节点汇总共享地址。机器人也要登记作用点和力矩。 |
| 联合求解与路径表示 | 求解整步的力系数，由同一组系数生成加速度、速度和位置。预条件矩阵只用于提出下一组系数。 | 每次真实力求值在当前候选路径上完成。独立验算最终输出的定律残差，资源耗尽即拒绝。 |
| 整段物理检查 | 独立重建原始输入绑定、硬间隙、力—间隙定律、两类时间矩、动量、能量和角动量。 | 检查每个时间区间和每个材料地址，分别报告已证安全、已证违反及无法判定。 |
| 提交与续接 | 通过后发布域状态、精确历史包、受力曲线和证书。拒绝时由公开运行时退回原始域状态和历史。 | 后一步只读实际发布包。端点相同但步内力错误的候选也须被识别。 |

实际核心读取 `mass`、`external`、有序的 `owners`、`forces(q,v)` 和 `linearization(q,v,first)`。其中 `Forces.material` 在自由度上存储材料力，`Forces.rows[a]` 记录地址 a 在各自由度上的成对作用，`Forces.pressures[a]` 记录本例中沿法向的力，单位为 N。线性化只影响收敛。布片适配器使用真实的有向弯曲梯度、距离弹性力、偏置点速度和完整雅可比，平台的对侧载荷在同一步内进入其动力学。[力提供者与 SceneProgram](../../scripts/probe_p65_common_motion.py)

## 3. 怎样验收一条曲线

1. **运动与载荷对得上。** 将发布的材料、逐地址映射载荷和原始外载逐项积分。对于本次 13 个坐标，独立有理计算须从每个坐标的两个力时间矩精确重建检查点的末位置和末速度。公开的粒子与机器人 FP64 数组须逐项等于该状态的规定投影。
2. **硬核覆盖每一时刻。** 本例的有限水平平面允许独立证书。用有理 Bernstein 区间证明两个面的投影方向为正，完整厚棱柱投影留在补丁内部，所有下表面节点的中面相对高度均非负。单位法向的竖向偏置项为 ρ(1−n_z)≥0。首步入点相切且真实速度为零，从节点相对高度中精确提出 t² 后检验剩余多项式。证书覆盖真实曲线上的所有棱柱点。
3. **定律沿同一运动成立。** 由变化的完整面法向求下表面间隙和速度，对每个地址包围实际压力与 SC-L1 定律之差。以整步绝对残差积分作为冲量和时间矩误差上界。材料力也独立核验完整距离行及有向铰链的角、梯度与能量，并把误差传到速度与位置。当前证书覆盖压缩为正、阻尼分支为正的整个区间。
4. **使用原始收支。** 核对动能、距离与弯曲势能、层势能、耗散和原外力做功。内力不计入外部功。角动量按真实材料作用点及原初位置约定分别给出上界。平台仅有一个平移自由度，其独立空间导轨反力尚无读回。
5. **区分计算预算。** 本例每步 21 个配点、四轮联合更新，入点复用，81 次系统求力共计 486 个地址力值，上限为 512。独立验证另用 64 个区间和 384 次地址区间包围。486 只计地址力求值。矩阵求解、系数生成和区间证明另有开销，本次没有将它们折算为总运算数。力系数以 2⁻⁶⁰ 的有符号网格发布，所有取整进入审计。端点检查点固定 1024 字节，其余量、时钟和状态都在包内。整段受力证据另行保存。[整段检查器](../../scripts/check_p65_common_motion.py) · [独立磁盘读回](../../scripts/audit_p65_common_motion.py)

## 5. 迁移边界与下一阶段

同一积分核心和精确检查点还用于两个质量分别为 1 kg、2 kg 的物体。它们具有独立弹簧、一个有限作用层和非零相对入速。改换力提供者后，参考系的质心满足抛体方程，相对运动满足角频率平方为 63 s⁻² 的振子方程。用独立解析区间核对两个坐标、速度和接触的两个时间矩，位置误差上界为 2.39×10⁻²² m，冲量误差上界为 7.60×10⁻²⁰ N·s。这一对照检验了不同自由度数、地址数和力模型下的核心复用。[解析迁移对照](../benchmarks/p65-common-motion-transfer-results.json) · [迁移代码](../../scripts/check_p65_common_motion_transfer.py)

对一般机器人，力提供者还需支持构形相关质量、偏置项、姿态流形以及实测空间力矩。对自接触、折叠、接触出生或阻尼截断，几何模块还需给出稳定的两侧材料身份、全路径事件隔离、当前雅可比及完整碰撞覆盖。这些扩展可以沿用同一运动和提交契约，必须另行提供模型及几何证书。

## 6. SC1 的 125 ms 支撑窗口

从已验 31.25 ms 检查点只执行剩余六步。八步共七个衔接，追溯的是同一条实际运动。每步都有公开返回、独立读回和相同的原始模型绑定。各节点、材料力、每个地址的两侧载荷及原重力分别累计。对第 i 步，冲量 Jᵢ 在整窗仍为 Jᵢ，局部时间矩 Bᵢ 对整窗的贡献为 Bᵢ+(T−tᵢ₊₁)Jᵢ。这样汇总的两类时间矩精确给出全部 13 个坐标的末位置和末速度。[窗口协议](../benchmarks/p65-common-motion-window-protocol.json) · [全窗结果](../benchmarks/p65-common-motion-window-results.json)

## 7. SC2 冲击的首次入层、峰值和卸载

原四节点每点 0.5 kg，平台 2 kg。起始硬间隙为 3/1024 m，层宽 2 mm。三个布节点初速为 −1/8 m/s，d 为 −7/64 m/s，平台静止。重力、其余外载及铰链静止角均为零。两面有独立的厚度法向，六个原始材料地址都参与计算。[试验协议](../benchmarks/p65-sc2-common-motion-entry-protocol.json)

**最早入层的是上面节点 c 的下表面，地址为 `U/2/lower`。** 在这条发布运动上，首次事件位于 7.4374828582–7.4374828619 ms。自由段每个时间叶上的六个间隙都严格减小。检查器以原始厚度法向重新核对六个根的端点符号，只有 c 的根先于其他五个区间。事件前六点零载，事件点冲量为零。随后的短段只给 c 施力，到 7.4374914293 ms 时载荷为 11.235–11.260 µN。全段入层定律相对误差上界为 0.128%，节点受力的位置残差上界为 1.31×10⁻⁹ m。材料力、成对节点力及平台反力的两个时间矩共同给出可续步的精确检查点。六个伪造均被拒绝。[首事件检查器](../../scripts/check_p65_sc2_common_entry.py) · [原始结果](../benchmarks/p65-sc2-common-motion-entry-results.json)
