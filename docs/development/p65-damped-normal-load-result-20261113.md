## 可以据此判断什么

与原无耗散完整N1相比，振动和峰值降低；新的实际轨迹仍未满足持续稳态支撑。
独立连续FP64参考误差远小于当前剩余振动量，下一步应调查物理/时间离散中的
阻尼模态，不能优先归咎于FP32精度，也不能仅增加迭代次数声称可解决。

一个源代码层面的有限解释是：D6每条边是有序轴向速度子步。固定另一端时，
理想速度更新为 v'=(I−α nnᵀ)v，其中
α=h c w/(1+h c w)，0≤α<1；这里不假设不同边同时求解。
原N1的h、c、自由中心w给α=8/9。继续增大c也只能使单边α趋于1；
平膜法向的一阶轴向零模不会因此消失。设计协议中的连续模态系数只是
物理选参起点，不能代替有限h的四边有序算子与接触相对运动的共同响应。
这个说明没有重算或拟合新轨迹，也不证明已经唯一定位全部剩余模态。
