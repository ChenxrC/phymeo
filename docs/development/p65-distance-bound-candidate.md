# 候选：从可行点与KKT残差构造几何距离下界

这是完整CCD的数学准备，**未实现为产品API、未通过连续碰撞验收**。当前closest返回的近似距离不能直接当安全下界；尤其不能因为端点无碰撞就接受关节旋转弧。

## 静态凸特征下界

A、B分别是给定顶点的凸包。先由非负权重构造真正可行的a0、b0（权重和必须严格归一；若使用浮点返回点，需要另计重建误差）。设d0=a0-b0，目标为`f(a,b)=0.5*||a-b||²`。

定义两个非负KKT误差：

`epsA=max(0, max_i(-d0·(A_i-a0)))`

`epsB=max(0, max_j( d0·(B_j-b0)))`

凸性给出任意可行(a,b)：

`f(a,b)>=f(a0,b0)+d0·(a-a0)-d0·(b-b0)>=f(a0,b0)-epsA-epsB`。

因此真实最小距离满足：

`distance(A,B)>=sqrt(max(0, ||d0||²-2*(epsA+epsB)))`。

该结论不要求(a0,b0)恰好最优：较差候选只会让下界变松，不能凭候选距离大就判安全。静态最近点的作用是提高下界质量，而不是替代下界证明。点/三角的点侧误差自然为0；边/边使用两侧误差。

## 可表示性条件不能省略

- 从原始浮点顶点和权重构造精确有理数可行点，可避免把舍入到凸包外的世界返回点当作可行点；这是候选认证路线，不是当前closest实现已提供的功能。
- KKT乘加、平方和、差、开方以及最终下界必须按保守方向处理舍入。一个普通float sqrt结果可能略高于严格下界，不能直接用于安全证书。
- 大坐标平方可能溢出，极小间距平方可能下溢；需尺度化/精确比较和明确失败路径，不能将inf或0当作已认证结果。
- 退化或近平行时，可行点仍可能给有效但较松的界；若无法在预算内证明安全则拒绝整个候选，不能跳过该对。接触求解所需的稳定材料点和法线仍是另一个问题。

## 连续区间证书

若整个区间上A、B的Hausdorff速度分别有已证明上界LA、LB，则距离函数的Lipschitz常数不超过L=LA+LB。中点的严格距离下界为D时，全区间下界为`D-L*interval_width/2`，同样需要向保守方向舍入。

该下界高于已冻结的允许间距才认证该区间；否则细分或拒绝。达到子区间/查询预算不能视为安全。机器人上界必须覆盖线性q路径对应的FK弧，包含所有祖先关节与移动关节行程；布线性顶点路径可用最大顶点速度界。厚度包络、初始支撑与最终接受路径需要配套明确的模型约定。

## 后续测试顺序

1. 解析点/线/三角对，含非最优可行点；验证下界始终不大于独立精确距离。
2. 极端尺度、输入权重重建、近平行和有理数转换的舍入方向反例；不能只测典型随机值。
3. 线性顶点中途穿越、长杆转动中途擦碰但端点分离、持续支撑与厚度容差带。
4. 先用穷举细采样查找证书错误作为反例来源，再以解析/区间证明作验收；采样本身不是连续安全证明。
5. 接入正式接触程序后注入后段子步CCD失败，检查双臂、布与全部history共同恢复。
