# P6.5 动态接触账本：下一切片需要排除的积分反例

本文件是2026-10-28续作分析，不是已实现的动态求解器或已冻结的最终积分方案。固定构型厚度端口已独立实现，接下来必须把构型、材料速度和接触冲量放在一致的时间推进合同中。

## 仅在预测位置上做速度摩擦会累积滑移

考虑质量m、恒定切向重力加速度-g、每步静摩擦容量足以支撑的理想点。若先用自由速度v_free=-g*h推进位置，再只用摩擦冲量m*g*h把末速度重置为0，则每一步末速度为0、摩擦冲量也恰好平衡重力，但位置每步仍下降g*h²。经过T秒总滑移是g*T*h。

例如g=9.81m/s²、T=2s、h=0.001s，累积滑移0.01962m；步长减半后为0.00981m。这个解析反例只针对候选分裂算法，不声称当前产品夹持模块已出现此问题（它尚未实现）。不能仅用“末速度为零”和“摩擦力承重”验收静态夹布，也不能用动画覆盖这段漂移。

## 重建必须有明确基准

已有参与者`prepare_velocity`会从材料/接触位置修正重建速度；若随后把同一位置修正再除以h当冲量施加，反作用被重复计数。反过来，把所有接触位置修正都当数值稳定化排除，也不能自动解决上面的切向漂移。

下一设计要明确：

- 物理速度、材料位移、接触物理冲量、纯数值位置稳定化分别用什么单位和基准；全部通过同一接受状态审计。
- 若接触速度修正也改变本步位移，必须规定在何构型计算质量/Jacobian，并从明确快照重建；不能用当前构型上的相反load“撤销”旧构型load。
- 材料约束、接触几何和机器人FK的非线性更新需一起收敛或拒绝；不能先完成材料、后来改变构型却不再检查材料残差。
- 活跃特征/材料重心变化不产生伪材料速度；接触反力只记一次，整域动能只记一次。
- 接触稳定化只记录数值修正，不能直接标为N；物理冲量平均力必须注明p/h和子步窗口。

## 首批必须通过的独立动态用例

1. 重力下平面支撑：静置完整时域，位置、速度、支撑冲量、势能/动能预算都通过。
2. 摩擦静置与低μ滑动：上面的切向重力例分别满足静止与解析滑移，比较h和h/2；不能靠固定节点。
3. 单关节转动接触：反力矩与真实作用点一致，更新后质量和运动学用法明确。
4. 同域双点/双域交叉响应：接触一次聚合；接触变化后撤回/重建有独立结果对照。
5. 最后子步/资源关闭失败：状态、控制/接触history和资源共同恢复；重试等于新实例。
6. 布/机器人接受路径由后续保守CCD认证；只有端点无穿透不能成为完整案例通过条件。
