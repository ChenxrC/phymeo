## 32 个真实构型

`scripts/heterogeneous_gallery_cases.py` 给出四组各八个模型。R/P/B 分别为 hinge/slide/ball，FREE 是真实自由根，不是渲染位姿。固定 R/P：R、RR、RP、PR、RPR、共享 R 的双分支、RPRP、八 R 链；固定 BALL：B、BR、RB、BP、PB、BB、BRP、R→(B,P)。FREE R/P：R、P、RR、RP、PR、PP、独立 R/P 分支、七关节二叉树；FREE BALL：B、BR、RB、BP、PB、BB、BRP、两 B 分支。括号里的 parent 索引在 cases 固定。

每体长度 `0.14+0.01*((case+body)%5)` m、质量 `0.5+((case+body)%5)/16` kg；实际关节轴循环 Y/X/Z/(1,2,-1)，偏心惯量/COM、自由根质量与完整惯量、各 motor gear 全部在同文件固定。指纹包括 native parent/joint/axis/pose/inertia/geom 数组，不以 model 名或颜色充作物理独特性。32 原 XML、MJB/源码哈希、完整结构数组和结构哈希均保存。

固定两组 gravity=(.2,-.3,-9.81)；FREE 两组 gravity=0，为太空机构，保非零真实根线/角速度与电机。每个模型至少一个真实 motor。所有潜在 contact pair 由原 geom mask=0 过滤，不扩窄相或接触响应域。每格独立固定 camera 可按全轨迹 bbox 一次确定；不得逐帧 recenter 或改 q。

一个 MuJoCoTyxHeterogeneousBatch 持有 32 models/32 sparse worlds `11+13*i`，一模型一桶。每桶可能顺序 launch，不称融合 kernel/同时32核/跨 world 接触。显式数组 payload budget=256 MiB。h=1/128 s，短验证12步，正式CUDA256步=2 s。正式轨迹不中途 reset/restore；另短事务节点才做这些操作。
