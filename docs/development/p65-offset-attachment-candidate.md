# 候选：薄布面偏置材料点的完整块Jacobian

本文件保留早期数学准备。2026-10-28恢复后，面材料点公式已实现为`TriangleOffsetPointPort`，参见[冻结合同](../superpowers/specs/2026-10-28-p65-offset-port-design.md)；工程验收另行记录，完整碰撞/动态夹持尚未完成。基于[续作入口](p65-continuation.md)中的力偶问题独立推导；不改当前H1a/H2b API或验收范围。

## 固定材料点的定义

三角形顶点x0、x1、x2，固定凸重心B（和为1），有符号半厚度s。令e1=x1-x0，e2=x2-x0，c=e1×e2，n=c/||c||，材料表面点为p=B*x+s*n。必须非退化；s的正负区分两侧，不能由任意数值噪声翻面。

以`[a]×`表示叉乘矩阵，有：

`C0=[e2-e1]×, C1=-[e2]×, C2=[e1]×`

`N=(I-n*n.T)/||c||`

`J_i=B_i*I+s*N*C_i`

于是材料速度`u=sum(J_i*v_i)`，世界冲量p_impulse产生节点载荷`f_i=J_i.T*p_impulse`。固定快照响应为`sum_i,j(J_i*R_ij*J_j.T)`；共享节点/同一刚体仍必须保留交叉响应并先合并所有载荷。

Jacobian导数来自`dc=(dx1-dx0)×e2+e1×(dx2-dx0)`与单位法向导数，不是把坐标偏移直接加到现有B矩阵。

## 独立物理恒等式

- 平移不改变n，所以`sum(J_i)=I`，节点合力等于作用点力。
- 刚体小转动使p也随之转动。虚功给出`sum(x_i×f_i)=p×p_impulse`，包含厚度偏置引起的真实力矩。
- 功率对偶为`sum(f_i·v_i)=p_impulse·u`。
- 节点逆质量正时，`J*W*J.T`应对称正定；重复挂接点的共享响应不能按独立质量处理。

单纯使用B分配切向载荷一般不能满足关于偏置表面点的力矩恒等式，因此不能仅调大共点容差来接入摩擦。

## 已做的有限数学探针

[原始24组数据](../benchmarks/p65-offset-design-probe.json)保存随机种子6510、全部坐标/权重/偏置/速度/载荷/逆质量。三角形是单位直角初形加标准差.1扰动，s交替±.005m；中心差分步长1e-6m。

- Jacobian逐分量中心差分最大绝对差约8.18e-11。
- 合力、关于实际偏置点的力矩、功率对偶最大误差分别约4.97e-16、4.44e-16、8.89e-16。
- 24组点响应正定检查通过。

这些只支持公式和上述非退化样本，不是任意尺度认证、真实设备执行或综合案例成功。这些数据来自实施前的独立设计探针，不能替代后续端口实际测试。

## 后续实施前仍需解决

1. 明确退化/病态面积门槛、算术舍入预算和连续旋转协变验收；不得用有限差分替代生产Jacobian。
2. 面内部的固定材料重心与滑动的最近点重心是不同概念。接触几何更新可换特征，瞬时材料速度不得包括“最近点沿表面滑动”的伪速度。
3. 体积厚度包络的边/顶点接触、接触法线、侧选择和接触身份须另定。面内公式不能自动覆盖圆角/边缘，也不能处理自交。
4. 新端口应返回自有快照；实际候选审计使用同一个固定构型J映射真实节点速度，域总动能仍只计一次。图上所有正负载荷先合并，不分别覆盖同一状态。
5. 在NumPy解析/虚功/力矩/有限差分/失败原子性通过后，再接现有tyx节点实际响应，记录launch与误差。主机J与设备响应的混合边界必须公开。
6. 实施计划完成后需要自己的代码审阅与工程门禁；不能把这份数学准备视作已通过实现审阅。
