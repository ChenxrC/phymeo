# 机器人—节点双向重放：角动量候选反例

状态：下一切片的方案否定探针，**不是产品求解器验收，也不是当前固定平面的缺陷**。不能把RobotPlaneContactProgram的最终J1映射直接接上相反节点冲量，就称双向闭环完成。

## 原因与独立推导

固定原点转子，标量I=1，单节点m=1，无外力和重力。采用现有末速度位置式q1=q0+h*w1、x1=x0+h*v1。设末接触共点r1=x1，节点冲量p，转子广义冲量-r1×p。节点角动量变化是x0×p，转子变化是-r1×p，因此总变化为(x0-r1)×p=-h*v1×p，通常不为零。理想原点轴承没有z力矩可补这项。

令q0=0、q1=h、w0=2、w1=1，r1=(cos(h),sin(h))、p=(-sin(h),cos(h))，v1=(1,0)、v0=v1-p，x0=r1-h*v1。初始位于转子初始切平面上方sin(h)>0，末间隙为0；相反冲量和所有离散位置/速度式都成立。

末材料相对做功为-(1+sin(h))，总动能变化为-(2+sin(h))，均耗散，但总角动量漂移为-h*cos(h)。减半步长只把它约减半，不能作为“守恒通过”。

## 给下一阶段agent

1. 固定平面可承接环境反力矩，现有机器人平面验收仍成立；先复用，不重写。
2. 双向接触先冻结“时间积分的冲量作用点/力矩”与“末几何、末材料速度”之间的合同。两者不能未经推导就视为相同。需研究一致的离散力矩积分、离散Jacobian/变分路径或事件分段积分，并说明与现有native重放如何兼容。
3. 先加无外部z力矩的机器人—节点独立线/角动量门禁，以及上述耗散但不守恒的负例，再实施双向接触。不得用能量不增替代角动量，也不得把漂移预算事后放宽至O(h)。
