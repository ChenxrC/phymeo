## 1. 已知边界与尚不能归因之处

[原 D4 协议](p65-deformable-normal-load-protocol.md)记录无阻尼 N1 在两个后端
完成3072步，但原稳态支撑失败；[D6-B实际结果](p65-damped-normal-load-result-20261113.md)
记录 c=4096 的3072步也失败：两窗平均支撑21.4613/19.3665N，刚体法向
RMS .3044/.2136m/s；原门分别12.8–19.2N和.1m/s。7条弹性短速度精度
失败另存，不能把稳态失败解释为这些浮点差。run148保存图仅复用，不再审计。

当前能从源码确定：

- [固定输入](../../examples/deformable_normal_load_cases.py:39)仅中心节点活动
  （质量.5kg），四角固定；四条径向 distance 边、四个原三角面。
  这些面分别贡献 NormalLayer site，不能把整个膜当单根法向弹簧、忽略面数。
- [D6实际核](../../src/phymeo/backends/_tyx_distance_dissipation.py:19)在同一候选
  几何上**按声明边序只走一次**隐式轴向速度更新；
  [D1接线](../../src/phymeo/backends/tyx_deformable_batch.py:981)先完成位置/重构速度，
  再做该耗散，随后共同发布。它既不是全网络隐式解，也不提供弯曲耗散。
- [接触核](../../src/phymeo/backends/_tyx_normal_layer.py:7)只阻尼接触相对法向率，
  离层时为零；[D3](../../src/phymeo/backends/tyx_deformable_contact.py:513)从共同入步
  采样载荷后推进。接触对象同向运动不等于相对压缩运动。
- [已有 BendingConstraints](../../src/phymeo/constraints/bending.py:1)是 HOST FP64
  独立 signed-dihedral 原语；当前 resident D1 没有接入该材料，也没有弯曲速度相。
  “已有弯曲类”不能当这条运行路径有板/壳弯曲刚度。

可手推的有限事实：对理想对称切片，中心(0,0,z)、角点(±1,±1,0)，
连续轴向粘性在中心法向上的系数为 `4*c*z²/(2+z²)`，平面处为零。
距离伸长 `sqrt(2+z²)-sqrt(2)` 是二阶量，零预应力时法向弹性回复也无一阶刚度。
**这是平面局部模式结论，不是实际有载偏转状态的全部模态。** 对单固定端边，
实际理想子步矩阵为 `P_e=I-α_e*n_e*n_eᵀ`，
`α_e=h*c*w/(1+h*c*w)`；四边需按原序取乘积，不能用连续系数替代有限步结果。
大c仅让α趋1；增加c不自动消除所有共同运动、分离期或平面轴向零模。

固定 [Newton v1.7.0 XPBD kernels](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/solvers/xpbd/kernels.py)
分别有 `solve_springs`（轴向应变率）和
`bending_constraint`（四顶点角度/梯度和独立ke/kd）。
[同版本 SolverXPBD](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/solvers/xpbd/solver_xpbd.py)
按 `edge_count` 独立调弯曲；其 `angular_damping` 是刚体角速度参数，不能当膜法向
环境阻尼。这里复用模块划分和参数语义，不承诺两引擎离散轨迹相同。

## 2. 先做一批辨识，不开第二轮长窗搜参

建议下批先交付**独立短试样与模态报告工具**，不修改产品求解器。
已有D6单边、刚体零模、平膜snapshot已绿证据直接引用；下表只补未覆盖组合。
全部试样参数/时间范围和独立参考在首执行前登记，单项只允许一次实现修复后复验，
不能看到支撑统计后换c/质量/初态。误差门沿相应现有模块；新的模态统计必须先冻结。

| --- | --- | --- |
| M0：源码/算子复核，无新轨迹 | 复用已验z=0轴向零模；新增z=±1/8的同一五点材料snapshot，在中心x/y/z三方向及一组合速度分别核原有序矩阵乘积。共同坐标旋转只测同一物理问题 | 若逐边输出不符参考，先修实现；若平面法向不衰减而其它方向衰减，支持“轴向模式覆盖不足”，仍不证明N1全因它 |
| M1：无接触材料短自由衰减 | 原五点拓扑；独立的z=1/8位移释放及含水平/法向速度的非对称释放两例。c只保原4096；T=1/4s，原h及h/2，仅两档，不扩长窗 | 独立FP64同离散材料+有序耗散参考，分别保存弹性能/动能/每边耗散和固定反力。若原法向模式本身衰减慢，接触不是必要原因；若材料单独衰减快，转查接触共同模式 |

## 3. 证据指向哪一层，才开发对应通用模块

1. **优先候选：resident 弯曲材料及角应变率耗散。** 若M0/M1证明缺失弯曲模式是
   所需材料能力，复用现有四顶点原身份、signed angle/gradient/能量约定，补TYX
   候选核与不可变phase，并接D1/D3共同发布。先两三角铰链的扭折/平移旋转零模、
   固定端反力、非对称小网格，再接接触；不用加world竖直弹簧伪装弯曲。
   这会改变新材料的刚度/模态，不能静默加给旧N1或承诺其稳态必过。
2. **有外部介质依据才加环境阻尼。** 若应用确有空气/流体/支座阻尼，显式声明
   介质速度场、坐标系、系数与单位；反力/损耗归外部功账。可先单质量相对介质
   解析衰减、共同速度变换、固定节点及双world负控。它可以耗散材料内部零模，
   但不是客观内部材料力；无介质依据时不选，不默认`v*=常数`。
3. **C0指向时间分裂后才研究接触步内耦合。** 候选为显式版本化的子步刷新或
   端点/中点共同载荷迭代，必须保双侧同次力与运动、分离/重入、原事务和有限资源。
   先1D独立参考、斜面及多site非对称例；不只把接触率改用“更好看”的候选速度。
   这是新离散模型，不是原NormalLayer参数修补，也不等于必须重写整引擎。

最先可开发的文件范围是NEW短试样/报告工具和其独立测试，不碰旧run入口或证据。
建议 NEW `examples/diagnose_deformable_support_modes.py`、
`tests/collision/test_deformable_support_modes.py`；预声明输入manifest、输出模式分解、
逐边原始数据和明确失败前缀。若进入弯曲产品片，再单独冻结：
NEW device bending/phase模块；MOD `tyx_deformable_batch.py`、
`_tyx_deformable_buffers.py`、`tyx_deformable_contact.py`、builder/public exports，
均由父拥有共享接缝；独立作者可拥有新核/独立测试。不得把设计文件当已授代码范围。
环境阻尼或接触新积分是备选独立grant，不与弯曲同时上线后再猜贡献。

## 4. 成功与停止规则

- 本轮调研成功：交付以上可运行的最小试样定义和一个优先开发方向；不是原FAIL转绿。
- 下批辨识成功：独立参考/原始账本/失败保存成立，并至少排除或支持一个具体假设。
  无法区分时允许结论“不足以定位”，只指出一个缺失观测，不新增大范围网格。
- 算子/反力/事务错误先修实现；参考和产品一致但应用不满足，就记录模型/离散/期待
  边界。两个没有新证据的调查回合即停止该分支，不再叠耗散、加迭代或延长原窗口。
- 只有独立模块两后端及安装资格完成，且新应用合同事前冻结，才考虑一次新长窗。
  原D4、D6-B稳态FAIL和所有strict精度失败永久保留；不追“Newton也必须更准”。
