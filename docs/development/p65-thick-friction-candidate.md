## 路线与范围

继续使用无自旋粒子表示材料节点。不能把原零半径摩擦程序的 radius 门禁直接删除：偏置点的切向冲量若只给节点中心，会漏掉厚度产生的力偶。给每个粒子新增自旋/惯量会改变模型和积分器，当前不选这条路线。

候选选用已交付 `TriangleOffsetPointPort`，把一个非退化三角形的厚度体明确建模为凸棱柱 `conv{x_i +/- rho*N}`。其中 `N` 是当前三角中面单位法向，rho 是有单位的半厚度。表面材料点 `y=sum(B_i*x_i)+s*N`，B 为凸重心，`s in [-rho,rho]`。上下表面、侧面与边界的 B/s 由真实有限几何产生。主 agent 提议首版先保持全 prismatic 机器人域以集中解决材料厚度/有限流形；单恒 I 转子原生边界已有证据但不自动沿用到新摩擦；多转动关节的一般树质量/整步能量仍未闭环，不能扩大旧声明。

当前两种对照分别使用完整三角上下表面的三个顶点。它们不自动构成任意 patch/triangle 接触的完整候选生成器：小 patch 穿过大三角内部时可能没有任何 cloth 顶点进入 patch。生产必须覆盖 patch 顶点/棱柱面、棱柱顶点/patch 面、边/边及接触流形边界，或将未覆盖响应明确拒绝；不能把有限角点采样当作完整碰撞检测。

## 复用端口与原生执行

记 `e1=x1-x0, e2=x2-x0, c=e1 cross e2, N=c/|c|`，
`C0=[e2-e1]x, C1=-[e2]x, C2=[e1]x`。现有端口已经实现

`J_i = B_i*I + s*(I-N*N.T)*C_i/|c|`。

瞬时材料速度是 `sum(J_i*v_i)`；世界冲量 P 对应节点冲量 `J_i.T*P`。固定几何的 `sum J_i=I`、力矩 `sum x_i cross(J_i.T*P)=y cross P`、功率对偶共同成立。接触几何的 B 可随特征更新，但计算瞬时材料速度时固定该 B，不能把接触点沿表面走动的 Bdot 混入材料速度。

held 使用初态真实 B0/s0/J0：先按所有接触精确聚合节点载荷，再以原输入加一次 `load/h` 完整 SceneLoadReplay。机器人仍在相同物理作用点用初态机器人 Jacobian 的转置施加反作用。terminal 在真实 pre 状态上构造当前 B1/s1/J1，先合并节点冲量，通过已有 native point velocity 操作在 close 前一次施加；不修改 host state、不做零 dt。

现有 `PointVelocityImpulses` 可以接收聚合后的节点冲量及机器人反作用；现有有限 terminal ledger 可复用独立末质量响应和能量验证，但**它本身不证明**这些节点冲量等于合法厚度映射，也不证明配对力矩。下一程序必须独立认证实际 FP64 请求中的完整 J.T 映射、双方世界力/矩、原生 FP32 提升和一次计数。旧 MaterialPath/FrozenRobot 只验 pre，独立 terminal 账验 post；全步最终 K/U、原输入功及按节点作用位置累计的材料角动量预算不减。

## 独立场景 A：两侧有限夹压，静态承重与低摩擦滑动

三节点每个质量 1 kg，初始三角顶点 `(-1,0,-1),(0,0,2),(1,0,-1)`，法向 +Y；rho=1/8 m。上下有限 patch 的 X/Z 范围均为 [-4,4]，初始 Y 为 +/-rho，分别属于质量 2 kg 的独立 Y-prismatic 连杆。每个 jaw 施加向内 2 N 的真实 effort。节点重力为 -Z 1 m/s^2，初速零。每侧在三个材料顶点形成三行，使用真实 +/-rho offset Jacobian。

法向静力内力**不唯一**：两侧各行相等 `p_top_i=p_bottom_i=a_i`、`sum a_i=2h` 已满足静止法向合同。均匀压力不是 Coulomb 唯一解。

拟采用通用确定性候选选择：全行零初值、共同标量步长、同步 world 法切更新。共同步长由完整响应的排列不变上界决定，不用逐行不同的对角近似。两侧相同切向冲量使 offset 导数力偶抵消；相同法向冲量互抵，三节点保持共同平移。该对称流形由同步更新保持，给出 `a_i=2h/3`。这是候选算法选择，不是一般非线性全局最小范数或收敛保证。任何非收敛/未知仍拒绝；实际聚合和排序须确定且重排误差受原预算检查。

- mu=1：每侧每行 `p=2h/3, t=+Z*h/2`，所有节点/jaw 静止，terminal 为零。静摩擦阈值为 mu>=3/4。
- mu=1/4：每侧每行 `t=+Z*h/6`，节点加速度 -Z*2/3。h=1/4 时节点 `vz=-1/6, dz=-1/24`，jaw 静止，terminal 为零。
- 连续窗口应预先固定 T 与 h；在上述平移解中 `vz=-2T/3, dz=-(T^2+T*h)/3`，连续解误差随 h 减半。不得先运行再调整窗口/预算。超过有限 patch 的退出/再入须另冻结真实几何场景，不能从这个始终在面内的公式直接宣称。

## 独立场景 B：单面新接触与厚度切向力偶

同一非退化三角、rho=1/8，每节点质量1；中面初始 Y=1/4。单个质量2的 Y-prismatic patch 初始 Y=0，X/Z 范围[-4,4]。节点初速 `(1,-1,0)`、robot 初速0、无外力/重力，h=1/4，mu=1/2。下表面初始间距1/8；初态 open，因此 held 切向冲量严格零。

全三顶点接触的独立解析结果：

- held 每行 `p_i=1/5`，合计3/5；pre 节点速度 `(1,-4/5,0)`，robot速度 -3/10；节点 X 平移1/4，中面 Y=1/20，robot位置 -3/40。
- 令 `T=sum tau_i=-3/5`，offset 切向力偶系数 `k=(-1/16,0,+1/16)`。节点 terminal Y 冲量是 `eta_i+k_i*T`，不能只算 eta_i。
- 三行 `eta=(13/80,1/5,19/80)`；新接触容量 `mu*(p_i+eta_i)` 给 `tau_X=(-29/160,-1/5,-7/32)`。
- post 节点 X 速度 `(131/160,4/5,25/32)`，所有节点及 robot Y 速度均 -3/5，故整个下表面的法向末速度不趋近，Ndot=0。三行切速仍正，滑动方向与 Coulomb 原式一致。
- K0=3 J，Kpre=51/20 J，Kpost=1905/1024 J；terminal deltaK=-3531/5120 J，全步 deltaK=-1167/1024 J；Py=-3 kg*m/s。
- 接受路径上全部节点共同平移，底面 gap 为 `(1-t)/8`，t 为归一化步内时间；finite patch 覆盖全部三角，整厚度棱柱安全。

只在 centroid 放单行也会得到合法的点级解析（Kpost=11913/6400），但其末角点速度不同且一角仍趋近 patch。因此**不使用单 centroid 结果代替完整面的末法向控制**。新的负控制应覆盖这个差别和删除 J 厚度块造成的力矩错误。

## 变形厚度体的连续路径证明候选

实际接受节点仍按 x_i(t)=x_i0+t*dx_i 解释；机器人仍按 q0+t*dq 的真实 FK 曲线。三角面积向量是二次多项式 `c(t)=c0+c1*t+c2*t^2`，厚度棱柱六顶点为 `v_i(t)=x_i(t)+/-rho*N(t)`。

对每个完整时间分割区间，先严格证明 `|c(t)|>=a>0`。令 C1 是整个区间 `|c'|` 的上界（c' 仿射，可取两端范数上界的最大值），C2=|2*c2|。有

`N'=P*c'/r`, `N''=P*c''/r-2*N'*(N.c')/r-N*|N'|^2`,

故 `|N''|<=C2/a+3*C1^2/a^2`。固定单位分离方向 d 下，所有 prism/robot 顶点对的投影差，均可用端点向外下界减去两侧曲率和乘 width^2/8。取全部顶点对的最小值可证明两个完整凸集合，非有限点采样。

平移例 c1=c2=0，厚度曲率为零，持续支撑可有限认证。若利用常法向简化，须证明各系数严格共线且标量在整个区间同号；不允许凭端点正常推断中途面积不退化。

若定义冻结几何预算 b，单位 d 上 `gap_d>=-b` 证明沿 d 平移该棱柱至多 b 即可分离（严格分离可再加任意正 eps），因此是明确的**平移分离深度上界**。它不是 unsigned distance>=0 的空条件。实际采用这一物理几何指标前须在生产 spec 冻结单位、归一误差、b 与旧预算的关系；不能后验放宽。面积/Gram未知、证明预算耗尽、无法覆盖实际候选都必须拒绝。
