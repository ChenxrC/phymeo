# 原双关节推杆的触物、推动、分离与面积压力对照

取原 RR 推杆和标准 T 形块已保存的 CUDA 电机驱动轨迹。在第一个推段，从首次受载到段末，T 块沿推向移动 **6.092 mm**，推杆给物体的该向冲量为 **0.5620 N·s**。随后连续 20 个输入帧的推杆–物体接触条目均为空，几何净距均超过 1 mm。最后一帧净距为 2.493 mm，桌面法向载荷为 1.570 N。原 PushT 最终目标仍未达成。[原轨迹与控制来源](p65-manipulation-push-feedback-report-20261115.md)

## 同一姿态下的比较

| 接受步的输入时刻 | 推杆与 T 块净距 mm | 原生推杆法向载荷 N | 面积参考的受压面积 mm² | 原生桌面法向载荷 N |
| --- | ---: | ---: | ---: | ---: |
| 初始，0 ms | +26.541 | 0 | 0 | 0 |
| 首次受载，750 ms | −0.0082 | 0.140 | 5.39–6.54 | 1.569 |
| 首个推段的法向载荷峰值，1255 ms | −0.1048 | 0.927 | 24.58–26.38 | 2.022 |
| 首个推段末，1699 ms | −0.1053 | 0.594 | 24.75–26.57 | 1.562 |
| 撤离，1767 ms | +2.493 | 0 | 0 | 1.570 |

原生数据来自原 12 秒 CUDA 文件的首个推段及其撤离。按连续步号、接受标志、接触相位和模型源摘要选取输入。首次载荷取首个正法向力，峰值取同一段最大法向载荷，撤离取连续 20 个清空帧的最后一帧。静态面积计算消费这些帧中已经发布的双方姿态。它给出的力没有施加回物体，表中运动全部来自原生动力学。[数据提取和同姿态计算](../../experiments/area_pressure/pusht_saved_contact.py)

**峰值和推段末的压入量都约 0.105 mm，原生法向载荷却从 0.927 N 降到了 0.594 N。** 用单一参数检验了一个具体候选接触律：胶囊内部压力等于压力梯度乘以到胶囊表面的深度。先在峰值帧拟合梯度，可行区间为 528–581 MPa/m。把整个拟合区间传播到其余帧，首次受载预测为 0.0145–0.0213 N，低于实测的 0.140 N；推段末预测为 0.842–1.017 N，高于实测的 0.594 N。即使保留积分区间宽度，单独调这一个常数也无法同时复现这三个原生法向载荷。这里比较的是固定运动下两种模型的输出，真实材料标定仍需独立载荷数据。

## 几何与求解器边界

- 对有限胶囊使用真实圆柱和球帽的轴段距离，在 T 形两盒并集的全部外露矩形面上积分。坐标合并分辨率为 1 nm，只对当前物体局部共轴的盒子建并集。内部公共面从积分中剔除，凹角保留。估算同时返回面积、压强积分、世界合力及绕物体质心的世界力矩。固定姿态使用两级网格深度 7 和 9。每个小矩形用中心的距离支撑平面和四个角点距离给出上下估计，含浮点余量，未计入模拟器姿态本身的离散误差。[参考积分实现](../../experiments/area_pressure/capsule_box_reference.py)
- 面积计划的编译和检查共用同一份候选分配。原 RR 指定整组 `tool–object` 时恰好覆盖推杆与 T 块两件几何，其余九对保留原生，两对桌面–T 块候选都在其中。峰值实际承载来自编号 5 的横梁 `object-1`。候选数量与活跃接触数量分别记录。[生产编译入口](../../src/phymeo/backends/mujoco_area_pressure.py)
- 对原模型实际调用面积摩擦编译入口。其 8 个速度自由度满足宽度限制，两个受限铰链、黏性阻尼及剩余原生约束的组合触发现有拒绝条件。原生和面积接触在这个机器人上共同推进的动力学仍待实现。已有无阻尼案例中，另一原生接触保留的 interpret/CUDA 回归均通过。

## 复现

在仓库根目录执行。仓库内附五个姿态及对应的原生读数，约 4 KB。其两个分辨率的积分输出和峰值拟合结果已与读取完整轨迹的输出逐字段对齐。构建模型目录和读取姿态无需运行 CUDA 仿真。

```powershell
$env:PYTHONPATH = (Resolve-Path src).Path
$python = ".\.venv-training-cuda313\Scripts\python.exe"
& $python -m experiments.area_pressure.pusht_saved_contact --output .\rr-area-poses.json
```

在有完整原档的机器上，要重新提取阶段、冲量及位移，可在命令中加入位置参数 `artifacts/mujoco-tyx-push-feedback-20261115-01/world5`，给结果使用新的文件名。独立测试覆盖球帽压平面的解析面积、载荷和偏心力矩，盒子相交内部面、凹角、圆柱侧触、真实撤离和原模型准入。本地命令与退出码在 `artifacts/rr-pusht-area-shadow-20261119-01`。[五姿态数据](../../experiments/area_pressure/pusht_reference_poses.json) · [测试](../../tests/test_pusht_area_shadow.py)
