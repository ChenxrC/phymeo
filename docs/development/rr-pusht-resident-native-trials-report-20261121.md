# 八自由度 RR Push‑T 的 GPU 单步接触与积分

2026-11-21，实验分支 `codex/exp`。从原始任务取出五个入步状态，在一个五世界 CUDA 批次里分别推进 1 ms。机械臂与自由 T 块均可运动。GPU 为每个世界装配原生约束，反复试算推杆面积载荷，最后用收敛载荷积分一次。设备实际写出的位姿、速度、时钟与独立双精度解已逐世界核对。五个世界各自在原记录的位置起步。

## 原始五个姿态

| 入步 | 原记录时刻（s） | 原生约束行 | 面积积分点 | 推杆面积法向合力（N） |
|---|---:|---:|---:|---:|
| 初态 | 0.000 | 0 | 0 | 0 |
| 首次受载 | 0.750 | 32 | 219 | 0.00012164 |
| 原记录峰值 | 1.255 | 32 | 237 | 0.00184717 |
| 推动末段 | 1.699 | 28 | 237 | 0.00178981 |
| 撤离 | 1.767 | 32 | 0 | 0 |

“原记录峰值”标识选取姿态的时刻。表中推力由本批的面积接触材料、速度和几何重新计算。上一份 1,018 步实验从首次受载状态起连续积分，得到另一条运动轨迹，其峰值 0.931 N 出现在 1.192 s。两种取样回答的问题不同。[连续轨迹基线](rr-pusht-entry-working-set-report-20261120.md)

## 计算路径

- 从原 MuJoCo 模型编译原生行。仅替换推杆与 T 块的两对几何体，另外九对候选、关节限位、电机、阻尼与自由关节沿用原模型。每个世界的接触与行容量分别为 64 和 512。
- 正常设备步进和试算共用入步运动学、惯量、约束行装配以及原生工作集求解器。同一入步可替换附加广义力，原控制和外载一直保留。活动集仍用物理质量矩阵；积分使用含阻尼的速度方程。
- 主机从设备当前位姿与雅可比算出面积积分点、双方点雅可比和载荷。在五个选定姿态，基线之后一次载荷更新即达到收敛判据。五世界共用一个试力缓冲，初始化和一次更新合计上传 320 字节。几何、迭代判断和实验比对均有主机读回，不能据此估计训练吞吐。
- 最后一次在 GPU 上重新求解选定载荷并积分。仅写候选状态缓冲，两个入步缓存中的所有记录及当前已发布状态逐字节保持。此时重新读出积分器实际写入的速度，检查各面积点的力以及广义冲量平衡。[设备入口](../../src/phymeo/backends/mujoco_tyx/_constraint_device.py) · [五世界实验](../../experiments/area_pressure/pusht_resident_native_trials.py)

## 误差和故障边界

独立基准从原始 CPU MuJoCo 状态执行前向装配，自行生成接触面与雅可比，再用双精度解联立原生约束和面积载荷。另有一份双精度解直接使用设备装配系数，用于区分装配与求解误差。逐行比对接触物体对、锥边或关节限位身份，逐点匹配接触力，再对比合关节力矩。自由根四元数角差在统一符号后计算。

| 五个姿态中取最大值 | 观测值 |
|---|---:|
| 出步速度相对原始模型双精度解的分量差 | 2.07 × 10⁻⁸（平移 m/s，转动 rad/s） |
| 自由 T 块姿态角差 | 1.97 × 10⁻⁹ rad |
| 匹配原生行的力差 | 7.45 × 10⁻⁷ N |
| 两电机关节的总接触力矩差 | 1.66 × 10⁻⁷ N·m |
| 按实际出步速度重算的单点力与收敛试算值的最大分量差 | 4.74 × 10⁻¹³ N |
| 按实际出步速度重算的广义面积载荷与上传值的最大归一化差 | 3.33 × 10⁻⁷ |
| 实际出步速度对应的最大归一化冲量残差 | 3.48 × 10⁻¹⁰ |

五个世界的补偿时钟两个字均与独立预期逐位相同。测试还覆盖两侧关节限位、容量少一行、非法设备缓冲、非有限试力、失效回调、失败后的重新入步，以及重复积分被拒绝。正常设备步进回归覆盖地面摩擦、自由根干摩擦、阻尼耦合、空接触及八自由度恢复重演。新增 5 项定向测试和 11 项原路径回归均通过。
