## 在设备上运行

安装与渲染分支相同版本的 Phymeo、MuJoCo 3.3.7、固定版 Tyx 和 Phymeo Rendering。指定 S4000 对应的 Vulkan ICD，并将包含着色器资源的本机渲染库路径传给 `--library`。训练画面为左右各 96 × 96 的 RGB。录像从真实状态轨迹再次渲染，可使用更高分辨率和更多面积灯采样。[MUSA 安装与动力学验证](mujoco-tyx-musa-slider.md)

以下是首代实验的 Linux 命令。每个任务使用独立输出目录。每次 CEM 更新在预先选定的训练种子上按完整回合回报排序候选策略，再更新控制参数的采样分布。候选世界共享同一个物理模型，在 S4000 上成批积分；腕部画面也由 S4000 生成。图像姿态估计、动作计算和这个小规模参数分布的更新在 CPU 完成。

```bash
common=(--mode musa --library /path/to/libphymeo_native.so --device-index 0
        --cache-dir ./training-cache --image-size 96 --action-repeat 8 --horizon 200
        --policy-variant registered --population 4 --generations 1 --train-seeds 2 --batch 4)
for task in carry push_t; do
    python examples/bimanual_musa_train.py "${common[@]}" --task "$task" --stage train --out "./runs/$task"
done
```

每个训练目录包含 `checkpoint.json`（采样分布、种子、候选回报、更新历史），训练与选模完成后写入 `frozen-policy.json`。恢复同次中断的训练使用原参数并加 `--resume`。运行 `--stage evaluate` 会重新读取冻结权重和源码绑定，输出各留出场景的 JSON、模型 XML 和记录物体及关节真实状态的 NPZ。目标完成率必须从冻结评估取得。录像中的慢动作与真实仿真时间分别标注。

## 第一轮实测

S4000 上两个独立关节树通过真实接触向自由载荷传力的回归通过。两项完整场景各用 12 步进行起始状态核验，S4000 与独立 CPU MuJoCo 的最大广义位置分量差均小于 `6e-9`，速度分量差均小于 `3e-7`。两腕观察实际使用同一张 S4000 的 Vulkan 着色器阴影和 4× MSAA。动力学每个场景完成 108 次内核启动。

在开发种子 701，每项任务用 1,600 个 2 ms 物理步测试首个未训练控制器。搬运时双手同时接触 2.232 s，峰值向上合力 46.39 N，物重 58.86 N，未成功起抬。PushT 最终位置误差 9.17 mm，偏航误差 19.99°，超过 6° 的验收门槛。仅看位置会把这次推 T 误判为成功。

## 交换两条机械臂后还能否完成同一个目标

原训练按种子奇偶指定左右轴数，PushT 的目标转向也依赖奇偶。为分开这两个因素，在 70001–70008 八组新工件和目标上，各自跑一次左六右七和一次左七右六，打乱执行顺序。每对都核对工件初态、目标、工具与腕镜的初始空间位姿。七轴模型实际多一段有质量的连杆和一个限矩 8 Nm 的驱动铰链。

| --- | ---: | ---: | ---: |
| 6 kg 侧缘箱 | 8/8 | 8/8 | **16/16** |

对两个成功搬运回合再问一个静力问题：在实际离台且两腕均有载荷的每个决策姿态，给定腕边与箱侧缘的接触几何、摩擦和原电机限矩，能否平衡 58.86 N 重力，同时保持水平合力与重心力矩为零？两回合分别有 112、113 个合格姿态，双臂在全部 225 个都能静托。在其中 83、81 个姿态，任何一只腕单独都不能静托，两个回合合计 **164/225**。另外 61 个姿态中至少有一侧具备理想静力平衡解。该结果描述已记录的姿态与力矩约束；实际单臂动态尝试另有四次有效对照。[43001 离台姿态](../../artifacts/mtt-bimanual-20261126/carry-capacity-43001.json) · [43002 离台姿态](../../artifacts/mtt-bimanual-20261126/carry-capacity-43002.json)

## 限力工具装到真正的转动关节腕座后

### 先用原顶头检验构型训练

保留原 9 kg T 形工件、相机、关节限矩、目标和三个终态门槛。在每个训练初态分别装上左六右七和左七右六两套实体关节树，训练两代，每代五组候选。每代先按在这两种构型上的成功总数排序，再按平均回报排序。在独立的 82001、82002 两个初态和两种装配上与原 CEM 参数比较，选出新权重后冻结。

在 83001–83004 四个新初态及各自的两种装配上，新权重 **8/8** 完成，原权重在完全相同的八次中 **6/8** 完成。平均回报由 1.939 提高到 2.185。另两个录像种子 84001、84002 也各跑了两种装配，四次均满足位置、角度和停稳门槛，每次实际运动 1.30–1.46 秒。两组成绩分别报告，录像种子未参与训练或选模。[训练入口](../../examples/bimanual_crossed_refinement.py) · [配对留出](../../artifacts/mtt-bimanual-20261126/push-crossfit-holdout.json) · [录像回合结果](../../artifacts/mtt-bimanual-20261126/push-crossfit-films.json)

同一冻结 PushT 策略在 83001–83004 的每个初态、每种装配都另跑三个配对对照。仅启用左臂、仅启用右臂以及双臂均启用但双腕图像全黑，各为 0/8。保留正常双臂与双腕图像时为 8/8。计分要求同时达到位置、朝向和停稳门槛。重物在未达到目标时仍可能被推动。[三个对照的逐回合记录](../../artifacts/mtt-bimanual-20261126/push-crossfit-controls.json)

### 28 N 工具的独立试验

给每个手腕加一个真实滑动关节和 28 N 限力电机。把杆、套筒和全部臂节都纳入工件与台面的碰撞候选，才能查明推力究竟经过哪个零件。S4000 上新增的胶囊–盒体测试覆盖法向、带摩擦接触和不同世界的接触启闭，与 CPU MuJoCo 核对；三项原生测试通过，耗时 38.60 秒。[S4000 测试输出](../../artifacts/mtt-bimanual-20261126/capsule-box-s4000-pytest.txt)

在种子 701，把已训练的 PushT 策略直接迁移到这套工具，双臂、仅左推、仅右推均运行了 2,880 个动力学步。双臂使工件移动最多 92.91 mm，但末端偏航仍差 14.95°。两枚顶头先后触桌，随后左右套筒直接顶到工件，接触峰值为 166.02 N 和 185.07 N。虽然两个滑杆电机始终在 28 N 内，套筒这条传力路径绕开了滑杆。单独启用左、右推杆时工件分别移动了 61.18 mm 和 56.05 mm。该轮三个条件均未通过限力工具的整步验收。[实际碰撞、力和终态](../../artifacts/mtt-bimanual-20261126/rated-articulated-03.json)

随后保留 9 kg 工件、原力矩限制、28 N 推杆及终态门槛，将腕座调平，使用长导向和小顶头，按实测腕载渐增推力。在相同种子和相同 5.76 s 窗口内，顶头以外的传力路径全部消失，双侧同时达到 18 N 的最长时间为 1.192 s；20 ms 窗口内两腕最大平均推力分别为 27.53 N 和 23.23 N。T 件移动了 123.14 mm，末端角度误差 4.33°，横向却偏离目标约 58 mm，总位置误差达到 59.17 mm。左右单推分别使重心移动了 10.61 mm 和 2.07 mm，超过预设的 2 mm 严格门槛。未启用的一侧保持腕座姿态，两次其实测顶头受力均为零。[限力腕座双臂与单臂实测](../../artifacts/mtt-bimanual-20261126/rated-guided-04.json)

在相同腕座、同一 XML、同一初态和同一 5.76 秒窗口内，用两腕图像同时修正平面路径与偏航。左单推的最大重心位移为 1.36 mm，右单推为 1.46 mm，停用侧均无顶头载荷。各自实际最高电机力为 22.32 N 和 21.47 N，低于额定 28 N。这两个单推回合满足 2 mm 门槛。双推时工件移动 131.12 mm，两腕持续共同受载 0.352 秒，20 ms 平均力最高分别为 28.06 N 和 26.31 N。最终距目标 50.55 mm，角度误差 19.60°，未对正或停稳。两类试验合起来说明，受限单臂与双臂的实测推进能力已经拉开，限力工具的转向和终端控制仍待解决。[同场景的三次对照](../../artifacts/mtt-bimanual-20261126/rated-guided-05.json) · [各步视觉和导向观测](../../artifacts/mtt-bimanual-20261126/rated-guided-05-vision.json)
