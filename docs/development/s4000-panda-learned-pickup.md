# 双 Panda 从学习到的接近末态夹起自由销

本实验把右手张开接近和右手闭指抬销连接起来，同时让左臂持板。销的质量是 120 g，重力为 1.1772 N。右手和销之间没有抓取约束。两个阶段各用一套训练出的权重，交接位于 2.048 秒接近回合的终点。选择何时结束接近尚未训练。[前一阶段与复位库](s4000-panda-reach-factors.md)

**同一份冻结拾取权重在 S4000 的 12 个独立起点中成功 3 个，原生 MuJoCo CPU 成功 5 个。** 在独立 CPU 上读取 S4000 保存的状态、权重和电机目标，复算了 1,920 次决策，全部 30,720 个归一化电机动作与实发记录精确一致。模型作为可选实验提供。[拾取权重](../../examples/checkpoints/panda-pickup-from-reach-s4000/student.npz) · [12 个设备起点和两类对照](../../examples/checkpoints/panda-pickup-from-reach-s4000/device-validation.json)

## 哪些动作是学出来的

| 部分 | 如何产生动作 | 运行时用什么 |
| --- | --- | --- |
| 接近并驻留 | 第 127 号网络先拟合示范，再经过 PPO 更新 | 根据当前 98 维状态生成 16 路归一化动作 |
| 闭指与抬升示范 | 反馈教师按对中、距离、相对速度和双侧接触决定何时下探、闭指、抬升 | 教师只在获取训练标签时使用 |
| 学出的拾取策略 | 径向基网络从 12 个起点的 1,920 次教师决策拟合 16 路动作。用训练起点做闭环筛选 | 加载 192 个中心及其读出权重，每 16 ms 根据 21 个实测和控制器状态量重新算动作 |
| 电机和物理 | 两个七轴臂及右手两个独立的指关节，沿用原有限力矩／推力的 PD 电机 | 臂增量、手指目标开度和实际速度决定每 2 ms 的电机力矩。接触求解器同时更新自由销和机器人 |

拾取网络观察手坐标系下销的位置与朝向、销的偏航、销和手相对交接高度、两指开度与目标、右臂关节目标误差。输入中没有回合时间、阶段编号、世界编号或教师目标。夹力和叉托反力留给独立评分。两组张指对照会人为改变指令，这些轨迹用来检验承重来源。[训练与物理回放](../../examples/panda_pickup_from_reach.py) · [学生网络](../../examples/_panda_pickup_student.py)

## 从哪里起步，怎样判定抓稳

训练取自 ±26° 接近评估的全部 12 个实际末态，拾取验证取自独立 ±22° 组的全部 12 个末态。每个起点保留上一阶段的关节、自由销位置和速度。用实际发出的 128 次动作重建电机目标，首步的滞后偏置由最后一次入步的状态用原生正运动学／动力学复算；碰撞求解器在新运行中重新初始化。S4000 的复位接口要求浮点单位四元数，设备报告另列重新量化前后的差异。[起点与模型数据](../../examples/checkpoints/panda-pickup-from-reach-s4000/results.json)

在一个连续双侧夹持区间中，要同时看到以下证据才计一次成功。

- 先有叉托支撑，随后两侧指垫都在销柄上实测到法向力，各自至少为销重的 2%。
- 销上升至少 25 mm，腕上升至少 20 mm；两垫向上合力至少为销重的 80%。叉托与其他接触的法向力分别降到销重的 5% 以内。
- 同次夹持中，销在手坐标系内的累计最大相对位移不超过 5 mm，上述承重持续至少 150 ms。禁止对销直接施加外力。

每个验证起点同时运行双指常开和仅第二指常开两条负控，两者逐步复制正常分支的臂目标，再根据各自状态计算实际力矩。单侧负控分别报告是否真的有单侧指垫受力。没有碰到销的轨迹也保留。[载荷提取与评分](../../examples/_panda_pickup_loads.py)

## 实测结果

原生 MuJoCo CPU 上，反馈教师在训练组为 12/12。首轮拟合的学生独立做到了 6/12，加入学生访问状态的标签再拟合一次得到 0/12。按训练组的实际承重成绩选首轮权重，再冻结验证。候选在独立的 12 个起点中成功 5 个。负偏航组 5/6，第六个曾抬起约 29 mm，但合格承载仅约 80 ms。正偏航组 0/6，均未出现双侧销柄承载。所有双指常开和单指常开的 CPU 对照均未合格抬销。只加载发布权重回放，12 个世界及其两种对照的分数可逐项复现。

在摩尔线程 S4000 的世界 0，左、右指垫在交接后约 0.292 s 和 0.294 s 首次对销柄施力。销最高抬起 **35.2 mm**。从 1.746 s 到 1.974 s 连续合格承重 228 ms，两垫各自最小法向力约 11.05 N，平均向上分力为 0.512 N 和 0.664 N，合计 1.177 N。法向力主要用于相向夹紧；向上分量才直接托住销。相同臂目标下，双指张开的销没有抬起，只张开一指时销最高移动约 0.29 mm（竖直）。反向偏航的配对世界 6 从未出现双侧承重。[两条代表性设备轨迹及完整分项](../../examples/checkpoints/panda-pickup-from-reach-s4000/s4000/summary.json)

设备实验的动力学、接触求解和运动积分在 S4000 上运行。每次决策读取设备当前状态，在主机上算正运动学和冻结网络的输出，再由电机驱动物理步进。力均来自该设备求解步对应的入步位姿。逐决策权重复算工具同时检查实发动作、八个物理子步中保持的动作和实际关节目标。[设备入口](../../examples/panda_pickup_musa_compare.py) · [动作复核](../../examples/panda_pickup_verify_actions.py)

| 验证偏航 | 原生 CPU 成功 | S4000 成功 | S4000 双侧指垫实际对销柄承载 | S4000 曾抬高 25 mm |
| --- | ---: | ---: | ---: | ---: |
| −22° | 5/6 | 3/6 | 6/6 | 6/6 |
| +22° | 0/6 | 0/6 | 0/6 | 0/6 |

36 条设备轨迹覆盖全部 12 个相同起点的正常、双开及单指常开分支。两个干预组均为 0/12 成功。单指常开组有 6 个世界观测到真实单侧受力，其余 6 个连单侧有效接触都没有观测到。执行分为三组，世界编号为 0、6；1 至 5；7 至 11。仓库中保留所有世界的结果、动作复核和轨迹哈希，另附世界 0、6 的六份完整设备轨迹。

### 下一步改什么

正偏航时腕部最接近销中心仍有 8.0–11.5 mm，六条轨迹均未建立双侧销柄承载。优先为“已接近但未对中”补充不同偏航和接近方向的纠偏、再接近示范，并用新的留出起点验证。这个现象本身不足以判断夹力上限偏低。

负偏航另有三条轨迹已把销抬高 28.6–36.8 mm，却没有达到合格驻留。世界 4 和 5 若单独移除滑移条件，其余条件可分别连续满足 536 ms 和 346 ms。按原 5 mm 滑移门槛，合格时间分别只有 50 ms 和 0 ms；世界 3 还有其他条件未同时满足。后续应针对闭指到抬升的过渡训练保持握持，并继续用原来的离托、滑移和承载判据评分。搬运、插入和释放仍需独立验证。

## 复现

从仓库根目录运行。以下为 Bash 示例，Windows 下可将 `PYTHONPATH` 对应改为 `$env:PYTHONPATH="$PWD/src;$PWD/examples"`。

```bash
export PYTHONPATH="$PWD/src:$PWD/examples${PYTHONPATH:+:$PYTHONPATH}"
pickup=examples/checkpoints/panda-pickup-from-reach-s4000
scene=examples/checkpoints/panda-reach-factors-s4000/scene.xml

# 只用冻结的权重和起点，重放 CPU 验证集以及两个张指对照。
python examples/panda_pickup_from_reach.py --handoff-dir "$pickup" --student "$pickup/student.npz" \
  --out artifacts/replay-panda-pickup
# 从相同起点重新拟合并验证，可省去 --student。

# 在配置好 MuJoCo-TYX MUSA 的 S4000 主机上执行。
python examples/panda_pickup_musa_compare.py --handoffs "$pickup/validation.npz" --student "$pickup/student.npz" \
  --scene "$scene" --world 0 6 --out artifacts/replay-panda-pickup-musa

# 普通 CPU 从已保存的设备入步状态和权重独立复算实发动作。
python examples/panda_pickup_verify_actions.py --handoffs "$pickup/validation.npz" --student "$pickup/student.npz" \
  --scene "$scene" --evidence "$pickup/s4000" --out artifacts/pickup-action-check.json
```
