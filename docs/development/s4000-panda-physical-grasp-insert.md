# 双 Panda 从叉托取销并插装

这个实验检验一个具体问题：松开的夹爪能否依靠真实指垫接触，把独立工件从叉托送入板孔，并在撤离后把重量留给板面。左臂用腕部边缘支架持板，右臂的两个指关节分别接受电机指令。销有一个自由关节，质量为 120 g。右腕与销之间没有连接件。机械臂使用厂家 URDF 的惯量、关节和指垫。参与碰撞的范围包括工件、右手指、叉托、板、板夹具及桌面，整臂外壳用于显示。

## 实验和两个对照

每个世界从同一初态出发，运行 12 秒，步长为 2 ms。一套分阶段的反馈控制器根据实际手腕、工件及板的位置生成目标。插入阶段使用实测销尖与孔口的偏差修正腕部目标。控制器只能向两个七轴机械臂和两个指关节提交电机力矩或推力。

| 世界 | 臂指令 | 夹爪指令 | 检验内容 |
| --- | --- | --- | --- |
| 取销装配 | 关节目标与反馈 | 接近、闭指、保持、释放 | 双指接触是否能连续承担重量，释放后板面能否独立承重 |
| 张指位置对照 | 逐步复制第一世界的 14 路关节目标，各自计算反馈 | 保持张指 | 手腕沿近似相同的路径运动，缺少夹持时，销能否留在叉托上 |
| 张指力矩对照 | 逐步复制第一世界实际提交的 14 路臂力矩 | 保持张指 | 卸掉载荷和位置反馈以后，手腕的真实运动会偏离多少 |

每步保留发布状态、实发指令、PD 复算所需的状态与偏置、两指对销柄的法向力、指垫向上分力、叉轨与板面对轴肩的向上分力，以及其它工件接触的向上分力。影片把每份力报告对应的入步位姿和时间一起读取，两章使用相同摄影视角。

## 通过条件

初态由叉托承重。闭指轨迹须在同一次连续的双指承载区间内抬高至少 25 mm，持续至少 0.15 s，并横移至少 80 mm。落座时插入深度须为 8–12 mm，两条横轴各自误差至多 0.9 mm，轴线偏角至多 2°。松手后腕与工件分离距离增加至少 40 mm。在最后 0.1 s 内，板面须持续承担至少 80% 的重量，工件平移速度至多 8 mm/s。全程工件与孔板之间的最大穿透限值为 0.7 mm。

主张指对照还要求两个世界的初态、关节目标及反馈参数相同，两个世界的实际腕部轨迹最大相差 20 mm，张指世界的销留在叉托。复制力矩的对照单独评分并报告腕部偏差。一个初态的结果只能说明这套控制和接触机制的可行性。

## 复现

在已安装 Phymeo、MuJoCo 和设备依赖的环境中运行。三个世界在同一次调用中推进。保存每次运行到新目录。

```bash
python examples/panda_grasp_insert.py --mode musa --urdf /path/to/panda.urdf --cache /path/to/cache --out runs/panda-grasp-musa
python examples/panda_grasp_insert_film.py --scene runs/panda-grasp-musa/scene.xml --trace runs/panda-grasp-musa/closed.npz --control-trace runs/panda-grasp-musa/open.npz --library /path/to/phymeo_native.dll --font /path/to/chinese-font.ttc --out runs/panda-grasp-movie
```

原生 MuJoCo 参考使用同一入口和 `--mode cpu`。设备测试使用 `PHYMEO_TEST_MUSA=1` 运行 `tests/test_mujoco_tyx_musa_box_box.py` 和 `tests/test_mujoco_tyx_musa_capsule_box.py`，包括活跃面接触、分离世界、原生合力和力矩对照，以及六维盒接触的拒绝检查。
