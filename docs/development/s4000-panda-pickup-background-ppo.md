# 双 Panda 拾取后台长训

本轮在同一个双 Panda 场景中学习右手稳定抓起自由销，左臂持板。进入回合时沿用接近策略产生的末态和速度。每 16 ms 策略根据当前状态决定 16 个电机动作，底层动力学每 2 ms 求解一次。独立评分要求两指实际承重，销离托抬高至少 25 mm，相对滑移在 5 mm 内，持续 150 ms。[前批实测与物理门槛](panda-randomized-pickup-ppo.md)

## 选定探索方式

在新的训练复位批次 402 中，两个物理参数组各取 16 个起点。各探索方式使用相同的初态和标准正态抽样。下面的数值均为原生 MuJoCo 上使用冻结先验的探索诊断，尚未更新权重。

| 采样方式 | 手臂和手指初始标准差 | 标称组稳定承重 | 扰动组稳定承重 |
| --- | --- | ---: | ---: |
| 确定性先验 | 0 | 6/16 | 7/16 |
| 上批已缩小手指噪声 | 左臂 0.035、右臂 0.10、手指 0.04 | 0/16 | 0/16 |
| 小幅独立 | 两臂 0.02、手指 0.04 | 6/16 | 6/16 |
| 小幅、手臂时间相关 | 两臂 0.02、手指 0.04 | 1/16 | 1/16 |
| 微幅独立 | 全部 0.006 | 7/16 | 8/16 |
| 微幅、手臂时间相关 | 全部 0.006 | 8/16 | 5/16 |

时间相关组使用一阶相关系数 0.8，保持边际标准差并按回合重置。标准差指归一化动作映射前的高斯残差。预定顺序先比较成功总数，再比较较差参数组的成功数。微幅独立采样入选。稳定承重成功达 15/32，这说明该探索方式可以为 PPO 提供成功样本。对其他物体和复位分布的表现仍待测量。[完整配对数据](../../examples/checkpoints/panda-pickup-long-271145/arm-exploration-402.zip)

## 后台作业与判定

| 项目 | 本次配置 |
| --- | --- |
| 硬件和模型 | 摩尔线程 S4000，设备驻留的 MuJoCo-TYX 动力学和 Torch MUSA 策略更新 |
| 长度 | 120 轮 × 32 个环境 × 160 次决策 × 8 个物理步，共 3,840 个训练回合、614,400 次决策、4,915,200 个训练物理世界步 |
| 初始化 | 已发布示范先验上的零均值残差，手臂和手指起始标准差均为 0.006，随后由 PPO 学习 |
| 优化 | Adam 学习率 0.00002，3 个 epoch，minibatch 256，种子 271145。起始探索分布较窄，因此也减小了学习率 |
| 随机化 | 每轮新起点，每三轮含一轮标称物理；其他组变化销质量、惯量、接触材料摩擦 |
| 选型与验证 | 每 12 轮冻结快照，在两个固定选型组各 32 个起点配对原策略；最后从快照中选一份，在另一组固定扰动上配对验证一次 |
| 保存 | 每一轮原子保存权重、Adam 状态、随机数状态、复位批次和计数。记录逐世界双指接触、承重、滑移、抬升与独立评估 |

选型以成功数为先，再比较承重持续时间。验证的两个参数组各自都至少持平且总数提高，并且选型也符合这一条件，才通过本轮筛选。使用了新的复位扰动，但其基础接近末态来自已有的验证库。泛化到新物体、腕部图像、插入和撤手要另行验证。[本次配置与源码绑定](../../examples/checkpoints/panda-pickup-long-271145/config.json)
