# 双 Panda 随机起点取销实验

检验位置与朝向变化时，训练得到的抓取目标修正能否帮助右臂完成取销、搬运、插入、松手和撤离。左臂仍由腕部支架持板。场景、夹指、工件质量、控制时序和完整任务通过条件沿用[固定起点基线](s4000-panda-physical-grasp-insert.md)。

## 执行前固定的实验

| 项目 | 约定 |
| --- | --- |
| 训练与留出 | 六个训练复位、四个独立留出复位。沿轨位置扰动约 5–15 mm，跨轨约 0.5–1.5 mm。训练朝向中心为 ±7°、±22°、±36°，留出中心为 ±15°、±29°。各层另有固定种子的微扰。十个复位使用同一编译模型。 |
| 观测与动作 | 每回合先沉降 0.5 s，再读取自由销的仿真位姿。策略用两个共享增益修正目标的水平位置和世界竖轴朝向。控制器保留原 16 个实际电机和插入阶段的销尖反馈。 |
| CPU 初选 | 原生 MuJoCo 对四组参数分别运行全部六个训练起点。零增益复用原路径，其余三组来自固定种子的分层二维探索。 |
| S4000 更新 | 从 CPU 训练胜者附近产生三个参数扰动，连同胜者共四组。所有候选在两个相同的训练复位上完整执行。用 SGS 根据初选的终局成败分配采样概率，并抽取两个不同复位。 |
| 选型 | 依次比较完整任务通过数、通过的物理门槛数、撤离阶段的平均横向误差。最后一项对每回合的最大横向误差取 50 mm 上限。相同回报保留先出现的候选。 |
| 冻结与盲测 | 写入策略和训练收据的 SHA-256。另一个进程从磁盘加载，在 S4000 上对四个留出复位逐一比较零增益、冻结策略和单位增益。单位增益直接采用观测到的全部位置与朝向修正。所有留出复位都进入分母。 |
| 负控与影片 | 预先指定第一个留出复位。张指世界逐步复制训练策略的关节位置目标并独立做 PD 反馈。分别记录实际腕轨迹差、叉托支承、销的运动以及闭指世界的落座结果，保留失败画面。 |

每个物理回合 12 秒，步长 2 ms。完整任务要求同一次持续双指承载中抬高至少 25 mm、横移至少 80 mm，随后按原深度、横向误差、角度和穿透门槛落座，松手撤离后板面独立承重。更少的失败或更小的定位误差分别报告。四个留出复位只能回答此次离散对照，无法估计未知场景的训练成功率。

## 训练记录

CPU 的四组候选各完成 6/6。SGS 看到每个训练起点的终局成败记录相同，给六个起点的采样概率均为 1/6。本批实际抽中了 train-04 和 train-03。S4000 用相同两组起点完整运行每个候选。

| S4000 上的位置增益 | 转角增益 | 完整任务通过 | 两回合撤离阶段最大横向误差的均值 |
| ---: | ---: | ---: | ---: |
| 0 | 0 | 2/2 | 0.205 mm |
| 0.1375 | 0 | 2/2 | 0.299 mm |
| 0 | 0.0194 | 2/2 | 0.259 mm |
| 0.4174 | 0.0586 | 1/2 | 0.252 mm |

最后一组在 train-03 完成落座，但没有满足同一段持续承载内横移 80 mm 的门槛。按事先固定的排序，选中零位置修正、零角度修正。这只关闭抓取目标在拾取前的两项修正，关节反馈和插入时的销尖纠偏照常工作。从写入协议到冻结策略约 22 分 49 秒，其中 CPU 初选约 9 分 06 秒，S4000 参数搜索约 13 分 43 秒。冻结文件摘要为 `0cd2bdf888cba0e750828a61c856558af84cccb9bc93925a2aec00eb945d2c35`（策略 JSON 的 SHA-256）。[可加载的策略](../../artifacts/s4000-panda-random-pickup-20261126/policy.json) · [CPU 训练测量](../../artifacts/s4000-panda-random-pickup-20261126/cpu-training.json) · [S4000 训练测量](../../artifacts/s4000-panda-random-pickup-20261126/musa-training.json)

## 四个留出起点的实测结果

MTT S4000 在同一批中推进 12 个闭指世界和 1 个张指世界，每个世界执行 6,000 个物理步。下表的误差是撤离期间销相对孔轴的最大横向距离，单位为 mm。末列对四个起点等权取均值。[逐回合物理测量和负控](../../artifacts/s4000-panda-random-pickup-20261126/summary.json)

| 抓取目标策略 | 完整任务 | 留出 01 | 留出 02 | 留出 03 | 留出 04 | 均值 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 原控制器 | 4/4 | 0.075 | 0.178 | 0.114 | 0.146 | 0.128 |
| 训练后冻结的控制器 | 4/4 | 0.075 | 0.178 | 0.114 | 0.146 | 0.128 |
| 全量位置和朝向修正 | 4/4 | 0.349 | 0.352 | 0.330 | 0.331 | 0.341 |

冻结策略选中了原控制器的两个增益，所以前两行在每个起点的测量也一致。本次训练没有提高通过率。全量修正在这四个起点也抓得住，但四次撤离的横向误差都更大。这一结果只覆盖当前叉托、销、姿态扰动范围和仿真位姿观测。

### 留出 01 的闭指与张指对照

销质量为 120 g。闭指时销最高抬升 85.8 mm，在同一次持续双指承载中横移 144.2 mm，随后入孔约 10 mm。松手撤离后，板支承销，指垫的向上载荷为零。保持张指时，从相同初态重放相同的手臂关节位置目标，每个世界都根据本身的状态计算力矩。两次实际腕路径的最大差为 2.10 mm，张指时销的最高抬升仅为 0.00155 mm，结束时仍由叉托支承。[闭指轨迹](../../artifacts/s4000-panda-random-pickup-20261126/closed.npz) · [张指轨迹](../../artifacts/s4000-panda-random-pickup-20261126/open.npz)

[30 秒闭指与张指对照影片](../../artifacts/s4000-panda-random-pickup-20261126/film01/panda-grasp-insert.mp4)的前后两段各 15 秒，用相同的仿真时刻和回放速度展示两种夹指设置。在仿真时间 4.578 s，闭指的两块指垫分别测得 16.17、16.07 N 法向力，托架支承为零。张指的指垫均为 0 N，托架承担 1.18 N。在闭指轨迹的 11.262 s，两指已经撤开，板承担 1.18 N。物理轨迹来自 S4000，影片由本机 RTX 4060 Laptop GPU 用 Phymeo Vulkan 渲染，输出 1600×900、24 fps、720 帧。[影片与同步帧记录](../../artifacts/s4000-panda-random-pickup-20261126/film01/film.json)

下一轮若要检验学习的收益，可先固定一组现有控制器确实会失败的孔边错位起点，再比较它与具备退回、对准、重插动作的策略。此次实验只训练了拾取前的位置和转角两个增益。插入仍使用原有销尖反馈，从腕部图像学习位姿、卡住后的恢复均待单独验证。

## 复现

```bash
python -m pytest -q tests/test_panda_pickup_policy.py
python examples/panda_pickup_train.py train --out runs/pickup-train --cache runs/kernels
python examples/panda_pickup_train.py validate --out runs/pickup-heldout --training runs/pickup-train --cache runs/kernels
```

训练和验证须在具备 Phymeo MuJoCo-TYX MUSA 环境的 S4000 上串行运行。两阶段接受同一可选 `--urdf`。验证从冻结的实验清单读取留出起点，产生逐回合结果和第一组闭指、张指完整轨迹。两条轨迹可用 `examples/panda_grasp_insert_film.py` 配合训练目录的 `scene.xml` 回放。
