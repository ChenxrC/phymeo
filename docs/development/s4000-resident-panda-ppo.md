# 双 Panda 的 S4000 常驻状态训练

后续实验保留了这一版模型和测试门槛，加入轴向接近示范，并在三个留出集比较训练策略和关闭电机的轨迹。[双 Panda 末端对准实验](s4000-panda-guided-reach.md)

本批截止北京时间 2026 年 11 月 27 日 07:00。任务是让同一张摩尔线程卡上的策略反复读取真实物理状态、产生动作、推进动力学、从后继状态计算回报，并用更新后的权重继续驱动场景。沿用双 Panda、双指电机、叉托和 120 g 自由销场景。上批采用两个取件增益搜索，适合作为独立的完整操作基线。[上批实验](s4000-random-panda-pickup.md)

## 验收顺序

**结果**　S4000 从北京时间 00:29:39 训练至 06:08:52，用时 5 小时 39 分 13 秒。06:14:57 完成独立留出对照。两次相邻物理步之间可以完成设备策略推理，PPO 更新后的动作也已实际推进双 Panda。最终策略在全部 12 个留出世界均缩短了终点手–销距离，达到完整接近判据的世界为 0/12。[最终权重](../../examples/checkpoints/panda-reach-s4000/policy.pt) · [逐世界结果及分批收据](../../examples/checkpoints/panda-reach-s4000/results.json)

| --- | ---: | ---: | ---: |
| 平均终点手–销距离 | 155.2 mm | 93.2 mm | 686.6 mm |

三个对照的起始距离均值都是 158.5 mm。训练后，各世界全过程最近距离的均值为 68.2 mm，最好的一个也只到 46.4 mm，尚有明显的空间定位误差。12 个起点在相同最终权重下的首动作最大分量跨度为 0.1252。同一组起点比较初始与最终权重，首动作最大分量变化为 0.3325。关闭电机对照保留同一策略，第一步的策略输出与训练后对照完全一致，提交给物理的电机控制量为零。

126 次 PPO 更新使用 193,536 条训练转移、4,032 个优化器小批次。连同每次更新的三条短对照和更新后物理探针，训练批次共推进 2,140,992 个世界子步，完成 1,605,744 个 TYX 内核调用。独立留出另有 36,864 个世界子步。CPU 用原生 MuJoCo 运动学复核了这些留出状态的手、板和销的位置、姿态及驻留判据。训练区间物理后端共回读 8,563,968 字节状态码，未回读状态数组。Torch 的证据保存流量另计。

**审计与交付时间**　最终检查点第一次 CPU 审计在 06:15 因 1,536 个返回值中有 2 个超出原直接比较门槛而中止。原始设备 reward 经 CPU FP32 递推，返回值与设备保存结果逐元素相同。独立运动学重建 reward 的最大差异为 0.00001566，经过 128 步折扣递推后会传入返回值。更新后的审计保留逐步 reward 和 GAE 原门槛，另行传播实测逐步差异。用同一份冻结轨迹复核后，CPU 新权重前向最大动作差为 0.000000060。训练和留出均在 07:00 前结束；本地监控中断后，最终审计修正和模型交付晚于截止时间。修正未改训练权重、训练逻辑、奖励和成功条件。

### 执行前设定的验收项

| 节点 | 所需实证 |
| --- | --- |
| 同卡传输与会话 | Torch 写动作、TYX 读动作，TYX 写状态、Torch 读状态。测试非默认流、稀疏世界、回读字节、非法输入、复位和旧视图失效。小模型和 CPU 物理参考核对。 |
| 第一次真实更新 | 使用双 Panda 场景和有限力矩，由 PPO 输出 14 维关节目标增量与两个夹指开度。GPU 存储轨迹、计算真实状态回报和 GAE，优化 actor 和 critic。保存更新前后权重，比较相同观测与噪声下的动作，将新动作送回同一个物理状态。 |
| 复核与续训 | 另行加载模型。依据保存的物理数据独立复算回报和策略动作，在同一起点比较更新前、更新后与电机关闭三条真实轨迹。分开报告物理步进的数据传输与检查点、调试证据的主机读回。 |
| 任务扩展 | 在关节跟踪闭环通过后，用销位置与右抓取中心的实际偏差训练接近任务，另外约束左板和工件的漂移。在独立起点报告表现；抓紧、搬运、插入和松手仍由原物理判据分别验收。 |

运行分成环境准备、设备回归、短训练、分批训练和独立评估。最后一小时优先留给重载、证据整理和 Git 推送。端到端训练采用状态观测；录像与腕相机不在本次数据回路。每个训练阶段只有一个 S4000 执行进程。

## 一次策略更新怎样影响两个真实机械臂

每个世界保存 23 维位形与 22 维速度，包含两台 Panda 和自由工件。接近任务的 98 维观测还包含板、手、销的相对几何量，上一步动作和电机目标偏差。Actor 和 critic 各有两层 64 单元的隐藏层。Actor 输出 14 个臂关节目标增量和右手两个独立夹指开度，经有限力矩的电机驱动。左腕通过固定支架持板，叉托上的销通过自由刚体动力学运动。接触覆盖销、右夹指、板、支架、叉托与桌面的指定组合。臂杆外形仅供显示。策略决策间隔 16 ms，中间推进八个 2 ms 物理步。

训练片段从指定物理初态开始。在 128 次决策后，程序用实际后继状态的距离、姿态、板和销的漂移、速度和控制代价计算累计回报，用 GAE 和 PPO 更新网络。每次更新都保存同一观测、同一随机噪声下的新旧动作，并在该片段末状态用新动作再推进一次。由于只有状态观测，改变灯光不会改变这一模型的输入。[物理与策略入口](../../examples/panda_state_ppo.py) · [几何观测和独立 MuJoCo 参考](../../examples/_panda_ppo_reach.py)

| 数据 | 训练时的真实位置与传输 |
| --- | --- |
| 位形、速度、电机控制 | TYX 和 Torch 在同一张 S4000 上显式复制设备缓冲。动作提交后由物理求解器更新状态。 |
| 策略、价值、梯度和优化 | Actor、critic、回报、GAE 和 Adam 一、二阶矩位于 MUSA。非捕获模式的 Adam 标量步数位于 CPU。 |
| 每个物理子步 | 主机发起内核并检查每世界一个 4 字节状态码。逐步运行期间，状态和动作没有经过主机往返。 |
| 初始化和取证 | 主机使用 MuJoCo 编译模型并上传。每个片段边界另有有限性检查、检查点和审计轨迹回读。传输计数中的“状态码”仅涵盖物理后端，不能用来概括整个 Python 进程的流量。 |

### 设备与短闭环

这次运行的硬件为 MTT S4000，架构 `mp_22`，MUSA 运行时与驱动均报告 5.2。实际运行环境是厂商镜像预装的 Python 3.10.12、NumPy 1.25.0、PyTorch / torch_musa 2.11.0.post1 与 MuJoCo 3.3.7。尝试在满足项目 Python 版本声明的独立 Python 3.12 环境加载另两组官方 wheel 时，设备镜像的 MCCL 缺少 `mcclAllToAllv`。因此本次结果验证了源码在该镜像上的计算路径。标准 Python 3.11+ 安装组合仍需单独验收。

四世界关节跟踪做了两次 PPO 更新。同观测、同噪声时，每次更新前后最大动作差分别为 0.02191、0.02526，两次新动作均推进了物理场景。含正负对照共 2,208 个世界子步、4,968 次已完成的 TYX 内核调用，读取 8,832 字节物理状态码。从训练区间起点计，动作方向设备间复制 141,312 字节，状态方向复制 597,504 字节；另有 720 字节初始状态在计时区间开始前已复制。另行在 CPU 上按保存的物理数据复算回报和 GAE，新旧权重前向最大动作偏差均小于 0.0000001。

### 接近任务的训练和留出比较

训练集和留出集各有 12 个世界。训练包含六个工件放置姿态，每个配两个不同的机器人初态。留出包含另外四个放置姿态，每个配三个机器人初态。两组分别以 271101 和 271127 为种子，对原始 14 个臂关节独立施加 ±0.025 rad 均匀扰动。所有评价共享同一份留出状态，分别运行初始策略、最终策略、关闭电机三条轨迹。初始策略使用第一个更新文件中保存的**更新前**权重。每条评价轨迹持续 2.048 s。

“达到接近条件”要求同一世界连续 50 个物理子步都满足五项指标：手–销距离 ≤20 mm，相对姿态误差 ≤15°，左板平移 ≤10 mm、旋转 ≤5°，销偏移 ≤10 mm。报告同时给出终点距离和达到该条件的世界数。夹持、承重和插入都需要另外的实验。

### 复现入口

从仓库根目录使用已经安装 TYX、MuJoCo、PyTorch 和相配的 `torch_musa` 的 S4000 Linux 环境。下面的 Bash 命令使用仓库内的 Panda URDF。每次训练和评估需要新的输出目录。场景、训练参数和初态都绑定到检查点，评估允许切换到专用留出集。

```bash
export PYTHONPATH="$PWD/src:$PWD/examples${PYTHONPATH:+:$PYTHONPATH}"
data=examples/checkpoints/panda-reach-s4000
common=(--task reach --worlds 12 --steps 128 --action-repeat 8 --epochs 4
        --minibatch 192 --seed 91027 --learning-rate 0.0003 --bias lagged)

# 从随机策略开始，训练两次 PPO 更新
python examples/panda_state_ppo.py --stage train "${common[@]}" \
  --reset-npz "$data/train-12.npz" --updates 2 --eval-steps 16 --out artifacts/panda-reach-new

# 从发布权重继续训练一个更新
python examples/panda_state_ppo.py --stage train "${common[@]}" \
  --reset-npz "$data/train-12.npz" --checkpoint "$data/policy.pt" \
  --updates 1 --eval-steps 16 --out artifacts/panda-reach-resume

# 在相同留出初态比较初始策略、发布策略和关闭电机
python examples/panda_state_ppo.py --stage evaluate "${common[@]}" \
  --reset-npz "$data/holdout-12.npz" --checkpoint "$data/policy.pt" \
  --baseline-checkpoint "$data/baseline-update-00000.pt" --eval-seed 99027 \
  --eval-steps 128 --out artifacts/panda-reach-evaluation

# 在 CPU 上复算发布检查点的策略动作、物理回报和 GAE
python examples/panda_state_ppo.py --stage audit --checkpoint "$data/policy.pt" \
  --out artifacts/panda-reach-cpu-audit.json
```
