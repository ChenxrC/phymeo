# MAT-001：StVK 材料的有限形变适用域

- 状态：已确认范围；大形变材料与稳定积分属于后续开发。
- 阶段：P4 T4 材料切片，2026-10-27；实现与测试随本记录提交，后续 P4 完整实验记录统一冻结源码。
- 当前要求：det(F)>0.2，所有奇异值位于 [0.6,1.4]；超域返回 SolverFailure，不能放宽门槛以通过场景。

## 现象、原因与证据

倒置、主伸长 0.5 / 1.5，以及行列式仍为 1 的过大简单剪切均被独立材料函数拒绝。
这不是未知崩溃，而是本次最小材料的显式适用域。StVK 使用 Green 应变并保留剪切响应，
但本轮没有承诺大形变下的稳定性。单元解析伸缩/剪切、能量中心差分、整体旋转不变性及
24 单元共享节点力装配均已验证；固定点内力保留用于支撑载荷审计。

后续 T5 在 `664c989` 完成了[冻结加载](../benchmarks/p4-softbody.md)：h=1/4000、400 步、最小 det(F)=0.98578，重复逐元素一致。
这只是一个成功负载，最大稳定步长、阻尼、长期能量误差仍未测；P5 接触负载继续验证。如果当前验收场景被此范围阻断，必须当作本轮问题处理。

## 给后续 agent 的指引

先固定质量、E/ν、单元尺度与边界，分别扫描剪切/伸缩和时间步；区分材料域拒绝、积分不稳定和接触收敛。
保留全部失败点、能量、最小 det(F)、奇异值和负载，而不是只展示可运行组合。
若要扩展范围，应单独比较材料模型（如有明确倒置政策的 Neo-Hookean）与隐式/更稳定积分器，
同时保留独立能量梯度、支撑载荷和后段失败全局回滚门禁。不能把夹紧 F 或清零内力作为默认修复。
