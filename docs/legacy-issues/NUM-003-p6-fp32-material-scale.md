# NUM-003：P6 FP32 材料数值尺度边界

- 状态：已确认范围；普通场景中由极小扰动引发的错误拒绝已修复待阶段验收，扩大极端尺度范围延期。
- 类别：精度/可表达性；不改变 P5 FP64 或 P6 冻结验收预算。
- 位置：`backends/_tyx_node_kernels.py::_bounded_material_product`、`stvk_material`；
  `backends/tyx_node_math.py::material`；`backends/tyx_articulated.py::TyxNodeRobotConstraints._dot`。

## 现象和原因

24 四面体的小软块压缩后，接触会留下约1e-24量级横向分量；参考逆矩阵中约1e-15的舍入余项与其相乘，
或归一化法向的小分量相乘，可能产生 FP32 subnormal。
此前对每个乘法一律拒绝 subnormal，导致主响应完全可表达的场景也无法提交。
解释器在外层 `np.errstate(under='raise')` 抛错，CUDA 的显式算术检查产生非有限结果并拒绝，均不是成功。
独立小复现表明这属于 phymeo 的数值策略，未发现 tyx 执行错误。

## 当前处理及限制

法向长度已按最大分量缩放；和式至少有一项1，因此低于 FP32 最小正规数的平方项不影响长度，原法向分量仍保留。
接触内积在设备端忽略不可表达的小乘积后，主机独立核对相对反向误差≤2e-5；若整个答案被丢失会拒绝，不用主机答案替换。

材料矩阵/能量归约采用同类小乘积省略。首次静态界漏掉了与刚度无关、随后被体积放大的项，独立审阅已复现：边长3e12、E=1e-25的合法四面体会错误返回零内力，实际最大内力约0.0433125N。该旧界不成立，不能作为安全证明。

修复后令`t=float(FP32 tiny)`、`K=mu+abs(lambda)+bulk`、`V=sum(volume)`、`R=max(abs(rest_inverse))`，明确用FP64计算
`1000*t*K*V*(1+9*R) + 27*t*V*R + 9*t*V <= 1e-6`。
后两项分别覆盖Piola归约和最终参考梯度归约的直接省略，含三个源节点列汇入原点的放大；它们不再被小刚度错误压低。普通与严格errstate两种反例均须明确拒绝。

静态预筛不能取代实际误差验收。`validation/material_device.py`现在以原FP64模型和输入，独立按体积/偏差能量及形函数梯度验算全节点内力和能量；逐分量使用冻结`atol=2e-4, rtol=5e-4`。超差抛出SolverFailure，绝不替换设备结果。单位四面体E=1e6的刚体旋转因FP32舍入产生约0.00764N伪内力，修复前被接受，修复后由此门禁拒绝。生产CPU材料求解函数禁用时，设备仍实际执行；验证器独立实现且只用于接受/拒绝。

独立单元、24单元、扰动及能量梯度测试仍使用原阈值。
边界转换、自由积分和一般矩阵原语的非零下溢拒绝不变；没有打开全局 flush-to-zero，也没有修改模型参数。

该上界保守，极高刚度/特殊尺度的模型可能被拒绝，即使特定构型没有发生下溢。
修复前32项材料/节点和26项接触曾在解释器/CUDA通过，却未覆盖上述反例，不能替代修复后验收。首次新增5个失败用例后，37项材料/节点和26项接触在解释器通过；这63项连同实验和记录器共79项实际CUDA通过。另补2项非有限输出拒绝，已按失败→修复在解释器和CUDA通过。当前完整39项材料/节点和26项接触的C++及全轨迹结果以最终验收记录为准。
