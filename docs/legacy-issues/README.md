# 遗留问题与能力边界

本目录记录已知精度限制、数值细节与暂不阻断本轮代表场景的能力缺口，供后续 agent 接手。用户于 2026-10-27 指定：本轮先跑通机器人、布料、最小体积软体及统一框架，性能优化随后处理。

## 分类规则

- 可以延期：已限定适用范围、当前验收仍通过的步长敏感性、精度差异、模型能力扩展与使用体验细节。
- 必须阻断当前模块验收：错误报告成功、非有限状态、错误冲量或重复作用、模型语义不符、输入被破坏、事务回滚失败、必要后端实际上未执行。
- 必需能力尚未实现应列入[本轮大纲](../superpowers/plans/2026-10-27-integrated-framework-outline.md)，不能通过放进本目录而从交付范围中消失。
- 延期只对已记录的场景、版本和误差范围有效；新场景若被该问题阻断，立即升级为本轮阻塞项。
- 性能现象和待剖析热点放在[性能瓶颈目录](../performance-bottlenecks/README.md)。因超时或内存不足无法完成最小验收时，需要处理运行可行性，仍不开展扩展性优化。

## 后续 agent 工作顺序

1. 读对应条目、关联设计和验收记录；核对当前 Git SHA 与工作区变更。
2. 按记录重现；已保存的实验可先读取，避免无理由重复耗时实验。
3. 一次只改变一个因素，先冻结验收范围与误差定义；不要通过放宽门槛掩盖失败。
4. 修改前补针对性回归；保留参数、命令、源码/依赖 SHA、原始结果及失败记录。
5. 更新原因与证据，明确是否影响其他场景；验证后提交。关闭条目仍保留历史。
