# PERF-009：厚度材料点host映射与小负载边界

状态：可复现串行观测；尚未profiler定位占比。本轮不优化。

## 事实与位置

`src/phymeo/coupling/offset_port.py::__init__`逐面计算法向、块Jacobian、实际偏置与力矩门禁。`_map/_loads`在host FP64显式乘积/归约；response/apply_impulses调用底层端口，并回到主机审计。

[7200次观测](measurements/p65-offset.md)包括1/16附件，全部聚合到3个共享节点。16附件host构造中位数约1.06ms，CUDA响应加断言约.91ms、候选审计约1.74ms；这些不是整步或大网格性能，也不能将差值全部归因tyx。实际GPU launch已验证，未做Warp测量。

## 待验证假设与后续方向

代表性网格接入后，分别剖析几何/Jacobian构造、暂存数组、跨后端传输、kernel、候选快照与审计成本。只有测量确定依赖自身实现问题或缺失能力时才转入tyx_flaw并附最小复现。

可研究批量构造/缓存，但配置或材料特征变化时必须失效；不能把fixed-snapshot Jacobian跨动态子步复用。并行归约必须保留共享节点全部交叉作用、反作用一次和极小项/下溢拒绝。不要删除力矩、真实偏置或动能门禁换取表面加速。重测应同时报告物理残差、拒绝数、实际执行计数和相同规模，不只报更快样本。
