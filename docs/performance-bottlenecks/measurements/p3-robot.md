## 口径与结果

1/2/8 个半米、1 kg 连杆，零外力、非零重力；每次从同一初始 q/v 开始，非连续 300 帧轨迹。
FP64、dt=1/2000、一个子步、完整事务及诊断保留。各算子首次调用后预热 2×100 次，随后 3×100 次。
三个规模的 900 个计时 step 全部接受，失败数 0，最大归一化动力学残差 2.82e-17；每阶段一次 sweep，无接触迭代。

构造（模型+运行器）分别 0.672 / 0.333 / 0.349 ms；首次 step 分别 2.259 / 2.595 / 7.982 ms。
这不是隔离的 Python 导入冷启动，也不是 JIT 测量。每个规模的前序算子已影响缓存，不能把首次调用称为完全冷缓存。

预测阶段中位数分别 1.183 / 1.759 / 6.489 ms；诊断 0.309 / 0.401 / 1.108 ms。
阶段计时不含最外层快照/报告构造，但总 step 包含；不把不同阶段中位数的比值冒充严格耗时占比。
峰值内存、分配次数、细算子调用成本、GPU、Warp、MuJoCo 速度均未测。
