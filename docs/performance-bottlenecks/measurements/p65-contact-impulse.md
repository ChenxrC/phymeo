# P6.5 固定构型联合接触冲量观测

2026-10-28，同[基础环境](p65-foundation.md)，固定tyx SHA与工作区TEMP/TMP、TYX_CACHE_DIR。这是两个2自由度机器人＋一个布节点、两条已共点接触的瞬时问题；构型和输入快照固定，每次从零接触冲量重求。**没有时间步、夹爪几何、持续抓布或递布性能声明。**

机器人各通过±.02Ns水平速度冲量形成相向速度，质量.25kg节点通过-.005Ns形成-.02m/s向下速度。高μ=.8消除向下速度，低μ=.0001保留约-.019984m/s下滑。法向与切向总冲量联合迭代；独立核对法向约.02Ns/侧、节点结果与能量下降。固定基座吸收竖直反力，不错误要求整个开放系统线动量守恒。

使用`python scripts/benchmark_contact_impulse.py --mode numpy --output artifacts/contact-numpy.json`，然后同命令`--mode cuda`。各模式/μ组合1首调用＋2预热＋3×10计时求解，共120计时求解通过，失败0。其他数值进程均已结束，串行测量；构造/预测/预载在计时外，响应矩阵查询、迭代、实际响应复核、候选验证及独立断言都在计时内。每次调用有完整的实际端口返回同步。

原始[NumPy](p65-contact-numpy.json)、[CUDA](p65-contact-cuda.json)含104产品源码和测量器的逐文件哈希、全部时序、迭代、残差、能量和执行计数，测量前后源码一致。独立功能测试中的预算/非法/最终响应不一致均明确拒绝；未混入成功计时样本。首调用不称冷JIT，未测峰值内存、字节、完整step、CCD与Warp，未优化。
