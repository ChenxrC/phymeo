# P3–P5 Robot and Softbody Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Inline implementation continues the previously authorized workflow; one builder check and one final independent whole-branch review, no implementer agent per task.

**Goal:** 完成固定基座机器人、最小体积软体和机器人—布料—软体 CPU 双向集成，并保存可重复物理/工程证据。

**Architecture:** 原生 q/v 或节点 x/v 由局部状态族管理，物理端口提供完整质量响应；分阶段参与者由组合 SceneProgram 连接，已有 SceneStepper 掌握时间、预算和全局事务。算法独立实现，MuJoCo 只做隔离对照。

**Tech Stack:** Python 3.11/3.12、NumPy FP64、uv/pip；可选 MuJoCo 3.3.7 独立锁；保留固定 tyx 及实际 CUDA 原有回归，不添加必需依赖。

**Spec:** [P3 机器人](../specs/2026-10-27-p3-robot-design.md)、[P4 柔体](../specs/2026-10-27-p4-softbody-design.md)、[P5 集成](../specs/2026-10-27-p5-cpu-integration-design.md)。

## Global Constraints

- 用户授权 P3–P5；基线 `2993614dd7a8e5630cf3e7d53c8ac32f21c11ac7`，分支 `codex/p3-p5-dynamics`，沿用专用 checkout 和已验证工具链；不合并或发布。
- SI、Y-up、xyzw，新增 CPU 数据只接收 FP64；P6 新算法 tyx 移植和性能优化、AI 训练不在本轮。
- 输入/模型副本和字段完整性、固定点不变量、显式历史、全帧原子提交均保留；禁止双重推进 dt 或重复位置等效冲量。
- 旋转/移动关节一连杆一自由度；n≥1、parent=-1 或 <i；轴/四元数误差≤1e-10；正质量和物理 COM 主惯量。
- 四面体 det(F)>0.2、奇异值 [0.6,1.4]；超出本材料域拒绝，不调宽演示门槛。
- S2–S4 共用 200 帧、dt=1/2000、2 子步、各阶段 200 次预算、tolerance=1e-8；每个节点域≥5 个实际接触子步。全部细节按规格冻结，改动必须先写原因和设计变更。
- 单向反事实是外部驱动边界实验，不修改普通动力学程序的反作用规则。
- 先失败用例再实现、小提交推送；每阶段记录性能/遗留问题，tyx 依赖问题进 `tyx_flaw/`，Warp 未测不宣称差距。
- 无截止时间；完整验收后结束当前 P3–P5 goal。用户于2026-10-27新增[P5.5 双臂递布目标](2026-10-27-dual-arm-cloth-handoff-milestone.md)，随后接续该目标，全部队列完成才结束自动续跑；P6仍未授权自动进入。只报告实测进度，不把文档或测试数量当动力学完成。

## Review Focus

- 零位非单位旋转、非零 COM、移动关节随父转动时的科氏项，以及分支共享祖先必须正确（T1/T2）。
- 惯量/矩阵在极端但有限输入下可能失去正定性或溢出；不得伪逆、静默零力或接受坏结果（T2/T4）。
- 同体多球、重复节点、不同节点域共享一个关节系统，必须保留交叉响应和每次相同作用点的反力（T2/T6）。
- 正体积但过度剪切、固定节点的材料支撑载荷、后段材料越界必须检查且全部域恢复（T4/T5/T6）。
- 反事实边界索引、诊断/历史别名和 close 失败不得污染下一帧；完整三域场景的两个交互都必须实际发生（T6/T7）。
