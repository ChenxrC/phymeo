# Newton 1.7.0 与 Phymeo 的刚体–柔体参考案例计划

**目标**　在同一组三角形和刚体上，分别量出节点检测与整面检测的差别，并区分离散几何、区间首触和真实受力子步。共冻结 11 项案例。集成者先收取双引擎的独立基线，再按失败项决定产品改动。[冻结输入、预期和容差](../../../tests/reference_newton/rd/cases.json) · [实际测量入口](../../../tests/reference_newton/rd/baseline.py)

**运行约束**　Newton 1.7.0 使用独立的 Warp 环境，Phymeo 使用原项目解释器。每进程只加载指定引擎，一次只运行一个设备。案例中的长度用 m，法向均从刚体向外。初始静止、几何零速度与时间步均按各项合同记录。[共享入口合同](../../../tests/reference_newton/README.md)

## 初级 · 球是否碰到了节点之间的布

- [ ] 从 `RD-SPHERE-FACE` 开始。半径 1/4 的球位于三角形重心上方 3/16 m。面间隙为 −1/16 m，三个节点和三条边均分离。Newton 缺省管线应无记录，开启 `enable_rigid_soft_full_surface_contact=True` 后应有一个三节点面记录。Phymeo HOST 应给出同一中面点、球面点和法向。
- [ ] 运行 `RD-SPHERE-SEPARATED`。球心升至 3/8 m 后两种 Newton 管线均须无接触。Phymeo 扩大宽相取样范围，核对它返回的正间隙 1/8 m。Newton 在空缓冲上只报告计数，无法从该缓冲读出分离距离。
- [ ] 按 `soft_contact_count` 截取活跃前缀，读取 `soft_contact_indices`、`soft_contact_barycentric`、`soft_contact_particle`、`soft_contact_shape`、`soft_contact_body_pos`、`soft_contact_body_vel`、`soft_contact_normal`。索引中有效项的个数区分点、边、面。用原状态顶点和这些权重重建布面位置。所列 Newton 夹具均使用世界刚体 `body=-1`，因此体局部的刚体表面点与世界坐标相同。净隙为沿法向的两点差减去粒子半径及形状 margin。各面节点取相同半径。检测余量 `soft_contact_gap` 单列，本组设为零。[缓冲定义](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/sim/contacts.py) · [粒子检测](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/geometry/kernels.py)

## 中级 · 材料地址、有限表面和形状配置

| 案例 | 独立核对 |
| --- | --- |
| `RD-SPHERE-MIRROR-HOLDOUT` | 球移至背侧并改变切向位置，绕序反转。垂足权重变为 (1/4, 3/8, 3/8)，法向变为 +z。 |
| `RD-SPHERE-EDGE` | 球心到轴向边中点的截面为 3∶4∶5，距离 5/8 m。边两端都在球外。Newton 同时输出独立边优化和相邻面的优化结果，逐条检查唯一边的地址、最近点误差及间隙。面优化在边界附近收敛较慢，其容差已单列。 |
| `RD-FINITE-PLANE` | 同高的两粒子分居有限平面边界内外。只有内侧节点接触。1.7 的有限 quad 用 L∞ 距离近似与固定 +z 粒子法向。 |
| `RD-HEIGHTFIELD` | 平坦标高 1/4 m。一个节点虽低于地表，却在横向边界外 3/32 m。只有域内靠近地表的节点接触。Phymeo 的公开几何输入缺少 heightfield。 |
| `RD-MESH-MISSING-SDF` | 方块以封闭三角网格登记。三个节点在顶面上方 1/32 m，半径为 1/16 m。缺省粒子查询应读到三点，随后构造整面碰撞管线须因缺 SDF 抛出指定 ValueError。 |
| `RD-ROUNDED-PLATE` | Phymeo 用同一次查询读四个探针。面、背、侧边、圆角的预期间隙依次为 −1/32、1/16、−1/32、1/32 m。圆角法向由横向偏移 (3/32, 4/32) 给出。 |

- [ ] 对有限 plane 和 heightfield，同时核实降级警告、零个边/面候选及保留的单节点记录。构造错误、无候选和真实几何分离分别入账。Phymeo 的圆边板是有限多边形加球，两面与圆滑侧边都属于边界。Newton 这两种形状的采样合同不能代替圆边板验收。[1.7 形状分流](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/sim/collide.py) · [标高域边界](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/utils/heightfield.py) · [Phymeo 圆边板原有回归](../../../tests/collision/test_rounded_plate_contact.py)
- [ ] 复核球形原语的解析 SDF。独立边优化取一维极小值，面优化在重心单纯形上做固定次数迭代。登记表预先区分两者的误差，检查软/硬表面点及法向，防止只看特征标签。镜像留出及分离控制在定位失败时保留原输入。[1.7 边与面内核](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/geometry/soft_contacts_sdf.py) · [Phymeo 既有 RD01～RD05 及约束](../../benchmarks/p65-collision-public-catalog.md)

## 高级 · 显式 SDF、首触和两向受力

- [ ] 在 CUDA 上执行 `RD-MESH-BAKED-SDF`。同一闭合方块网格在加入 builder 前调用 `mesh.build_sdf(device="cuda:0", max_resolution=32, margin=0.078125)`。构造时保留 `ShapeConfig.has_particle_collision=True`。此带宽覆盖探针，整面路径须给出三点、三边和一面，七个材料位置均应投影到 z=1/4 m 的顶面。体纹理的生成需要 CUDA。若采用 builder 的默认解析度，可在登记前对实际使用的 config 调 `configure_sdf(force_sdf=True)`。显式网格解析度与 padding 本例直接交给 `Mesh.build_sdf`。[网格构造](https://newton-physics.github.io/newton/1.7.0/api/_generated/newton.Mesh.html) · [形状配置与 finalize](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/sim/builder.py)
- [ ] 运行 `RD-SWEPT-INTERIOR`。端点间球心高度为 1/2−t，t 为归一化时间。两端均净空 1/4 m，在 t=1/4 首次相触。Phymeo 要求返回包住 1/4 的区间及面内见证。CUDA 执行要读回 tyx 面特征内核完成数、下载数与同步数，随后由 HOST 认证区间。Newton 单次 `collide(state, contacts)` 的 RD 缓冲对应离散状态，本行在该引擎登记为 `not_comparable`。[Phymeo 首触回归](../../../tests/collision/test_sphere_face_sweep.py) · [设备候选与 HOST 核对](../../../tests/collision/test_tyx_sphere_face_sweep.py) · [Newton 碰撞频率与时间语义](https://newton-physics.github.io/newton/1.7.0/concepts/collisions.html)
- [ ] 运行 `RD-PRISMATIC-LINK-STEP`。面积 3 m²、层压缩 1/32 m、面刚度 64/3 Pa/m，构成 2 N 法向载荷。静止滑块质量 1/2 kg，三个布节点各 1 kg。实际推进 1/256 s，读回中点力、关节广义力、末关节位移及速度、全部节点速度与总竖直动量。对称轴的两个支点平均分担载荷，滑块速度为 +1/64 m/s，三个节点各为 −1/384 m/s。CUDA 在这里仅承担 `TyxNormalLayer` 载荷运算，材料地址映射与积分在 HOST。已有胶囊结构载荷另有细化、转动和摩擦对照。[铰接子步回归](../../../tests/test_cloth_link_contact.py) · [真实 tyx 受力](../../../tests/test_tyx_cloth_link_contact.py) · [材料适用范围](../../benchmarks/p65-cloth-link-response.md)
- [ ] 保持两种验证的力学范围。Newton 1.7 的 VBD 消费上述 E/F 材料权重并将力传入粒子自由度。其 `CONTACT_F` 求解器观测可在同一 contacts 缓冲绑定后读末配置的刚体受力，软记录位于 `rigid_contact_max + i`。XPBD 的粒子路径会拒绝带整面标志的缓冲。本轮 Newton RD 数值行测量生成器输出。Phymeo 单步使用独立的参考面积接触层。若要比较两个引擎的接触力，应另立同一质量、接触定律、观测时刻和反作用边界的实验。[VBD 实现](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/solvers/vbd/solver_vbd.py) · [XPBD 消费入口](https://github.com/newton-physics/newton/blob/v1.7.0/newton/_src/solvers/xpbd/solver_xpbd.py)

## 串行复现与停线条件

从集成工作树根运行下列命令。最后两条的 `python` 选用已安装 Phymeo 依赖、固定 tyx 的原项目解释器。若需写报告，给每次执行增加 `--out` 与新的输出路径。定位时可添加 `--case RD-SPHERE-EDGE` 等单项选择。

```powershell
.\.venv-newton-1.7.0\Scripts\python.exe tests/reference_newton/run_matrix.py --list --lane rd
.\.venv-newton-1.7.0\Scripts\python.exe tests/reference_newton/run_matrix.py --engine newton --lane rd --device cpu
.\.venv-newton-1.7.0\Scripts\python.exe tests/reference_newton/run_matrix.py --engine newton --lane rd --device cuda:0
$env:PYTHONPATH = (Resolve-Path src).Path
python tests/reference_newton/run_matrix.py --engine phymeo --lane rd --device cpu
python tests/reference_newton/run_matrix.py --engine phymeo --lane rd --device cuda:0
```

任一引擎的实测硬表面量超限、记录溢出、材料地址错配、漏报边界降级、首触超出区间，或结构力无法在双方末状态闭合时，保留失败记录并停止该组升级。设备行缺少真实 kernel 计数或结果缓冲落在另一设备时也要停止。分别计 `fail`、`gap`、`not_comparable` 和 `device_not_covered`。现有判断只针对这 11 行，系统递布仍有单独的验收条件。

父任务取得四份报告后再定产品工作。若差异在节点间几何，先用原始材料地址复现并定位到公开检测分流与窄相。若仅剩高度场缺口，先固定域外距离和法向合同。若几何已合而冲量不合，进入载荷映射及步进的单独对照。每个产品变更都需重跑原留出、既有对应族回归和针对该差异的新反例。[几何入口](../../../src/phymeo/geometry/collision_pipeline.py) · [铰接布–杆载荷入口](../../../src/phymeo/solvers/cloth_link_contact.py)
