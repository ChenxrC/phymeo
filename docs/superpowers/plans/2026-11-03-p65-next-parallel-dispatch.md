## A　移动参考系下的机器人传感

- [ ] **接口与用例。** 作者负责新增 `src/phymeo/sensors/robot_frame.py`、必要的子包入口、`tests/test_robot_frame_sensor.py` 和 `tests/reference_newton/robot/site_frames.py`。拟提供 `measure_relative_site(model, state, reference, target)`。一个 site 绑定 link 或世界、局部点（m）和局部 XYZW 姿态。返回参考系中的位置、旋转矩阵、线速度（m/s）和角速度（rad/s）。一条读数只用同一个已发布状态的 q、v。
- [ ] **HOST 实现。** 复用 FK 及点的线、角雅可比。令 d=pT−pR，RR 为参考系到世界的旋转，则读数依次为 RRᵀd、RRᵀRT、RRᵀ(vT−vR−ωR×d)、RRᵀ(ωT−ωR)。vR、vT 均在各自 site 取值。对基于质心的速度先换点。[运动学](../../../src/phymeo/dynamics/robot_kinematics.py) · [实际点端口](../../../src/phymeo/coupling/robot_port.py)
- [ ] **独立判据。** 世界点 (1/4,0,0) m 在绕 Z 转 +90° 的参考系中读成 (0,−1/4,0) m。给参考系角速度 +2 rad/s、点保持世界静止，应读到线速度 (−1/2,0,0) 和角速度 (0,0,−2)。倒转速度时这两项换号。两 site 共用一个旋转 link、选不同局部偏心点及不同局部姿态时，相对位姿恒定，两项相对速度都为零。斜轴留出用两支链和偏心质心。参考 Z 铰 cosθ=3/5、sinθ=4/5、转速 1/2，参考偏心点 (1/4,0,0)。目标 X 滑轨从 (0,−1/8,1/4) 出发，s=1/4、ṡ=1/8，下接 X 铰 α=π/2、α̇=1/4，工具局部点 (0,1/8,0)。两 site 局部姿态为 I。应得相对位置 (−0.2,−0.275,0.375)、线速度 (−0.0875,−0.14375,0)、角速度 (0.15,−0.2,−0.5)。
- [ ] **时刻与设备。** 用已通过的 2 kg 滑轨，零初史、两步延迟、+2 N 前馈、h=1/16 s，无其他载荷。读前三个已接受子步，速度应为 (0,0,1/16) m/s，位移为 (0,0,1/256) m。拒绝整帧后重新读帧初状态。Newton 的 `SensorFrameTransform` 对照位姿，速度从同刻 `body_qd` 和 site 偏心量独立换算。TYX 留出记录实际 FK/雅可比核完成数与读回，注明相对量的组合在 HOST 还是设备上执行。[Newton 1.7 传感器](https://newton-physics.github.io/newton/1.7.0/concepts/sensors.html) · [TYX 机器人计算入口](../../../src/phymeo/backends/tyx_robot_math.py)
- [ ] **放行。** 各物理量分别比较。上述米制小场景的 HOST 绝对误差目标 2×10⁻¹²，FP32 留出 2×10⁻⁵，旋转按旋转矩阵或三个基向量比较。共转不归零时先查旋转运输项，偏心项失败时先查质心换点。IMU 另需真实加速度与重力约定，浮动根另需 7 坐标/6 速度接口。

## B　非零转动刚体的连续碰撞

- [ ] **案例优先。** 作者负责 `tests/collision/rotating_ellipsoid_oracles.py`、`tests/collision/test_rotating_ellipsoid_plane.py` 和 `src/phymeo/geometry/_rotating_ellipsoid_plane.py`。首域为静止平面、绕自身固定中心及固定世界轴旋转的椭球，任意有效初始姿态，0<|angle|≤float(π)。输入沿用 `RigidTurn` 的实际有符号弧度。移动或偏心枢轴、移动平面和更长转弧留给单独的支持域。
- [ ] **解析正反控。** 保留原基准半轴 (1/2,1/4,1/4) m、中心高 3/8 m、平面 z=0，绕 Y 转 ±float(π)。两端净空 1/8 m（末端按存储角读回），峰值压入 1/8 m。令 α=atan√(5/7)、A=|实际输入角|，入、出时刻为 α/A 和 (π−α)/A。反转时切向支撑点镜像。h=1/2 m 给孤立擦边，h=9/16 m 给全段净空，此处 h 为中心高度。交换形状顺序应交换双方点并翻转法向。
- [ ] **跨构型留出。** 用 3 rad 的非半圈路径及 h=1/2−1/16384 m，步中有短接触，65 个等距采样均分离。再取 2 rad、h=3/8 m 验证末态仍接触、末次接触时刻为 1。另取半轴 (1/2,3/8,1/4) m 和非主轴 u=(3/5,4/5,0)。中心高 3/8 m 时，理想轴的首触满足 sin²θ=125/237。独立判据使用实际存储轴归一化后计算横向支撑系数 a²u_y²+b²u_x²。另将椭球、枢轴、平面和见证一起旋转平移，核对变换前后的时刻和位置。一个 FP64 刻度的近失作为诊断附录。常规放行取上述物理间隙与独立擦边例，避免因极限精度试片推迟主线。
- [ ] **实现与发布。** 复用既有半角图、区间转时刻和有界多项式隔根。单位法向 n、S=R·diag(a²,b²,c²)·Rᵀ 时，支撑半径为 √(nᵀSn)。在同一姿态独立重建椭球点与其平面投影。公开查询保留末态见证及原 `CollisionSweep.first_t`，追加可选曲面首/末事件，各自绑定时间区间、采样时刻及双方材料地址/偏移。父负责 `_curved_solids.py`、`collision_pipeline.py` 的分派与兼容。资源不足以区分边界时返回 `unresolved`。[原静态支撑](../../../src/phymeo/geometry/_curved_solids.py) · [已有角度区间](../../../src/phymeo/geometry/_rotation_angle.py) · [现有扫掠见证](../../../src/phymeo/geometry/collision_witness.py)
- [ ] **放行。** 首末区间各自包含对应的独立根。本批米制案例目标为归一化区间宽 ≤10⁻⁶、重建点和间隙误差 ≤1 µm、法向分量误差 ≤10⁻⁵。孤立擦边与有限净空要能区分。Newton 1.7 现有 `collide(state, contacts)` 对照指定姿态，首末时刻由整段解析预期验收。连续两次修改仅改善某一姿态时，按角度映射、根隔离、材料见证分别定位。双凹网格非零转动需另有转弧包围、三角特征和包含关系的多案例库。[Newton 1.7 碰撞接口](https://newton-physics.github.io/newton/1.7.0/concepts/collisions.html)

## C　TYX 世界内配对与多世界测试

- [ ] **索引与 API。** 作者负责 `src/phymeo/geometry/batched_collision.py`、`tests/scale/test_partitioned_collision.py` 和基准脚本的新布局。拟用 `WorldCollisionWorkspace([(world_id, model), ...], backend)`，以 `detect(motion_by_world, policy_by_world)` 查询，以 `last_result(world_id)` 获取该世界上一次成功结果。保留外部世界键、局部形状和材料 ID。重复世界、跨世界引用、遗漏 motion 在分配或发布前诊断。首批使用 all_pairs，沿用现有形状/顶点总上限。
- [ ] **结构与真实设备。** 直接按各世界构造 i<j 的同世界配对表和前缀和，允许空世界、单形状、不同形状数及掩码。W=64、每世界 4 球时，主机与设备各 384 配对槽、跨世界 0 槽。记录临时建表与设备存储，排除先建 32,640 槽再切片。旧 `detect` 保持完整诊断。父负责从 `collision_pipeline.py` 提取接受显式配对表的最小共用接口，作者复用现有 TYX bounds/分类。G1 每次非空合批在同一引擎完成归约和分类两次核调用，记录 launch、同步、实际传输、材料见证来源。[旧建表与发布](../../../src/phymeo/geometry/collision_pipeline.py) · [设备批处理](../../../src/phymeo/backends/tyx_collision.py)
- [ ] **隔离与故障。** 复用 G1 的 W=1、2、8、32、64，以逐世界独立查询为预期，按 ID 核对同世界完整结果、两侧点和间隙。重排输入，只移动一个世界，再恢复。G5 先给 A/B 各发布一次，随后 A 需要 1 个候选而容量为 0、B 输入非零位移。要求 A 报所需容量并保留旧结果，B 与单跑一致，增大 A 容量后可重试。在设备 launch/下载处注入故障，整个批在失败调用中均不发布新结果。另测空批、异构球数、掩码、容量边界及跨世界别名。[原 G1 案例与两侧见证](../../../tests/scale/cases.py) · [世界 ID 语义](https://newton-physics.github.io/newton/1.7.0/concepts/worlds.html)
- [ ] **单独验性能。** 用相同输入、每世界输出行、同步、读回与记录设置，对比 TYX 的 `serial` 和新增的 `partitioned`。按既定计划作三轮独立进程配对，交替运行顺序。每配置至少五个预热窗口，再测至少二十个窗口，每窗 32 次静态查询。W=32 吞吐比目标 ≥1.25，三轮均同向。W=1 延迟回退超过 10% 要在报告说明并保留原入口。上一批的 31.698/117.513 ms 来自两种不同发布合同，只用作定位开销。结构正确可先合入为可选入口。性能未达只针对实测耗时最大的阶段再试，连续两次端到端无改善便停止加核。真实动力学吞吐、设备状态驻留另进阶段 2/3。[原始样本与口径](../../benchmarks/p65-g1-world-isolation.md) · [完整规模计划](2026-11-03-tyx-gpu-multiworld.md)
