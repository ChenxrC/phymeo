# 受载接触模型与最近特征查询（2026-11-04）

基线 `638b37f`。沿用[首批结果](2026-11-04-contact-load-parallel.md)的两份夹持输入、材料参数和已保存的四组 CUDA 世界。以下三项可独立开发，只允许一组项目命令运行。

| 优先级与责任 | 本批要回答的问题 | 验收和停止条件 |
| --- | --- | --- |
| P0 机器人 | 在 Newton 保留原生惯量和积分、对齐接触载荷后，强夹和弱夹能否复现？ | 先用自由刚体核对力、作用点、力矩和功，再跑两份冻结输入。强夹检查离台、搬运、卸载和桌面承重，弱夹检查留台。若仍分歧，定位第一处足以区分两条轨迹的实测量。 |
| P0 柔性接触 | 有限材料面也能移动时，静持、转滑、再分离是否给双方正确反力？ | 验证两侧质量与重心权重、总动量、实际节点功及切向储能。带压越出有限面的行为单列，抬离后另一面重新接触须清空旧历史。 |
| P1 多世界性能 | 上一批耗时最多的单姿态胶囊–三角面查询能否加速？ | 距离、两侧材料特征、权重及并列解对照原路径。实际 CUDA W1/W4/W16/W32 交替对照同进程热运行，逐帧及设备计数相同才比较耗时。 |

父工作树负责同场 A/B 计时和集成。测试工具开源暂留后续。每项分别记录已执行的域和仍未通过的目标。
