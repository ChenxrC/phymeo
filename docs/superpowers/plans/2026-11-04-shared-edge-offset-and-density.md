基线 `b17d8a9`。复用[上批报告](2026-11-04-contact-model-and-geometry.md)中的已验控制。每项独立提交，执行使用同一串行槽。

## 已验证结果

- **Panda。** 四条独立轨迹各走满 3,600 步。正常摩擦时 Phymeo / Newton 各抬升 54.783 / 54.782 mm，放置误差 0.550 / 0.545 mm；零指面摩擦虽有约 6.50 N 双侧夹力，物体仍留台。两条 Newton 轨迹从稠密读回重建的累计逐步角冲量相对误差分别为 0.00855% 和 0.02132%。[实验与角动量核查](../../benchmarks/p65-panda-rotated-grasp.md) · [可切换的双轨迹 3D 回放](../../../artifacts/p65-crossing-rotated-density-20261104-01/panda-grasp-replay.html)


- **材料换面。** 2 N 载荷滑动时，同一物理步在 64/125 处分开为两段，两面的切向功分别为 −0.125 J、−0.119140625 J。反向运动的换面事件位于 61/128 处。静持时储能跨边延续，无永久滑移。此入口对应只有平移自由度的共面材料片。三角节点记录冲量的空间分布，片的转动约束角冲量单列；任意变形布的带压换面仍开放。[物理量、负控与后端分工](../../benchmarks/p65-material-seam-transfer.md)


- **每世界多个真实受载面。** 同一面积的布细分为 2 或 8 个相连三角面，连续四步均承载且各面实际法向变化。W1 两档的普通窗 p50 为 24.10 / 44.28 ms，W4 为 81.54 / 175.73 ms。W4×8 的插桩墙钟中，单姿态最近特征占 48.25%，D2H API 占 1.13%。TYX CUDA 计算每个世界内的法向层，HOST 依序调度多个世界。现有多世界批入口实际拒绝两种受载网格。与各世界独立构建的对照相比，状态、力和历史均相同；仅子步报告的墙钟字段另存。[四档对照与当前批处理边界](../../benchmarks/p65-multiface-loaded-worlds.md) · [W4×8 原始观测、逐面受力与设备计数](../../../artifacts/p65-multiface-world-profile-20261104-01/multiface-formal-w4-f8/measurements.json)

## 下批入口与判据

1. **可变形材料的共享边。** 按本批拓扑反例，先让有独立质量的共享节点发生可测的面内应变，再检验换面时双方的节点冲量、储能、不可逆滑移和约束力矩。随后增加非共面两面的小角度变化。保留未连接近邻的负控。
2. **多面、多世界 CUDA 合批。** 在独立逐世界结果前冻结一组面数不同且存在零接触的世界。用分段索引连接世界、面、材料站点和粒子，检查同号局部 ID 不串世界、共享节点聚合正确、单世界重置及容量不足时可重放。通过物理等价后再对照核启动、传输和吞吐，原 W4×8 的 48 次核启动可作为起点。
3. **机器人接触泛化。** 把已有偏航、偏心和材料控制留作回归，再用第二种载荷几何检验同一公共入口的抓持、滑落与释放。最终软布递交仍单独验收。
