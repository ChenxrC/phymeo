# 持载换面、偏心抓取与多面规模

基线 `b17d8a9`。复用[上批报告](2026-11-04-contact-model-and-geometry.md)中的已验控制。每项独立提交，执行使用同一串行槽。

| 优先级 | 新输入及判据 |
| --- | --- |
| P0 柔性 | 在共面、共享材料节点的三角片上，受压顶点跨边时按实际穿越时刻向两面分别累计节点冲量与功。推进已有弹性/塑性历史。断开的同形面拒绝接续历史，模糊转移须能回滚。 |
| P0 机器人 | 使用 120 g 均匀长方体、世界 Z 轴主动旋转 12°、质心相对夹取中心偏移 (+3,−1) mm。24 mm 闭合命令相同，指面摩擦分别为 0.65 和 0；以同一完整抓放窗口区分持载和留台。两引擎使用同一份输入。 |
| P1 规模 | 一个物理世界内改变实际受载面数，保持每步有真实接触和布姿态变化。分别测 W1 和 W4，公布面级载荷、设备传输、完整状态核对和当前真正支持的合批层级。 |
| 集成核查 | 从新 Newton 世界姿态、角速度和绕质心施加的力矩逐步重建角动量，比较每步角冲量；同一状态去掉力矩作反事实。预先规定累计逐步误差与累计施加角冲量之比 10% 为诊断门槛，同时报告峰值和有符号累计漂移。 |

强夹与零摩擦对照独立验收。角动量检查只使用质量、独立惯量、初态及保存的动力学读数，不改变控制或重新仿真。
