# 多世界变长接触、自由材料换面和第二种抓取载荷

基线 `6c3f377`。[上批的差异和判据](2026-11-04-shared-edge-offset-and-density.md)保持有效。三项可独立开发，TYX、Newton 和所有项目验证共用一个串行槽。

| 优先级 | 输入、比较与交付 |
| --- | --- |
| P0 多世界 | 同批包含布面数不同、局部材料编号重复和无接触的世界。使用单世界连续物理步作为对照，检查实际受力、历史、路径审计、选定世界复位和容量失败后的重放。设备提交按同一阶段合并。记录相同物理输出下的核数、传输和墙钟。 |
| P0 柔性 | 以独立正质量的自由顶点和共享节点组成两张面，真实步内产生面内应变并带压越边。核对何时换面、两侧节点收到的冲量和做功、切向历史及未连接近邻的回滚。将平面应变与改变二面角的情形分列。 |
| P1 机器人 | 在同一动作和控制器下添加非箱形载荷。几何、惯量、指面采样和桌面作用点须来自真实形状。固定摩擦与零摩擦两窗，分别读回运动、接触力、释放和终态；保留未达门槛的原始轨迹。 |
| 集成 | 在实际新载荷轨迹上独立核对绕质心的角动量，以既有 10% 累计逐步相对误差门槛作诊断。离线 3D 回放读取保存的形状和尺寸，旧箱形记录仍可打开。 |
