# 结构碰撞、折角换面与跨世界主机成本

基线 `0764463`。[原始窗口和开放项](2026-11-05-ragged-contact-and-payloads.md)是本批对照。原三个隔离工作树并行开发，项目执行串行。

| 责任 | 冻结的验证问题 |
| --- | --- |
| 机器人 | 用 50 mm 自由球的同一初态、URDF 和控制复现第一次非指垫接触，将通用球–连杆几何及接触律用于双方真实出步。先在独立形状上查轴部、端点、分离、反力矩和功，再检查原轨迹的首触时刻及后续。若后续存在未求解配对，记录首个时刻。 |
| 柔性 | 开始于小二面角的两面保持独立材料身份和节点惯量，步内包含真实的角度变化。分别核查材料切向运输、节点冲量与功、共同刚转和不连通反例。明确有限支持域。 |
| 规模 | 在同一 W4×8 输出上分解等待/恢复、几何、状态复制和设备接口成本，处理主线程及工作线程的重叠时间。若有充分依据再改实现，保留独立推进、上一版合批、故障回滚及真实 CUDA 对照。 |
| 父集成 | 用保存的入步质心、接触位置、各作用端力和出步动量独立核对结构载荷。回放能跳转到实际的结构接触样本，显示当时的物体和机械臂姿态以及施加在球上的世界力。 |
