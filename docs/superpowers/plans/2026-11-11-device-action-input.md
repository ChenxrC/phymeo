## Public contract

`runtime.set_controls_from_device(ctrl, *, qfrc_applied=None, xfrc_applied=None, expected_revision, producer_stream=None)` submits an entire ordered batch. CUDA accepts live contiguous same-device float32 TYX arrays; interpret accepts copied numpy arrays. Shapes derive only from the admitted runtime: [W,nu], [W,nv], [W,nbody,6]. For nu=0, ctrl is None and internal zero padding is generated. Omitted force channels mean fresh zeros, never carryover.

Arrays use runtime.world_keys order and native actuator/generalized/body coordinates. Raw arrays do not carry semantic world labels: the API cannot detect a user swapping two otherwise valid rows. Record the declared runtime order, test explicit permutation covariance, and do not claim automatic semantic-order detection. Internal owned packets do bind runtime/model/source/device/layout/order/epoch and reject forged or stale packet use.

The supplied producer stream is live and on the correct device. Synchronize it before borrowing arrays; define stream=None as an explicitly synchronous default-stream contract. Caller must not mutate/free during the call. Reject dtype, shape, device, liveness, supplied-channel overlap and physical/action-bank aliasing before writes. Runtime owns independent staged/accepted copies, so caller mutation or free after return cannot change held action.

Copy/pad/validate all three channels, retaining exact finite normal-or-zero FP32 values. Reject NaN, Inf and nonzero subnormal values; never clip, flush or normalize. Keep native actuator gain/bias/range handling in the existing physics kernels. Prepare complete immutable HOST audit mirrors and receipt before a single CAS commit; revision increments exactly once. No potentially failing allocation, copy, readback or receipt construction after commit. Retire previous packets without a post-commit exception; cleanup failures remain owned for retry and are reported separately. Pre-commit failure preserves prior held control, packet, revision, physical state and last physics receipt.

The existing public step(h) loads a trusted owned packet by D2D through the common TyxDevice._put seam. No second force law, integration or clipping. Committed held packets remain valid across accepted physical steps; only new submissions compare expected_revision. A submitted action followed by a failed physical step intentionally leaves the new held action and old physical state/clock/tick: it is a two-stage public API, not action+physics rollback.

HOST set_controls, partial reset, successful restore and close invalidate/retire the transport cache. Preserve untouched worlds' canonical controls on partial reset. A1 checkpoints serialize canonical control values, never pointers; restore can use the ordinary HOST load once or rebuild exact FP32 cached controls. Failed restore keeps old action usable. Close attempts every owner, retains failures, and supports retry. Controller memory remains caller-owned.
