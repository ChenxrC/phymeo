# Kamino 与 FFT：看得懂、可选择的两个参考实验

日期：2026-11-16。分支 codex/exp；稳定 dev 不变。本计划恢复原始研究问题：不同算法在什么问题上有价值，是否值得组合。先做外部参考实验，再决定集成；本批不继续扩展 I2，不重跑已验 Hydroelastic 几何。

## 1. 三层分工与选择

| 层 | 要解决的问题 | 当前候选 | 不能替代 |
| --- | --- | --- | --- |
| 整体动力学 | 机器人、关节、接触约束一起决定下一步运动 | Kamino 的 PADMM / DVI；现有 Phymeo MuJoCo-TYX | 不自动提供真实材料压力场 |
| 接触模型 | 压入多少产生多大力，摩擦、耗散如何随运动变化 | Hydroelastic / 柔顺层 / 硬接触 | 换检测算法不能自动改变材料模型 |
| 材料响应 | 一处受压如何影响周围变形、压力如何分布 | 非周期 FFT 弹性半空间 | 不独立完成一般机器人动力学或薄布折叠 |

可以按精度、速度、内存和适用范围做组合。例如 FFT 离线标定材料，再由动力学求解器运行；或在确有需要的接触区域调用非局部材料响应。选项必须保持同一物体对唯一接触载荷来源，双方反作用、力矩、摩擦承载及同一步状态一致。

Kamino 与 FFT 不排同一张“谁更快”榜。Kamino 内部比较同场景 PADMM/DVI 的整步时间；FFT 比较同一模型三档网格的误差与求解时间。跨引擎性能比较另需同模型、同输出及完整成本。

## 2. K：箱子站稳后被推下有限台面（中）

**画面问题**：箱子能站稳吗？施加真正的力后，它会滑动、翻转并失去支撑吗？选择不同求解方法，结果和时间如何变化？

使用现有 Newton 1.7.0 / Warp 1.17.0 外部参考。一个完整 6DOF、0.5 kg 的 40×40×20 mm 盒；80×80×10 mm 固定有限台面，顶面 z=0。盒初始中心 z=.011 m，即底面离台1 mm，姿态单位、速度零，重力 -9.81 m/s²；库仑摩擦系数 .5，无正恢复。两形状 margin=0、gap=0，不借 prescribed motion 支撑盒子。

窗口 .6 s，步长 1/.5 ms。盒局部点(0,0,.01) m施加 world +x 的4 N外力（每步由入步姿态计算r×F，初始偏心矩+.04 N·m），时间 [.2,.4) s；其余时刻零。是真实外力程序，不按位置修改状态。完整 3D 碰撞，不强制 xz 平面、不加固定姿态约束。这个体量/载荷沿用旧 V05，初始1 mm间隙与偏心施力是本批预先声明的差异。

固定四格：PADMM/DVI × 1/.5 ms，CUDA 单 world。内部primitive碰撞、Euler、容量32；PADMM三个残差阈值1e-6/最多200次/rho_0=.1/preconditioning开启；DVI保留1.7.0默认1e-5/24 outer×2 sweeps/preconditioning关闭。配置完整序列化，构造时选solver名。若实际安装不支持某格，记录 UNSUPPORTED，不更换接口或伪称 GPU。每格全程保存入步/出步位姿和速度、输入外力、实际接触位置与双方身份、公开接触 wrench、求解状态/迭代计数。接触量必须按本机 API 的入步/出步相位解释。

**功能判据**：完整有限状态；.15–.2 s 平均竖直支撑在 mg±10%，该段 COM z 范围 <.1 mm 且末竖直速度 <1 mm/s；窗口出现 |俯仰|>1度或明显三维倾覆、x位移>60 mm；最后 .05 s 无台面支撑，COM较初态降低>10 mm。接触丢失不能用无限地面补上。两 h 的累计竖直冲量差≤10%、最后接触时间差≤.01 s作为时间离散比较；失败照实保留，不改变载荷或摩擦追绿。

**成本**：首次编译/模型创建单列；每格首段保留编译时间，稳态 step 前后设备同步，计入该 solver 内部碰撞。观察/保存耗时另列，同时给出 step+必要读取整步成本。单 world 小案例不代表批量训练吞吐。仅相同模型物理判据均达标时比较 PADMM/DVI；不把各后端不同定义的原始残差直接排名。

双指夹持是下一扩展：两真实执行器夹持有限盒，测滑移和关节反力；本批不因它未做而阻塞首个可视实验。

## 3. F：刚性球压弹性半空间（中）

**画面问题**：相同压入量，接触盘有多大？中央压力多高？网格加密后误差下降多少、成本增加多少？

外部 ContactMechanics 1.8.3 的 FreeFFTElasticHalfSpace，位移控制、非粘附、线弹性半空间。保留原固定参数：球半径 R=.02 m，E*=1e6 Pa，压入 δ=.00005/.0001/.0002 m；非周期物理域 .16×.16 m；128²/256²/512²。使用 Hertz 小变形抛物面高度 h(x,y)=-(x²+y²)/(2R)，明确这是球的局部近似，不是有限球面或有限厚板。自由边界按库的非周期 padding/Green 函数处理，不把周期 DC 清零冒充自由半空间。

完整九格均输出，禁止根据结果再增加网格或调模量。独立解析参考：
a=sqrt(Rδ)，F=(4/3)E*sqrt(R)δ^(3/2)，p0=2E*a/(πR)。
保存原压力、位移、间隙、力、实际接触面积、物理网格和单位；明确库返回的是每点力还是压力，以 dA 转换。

**两类误差分开**：一是实际离散接触问题的约束/收敛（非负压力、非穿入、互补、优化器状态）；二是载荷、接触面积、中心压力与 Hertz 的离散/模型误差。细网格相对 Hertz 的载荷/面积/峰值 5%作为研究精度目标，三档全部报告；原固定格可能不满足，尤其最小接触盘仅数个网格宽，不据此放宽门或称算法错误。δ=.1 mm用于将来标定，.05/.2 mm保留验证；本轮只计算独立参考，不拟合 Hydroelastic。

创建/首次 FFT/求解时间、迭代数、内存与保存时间分列。仅 CPU 外部参考，不称 TYX/CUDA FFT，不与 Kamino 每步时间直接排名。有限厚层、粘附、大变形、薄布不在本模型范围。

## 4. 交付与执行顺序

1. 固定本计划与版本/接口；两位原作者隔离准备 Kamino、FFT 驱动，禁止项目执行。
2. 父唯一串行 owner：依赖预检 → 必要参考安装 → 新驱动静态/短检查 → 四个 Kamino 窗口与九个 FFT 格。每种执行前 fresh guard；保留首失败与一次有依据修复，不改物理输入。
3. 从同次保存数据生成离线 HTML：上方一句话问题、中央实际运动/压力图、下方误差/耗时、明确 PASS/FAIL/UNSUPPORTED。可选择方法/网格/步长，重放已存结果，不能伪装实时求解。短视频也只读这些数据。
4. 结果表给出“适合哪类任务、代价、证据不足处、是否值得下一集成”；能否混合由这两组证据决定，不预先宣称创新成功。

原 I0/I1、V05/V06 证据只复用，V03面积/收敛失败仍保留；dev及训练主线不改。独立研究不得变成新一轮无休止的精确接触证明。

## 6. 执行前数值配置补充

FFT 固定 pentol=1e-10 m、forcetol=1e-10 N（每像素力）、thermotol=1e-8（相邻迭代总力相对变化），maxiter=10000。首次调用前以实际安装 optimizer 源码确认单位。所有九格相同，不依据输出调整。
KKT门：优化器success、有限数/原shape/offset一致；min(gap)>=-pentol；min(p)>=-forcetol/dA；正力点max|gap|<=10*pentol；sum|f*gap|/(F_Hertz*δ)<=1e-5；独立恢复弹性力在物理域与f的差、padding恢复力均<=10*forcetol；库free边界检查通过。恢复力的负号、物理域切片和实际dA明确保存。接触面积严格使用f>0的像素面积，不按输出再改阈值。

Kamino四格报告实际constraint convergence与capacity overflow；有限但未收敛可继续保存观察，资格不能PASS。末端无新contact query时不把上一入步载荷绑成端点瞬时力。FFT热图放大中心±4mm并显示实际网格块，不用平滑图像冒精度；全160mm域数据仍保存。
