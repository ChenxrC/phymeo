# 双峰形貌数值参考与接触架构（2026-11-17）

状态：参数和停止规则在新数值结果产生前冻结。工作分支 codex/exp；stable dev 不变。父 sole execution owner，原两作者仅隔离树纯编码/源码审阅，所有项目执行严格串行。复用已通过的旧结果，不重跑旧 Hertz、Kamino 或静态面积压力套。

## 1. 问题与范围

采用光滑、非轴对称、高低不同的双峰刚性高度场，压入非周期线弹性半空间。一个峰受压会使另一个位置产生位移，因此不能把两个独立 Hertz 力简单相加作为准确答案。没有声明所有数学方法都无解析表达；本批确认现有单抛物面解析候选不适用。

这是静态无摩擦、非黏附、小变形的半空间模型，不是有限厚层、大变形、刚体时间积分或产品碰撞实现。24mm 是计算窗口，不是把半空间改成24mm宽有限实体。依据：[ContactMechanics 定义](https://contactengineering.github.io/ContactMechanics/usage.html)、[官方实现及假设](https://github.com/ContactEngineering/ContactMechanics)。

## 2. 冻结几何与输入（全部 SI）

E*=1e6 Pa，物理窗口 Lx=Ly=0.024 m；x_i=(i-n/2)L/n。令 s(r)=max(1-r²,0)^3：

- r1²=((x+0.003)/0.003)^2+((y+0.000375)/0.002)^2；
- r2²=((x-0.003)/0.0025)^2+((y-0.000375)/0.0035)^2；
- h(x,y)=0.0002*s(r1)+0.00016*s(r2)-0.0002 m。

两峰支撑在x方向不重叠；峰高相对初触平面分别0、-40μm。高度场C2，但不称全域凸形状。峰中心落在两网格的节点。最大初始坡度<0.18，压入/最小横向半轴<=0.05；这支持所选小变形预研范围，并非有限应变验证。

固定压入20/40/60/80/100μm，每个在n=256/512各求一次，共10次。再仅在n=512、100μm各独立保留一个峰，baseline仍-200μm，共2次，用于量化忽略远处弹性耦合的误差。总计最多12次新 solve，全部冷启动，不补点、不调参数。

使用已有 ContactMechanics 1.8.3 FreeFFTElasticHalfSpace CPU serial，padding2、check_boundaries=True、pentol=1e-10m、forcetol=1e-10N/pixel、thermotol=1e-8、maxiter=10000；external_force/hardness/initial_displacements/initial_forces均None。保存原始数组和优化器；失败也保留，不修数组。

## 3. 参考资格与停止门

每case：optimizer success；raw压力>=-forcetol/dA；gap>=-pentol；所有raw f>0点|gap|<=10pentol；Σ|f gap|/(F δ)<=1e-5且F>0；一次独立弹性恢复负evaluate_force(u)与raw f最大差<=10forcetol；padding<=10forcetol；物理外环f=0。

保存F、raw正像素面积、峰压、CoP(x,y)、+z力的Mx=Σyf/My=-Σxf、每峰载荷/面积、窗口外峰区域载荷，及solve/构造/检查/保存成本。零载荷峰合法，不人为要求任何给定压入下两个峰都激活。

以512为分母比较256→512：F相对差<=2%，面积<=8%，峰压<=5%，CoP绝对距离<=50μm。全部结果逐项报告；这是两档网格一致性，不是精确真值或严格误差界。某输出失败不抹去其他输出结果，但该输出不获资格。两isolated合成相对joint100的F/CoP/M另表，不设“必须显著”的结果要求。

任一数值目标失败，先保存并解释；只允许修明确实现/记录缺陷，不追加网格、改几何/门槛追绿。研究目标失败不能写成测试框架或程序崩溃。

## 4. 有界低成本候选（不作产品动力学）

固定 force-only PCHIP 插值候选：用δ=0解析无接触F=0，以及20/60/100μm的FFT512载荷标定；40/80μm只作前瞻资格验证。参数文件先写，再读取验证数据。无每点重新标定、无根据验证误差改变阶数/节点。Hertz候选明确不适用。

资格要求：所有五点force网格一致性通过、全部输入FFT KKT通过，两个未用于拟合点的相对载荷差均<=5%。这只在五个声明点形成有限证据，不把PCHIP在点间可计算误称连续域已验证。压力场、面积、力矩、切线及储能不由该力表冒充输出。即便公式可求导/积分，本批也没有这些物理量的验证。

一次离线资格生成与初始化决定后复用已选模型；按输出/物理域/几何与材料绑定拒绝不支持请求。未准入时保留需要数值参考的状态，不偷换硬接触/本地弹簧。记录公式评价与完整接口开销；离线12次FFT与数据处理成本单列，不把读取缓存当FFT在线速度。固定32warmup、7×1000次纯公式评价，报告median/range，仅作本机小型成本，不声称引擎加速。
