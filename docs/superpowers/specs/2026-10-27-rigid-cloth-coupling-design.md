# 可重复验证的刚柔双向交互场景

日期：2026-10-27。基线：`b4cbc6b`，分支：`codex/rigid-cloth-coupling`。

## 授权与目标

用户已选定“一个可重复验证的刚柔双向交互场景”，并授权开启长程任务。
沿用已批准的物理/计算边界、独立实现原则，以及专用分支提交和上传权限。
本轮没有指定截止时间；此前 08:00 的截止仅适用于上一轮已收口任务。
以下场景参数、算法和验收值为实施者的工程决策，不声称用户逐项指定。

目标场景是一块四角固定的布片与一个自由运动的球形刚体接触。
刚体推动布片，布片的反作用改变刚体轨迹。交付包括数学实现、反事实对照、
机器可检查的数值证据、离线回放和独立安装后的复现命令。
先有 NumPy FP64 参考，再交付同场景 tyx FP32 路径。不能用动画或测试数量代替验收。

## 范围与方案

考虑三条路线：

1. 把布料和刚体分别推进，再单次修正接触：改动小，但共享自由度的反馈滞后，
   无法用各自已收敛的报告证明联合约束收敛。
2. **本轮选用：统一预测、交替投影距离/接触约束、联合验收、原子提交。**
   复用独立数据和数学算子，保持可验证的小范围；首先串行参考，后端随后对照。
3. 一次实现通用摩擦接触、机器人关节和多物理调度：能力更广，但不是该场景的前置条件。

首版只处理零厚度布料顶点与质心球形边界的离散、无摩擦硬接触；
不声称三角面无穿透、连续碰撞、自碰撞、弯曲材料、任意刚体几何或机器人已完成。
球面法向通过质心，法向反作用没有接触力矩；刚体自由旋转仍被推进，不能伪造角响应。
已有任意作用点冲量端口保持可复用，不为证明旋转反馈而加入没有物理依据的力矩。
本目标不依赖训练模型；保留原有学习接口即可，真实 AI 加速单独立项。

## 固定场景与复现条件

初始候选参数（M4 冻结前允许依据收敛实验调整，必须留记录，不能静默放宽验收）：

- SI、Y 向上；布片 7×7 点，间距 0.1 m，原点 `(-0.3, 0.6, -0.3)`。
- 面密度 0.4 kg/m²，结构/剪切逐边柔度各 `1e-4 m/N`，四角索引 `0,6,42,48` 固定。
- 单球质量 0.05 kg，半径 0.18 m；均质球主惯量 `2*m*r*r/5`。
- 球心 `(0.02,0.30,0)`，初速度 `(0,2,0)` m/s；初始角速度零。
- 双方重力 `(0,-9.81,0)`；无其他外力或外力矩，无地面。
- 帧步长 1/120 s，每帧 4 个子步，持续 2 s（240 帧）。
- 每子步最多 200 次位置迭代，CPU 归一化容差 `1e-7`，参考长度 1 m。
- 不用随机性；扩展质量/步长测试使用固定参数表而非隐式随机种子。

四角固定会交换外部动量，因此不能对演示场景直接宣称总动量守恒。
守恒证明用无重力、无固定点的隔离测试；演示另外报告支撑影响与外部重力。
“关闭反作用”对照仅存在于实验脚本：球按无接触自由轨迹驱动，布仍响应球；
明确标为单向、非物理对照，不作为正式求解器的可接受物理配置。

## 数据与数学边界

### 几何

`particle_sphere_geometry(particle_position, rigid_position, spheres)` 计算所有点/球对，
按粒子索引优先、刚体索引次序返回稳定行序。小规模参考为 O(Np*Nb)，没有宽相声明。
`ParticleSphereGeometry` 拥有只读 int64 索引，以及 FP64 法向和有符号间隙。
输入位置与半径必须同为 FP32 或 FP64；输出几何显式提升 FP64，不修改输入。

对每对：`d=x-c`，`n=d/||d||`，`g=||d||-r`，负间隙表示穿透。
中心重合的法向固定为 +X，标记 `degenerate`，不把任意方向声称为唯一物理解。
合法空集合返回零行；类型/形状/有限性错误在入口抛出；无法表示的中间结果是 SolverFailure。

### 联合位置求解

独立预测两组自由运动，每子步距离乘子及接触乘子清零；在同一迭代里先距离、后接触。
接触硬约束 `g>=0`，乘子 `lambda>=0`，互补条件 `lambda*g=0`。
法向有效逆质量 `w=wp+wb`，因为球的法向旋转雅可比为零。
投影采用 `lambda_new=max(0,lambda-g/w)`，`delta=lambda_new-lambda`，
`x+=wp*delta*n`，`c-=wb*delta*n`。共享刚体必须顺序更新或正确归约，不能并发丢写。
固定-固定对不除零；穿透不能移动时返回未收敛，不能假装接受。

所有对保留稳定乘子槽并每轮重新计算几何；接触不能只在子步开始检测一次。
检测新接触和释放旧乘子都要覆盖。残差含距离本构误差以及接触投影互补残差，
接触不能只检查“负间隙为零”而漏掉分离后的正乘子。
有效 w>0 时用 `abs(max(0,lambda-g/w)-lambda)*w/reference_length`；
固定-固定用穿透/reference_length。数值不可表示时拒绝，不能通过除法下溢假报零。

### 速度、接触与记账

位置收敛后用校正位置相对本子步初态重建线速度；刚体姿态/角速度保留自由旋转预测。
未发生位置修正的自由度保留预测速度，避免大坐标舍入吞掉位移后把自由速度清零；
这个数值选择由无接触解析轨迹及大坐标回归检验。
活动接触再进行无摩擦、零恢复的法向速度投影，按相反线冲量更新双方，保留切向和球旋转。
多个接触共享刚体时也必须迭代并检查法向速度残差，不能只作一次裁剪。
接触位置乘子带来的有效冲量与速度修正冲量分别记录，避免重复施加。
正式基准初态无穿透；一般初始深穿透可能因位置稳定化增加能量，必须报告边界，
不得借此声称该路径对任意输入保持能量或符合精确碰撞时刻。

### 联合事务

新增 `CoupledState(particles, rigid)`、`CoupledInputs(particles, rigid)` 和联合结果，
规范化复制内置状态字段；不信任子类虚方法 copy。模型和状态双方精度一致。
`CoupledXPBDSolver` 绑定模型、距离约束、球形状与设置，
`step(state, inputs, dt) -> CoupledStepResult`。
每个外层 step 含子步；任何子步非有限、资源失败或未收敛，恢复外层最初的双方状态。
合法无接触场景仍推进双方自由运动；空粒子/空刚体兼容。
结果报告包含接受与否、完成的子步/迭代、距离/接触/速度残差和失败原因。
每子步保留独立报告、位置修正有效冲量和额外速度冲量；两者不能重复作用。
`record_substeps=True` 时返回各成功子步的独立状态副本，供外部重算几何与轨迹；
整帧失败时这些部分状态不作为结果返回。`completed_substeps` 记录失败前完成的计算数，
不表示它们已提交。速度残差另用 `reference_speed`（默认 1 m/s）归一化；
活动速度接触带为 `tolerance*reference_length`，在同一速度求解内保持几何不变。
此切片新增显式混合状态求解边界，不凭字段相似把它伪装成现有单状态族 Stepper。

## 验收门槛

| 证据 | 门槛 |
| --- | --- |
| 单对质量加权解析响应 | FP64 绝对误差 <=1e-12；双方位置/速度改变量满足质量比 |
| 孤立接触动量 | 无重力/固定点，线动量误差 <=1e-10 kg·m/s；接触法向旋转增量为零 |
| 纯法向碰撞耗散 | 无初始穿透的单对碰撞动能不增加（容差 1e-10 J） |
| 所有权和原子性 | 输入逐元素不变；失败后两组全字段与外层初态相同、无别名 |
| CPU 场景 | 240 帧全部接受；所有值有限；固定点不漂移；四元数保持单位长度 |
| 接触与约束 | 每子步报告残差 <=请求容差；独立重算顶点穿透 <=2e-6 m；不能把柔顺伸长当不收敛 |
| 双向性 | 接触步数>0；与单向对照的球轨迹最大差 >=1e-3 m；布片也有非零接触响应 |
| 确定性 | 同后端/精度/环境独立运行两次，轨迹数组逐元素一致；不要求跨硬件 bitwise |
| 步长检查 | h 与 h/2 全程通过，报告末态/最大轨迹差；独立简单算例须呈预期收敛趋势 |
| tyx FP32 | 真实 CUDA 必须执行；同一着色顺序的 NumPy FP32 对照，位置最大差 <=2e-3 m；另报 FP64 差异 |
| 失败注入 | 后续子步预算耗尽及后端异常恢复外层两组状态，报告可观察 |
| 分发 | uv/pip、多 Python 核心测试、当前源码 wheel 隔离安装通过 |
| 可查看结果 | 离线 HTML 回放同一份数值轨迹，暂停/拖动时间，双向/单向并排；不可手写动画代替数据 |

tyx 路径必须实际执行布料约束、球接触与自由运动计算。允许初版主机调度/残差同步，
但需明确传输；不得把“只导入 tyx”或“只用 GPU 积分、所有接触留 CPU”称作完成后端。
已有 `codex/tyx-rigid-wip` 只能作待修复原型，数值边界、资源故障和完整回归通过后才能选入。
验收失败时记录原因、缩小到解析问题定位；变更场景/阈值必须有新的物理理由和显式记录。
