# P6.5 H1b：静态表面特征最近点

本设计接续已冻结的[H1a表面端口](2026-10-28-p65-surface-ports-design.md)。用户已授权按大纲持续实施；这里只冻结独立几何数学，不把完整抓取候选参数变为执行规格。仍截至2026-10-28 08:00北京时间。

## 选择与边界

选择自行推导的约束二次距离最小值：点/三角形枚举面内部投影及三条边；边/边枚举两条无限直线的内点解及四条边界。每个候选满足重心权重域，选最小距离，固定枚举顺序保证同输入确定性。有限候选覆盖凸域内部及全部边界，因此没有采样漏检。不开新碰撞库依赖，不复制其他引擎代码。

它是静态最近点基础，输出可直接构造H1a重心权重；不生成接触法线，不判断闭合体内外，不认证连续路径，不求接触力。两特征相交时距离为零，不能据此随意选择法线。宽相、网格所有权/邻接、自碰撞、CCD与联合求解仍未实现，不能以此勾选完整H1。

## 合同

新增`geometry/surface_features.py`：

- `closest_point_triangle(point, triangle)`，输入FP64有限数组形状(3,)、(3,3)。
- `closest_segment_segment(first, second)`，输入FP64有限数组各(2,3)。
- 均返回`ClosestFeaturePair`：`first`/`second`世界最近点各(3,)，`first_weights`/`second_weights`对应输入顶点的凸权重，`distance`单位m。数组自有、只读；调用输入或其他返回值不能影响结果。没有归一化调用者输入或状态写入。
- 点/三角权重长度1/3；边/边长度2/2。权重非负、和1；同分候选按固定枚举顺序选择，不承诺换顶点顺序后选择相同的非唯一最近点，但最小距离不变。
- 所有点先相对第一几何顶点平移，再按最大绝对坐标差缩放计算，最后恢复世界点。平移/乘法/距离不可表示时抛`SolverFailure`，不输出NaN/inf。
- 形状/dtype/非有限输入为配置错误；零长度线段、三角形归一化二倍面积小于等于最长边平方的`1e-12`为明确不支持的退化几何，抛`ValueError`。
- 边方向叉积恰为零时采用边界解，覆盖平行/共线/重叠。非零但夹角正弦小于等于`1e-12`时抛`SolverFailure`，避免把条件数不可靠的内点当精确解；该限制必须在后续网格检测器接入前处理或显式拒绝全步，不能忽略该对。当前切片不宣称通用碰撞器已可用。
- 面内投影用正交平面基计算重心坐标，避免直接求病态Gram行列式。边/边内点使用叉积恒等式计算参数；其余候选是有限段投影并夹到[0,1]。

## 独立验收

1. 面内部、每条边/顶点、三角相交距离零；平行分离/共线重叠、交叉边、偏斜边和端点钳制，检查已知精确答案。
2. 凸权重重建世界点；对任一输入顶点方向检查最近点KKT不等式；不能只与另一份相同代码比对。
3. 刚体旋转/平移、几何统一缩放和两段交换；距离对称、结果自有、输入不变、确定性重复。
4. 错误shape/dtype、NaN/inf、退化与近平行不可靠输入、极端尺度数值不可表示，均明确拒绝。
5. 三角重心点接H1a端口，手工逐节点冲量/反作用与功率对偶验证，不把几何坐标正确当物理响应正确。
6. 只执行主机FP64，报告小负载观测与限制；tyx底层响应已有H1a实际三模式验证，不声称几何运行在GPU。

完整接触程序的五项设计未决保持[原裁定](2026-10-28-p65-design-review.md)。H1b可独立实施；后续必须解决接触侧、弧路径与非线性增量账本，才能称综合碰撞/夹持完成。
