# P6.5 面材料点法向偏置端口合同

日期2026-10-28；承接73bcda6及用户恢复指令。[总里程碑](../plans/2026-10-27-dual-arm-cloth-handoff-milestone.md)保持不变。此切片只完成固定构型面偏置运动学和冲量映射，不代表动态接触/CCD/双臂递布完成。

## 接口和所有权

`TriangleOffsetPointPort(base, triangles, weights, offsets)`实现PointPort。base为可信不可变FP64状态存储端口，执行后端不改变。triangles为(k,3)整数局部点索引；weights为(k,3)非负FP64；offsets为(k,)有限FP64有符号米。权重行和偏离1不超过1e-12，除以fsum归一化后以B0=1-B1-B2保持仿射重建；若归一化产生负系数则拒绝。输入和查询均复制，k=0可用。

作用点固定在给定面的材料重心坐标；面有向法向由顶点顺序定义，正负偏置明确。不含最近点滑移、侧选择、接触身份或边/顶点圆壳；即使某个权重为零也仍是该面法向的材料点。

每次构造绑定完整固定构型。positions返回构造时的p；velocities、response、candidate_audit均使用同一J。apply_impulses先合并所有映射载荷，再调用base一次，配置不可改变。整域候选动能来自base一次审计，不能按表面点重复计算。配置变化后调用者必须创建新端口。

## 数学与数值拒绝

p=x0+B1*(x1-x0)+B2*(x2-x0)+s*n，n=(e1×e2)/||e1×e2||。

C0=[e2-e1]x，C1=-[e2]x，C2=[e1]x；Ji=Bi*I+s*(I-n*n.T)*Ci/||e1×e2||。u=Jv，f=J.T*impulse，R_surface=J*R_base*J.T。必须保留共享节点/关节的所有交叉项。

计算时用最大边分量缩放e1/e2，避免不必要的平方溢出。缩放后交叉积长度<=1e-10时明确SolverFailure；不自动正则化。有限输入算术溢出/下溢、非有限输出、不可表示的偏置或未通过下面的运动学一致性门禁均SolverFailure。

门禁：sum(Ji)=I（最大分量误差<=1e-10），sum([xi-x0]x*Ji.T)=[p-x0]x（最大分量误差<=1e-10*max(edge_scale,abs(s))）。第二项使用实际存储p而非理想偏置，避免大世界坐标把小偏置舍入丢失后仍宣布力矩正确。不根据测试失败改变容差；极端尺度可明确拒绝，不承诺完整数值域。

## 独立验收

单位三角形、B=(.2,.3,.5)、s=.2、inverse_mass=(1,2,3)、F=(1,0,0)：节点冲量(.2,0,.2)、(.3,0,-.2)、(.5,0,0)；点速度响应(1.09,.04,-.08)；静止动能增加.545；总力矩(0,.2,-.5)。这些固定数字独立于实现公式。

还要覆盖：刚体平移和旋转速度，中心差分材料点导数，虚功/净力/关于真实作用点的力矩，共享节点多作用点、一次候选、SPD与交叉响应，零偏置与WeightedPointPort相同，变换协变、负偏置、所有权、退化与精度损失拒绝，空端口，实际tyx interpret/C++/CUDA执行计数与实际候选能量。

映射与验算为host FP64，底层实际响应仍走base设备；不称此新端口整体GPU原生。性能只记录端口构造/响应/候选串行测量，不优化。未发现依赖实现证据不新增tyx_flaw结论；不得推测Warp差距。
