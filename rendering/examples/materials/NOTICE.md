# Workbench color texture

The optional surface finish uses the registered CC0 Wood Table 001 roughness JPEG, 237,261 bytes. SHA256 `a2ca9ae89dfe7b8e2e5e92f0aa43467845417de8a50205b5852ef0d57c7624f9`, publisher MD5 `05b60bd20a1cc4355c5d73a99b245d44`. Its red channel encodes linear perceptual roughness. Both maps use the same physical UV scale. [Original roughness scan](https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/wood_table_001/wood_table_001_rough_1k.jpg)

“Wood Table 001” is a Poly Haven CC0 asset. Photography by Dimitrios Savva and processing by Rico Cilliers. The included file is the original 1K diffuse JPEG, 215,573 bytes. Its SHA256 is `460dd08d240f4a1f02982415048c3c5c200f385db212da18dc7e2df68bf4d0be`. Poly Haven lists a 1,500 mm square scan and publishes the MD5 `56652a7339b16a76afad20d3585f66ea`. The example uses the color scan at that physical scale. Its roughness is an authored rendering parameter.
