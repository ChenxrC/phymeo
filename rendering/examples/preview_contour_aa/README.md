# 运动预览的轮廓覆盖采样

此生成步骤作用于完整距离八路、低分辨率滤波和刚体历史组合后的源码。选用该构建后，普通 RGB 拍摄会执行轮廓合成，单独读取传感通道仍走原中心光栅路径。

每个输出像素先保留原本的完整着色、短历史与中心几何。若其屏幕内 3×3 邻域包含不同实例 ID（包括背景 0），计算着色器就在该像素内的四个固定位置查询当前场景 TLAS 的最近不透明表面。所有射线使用实际相机与近远裁剪面。子位置命中中心实例时采用中心颜色，命中另一实例时取 3×3 中距子位置最近、同 ID 且前向深度相差不超过 3% 的着色位置。背景样本取最近的背景中心。任一子位置缺少可用颜色，整个像素沿用已有结果。有效混合使用等权场景线性辐亮度，随后执行曝光、显示变换和 sRGB 编码。

这项方法针对中心采样已经显露的不同实例边界。同一实例内部的自遮挡边、整个邻域中心都未命中的亚像素细杆，以及只由纹理、阴影或高光产生的边缘，沿用原像素着色。回退数与实际射线数可随每帧一起记录。历史保留各表面的中心着色，最终 RGB 和重建线性图包含轮廓合成的结果。

串行设备验证可从设置了 `PYTHONPATH=rendering/examples` 的检出运行。用已经集成该步骤的新构建作为输入，输出目录应为新目录。

```powershell
& $python -B -m preview_contour_aa.calibrate --prepared $prepared --device-index 1 --output $newOutput
```

标定使用 128×96 的实拍亮面和斜边，用原始网格投影与单位像素方格相交得到解析覆盖面积。报告列出中心采样和新管线的边界 MAE、相同相机下深度/ID/有效性的解析校验、可见性射线数及资源关闭状态。运动预览耗时需在真实姿态和目标分辨率下另行测量。
