# 一次漫反射间接光

一块受光的红板能不能把原本背光的白色夹爪照红？用同亮度的灰板排除亮度差，再加入黑色遮光板，检查传光路径被挡住后颜色是否减弱。原生模式、高采样参考和实物资产摆台分别解决实现、计量和外观三个问题。[画质总路线](2026-11-23-native-vulkan-quality.md)

## 渲染合同

公开入口为 `NativeBackend(resident=True, shadow_mode="ray_query", indirect_mode="diffuse_bounce", indirect_seed=0)`。默认 `indirect_mode="none"`。种子取无符号 32 位整数。固定种子和输入的曝光可重放，无跨帧辐亮度累积。一次镜面反射由已有的 `reflection_mode` 控制。

主表面的漫反射系数沿用已有材质约定 `rho_d = (1 - metallic) * albedo * (1 - F0)`。每个有效着色点发出 16 条按余弦密度分层取样的射线。结果取 `rho_d * sum(Li) / 16`。命中最近的不透明几何时，从该点材质及既有直接光、终端环境光计算 `Li`。未命中时读取远场入射辐亮度，无环境时为零。朝向真实三角面内部的方向贡献为零，仍在 16 个样本的分母中。此估计替代旧的主表面漫反射环境项；镜面项、直接光和显示变换分开计算。

两种一次反弹同时开启时，镜面与漫反射分别从主表面对同一当前场景查询，终端着色不再递归。通过精确输入配对核对几何传感、相同种子的重放、种子变化、场景移位或 reset、遮挡、零能量与资源回收。

## 三路任务与验收

| 环节 | 固定输入与可否证的检查 |
| --- | --- |
| 原生实现 | 独立着色器变体保留默认路径。有效漫反射接收的线性贡献随照明和反射率变化，零光源与零环境得到零光能。均匀环境中的无遮挡面不会因为开启新模式多算一次远场光。显式配置须经过硬件与 ABI 检查。 |
| 有限面积标定 | 水平白面与有限色板由固定方向光照明。计算色板对预定中心区域的投影视角与材质响应，独立面积积分包含两个余弦和距离平方。相同板几何切换红色与等线性亮度灰色，成对加入黑色遮光板。原生用四个独立随机化种子，SAPIEN 路径追踪同场高采样记录种子间离散度。报告线性量、量化范围和两个材质模型间的差异。 |
| Panda 手与两指 | 使用真实手爪网格与固定开度、位姿和机位。保留红、灰、遮红、遮灰四态以及各态的关闭、开启曝光。以实际手指的局部坐标、朝向、最近三角形及内部重心坐标预注册两指像素。对各自同一组像素比较红度变化与挡板抑制效果，同时对比全幅几何通道。 |
| 集成交付 | 构建、独立标定、摆台按一个执行槽串行。核对各路使用的 DLL、着色器、读回与证据。提供可切换不同板、遮挡及同帧局部的查看器，并写明直接光、噪声、成本和支持边界。 |

固定种子重复采一幅静物只用于验证可重放及测量成本。精度比较另用独立种子，区分像素噪声与多个种子估计均值的不确定度。现场夹爪摆台展示有限反弹；完整封闭室多次反弹、降噪和离线路径追踪仍有单独的后续关口。
