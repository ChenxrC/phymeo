# 运动后的第一帧如何降噪

上一批已经在静止视图上验证线性累积。相机或物体每动一次，首批又回到每像素 16 条路径。这一批把已测的 5 × 5 空间滤波移到 Vulkan，并检查黑色遮挡板扫过红色夹指后，刚露出的细节和轮廓是否保真。[上一批原图及 CPU 原型](../results/progressive-room/README.md)

## 对照设置

复用 Panda 夹爪、红板、灯位、材质和原 1280 × 960 机位。两秒光学回放共 25 个不同姿态。相机横移 24 mm，黑板从一侧进入画面再从另一侧离开。分别使用关闭和开启空间滤波的原生会话，以相同的种子和场景逐帧采集。每个姿态保存首批，并固定姿态继续到第二和第四批。后两者用来检查停稳时从滤波显示切回原始累积显示的行为。

三个参考姿态预先固定为 0、15、24。三者各用独立种子、不加滤波累积至每像素 256 个样本。三张有限采样参考只用于上述姿态。姿态 15 检查上一帧被黑板盖住、当前显露的有效前景，另列其中属于夹指的像素数。相机同时移动，因此这是同一屏幕位置的可见性变化。对每个参考姿态另开新会话检查同样的新状态。固定回放不推进关节动力学。

## 产品接口与范围

`spatial_filter="guided"` 显式启用在 GPU 上的首批显示滤波，默认 `"none"`。沿用已验证的 progressive、硬件射线查询和 1× MSAA 范围。滤波读取当前帧的 ID／有效性、正向深度和直接光指引。仅接纳同一可见对象、深度相对差至多 0.003、各指引通道差至多 2 个 RGB8 色阶的邻点，使用横纵 `[1,4,6,4,1]` 相乘的权重。浮点原始累积和几何传感继续独立发布。直接光指引由设备产生，其生成、附件开销与滤波均计入公开采集时间。

## 事前验收条件

| 问题 | 冻结比较 |
| --- | --- |
| 夹指表面趋近参考吗？ | 反解 sRGB 后在显示线性空间计算对独立参考的 RGB RMS。实例 156、158 各自腐蚀一像素以隔离内部，记录样本数与平均色偏。两指按像素汇总的误差比至多为关闭时的 0.80，逐指及逐姿态同时报告。 |
| 轮廓或显露区是否变糊？ | 真实有效几何边界与前一姿态黑板退出后显露的前景分别评估。各自误差比至多为关闭时的 1.05。注册选区至少 16 个像素，空区、零误差分母或未提供的参考单独说明。保留有利和不利的姿态。 |
| 混入了旧信息吗？ | 在注册姿态比较“运动后”与“新会话”的同姿态同种子输出；滤波开关的原始浮点均值、深度、ID、掩码逐字节核对。第一批允许显示图不同，第二、第四批应恢复相同显示。另报停稳后质量跳变。 |
| 实际代价多少？ | 报告首批开／关的公开采集 p50、p95，保留逐姿态数据及会话显式分配峰值。原始线性及指引的诊断读回单列。在固定参考机位对照 CPU 规则与 GPU 输出。只有端到端 p95 达到 33.3 ms 才能标注 30 fps。 |

按同一姿态、采样量和曝光发布原图，运动对照可暂停逐帧查看。若指标未过，先根据误差落在夹指内部、显露区或光照边界诊断原因，保留失败的原始数据与验收线。运动重投影留给独立实验。
