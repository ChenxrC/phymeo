# 自研 Vulkan · 附近物体的一次镜面反射

钢球旁的红块先出现在相机里，再移到画外。如果观察方向仍允许钢球把红块反射给相机，球上的倒影应继续移动。用这个动作检验近场光路，用平面镜和已知色块单独测量位置误差。两档的几何、材质、帧、机位和光源使用相同输入。[四步画质路线](2026-11-23-native-vulkan-quality.md)

## 运行合同

- `NativeBackend` 增加 `reflection_mode`。默认 `environment` 仍可使用原来的驱动接口与着色器。`single_bounce` 显式要求 `resident=True`、`shadow_mode="ray_query"` 和配套的 Vulkan 构建。
- 首期接收倒影的是不透明光滑金属。按上传的 FP32 材质系数筛选，金属度至少 0.99，粗糙度至多 0.10。局部粗糙度图仍参与材质着色。其他不透明物体可以出现在倒影中。
- 从可见表面沿理想镜向查询当前帧的场景加速结构。最近命中给出实例、三角形与重心坐标，再取当前变换和材质进行终端着色。将所得线性辐亮度作为该表面的镜面入射光；未命中沿用环境光。直接光高光、曝光和显示变换各保留一次。反射只改变 RGB。漫反射间接光、多次反弹和粗糙反射有各自的后续验收。

## 开发与固定验收

| 负责部分 | 工作与判据 |
| --- | --- |
| A · 原生路径 | 公开入口检查配置和设备能力，默认路径继续使用原 shader。着色器访问最近命中，区分栅格可见物体 ID 与反射命中实例，使用正确的偏移、正反面和材质。用真正的设备调用检查结果、资源关闭和验证层。 |
| B · 独立计量 | 按虚像投影预计平面镜上的色块边界。分别检查位置、移动、画外物体、前物遮挡后物、未命中环境和单世界 reset。可比边界最大偏差 ≤1 个像素，单列两侧的离散化约定。记录原始 RGB、几何传感、预定区域、设备和构建。 |
| C · 运动样片 | 1280×720、30 Hz、90 对同帧画面。镜球半径 0.30 m，0.28 m 红块沿同一条横移路径运动；第 15 帧观察画内，第 75 帧观察画外。先按解析球面反射线与方块相交选定测量区域。画外帧红块的直接实例 ID 像素必须为零，同时球上出现可量测的红色倒影。两模式几何通道一致。保留两个时刻的无损局部。 |
| 集成与交付 | 原生实现、标定、样片共用同一构建；项目运行串行。比较开关档在同一硬件上的同步采集耗时、设备内存和完整视频解码。提供可直接打开的同帧观察入口、设备条件及公开 API 用法。 |

若有红色变化而投影或最近遮挡关系不符，保留源帧，检查射线、实例和三角形映射。若几何正确但红块太暗，先核实颜色、光照和测量定义。固定的阈值与几何作为判据保留；修复后只重验受影响的路径。

## 已验结果

RTX 4060 Laptop 上的平面镜标定完成 19 次真实采集，最近遮挡、独立虚像边界和世界回放检查通过。运动样片在画外时刻记录到红块直接 ID 像素数为 0，镜内预定 198 个像素的平均红度增加 186 个 RGB8 码值。90 对曝光的几何通道全部一致。下一阶段以单次漫反射间接光为目标，用红板、灰板和遮光板对照夹爪暗面的颜色变化。[同帧观看](../results/near-reflections/index.html) · [测量与实现边界](../results/near-reflections/README.md)
