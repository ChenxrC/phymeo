# 切线空间法线贴图与材质回放

## 目标与范围

用同一网格表现钢面细划纹和橡胶颗粒。比较中保持几何、金属度、粗糙度、照明、曝光和相机运动一致。输入为带 SHA256 的线性 RGB 法线图，绑定到 `TexturedMaterial.normal_map`。允许只提供法线图。本批采用 glTF 的 +Y 约定，强度为 1。纹理方向只改变着色，轮廓、阴影射线起点及几何传感仍取原表面。

原生实现按每个三角形的位置与第一套 UV 重建切线基，并保留镜像 UV 的手性。现有网格读取器只接受其声明支持的属性。带预烘焙顶点切线的资产与 MikkTSpace 的一致性留待单独验证。SAPIEN 参考后端遇到实际绑定的法线图必须明确报告能力范围。[glTF 网格与切线约定](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#meshes) · [画质总路线](2026-11-23-native-vulkan-quality.md)

## 交付与验收

| 任务 | 负责人 | 冻结条件 |
| --- | --- | --- |
| 材质声明、线性纹理上传、切线基与着色 | A | 使用公共驻留式 Vulkan 接口。覆盖仅法线图以及多贴图材料，检查镜像手性、缺失及退化 UV、资源回收与旧构建兼容范围。软件与硬件阴影分别验证，涵盖 1× 与 4×。 |
| 独立定量标定 | B | 平面、几何倾斜 25° 及镜像 U 三板，左右两盏方向光分别拍摄。24×24 的预定内部区域比较关闭、平图、倾斜 XY 与 +Y 图。平图与关闭差 ≤1 RGB8，解析光照误差 ≤2 RGB8；有方向的探针须越过预设亮暗裕量，深度、实例 ID、掩码逐字节相同。 |
| 钢与橡胶的动态样片 | C | 从既有材质绕拍的 240 个机位中固定第 60–179 帧，30 Hz，成对采集 4 秒。使用来自已知高度函数的程序纹理，保存材料参数、纹理来源与哈希。在同一时刻对照原尺寸局部，报告两档公开采集耗时、显存、关闭后的计数和 MP4 解码结果。 |
| 集成与观看入口 | 父 | 三路使用同一份原生构建。核对公开 API、实测收据与发布媒体，分别记录渲染正确性、传感、成本和支持边界。在能力表与影片页提供入口。 |

项目执行按原生构建、独立标定、材质回放顺序占用同一个执行槽。作者可并行编写代码。若镜像方向、传感或平图误差超限，保留首次结果，定位到贴图解码、切线方向或着色阶段后修正。发布前分别核对源帧、视频编码和档位成本。纹理外观改善的判断以影片和无损局部为依据。
