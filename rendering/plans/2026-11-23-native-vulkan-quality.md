# 自研 Vulkan 的四步画质路线

目标是在机器人操作中看清细夹指、表面纹理、附近物体的倒影和遮挡处的间接光。起点是已通过独立安装的版本 `49e529ba`。现有实时路径具有单采样光栅、直接 PBR、可选硬件阴影查询、HDR 环境及粗糙度贴图。SAPIEN 路径追踪继续作为同场景参考。[首版签收](09-acceptance.md) · [具名设备的能力与样片](../results/engine-capabilities.md)

| 顺序与难度 | 开发接口与依赖 | 固定对照与进入下一阶段的条件 |
| --- | --- | --- |
| 1. 轮廓抗锯齿与运动稳定性，高，已实现 4× 并实测 | 自研 resident 后端显式提供 1×、4× MSAA；材质、灯面采样与相机轨迹固定。 | 斜边和细杆对独立面积参考的误差下降，移动细杆的时间误差下降；深度、整数 ID、掩码与原路径逐字相同。交付同帧 Panda 开关对照视频。720p 快速档单独报告 p95，目标 33.3 ms。[实测与未达标项](../results/msaa/README.md) · [开发与验收任务单](2026-11-23-native-msaa.md) |
| 2. 材质微表面细节，中高，已完成标定与动态对照 | 自研 resident 后端支持带来源的线性切线空间法线图、第一套 UV 与镜像手性。 | 平直、倾斜、镜像三块标定板的 24 个固定区域与解析 RGB8 逐字节一致，平图对关闭的最大差为 1。钢与橡胶同轨迹 120 对画面，三帧全幅几何通道一致。[样片与实测成本](../results/normal-maps/README.md) · [开发与验收任务单](2026-11-23-native-normal-maps.md) |
| 3. 附近物体的一次镜面反射，高，已完成标定与运动样片 | 自研驻留式硬件路径读取真实最近实例、三角形、重心及材质。光滑金属产生一次镜向反射，未命中读取原有环境。 | 平面镜通过独立虚像 1 px 边界门、前后遮挡与双世界回放检查。移动红块在直接 ID 为 0 的画外时刻仍映入钢球；90 对画面的几何传感一致。粗糙反射与降噪仍待开发。[样片与测量](../results/near-reflections/README.md) · [开发与验收任务单](2026-11-23-native-near-reflections.md) |
| 4a. 一次漫反射间接光，高，已在两套场景实测 | 硬件最近三角形查询、16 个分层余弦方向、当前材质与终端光照。可与一次镜面反射同时开启。 | 有限色板通过独立面积积分和同场 SAPIEN 512 样本参考的各自模型检查。真实 Panda 背光两指可见染色，遮挡后净红度下降 85.5%–86.3%。[查看器与测量](../results/diffuse-bounce/README.md) · [任务单](2026-11-23-native-diffuse-bounce.md) |
| 4b. 封闭室二次反弹、静止累积与历史失效，高，已在真实设备实测 | 原生硬件查询支持一至两次漫反射和每批 16 样本的 GPU 线性累积。封闭室在原生与独立参考之间逐阶对照。 | Panda 两指在 1024 样本时剩首批噪声的 12.67%。移动相机、方向灯、色板或遮板后的第一和第四批均与同状态独立重开逐字一致。两次反弹的 SAPIEN 白墙亮度仍比六次低 12.82%。[查看器和实测成本](../results/progressive-room/README.md) |
| 4c. 运动首帧质量与成本，高，已完成 CPU 原型，待设备化 | 先在 GPU 用当前帧的几何与光照保护边界，覆盖运动中的遮挡、显露和材质交界。再评估带表面对应与光照失效的时域重投影。 | 使用独立高采样运动序列做参考，报告移动边界误差、滞后帧数及包括指引生成在内的端到端 p95。空间滤波开关保留原始传感输出。[当前首帧对照](../results/progressive-room/preview/first-preview-reference.png) |

后续阶段各自先冻结夹具、误差口径和设备能力，再动共享着色器。已有标定桌、真实 Panda 和材质绕拍分别覆盖计量、动态运动和表面外观。所有画质实验保存未压缩读回或其可复核的统计、相机与材质绑定、具名配置和成对示例。帧耗包括请求到同步读回，影片编码单列。只有达到快速档门槛的配置才登记为交互档。
