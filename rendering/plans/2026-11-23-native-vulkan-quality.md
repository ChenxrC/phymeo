# 自研 Vulkan 的四步画质路线

目标是在机器人操作中看清细夹指、表面纹理、附近物体的倒影和遮挡处的间接光。起点是已通过独立安装的版本 `49e529ba`。现有实时路径具有单采样光栅、直接 PBR、可选硬件阴影查询、HDR 环境及粗糙度贴图。SAPIEN 路径追踪继续作为同场景参考。[首版签收](09-acceptance.md) · [具名设备的能力与样片](../results/engine-capabilities.md)

| 顺序与难度 | 开发接口与依赖 | 固定对照与进入下一阶段的条件 |
| --- | --- | --- |
| 1. 轮廓抗锯齿与运动稳定性，高，已实现 4× 并实测 | 自研 resident 后端显式提供 1×、4× MSAA；材质、灯面采样与相机轨迹固定。 | 斜边和细杆对独立面积参考的误差下降，移动细杆的时间误差下降；深度、整数 ID、掩码与原路径逐字相同。交付同帧 Panda 开关对照视频。720p 快速档单独报告 p95，目标 33.3 ms。[实测与未达标项](../results/msaa/README.md) · [开发与验收任务单](2026-11-23-native-msaa.md) |
| 2. 材质微表面细节，中高 | 在已有 UV／纹理基础上加入切线空间法线贴图、切线手性与必要的资产导入。纹理使用线性数据，资产携带来源。 | 用具有平直、倾斜、镜像 UV 三块的标定板检查光照方向，另拍拉丝钢及橡胶。平坦法线图与原材质内部像素差 ≤1 RGB8；方向光左右互换时亮暗侧随解析法线翻转；三种几何通道逐字一致。交付同机位开关视频与显存、帧耗。[开发与验收任务单](2026-11-23-native-normal-maps.md) |
| 3. 附近物体的一次镜面反射，高 | 复用已验证的 BLAS/TLAS 与当前实例变换，扩展命中实例、三角形、重心及材质读取。一次命中着色，未命中读取原有环境。先支持不透明材质与光滑反射。 | 依次测平面镜中的已知色块、钢球旁移动的红块、画面外的反射物、遮挡和单世界 reset。平面镜反射边界对解析投影内部误差 ≤1 px（边缘单列）；命中颜色随物体身份与位置改变；未命中仍显示环境。粗糙反射、降噪各自登记是否验证。 |
| 4. 间接光，再评估自研路径追踪，高 | 先验证一次漫反射的能量传递，再扩展多次反弹、累积、场景修订失效和离线采样配置。以第三阶段的材质命中读取为基础。 | 用白夹爪＋红板、等反射率灰板和黑色遮光板成对拍摄，锁定直接光、曝光与机位。比较遮挡区线性 RGB、独立种子不确定度与 SAPIEN 同场高采样参考；确认红板引起可复现的染色、遮挡后响应下降。再用封闭测试室测多次反弹收敛，记录噪声、偏差、每帧秒数、显存和 reset 后旧影。 |

后续阶段各自先冻结夹具、误差口径和设备能力，再动共享着色器。已有标定桌、真实 Panda 和材质绕拍分别覆盖计量、动态运动和表面外观。所有画质实验保存未压缩读回或其可复核的统计、相机与材质绑定、具名配置和成对示例。帧耗包括请求到同步读回，影片编码单列。只有达到快速档门槛的配置才登记为交互档。
