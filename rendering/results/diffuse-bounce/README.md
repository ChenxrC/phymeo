# 红板照亮夹爪暗面

打开[夹爪同帧对照](index.html)。选「红板」和「敞开」，看右图中两根白指朝向板的一面。切换成等线性亮度的灰板，可以区分染色与单纯变亮。保留红板再选「加黑色遮光板」，可以看出挡住板到指爪的光路后还剩多少红色。选「整个摆台」查看灯照方向、板与夹爪的位置关系。

每一对图共用同一机位、直接照明、材质、曝光和 Panda 姿态。左边关闭一次漫反射，右边开启。夹爪使用 Panda 的手部和两指网格，以及统一的浅色粗糙涂层。这里的固定姿态便于在相同的手指表面比较像素。[四种摆台](overview.png) · [开发与验收条件](../../plans/2026-11-23-native-diffuse-bounce.md)

## 在自己的场景中启用

```python
from phymeo_rendering.backends.native import NativeBackend

backend = NativeBackend(
    library_path=library_path,
    shader_directory=shader_directory,
    device_index=device_index,
    resident=True,
    shadow_mode="ray_query",
    indirect_mode="diffuse_bounce",
    indirect_seed=0,
)
```

需要本批构建的原生库和着色器，以及支持 Vulkan 硬件射线查询的设备。默认的 `indirect_mode="none"` 保留原有照明。若场景还有符合现有光滑金属条件的表面，可同时指定 `reflection_mode="single_bounce"`。

相机看见白指后，着色器从该处按余弦分布发出 16 个方向的查询。射线打在红板上时，取命中位置的材质和光照；打在挡板上时，取挡板该处的光照。未命中时读取远场环境。平均入射光乘以指爪的漫反射系数，替代该位置原有的漫反射环境项。孔径较小或存在遮挡时，16 个样本的单帧结果会有颗粒。种子固定便于复现，重复相同的曝光不会积累更多样本。

## 有限色板传回了多少光

独立标定台用一块水平白面接收有限矩形板的反光。对同一组 32 × 32 接收像素，用板面积、两处法向和距离算出应有的传递系数，再与实际曝光比较。红板换成等亮度灰板可消去两者相同的高光项。黑挡板截断这些接收点到色板的光路。原生渲染器沿用其材质的菲涅耳项，SAPIEN 3.0.3 使用此配置下的朗伯材料，因此各用自己的独立预测值。[标定图](calibration.png) · [逐种子测量](calibration.json) · [完整原始读回](calibration.zip)

| 每像素样本数 | 预测系数 | 四种子实测均值 | 均值相对误差 | 像素归一化均方根误差 |
| --- | ---: | ---: | ---: | ---: |
| 自研 Vulkan，16 | 0.059337 | 0.059155 | −0.31% | 30.54% |
| SAPIEN 路径追踪，512 | 0.064571 | 0.065278 | +1.09% | 6.94% |

两端遮挡后的红灰差均为零。四种子平均值的描述性标准误分别为 0.000386 和 0.000130。原生结果由 RGB8 逆变换取得，计入半码量化范围后均值可落在 [0.05705, 0.06126]。参考端直接读取显示变换前的浮点辐亮度。这些数字说明区域平均传光量已接近预测，16 样本在单幅图上仍有明显噪声。两端样本率和材质律不同，本实验用于验证传光量。

## 在夹爪上能看见什么

灯只从一侧照来，场景没有环境填充光。看左图时，下方的红色是色板，板前方两块黑色轮廓是白指的背光面。右图指面上出现的暗红来自附近物体反光。换成灰板，这些指面收到灰色反光。黑色遮光板会同时挡住部分板到指爪的光，并在板上投影。[红板局部](red-roi-pair.png) · [灰板局部](grey-roi-pair.png) · [遮住红板后的局部](red-blocked-roi-pair.png)

用原网格、相机和可见三角形预先选定两指的 4,120 个像素，包括关闭档读数为零的暗部。先对同一块板计算开启减去关闭的 RGB，再比较红板与灰板，用 R − (G + B)/2 衡量净染红程度。数值取已发布的 RGB8，经逆 sRGB 得到显示线性值，包含 PBR Neutral 显示变换的影响。

| 手指实例 | 取样像素 | 敞开的净红度 | 遮住后的净红度 | 减弱幅度 |
| --- | ---: | ---: | ---: | ---: |
| 156 | 2,058 | 0.03727 | 0.00512 | 86.3% |
| 158 | 2,062 | 0.03767 | 0.00547 | 85.5% |

同一摆台开关前后，全幅深度、实例 ID 和有效掩码逐字节一致。独立射线计算与实际选区的最大深度差为 0.000811 mm。四种摆台每种开关各采 12 次，共 96 次公开四通道读回，同种子静态曝光可逐字节重放。[原始测量](summary.json) · [预注册和材质来源](protocol.json) · [两指选区](reference.npz) · [原图与几何完整清单](file-manifest.json)

## 成本与可复现范围

RTX 4060 Laptop GPU，1280 × 960，1× MSAA。下表给出请求到四通道同步读回的耗时，预热三次后计九次，p95 在这个样本量下等于最慢的一次。图像保存另计。

| 摆台 | 关闭 p50 / p95，ms | 开启 p50 / p95，ms |
| --- | ---: | ---: |
| 红板 | 26.47 / 27.16 | 47.48 / 49.65 |
| 灰板 | 28.65 / 31.23 | 51.44 / 69.44 |
| 红板加遮挡 | 26.10 / 26.91 | 52.39 / 61.07 |
| 灰板加遮挡 | 27.43 / 28.02 | 51.74 / 58.82 |

该分辨率开启间接光后，四种摆台均高于 33.3 ms 的交互目标。上下文显式分配的本地设备内存峰值为 23,879,616 字节。八个会话关闭时的设备和主机可见当前分配均归零。[采集与回收记录](handoff.json) · [八种查看器切换验证](viewer-check.json)

本批从源码构建 Vulkan DLL 与 40 个 SPIR-V。原有 22 个基础着色器的字节一致，6 个原有镜面变体通过新旧构建的输出对照，另有 12 个新变体。新功能支持一次漫反射及其与一次镜面同时启用。本批测量限定在整幅曝光。跨帧累积、降噪、多次漫反射和新版本的独立 wheel 验收留待后续。[原生构建与设备验证](native-build.json) · [集成源码与实验绑定](delivery.json)
