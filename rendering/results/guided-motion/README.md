# Panda 运动首帧的 GPU 降噪

打开[同帧运动对照](index.html)，用滑块让黑色薄板扫过夹爪。左图是原生渲染的 16 样本首帧，右图在同一批样本上启用 GPU 空间滤波。姿态 0、15、24 还提供独立种子累积到 256 样本的原图。先看两指的细小颗粒，再看板边经过指尖时有没有把黑色抹到后面的表面。[实验前确定的姿态、抽样与验收线](../../plans/2026-11-23-native-guided-motion.md)

“同姿态第二批”和“第四批”表示停下后继续采集到 32 或 64 样本。首批滤波仅改变显示颜色，这两个档位可直接观察切回原始累积后的细节。播放按姿态序列展示，采集速度见实测记录。

后续实验已经实测逐批降低滤波强度。[查看停稳后的五批曝光](../guided-settling/index.html)

## 在自己的场景中开启

```python
from phymeo_rendering.backends.native import NativeBackend

backend = NativeBackend(
    library_path=dll, shader_directory=shaders, device_index=gpu,
    resident=True, shadow_mode="ray_query", msaa_samples=1,
    indirect_mode="diffuse_bounce", progressive=True,
    spatial_filter="guided",
)
session = backend.open_scene(scene)
try:
    image = session.capture(frame, request)
finally:
    session.close()
```

每次因相机、模型位姿或有效灯光变化而清空累积，新状态的第一批用邻近像素重建显示颜色。25 个邻点按像素距离加权，只采纳当前视图中同一可见实例、深度接近且直接照明相近的像素。线性平均光能与 RGB 显示分开保存，调用 `read_linear_mean()` 仍获取原始浮点采样。对深度、实例 ID 和有效掩码直接使用几何传感接口。只需要原始采样时，保留默认 `spatial_filter="none"`。

运动中的参考只有三个注册姿态。误差取自公开的 RGB8 图，经逆 sRGB 转换为显示线性量，曝光与色调映射已生效。上一批 CPU 空间原型采用显示变换前的辐亮度计算误差；两次结果各自与同批参考比较。[上一批静止夹爪的线性实测](../progressive-room/README.md)

这 69 个右夹指像素单独计算，首批误差由 0.02077 降到 0.00915。这只是一个姿态的小区域；上表 57.4% 的分母是全部 48,191 个有效显露前景像素。

## 停稳后的变化

同一姿态停稳后，GPU 原始浮点均值继续累积。第 2、4 批的 RGB 在两种设置下完全相同，但切回未滤波显示会引起可见的质量跳变。两指对独立参考的误差从首批滤波的 **0.005295** 升到第 2 批的 **0.009552**，第 4 批降到 **0.007174**，仍高于首批滤波结果。后续应比较在同状态复用指引并随样本数减弱滤波强度，检查停稳后头几次曝光的画质与成本。[两种设置的全部批次](metrics.json) · [开发路线](../../plans/2026-11-23-native-vulkan-quality.md)

## 实现与耗时

首版尝试在原绘制中额外输出光照指引，实机发现开关会让少量原始浮点值相差一个最小刻度。交付版沿用原主着色器字节，在同一会话与命令缓冲内额外绘制一次直接光和环境项，使用同一相机、位姿、遮挡结构和灯光。额外绘制关闭传感通道写入，随后计算 25 邻点滤波。后续批次跳过指引绘制。真实设备验证中，开启与关闭的原始线性均值、深度、实例 ID 和有效掩码均逐字一致。GPU 的滤波显示与冻结的 CPU 规则在标定图上最大相差一个 RGB8 色阶。[Vulkan 构建、初版问题及设备验证](native-build.json)

| 后续 24 个运动姿态的首批 p50 | 63.00 ms | 65.80 ms |

计时从四通道采集请求到同步返回，包括导引绘制、阴影查询、滤波和常规读回。先运行整条关闭轨迹，再运行整条开启轨迹。两组 p95 相差 4.77 ms，不能由此分解出单个计算着色器的耗时。当前分辨率的两种模式都超过 33.3 ms。两秒运动按 12 Hz 编排，影片按此节奏播放。额外 171 次原始浮点读回、28 次指引读回及图片写盘分别计时。[完整采集收据](summary.json) · [固定的每帧相机与物体位姿](protocol.json)
